## Read Before Updating

Applicable products
This update applies to products running StationOS Pro. Before upgrading, confirm the processor architecture for your product model.

● DA Series: DA400 Series

Update reminders
1. To use the features described in this article, upgrade the system firmware, app suites, or clients to the corresponding version or later.
2. Some new features in app suites require a specific system firmware version. If the system firmware is below the minimum compatible version, you may not receive app update notifications or be able to use the related features.

## StationOS Pro System Firmware

### Version Information

System firmware version: v0.32.2.11

This update involves interface adjustments. To ensure everything works properly, it is recommended to upgrade the firmware, clients, and related apps to the latest versions.

### Storage Management
- Fixed: abnormal storage space after an SSD cache drive was unplugged
- Fixed: storage anomalies after restarting during RAID5 sync, and abnormal NVMe storage space after reset
- Fixed: drive health status display inconsistent with S.M.A.R.T

### External Storage
- New: unified naming for external devices, shown consistently across modules for easy identification
- New: display of insertion time, read-only status, and unmounted status
- Fixed: unmount failure for unmounted USB devices, list not refreshing after formatting, inaccurate partition capacity display
- Fixed: false "insufficient capacity" warning for large file uploads, and double-clicking a folder jumping back to the top of the list

### File Management
- Fixed: abnormal progress when resuming a paused task, inconsistent task count display
- Fixed: album thumbnails not displayed after renaming a folder

### Video Codec
- New: video info now shows audio track specs, HDR, frame rate, etc., with adaptive audio transcoding parameters
- Improved: transcoding cache now stored on the storage volume to avoid filling up system storage
- Fixed: transcoding failure hanging forever; it now clearly reports the failure

### Docker
- New: pre-checks before changing storage space, confirmation before overwriting old data, and migration progress display
- Fixed: state loss after closing the migration dialog, service stopping automatically
- Fixed: duplicate registry requests and stacked error messages

### App Center
- New: MD5 verification of installation packages for more reliable installation
- New: multi-device sync of app enabled/disabled status
- Improved: lifecycle management of Compose apps
- Fixed: false warnings for community apps during remote access, abnormal install/disable prompts

### AI Assistant
- Fixed: local model failing to load after reset, CLIP index query infinite loop
- Improved: low index space warnings and migration guidance

### Backup
- Fixed: loss of photo capture time, abnormal peripheral list refresh

### Resource Monitoring
- Fixed: unified monitoring data metrics, abnormal display at the left edge of line charts

## Clients

### iOS & Android Client

App version: v0.32.0

#### New Features

- Added Docker container storage migration with migration status tracking, confirmation flow, and automatic refresh of configuration and storage lists after migration
- Added task progress display for album smart classification and similar photo detection, including staged progress, status animations, and icons

#### Experience Improvements

- IP login supports automatic default port redirection (HTTP 80 / HTTPS 443) so you can sign in without specifying a port
- App Center syncs the "Enabled / Disabled" status of apps in real time, reducing flicker and misjudgment during operations
- External drive details page now shows file system, vendor, and serial number, plus a compatibility hint when unmounted
- Improved SSD cache page layout and empty-state display when no SSD is available
- Added a second confirmation when the manually set time deviates too far from standard time to prevent mistakes
- Unified input field and popup styles in Settings; fixed display issue with the remote mount password field
- Added monotonic protection to album backup progress to prevent the percentage going backwards
- Log reporting now includes the current NAS device serial number, name, model, and firmware version
- Unified header icon button specs on non-home pages and enlarged tap targets

#### Bug Fixes

- Fixed popups on iPad being accidentally dismissed by pointer events; popups on large screens now span full width
- Fixed untranslated device connection failure messages and completed translations in six languages
- Fixed an exception where the SSD cache details page accessed deallocated objects
- Fixed popup dismissal logic when smart classification tasks end
- Corrected the factory reset confirmation message
- Release builds uploaded to the backend now default to "Unpublished" to prevent going live before review approval
- Unified the display names of external storage paths
