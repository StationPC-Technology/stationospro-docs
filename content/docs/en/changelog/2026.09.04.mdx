## Read Before Updating

Applicable products
This update applies to products running StationOS Pro. Before upgrading, confirm the processor architecture for your product model.

● DA Series: DA400 Series

Update reminders
1. To use the features described in this article, upgrade the system firmware, app suites, or clients to the corresponding version or later.
2. Some new features in app suites require a specific system firmware version. If the system firmware is below the minimum compatible version, you may not receive app update notifications or be able to use the related features.

## StationOS Pro System Firmware

### Version Information

System firmware version: v0.33.0.8

This update involves interface adjustments. To ensure everything works properly, it is recommended to upgrade the firmware, clients, and related apps to the latest versions.

### System
- Added AI accelerator card monitoring and desktop widgets.
- Improved AI accelerator card thermal control, fan anti-oscillation, and dynamic monitoring data collection.
- Improved process CPU monitoring metrics for better accuracy.
- The SSH enabled state is now preserved across reboots, and device model suffix display is refined.
- Fixed occasional shutdown failures and the system update refresh banner not showing.
- Hid the Beta update entry and added an entry to the update details documentation.

### Storage
- Mounting is now supported during RAID sync, improving storage space availability.
- Added event notifications and progress dialogs for storage space creation stages.
- Decoupled storage pool status from storage space status and streamlined the creation flow.
- Added error classification for unknown file systems and improved external storage mount error messages.
- Reports the cause of external storage mount failures for finer-grained error distinction.
- Fixed degraded array misjudgment and abnormal external storage mount status.

### Files
- Added pre-checks for folder uploads and streamlined the upload flow.
- Improved large-batch file uploads, upload progress sync, and task scheduling.
- Fixed file name sorting, duplicate file detection, and the EXIF jump icon in preview.
- Improved pagination of external storage file lists, image thumbnail loading, and upload thumbnail display.
- Unified table headers and status bar display in File Manager for more consistent list interactions.

### Backup
- Improved album backup thumbnail handling.
- Supports one-tap backup launch after hot-plugging an external drive.
- Tightened one-tap backup button trigger logic to reduce accidental triggers.
- Fixed retry failures of the one-tap drive-insert backup launch.

### App Store / Docker
- Supports configuring host mount paths for data volumes and expanded configurable app access paths.
- Fixed desktop app status not syncing after reboot.
- Improved Compose deployment terminal logs and real-time log display.
- Fixed Docker search box layout, overly long network names being covered, and storage migration progress.
- Added circular progress bars and badge hints for app install/download status.

### AI / Station AI
- Improved local model loading, download progress, on-demand loading, and idle unloading.
- Adjusted on-device AI routing and vector models to reduce memory usage and improve hit accuracy.
- Fixed network query routing, missing numeric parameters, summary output, and false service-availability warnings.
- Improved multilingual positive examples, skill declarations, and safety policies.

### Notifications / Devices
- Passes through peripheral notification action types and plug/unplug event types.
- Reduced system log noise and suppressed some debug output.
- Fixed network error prompts after shutting down from Resource Manager and storage space creation debug logs.

## Clients

### iOS & Android Client

App version: v0.33.0

- Added AI accelerator card monitoring with a home-screen widget, plus model, utilization, memory, temperature, and running status in Resource Monitoring.
- Independently control the visibility of the AI accelerator card widget, with improved real-time data updates and abnormal status hints.
- Improved memory, disk, and device health displays in Resource Monitoring with clearer explanations of issues.
- Improved SSD cache damage and degraded status displays, with fault details and repair guidance.
- Improved external storage capacity display and storage space detection to reduce misjudgments from delayed data refresh.
- Improved one-tap backup task, source device, partition info, backup status, and file count displays, clarifying SD card vs. USB backup priority.
- Improved album backup progress, speed, and list refresh after waking the screen, making backup more visible.
- Improved album sync scanning and similar photo index progress display, reducing duplicate checks and inaccurate statistics.
- Added real-time file thumbnail updates and improved image zoom after loading originals.
- Improved HTTPS connections, redirects, foreground/background recovery, and WebSocket reconnection for more stable device connections.
- Improved app update dialogs, update badges, OTA, and system reset progress prompts, reducing duplicate reminders and improving multilingual display.
- Improved new-device setup guidance, AI assistant storage space hints, two-factor authentication, avatar changes, and App Store screenshot display.
