## System Firmware v2.24.0.9
1. Added USB Drive Mode, supporting the activation of cooling fan and screen‑off protection functions.
2. Added display of MAC addresses for wired/wireless network cards.
3. Added mutual backup operations between the main hard drive, Dock, SD card, and USB devices in the Backup Center.
4. Added functions to reset data index and regenerate thumbnails in the File module.
5. Added file filtering function for directory configuration in the Cinema Media Library.
6. Added read‑write permission support for shared directories in internal file sharing.
7. Optimized the log upload process on the small screen.
8. Fixed other known issues.

## APP/PC v1.5.0
1. Added file path filtering and size filtering in the Backup Center, supporting free selection of backup sources between the main drive and external devices.
2. Added view‑only and editable permissions when sharing folders.
3. Added file size and video duration filtering in the Media Library settings.
4. Added display of network MAC address in Device Settings.
5. Added unbinding of remote access in Device Settings.
6. Added File Index module, supporting index reset and thumbnail regeneration.
7. Optimized file naming rules.
8. Optimized the log upload process for feedback submissions.
9. Fixed other known issues.
