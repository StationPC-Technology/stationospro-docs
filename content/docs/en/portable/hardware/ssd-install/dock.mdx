---

You can install one M.2 NVMe 2280 SSD on your device.

## Operation Steps

1. Ensure the Dock is disconnected from the power source. 

2. Using the screwdriver loosen the screws and remove the bottom panel.

![](/images/common/portable/hardware/ssd-install/dock/dock-ssd-install_1.png)

3. Insert the SSD into the slot and tighten the screw.

![](/images/common/portable/hardware/ssd-install/dock/dock-ssd-install_2.png)

4. Install the bottom panel back and tighten the screws.

![](/images/common/portable/hardware/ssd-install/dock/dock-ssd-install_3.png)
