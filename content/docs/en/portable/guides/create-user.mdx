title: "How to Create New User?"
---

You can create multiple user accounts on PocketCloud, making it easy for multiple people to use the device.

> **Notes**:  
> - Different users have independent storage spaces and cannot directly access each other’s data.  
> - User can access each other’s data via local sharing.  
> - Admin cannot view other users’ data.  
> - Users have access to the Cinema feature. 

1. Open the app, log in with an admin account, navigate to the **Devices** page, then go to **User Management > Users**, and click the "+" button to add a new user.
