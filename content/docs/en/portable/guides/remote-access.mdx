title: "How to Remotely Access PocketCloud?"
---

PocketCloud has a built-in remote access service, which provides you with secure remote access capabilities. Before using this service, you need to bind your mobile number/email and create a unique Station ID (used to identify your device). You can then quickly access your PocketCloud via this Station ID.

> **Note**:  
> * Using the remote access service requires binding a mobile number/email.  
> * The service will automatically create a unique Station ID for your PocketCloud, and you can securely access the device via this ID.  
> * Based on the current network environment, the system will automatically select the optimal access method for connection.  
> * The Station ID supports custom modification.  

## Enable Remote Service  

### Method 1:  
During the device’s initial setup, follow the prompts to check the **Enable Remote Access** option.

<img src="/images/common/portable/guides/remote-access/setupwized-remote_access-2.jpg" width="30%" />

### Method 2:  
1. Open the app and navigate to the **Devices** page. 
2. Find **Device Connection**; you can manually enable or disable the remote service here.

## Unbind Remote Service  

When you restore the device to factory settings, the system will automatically unbind the remote service.  

> If the device is already bound to remote service, restoring it to factory settings requires an internet connection.
