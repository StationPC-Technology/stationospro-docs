## Introduction
Beta versions are pre-release versions made available to beta testers before the official launch. They allow users to preview new features of system firmware and client software that have not yet been publicly released. Meanwhile, they help collect user feedback, identify potential issues, and support the optimization and improvement of the official version.

## iOS Client Beta Update Steps
### 1. Install TestFlight
Open the link to [TestFlight](https://testflight.apple.com/join/kH1Fmjby), then tap **View in App Store** to download or update TestFlight.

<img src="/images/common/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-2.png" width="30%" />

### 2. Go to the PocketCloud Beta Page in TestFlight
Open the link again: [TestFlight](https://testflight.apple.com/join/kH1Fmjby), then tap **View in TestFlight** to enter the app.

<img src="/images/common/portable/guides/beta-version-update/2-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3. Install the Beta Version
When the beta version appears, tap **Accept** to install the latest beta build.

## Android Client Beta Update Steps
If you installed the Android client from the official website, no extra steps are required. You will receive an in-app update notification when a new beta version is available.
If you installed it from Google Play, please follow the steps below.

### 1. Open the Google Play Beta Testing Page
Open the link to [Google Play](https://play.google.com/apps/testing/com.stationpc.nas), then tap **Become a tester** to join the program.

<img src="/images/common/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-2.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-3.png" width="30%" />

### 2. Install the Beta Version
You must uninstall the official version first before installing the beta version.

<img src="/images/common/portable/guides/beta-version-update/2-1.jpg" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3. Leave the Beta Program
If you want to reinstall the official version, open the link to [Google Play](https://play.google.com/apps/testing/com.stationpc.nas) and tap **Leave** to exit the testing program.

<img src="/images/common/portable/guides/beta-version-update/3-1.jpg" width="30%" />
