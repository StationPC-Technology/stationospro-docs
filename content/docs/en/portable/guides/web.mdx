title: "How to Access Your Device via the Web Client?"
---

The Web Client (Beta) allows you to access and manage your device directly through a browser, without installing the desktop or mobile app. It supports two access modes: **local LAN access** and **remote access**, to meet usage needs in different scenarios.

## Prerequisites
1. Ensure your device is powered on and connected to the network properly.
2. For remote access, please first [enable the remote access feature](/portable/pocketcloud/remote-access) in the client app and complete your Station ID setup.

## Access Methods
### Method 1: LAN Access
Suitable for scenarios where your computer and the device are on the same local area network (same WiFi / wired network), offering faster access speed and higher stability.

Steps:
1. Find the local IP address of your device: you can check it via the device's built-in display, or on the **Device Info** page in the client app.
2. Open your browser and enter the address in the format of `http://Device IP:9500` in the address bar.
3. Enter your username and password on the login page to enter the web management interface.

> Example: If the device IP is `192.168.3.10`, enter `http://192.168.3.10:9500` in the address bar.

### Method 2: Remote Access
Suitable for external network scenarios such as traveling or working off-site. You can access your device at home or in the office through the official remote portal.

Steps:
1. Enable the remote access feature.
2. Open your browser and enter the official remote access address: `https://login.stationpc.com/`
3. Enter your Station ID, username and password on the login page. After verification, you can access your device.

## Supported Browsers
To ensure full functionality and the best user experience, we recommend using the following browsers (or newer versions) to access the Web Client:
1. Chrome version 50 and above
2. Microsoft Edge version 78 and above
3. QQ Browser Speed Edition, 360 Browser Speed Edition
4. Firefox version 54 and above
5. Safari version 10 and above (Mac)

## Notes
1. The Web Client is currently in Beta testing. Some features may not be available yet. It is recommended to use it with the client app for full functionality.
2. For LAN access, make sure your computer and the device are connected to the same network, otherwise you cannot access via the IP address.
3. For remote access, make sure the device is connected to the Internet, otherwise it cannot be connected via the remote portal.
4. If the page loads abnormally, please switch to a recommended browser, or clear your browser cache and try again.
