## 1. Install TestFlight
Open the link to [TestFlight](https://testflight.apple.com/join/kH1Fmjby), then tap **View in App Store** to download or update TestFlight.

<img src="/images/common/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-2.png" width="30%" />

## 2. Go to the PocketCloud Beta Page in TestFlight
Open the link again: [TestFlight](https://testflight.apple.com/join/kH1Fmjby), then tap **View in TestFlight** to enter the app.

<img src="/images/common/portable/guides/beta-version-update/2-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/2-2.jpg" width="30%" />

## 3. Install the Beta Version
When the beta version appears, tap **Accept** to install the latest beta build.

<img src="/images/common/portable/guides/beta-version-update/3-1.jpg" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/3-2.jpg" width="30%" />
