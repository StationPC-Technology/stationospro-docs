This article will explain how to install the "PocketNAS" app on various platforms.

## Mobile
<Tabs items={["iOS","Android"]}>

<Tab>

1. Open the App Store, search for "PocketNAS";
2. Download and follow the prompts to complete the installation of the PocketNAS app.

\* Only supports iOS 12 and later versions.

</Tab>

<Tab>

* Method 1:
1. Open the Google Play Store, search for "PocketNAS";
2. Download and follow the prompts to complete the installation of the PocketNAS app.

* Method 2:
1. Visit the StationPC official website and download [the Android client installation package](https://www.stationpc.com/pages/download);
2. After the download is complete, run the installation package and follow the prompts to install the Android client.

\* Only supports Android 10 and later versions.

</Tab>

</Tabs>

## Desktop
<Tabs items={["MacOS","Windows"]}>

<Tab>

1. Visit the StationPC official website, select the corresponding platform based on your device's chip type (X86 or M-series chip), and download [the macOS client installation package](https://www.stationpc.com/pages/download);
2. After the download is complete, run the installation package and follow the prompts to install the macOS client.

\* Only supports macOS 14.0 and later versions.

</Tab>

<Tab>

1. Visit the StationPC official website and download [the Windows client installation package](https://www.stationpc.com/pages/download);
2. After the download is complete, run the installation package and follow the prompts to install the Windows client.

\* Only supports Windows 10 and later versions.

</Tab>

</Tabs>

## TV
<Tabs items={["AppleTV","AndroidTV"]}>

<Tab>

* Method 1:
1. Open the App Store, search for "StationCloudTV";
2. Download and follow the prompts to complete the installation of the StationCloudTV app.

* Method 2:
1. Visit the StationPC official website and download [the TV client installation package](https://www.stationpc.com/pages/download);
2. Transfer the installation package file to a USB flash drive;
3. Insert the USB flash drive with the installation package file into the TV device, then install the TV client on the device.

</Tab>

<Tab>

* Method 1:
1. Open the Google Play Store, search for "StationCloudTV";
2. Download and follow the prompts to complete the installation of the StationCloudTV app.

* Method 2:
1. Visit the StationPC official website and download [the TV client installation package](https://www.stationpc.com/pages/download);
2. Transfer the installation package file to a USB flash drive;
3. Insert the USB flash drive with the installation package file into the TV device, then install the TV client on the device.

\* Only supports Android TV 6.0 and later versions.

</Tab>

</Tabs>
