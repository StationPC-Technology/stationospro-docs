PocketCloud features a built-in "Cinema" function, which supports the convenient setup of a video server and enables efficient management of personal video resources.

## How to Create a Media Library?

1. Add a New Media Library  
* Method 1: In the initial state, tap **Create Media Library**;  
* Method 2: Go to **Settings > Media Library Management**, then tap **Add Media Library** in the top-right corner.  

<img src="/images/common/portable/cinema/create-cinema/1-1.jpg" width="30%" />
<img src="/images/common/portable/cinema/create-cinema/1-2.jpg" width="30%" />
<img src="/images/common/portable/cinema/create-cinema/1-3.jpg" width="30%" />

2. **Set Basic Media Library Info and Add Media Folders**  
* Media Data Language: Optional (Chinese/English);  
* Info Source: Optional ("Official Smart Recognition" or "TMDB"). A TMDB API key is required to use TMDB. 

<img src="/images/common/portable/cinema/create-cinema/2-1.jpg" width="30%" />
<img src="/images/common/portable/cinema/create-cinema/2-2.jpg" width="30%" />

3. **Auto-scan and Metadata Scraping After Successful Creation**  
Once the media library is created, the system will automatically start scanning files in the library. The first scan includes file recognition and metadata scraping, which takes some time. You can tap the top-right corner to check the scraping progress.  

<img src="/images/common/portable/cinema/create-cinema/3-1.jpg" width="30%" />

## How to Share a Media Library?
You can share a specific media library with other local users by following these steps:  
1. Go to **Settings > Users**;  
2. Select the target user you want to share with;  
3. Check the media library(s) you wish to share.
