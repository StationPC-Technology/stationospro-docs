## 内置存储支持的文件系统格式

内置存储主要支持 exFAT、NTFS 与 FAT32，官方推荐使用 exFAT。

exFAT、NTFS 与 FAT32 文件系统对比：

| 特点          | exFAT（推荐）                          | NTFS                  | FAT32                   |
| :------------ | :------------------------------------- | :------------------------------------ | :------------------------------------ |
| **最大文件**  | **支持超大文件** | **支持超大文件** | **单个文件不能超过4GB** |
| **最大分区**  | **支持超大分区** | **支持超大分区**     | **最大只能2TB**      |
| **系统兼容性** | **Windows、Mac、Linux 均支持**     | **Mac 只能读** | **Windows、Mac、Linux 均支持**                       |
| **安全性**    | **一般**               | **高**        | **低**                |
| **稳定性**    | **较好**             | **最好**              | **较差**               |
| **速度**      | **快**         | **快**            | **慢**         |
