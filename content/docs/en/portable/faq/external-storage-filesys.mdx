title: "What file systems are supported by external storage? What are the differences vs. internal hard drives?"
---

External storage supports file systems including FAT32, exFAT, and NTFS; we will also evaluate adding support for more file systems in the future. 
 
Compared with internal hard drives, the main differences are in two aspects:  
* File system support : Internal M.2 SSD only supports the exFAT format, while external storage supports more types of file systems, offering more flexible compatibility;  
* Feature support: Internal M.2 SSD supports all features. External storage currently only supports backup, file operations, downloads, and video playback, and does not yet support features such as photo albums, SMB sharing, and WebDAV sharing.
