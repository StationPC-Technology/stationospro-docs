title: "Difference between actual and theoretical file Read/Write speeds?"
---

Actual read/write speeds are affected by multiple factors, including the transmission efficiency of the data bus, system resource overhead, and the load of other processes running on the device simultaneously. Additionally, during file backup, the device synchronously performs data verification to ensure integrity, which may also result in differences between the actual transmission rate and the theoretical maximum.
