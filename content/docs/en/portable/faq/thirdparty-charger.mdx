title: "Does PocketCloud support third-Party chargers?"
---

PocketCloud supports third-party chargers, but they must meet the following requirements:
* Must be compatible with the PD charging protocol;
* Power requirements: When using the host alone, the charger power must be ≥20W; when using the host and dock together, the charger power must be ≥30W.
