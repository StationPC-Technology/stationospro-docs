title: "How to Create a Cloud Drive Backup?"
---

PocketCloud supports **two-way cloud drive data backup**, with core features including:  
- Back up files from PocketCloud's internal storage to a cloud drive  
- Download files from a cloud drive to PocketCloud's internal storage  

Currently supported cloud services: Google Drive, Dropbox, OneDrive.  

> Note: 
> The features for backing up the Dock and external storage to cloud drives are under development.

## 1. Backup from PocketCloud to Cloud Drive  
1. Open the app and go to **Home > Common Features > Backup Center**.  
2. Tap the **Add** button in the upper right corner, select **From PocketCloud to another**, and create an upload task.  
<img src="/images/common/portable/backup/create-cloud-backup/1-1.jpg" width="30%" />
<img src="/images/common/portable/backup/create-cloud-backup/1-2.jpg" width="30%" />

3. Configure the backup source and destination:  
   - Backup Source: Tap **Add file path** and select the folder you want to upload.  
      <img src="/images/common/portable/backup/create-cloud-backup/1-3.jpg" width="30%" />
      <img src="/images/common/portable/backup/create-cloud-backup/1-4.jpg" width="30%" />
      <img src="/images/common/portable/backup/create-cloud-backup/1-5.jpg" width="30%" />
   - Backup Destination: Tap **Go to add destination** and select the target cloud drive.  
      <img src="/images/common/portable/backup/create-cloud-backup/1-6.jpg" width="30%" />
      <img src="/images/common/portable/backup/create-cloud-backup/1-7.jpg" width="30%" />
      <img src="/images/common/portable/backup/create-cloud-backup/1-8.jpg" width="30%" />

4. Set backup parameters (configure as needed):  
   - Backup Mode: Manual Backup, Scheduled Backup
   - File Filtering: Optional. You can choose to filter large files or small files.   
   <img src="/images/common/portable/backup/create-cloud-backup/1-9.jpg" width="30%" />

5. Customize the task name, then confirm and create the task.  
<img src="/images/common/portable/backup/create-cloud-backup/1-10.jpg" width="30%" />
<img src="/images/common/portable/backup/create-cloud-backup/1-11.jpg" width="30%" />

6. Tap the **Backup** button to start the backup process.    
<img src="/images/common/portable/backup/create-cloud-backup/1-12.jpg" width="30%" />

## 2. Backup from Cloud Drive to PocketCloud
1. Open the app and go to **Home > Common Features > Backup Center**.  
2. Tap the **Add** button in the upper right corner, select **From another to PocketCloud**, and create a download task.  
3. For subsequent configuration steps (including backup source/destination setup, parameter settings, and task creation), refer to Steps 3–6 in "Backup from PocketCloud to Cloud Drive".    
<img src="/images/common/portable/backup/create-cloud-backup/1-1.jpg" width="30%" />
<img src="/images/common/portable/backup/create-cloud-backup/2-1.jpg" width="30%" />

## 3. Disable/Delete a Backup Task  
1. Open the app and go to **Home > Common Features > Backup Center**.  
2. Select the backup task you want to operate on from the task list.  
3. Tap the menu in the upper right corner, then select **Disable** or **Delete** to complete the operation.
