## 1. Check Network Status on the Small Screen
Small screen: Device Settings -> Device Info -> Check device network status

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/1-2.jpg" width="80%" />

## 2. Direct Connection
### 2.1 Check on the Small Screen
2.1.1 Rotate/scroll to AP mode  
2.1.2 View IP, name, and password

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/2-1.jpg" width="80%" />

### 2.2 Operate in the App
#### 2.2.1 Connect via system Wi-Fi on the phone
Based on the AP mode name (Wi-Fi name) and password, connect in the system Wi-Fi list

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/2-2-1.jpg" width="80%" />

#### 2.2.2 Enter the direct connection IP to log in
When logging in, use the IP from AP mode along with the corresponding account and password

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/2-2-2.jpg" width="80%" />

## 3. Not Connected
### 3.1 Check on the Small Screen
Device Settings -> Device Info  
Scroll to view the name

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/3-1.jpg" width="80%" />

### 3.2 Operate in the App
#### 3.2.1 Connect via device network configuration
Based on the device name in device info, find the corresponding name in the device list and click to connect

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/3-2-1-1.jpg" width="40%" />
<img src="/images/common/portable/troubleshooting/app-client-connect-issue/3-2-1-2.jpg" width="40%" />

#### 3.2.2 Enter the configured network IP to log in
After successful configuration, return to the login page  
Use the auto-filled IP or the device info IP on the small screen, along with the corresponding account and password to log in

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/3-2-2-1.jpg" width="80%" />
<img src="/images/common/portable/troubleshooting/app-client-connect-issue/3-2-2-2.jpg" width="80%" />

## 4. Already Connected to Network
### 4.1 IP Login
Ensure the phone and device are on the same network  
Use the device info IP from the small screen, and enter the corresponding account and password to log in  
Same as step 3.2.2

### 4.2 StationID Login
Use the StationID information set during activation, usually a phone number or email  
Enter the StationID and password on the login page to log in

<img src="/images/common/portable/troubleshooting/app-client-connect-issue/4-2-1.jpg" width="40%" />
<img src="/images/common/portable/troubleshooting/app-client-connect-issue/4-2-2.jpg" width="40%" />

#### 4.2.1 Note
Check that there are no spaces before or after the StationID, and ensure it matches the one used when enabling remote login

## 5. Still Unable to Connect
On the device connection failure page, go to Feedback and upload logs
