App Center is the StationOS Pro app store. It provides one-stop installation, updates, and management for both official and third-party apps. Just like a mobile app store, you can extend your NAS with downloads, media, sync, productivity, and developer tools.

## Interface Overview

The top of App Center provides the following navigation:

- **All Applications**: browse every app available in the store;
- **Installed**: view and manage apps installed on this device;
- **Categories**: filter apps quickly by Sync, Movie, Video Record, Download, Productivity, and Dev Tools;
- **Search box**: find an app instantly by name.

The app list is divided into an "Official Apps" section and a third-party section. Each app card shows the name, a brief description or category tag, and an install button.

![App Center](/images/common/app-guide/app-center-img/all-apps.png)

## Installing an App

1. Find the target app via categories or the search box.
2. Click the app card to open its detail page.
3. Confirm the app information, then click **Install**. The system downloads and installs the app automatically.
4. Once installed, the app appears in the app launcher; if "Automatically create desktop shortcuts" is enabled, a desktop shortcut is created as well.

## App Detail Page

The detail page shows the following information to help you evaluate an app:

| Field | Description |
| --- | --- |
| Developer | The developer or team behind the app |
| Publisher | The publisher of the app |
| Downloads | Cumulative download count |
| Size | Size of the installation package |
| Current Version | Latest version available in the store |
| App Introduction | Feature highlights and usage notes |

![App Detail](/images/common/app-guide/app-center-img/app-detail.png)

## App Center Settings

Click the **Settings** button in the upper-right corner of App Center to configure:

- **Default Storage Location**:
  - **Ask every time**: choose a storage location manually each time you install;
  - **Fixed storage location**: always install new apps into the specified storage space.
- **Automatically create desktop shortcuts**: when enabled, a desktop shortcut is created automatically after each new app is installed.

![App Center Settings](/images/common/app-guide/app-center-img/settings.png)

<Callout title="Caution" type="warn">
  - Make sure the selected storage space has enough free capacity before installing, otherwise the installation may fail.
  - Some third-party apps are provided by external developers. Confirm the source and required permissions before installing.
  - In some cases the app installation location cannot be changed. To migrate an app, uninstall it first and then reinstall it.
</Callout>
