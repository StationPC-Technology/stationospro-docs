StationOS Pro is the operating system that powers StationNAS devices. It delivers a complete, app-centered management experience covering data storage, file sharing, backup and disaster recovery, containerized applications, and AI services. This chapter walks through each built-in app and shows you how to get the most out of your device.

## Desktop Overview

After signing in, you land on the desktop. It consists of a top status bar, the desktop area, and a bottom dock:

- **Top status bar**: the left side provides the "Back to Desktop" and "App Launcher" buttons; the center shows live resource information such as CPU, RAM, and network speeds; the right side offers the notification center and personal settings.
- **Dock**: pinned apps sit in the dock. Click an icon to open the corresponding app window.
- **Window management**: the upper-right corner of each app window provides minimize, maximize/restore, and close buttons, so you can arrange windows just like on a traditional desktop.

![Desktop](/images/common/app-guide/overview-img/desktop.png)

## App Launcher

Click the launcher button on the left side of the top status bar to open the app launcher. The launcher lets you:

- Quickly find apps by name using the search box at the top;
- Browse every built-in app and launch one with a single click.

![App Launcher](/images/common/app-guide/overview-img/app-launcher.png)

## Built-in Apps

| App | Description |
| --- | --- |
| Files | Manage personal and team files with upload/download, link sharing, recycle bin, duplicate cleanup, and SMB/WebDAV/FTP/NFS file services |
| Backup | Local backup, remote backup, and one-touch backup from NAS, external storage, cloud drives, and file protocols |
| Docker | Full container platform for managing containers, Compose projects, images, and networks |
| Log Center | Review system logs with keyword search and multi-condition filtering |
| Monitor | Real-time monitoring of CPU, memory, network, NPU, and disks, plus service and process management |
| Settings | Manage device info, users, storage, network, remote access, hardware and power, security, and system updates |
| App Center | One-stop app store for installing, updating, and managing official and third-party apps |
| Station AI | Built-in AI assistant with chat, knowledge base retrieval, document translation, and summarization |
| Help Center | Open this documentation site for installation guides, app tutorials, and FAQs |

<Callout title="Note" type="info">
  Available features and apps may vary depending on your device model, firmware version, and installed applications. Your actual interface prevails.
</Callout>
