Files is the core app of StationOS Pro for managing everything stored on your device. In the browser you can upload and download files, manage folders, share with permissions, restore from the recycle bin, and clean up duplicates. You can also configure SMB, WebDAV, FTP, and NFS file services so computers and phones can access NAS files directly.

## Interface Overview

The top of Files is organized into the following tabs:

| Tab | Description |
| --- | --- |
| My Files | The current user's personal file space |
| Team Files | Shared team space for multi-user collaboration |
| External Storage | Manage files on USB drives and other external devices |
| Remote Mount | Mount shared folders from remote NAS devices or servers |
| App Files | Browse data files generated by apps |
| My Favorites | Quick access to favorited files and folders |
| External Share Links | Manage external share links you have created |
| Recycle Bin | Restore or permanently delete removed files |
| Duplicate Files | Scan and clean duplicate files to free up space |
| Admin Perspective | Admins can browse all users' files (admin only) |

The file list supports list/grid view switching and shows file name, size, type, modified time, storage location, creation time, and owner. Click a column header to sort.

![My Files](/images/common/app-guide/files-img/my-files.png)

## Basic File Operations

The toolbar provides common actions:

- **Upload**: upload files or entire folders;
- **New Folder**: create a new directory;
- **Sort**: sort by name, size, time, and more;
- **View switch**: toggle between list view and grid view.

### Creating a Folder

1. Navigate to the target directory and click **New Folder** in the toolbar.
2. Enter the folder name (up to 180 characters).
3. Choose the storage location for the folder (for example, Storage Space 1).
4. Click **Confirm** to finish.

![New Folder](/images/common/app-guide/files-img/new-folder.png)

### Context Menu

Right-click a file or folder to access these actions:

| Menu item | Description |
| --- | --- |
| Open in New Window | Open in a new window (folders) |
| Download | Download to your computer |
| Copy To / Move To | Copy or move to another directory |
| Cut / Copy | Cut or copy |
| Delete | Delete (moved to Recycle Bin) |
| Rename | Rename |
| Favorite | Add to favorites |
| Share External Link | Create an external share link |
| Details | View file details |

![Context Menu](/images/common/app-guide/files-img/context-menu.png)

## Sharing via Link

External link sharing lets you share files or folders with users who do not have a NAS account:

1. Right-click the target file or folder and choose **Share External Link**.
2. Configure the sharing options:
   - **Share Name**: the display name of the link;
   - **Expiration Time**: permanent validity or a custom end time;
   - **Allow Download**: whether visitors can download the file;
   - **Password Protection**: require a password to open the link;
   - **Access Count Limit**: cap the number of times the link can be visited.
3. Click **Create Link** to generate the share link.

Created links are managed centrally in the "External Share Links" tab, where you can view links, change rules, or stop sharing.

![Share Link](/images/common/app-guide/files-img/share-link.png)

<Callout title="Security tip" type="warn">
  When sharing sensitive files, enable password protection and set an expiration time. Close links you no longer need to avoid data exposure.
</Callout>

## File Service Settings

Click **Settings** in the upper-right corner of Files to configure file services. The settings window contains these tabs:

- **File Sharing Protocol**: configure SMB, WebDAV, FTP, and NFS separately;
- **File Rules**: configure file naming and other rules;
- **Remote Mount**: configure remote mount parameters;
- **External Share**: configure global rules for external sharing.

Taking SMB as an example, the settings page provides:

- **Visible Folder Scope**: control how My Files, Team Files, and App Files are exposed over the protocol;
- **Connection Method**: illustrated guides and addresses for connecting from Windows and macOS;
- **Other connection info**: shows the device IP addresses and the default port (445 for SMB) with one-click copy.

![File Settings](/images/common/app-guide/files-img/settings.png)

### Accessing NAS Files from a Computer

- **macOS**: Open Finder → Go → Connect to Server, enter `smb://DEVICE_IP`, then sign in with your NAS local account and password.
- **Windows**: Press `Win + R`, enter `\\DEVICE_IP`, then sign in with your NAS local account and password.

## Recycle Bin

Deleted files are moved to the recycle bin to protect against accidental deletion:

- **Restore**: restore files to their original location;
- **Permanently Delete**: remove the selected files permanently — this cannot be undone;
- **Empty the Recycle Bin**: clear all files in the recycle bin at once.

The recycle bin separates My Files from Team Files. Administrators can view every user's recycle bin.
