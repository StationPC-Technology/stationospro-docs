Log Center centrally records system runtime, login, file-transfer, and disk-storage events. You can search logs by keyword and filter them by level, module, user, and time range for security audits, operation tracing, and troubleshooting.

## Page layout

Log Center has a top toolbar, a log table, and bottom pagination:

| Area | Function |
| --- | --- |
| Keyword search | Searches event content. Press Enter or move focus out of the input to apply the keyword. |
| Filter | Combines level, module, user, and time-range filters. |
| Empty | Clears logs in a selected time range. |
| Export logs | Exports logs in the selected time range as a CSV file. |
| Log archive | Configures automatic archive conditions and storage location. |
| Log table | Shows level, module, time, user, and event. |
| Pagination | Shows the total count and supports refresh, page switching, page size, and quick page jumping. |

## View logs from the system user

To show only events generated by the system, filter the **User** field to `system`:

1. Click **Filter**.
2. Select `system` under **User**.
3. Click **Confirm**.

The resulting User column contains only `system`. This view is useful for system startup/shutdown, system updates, network-interface state, disk detection, disk S.M.A.R.T status, and storage-volume exceptions.

![Log list filtered by the system user](/images/common/app-guide/log-center-img/logs.png)

## Log fields

| Field | Description |
| --- | --- |
| Level | Severity: Common, Warning, or Serious. Common is routine information, Warning requires attention, and Serious indicates high functional or hardware risk. |
| Module | Event source: System, Login connection, File transfer, or hard disk storage. |
| Time | When the event occurred. |
| User | User who triggered the event. `system` means the event was generated automatically by the system; a normal username indicates a user action or session event. |
| Event | Details such as system shutdown, disk removal, volume degradation, or system-version update. |

## Search and filter

### Keyword search

Enter a keyword from event content, such as a disk model, volume name, system version, or error description, then press Enter. Keyword search applies together with condition filters.

### Condition filtering

Click **Filter** to combine these conditions:

| Condition | Values/description |
| --- | --- |
| Level | Common, Warning, Serious; supports multiple selection and select all. |
| Module | System, Login connection, File transfer, hard disk storage; supports multiple selection and select all. |
| User | Options come from users present in current logs; supports multiple selection and select all. This guide uses `system`. |
| Time | Choose start and end dates to limit the time range. |

Filters remain pending in the popover until you click **Confirm**. Click **Reset** to clear conditions and restore the default view.

![Filter with the system user selected](/images/common/app-guide/log-center-img/filter.png)

## Pagination and refresh

- **Total**: Shows the number of logs matching current filters.
- **Refresh**: Select the refresh icon beside the total to reload the list.
- **Page size**: 50, 100, or 500 entries per page.
- **Quick jump**: Enter a page number and press Enter, or use the previous/next controls.

## Export logs

Click the download icon at the top to export logs:

1. Select a range: All, recent week, recent month, recent three months, recent six months, or recent year.
2. Click **Confirm**.
3. Wait for file generation; the CSV is saved to your browser download directory.

Export is useful for long-term audit retention or sharing logs with technical support.

## Clear logs

Click **Empty** to clear logs:

1. Choose a range: All, older than one year, six months, three months, one month, or one week.
2. Confirm the range.
3. Wait for the cleanup progress to finish.

<Callout title="Caution" type="warn">
  Clearing logs cannot be undone. Export important history first, and do not clear relevant periods while investigating security or hardware events.
</Callout>

## Log archive

Click the settings icon to open **Log Archive**. By default, the system keeps the most recent 3 million transfer logs and does not archive them automatically. After enabling automatic archiving, either condition can trigger it:

| Condition | Values |
| --- | --- |
| Log data size greater than | 500 MB, 1 GB, 3 GB |
| Log time earlier than | One week, one month, three months, six months, or one year ago |

Also choose an archive location in Team Files. At least one archive condition must be enabled before saving.

<Callout title="Tip" type="info">
  - For sign-in problems, filter Login connection and focus on Warning and Serious levels.
  - For disk or volume issues, filter User to `system` and Module to System or hard disk storage.
  - Export or archive important logs regularly so they remain traceable after cleanup.
</Callout>
