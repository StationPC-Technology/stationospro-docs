Updated: October 20, 2026

StationHub requests a permission only when you enter the feature that needs it. Permission names in system prompts may vary across iOS, Android, Windows, and macOS versions. You decide whether to allow access; denying a permission does not affect unrelated core features.

## 1. Permission principles

- A permission is requested when you first use the relevant feature, not all at launch.
- It is used for the stated feature. Turning it off may disable that feature but does not automatically expose other data.
- Third-party plugins or system services may show additional prompts; you remain in control.
- Location is used only during setup to read the Wi-Fi name and derive a country code. We do not track in the background or upload or retain coordinates.

## 2. iPhone and iPad

| System permission | Trigger | What we do | If disabled |
| --- | --- | --- | --- |
| Camera | QR binding, quick sign-in, avatar setup | Read the camera on the device to recognize a code or take an avatar photo | QR binding and avatar photos are unavailable |
| Photos and videos | Album backup, selected-media upload, avatar setup | Read the media you select; iOS limited-photo access is supported | The related backup or upload cannot run |
| Local network | Find and connect to a NAS on the same LAN | Discover LAN devices and make a local connection | LAN NAS discovery and connection are unavailable |
| Notifications | Device status, backup progress, and account-security alerts | Send system notifications you allow | Related alerts are unavailable |
| Bluetooth | Device binding and setup | Discover nearby devices and send setup information | Bluetooth binding and setup are unavailable |
| Location while in use | Identify the Wi-Fi region during setup | Temporarily read the Wi-Fi name and derive a country code | You must choose the Wi-Fi and region manually |

## 3. Android phones and tablets

| System permission | Trigger | Use | If disabled |
| --- | --- | --- | --- |
| Camera | QR binding and quick sign-in | Recognize codes on the device | Binding and sign-in by QR are unavailable |
| Photos, videos, or local storage | File transfer and automatic album backup | Access files and media you select | Related file operations are unavailable |
| Nearby devices, LAN, and Wi-Fi | Device discovery, local connection, and setup | Read network status needed for the connection | Devices cannot be discovered or connected locally |
| Notifications | Task progress, device errors, and account-security alerts | Send push or local notifications | Related alerts are unavailable |
| Bluetooth | Pairing and network initialization | Discover and connect setup devices | Bluetooth setup is unavailable |
| Network location | Assisted setup recognition | Help identify the Wi-Fi region during setup | You must choose the region manually |
| Background start | A continuous backup you turn on | Keep the backup task running | The system may interrupt the backup |
| Clipboard | Recognize a sharing link and open file transfer | Read it only when the sharing-link feature is triggered | Sharing links are not recognized automatically |

## 4. Windows and macOS clients

| Platform | Permission or capability | Used for | If disabled |
| --- | --- | --- | --- |
| Windows | Desktop notifications | Show task progress, device status, and errors | Desktop alerts are unavailable |
| Windows | Local file system | Upload, download, and folder sync | Local file operations are unavailable |
| macOS | System notifications | Show backup progress and device status | System alerts are unavailable |
| macOS | Local directories | File management, upload, download, and sync | Related file tasks are unavailable |

## 5. Other information

Permission does not mean continuous collection. Without your explicit authorization, we do not actively read or upload private NAS files, request background location, or collect advertising identifiers. You can revoke a permission in system settings; the next use will explain the affected feature and alternatives.

If a feature is provided by a third-party app or service, also read the [Third-Party Personal Information Sharing List](./third-party-sdk-list) and that provider’s policy. For overall processing, see the [Privacy Policy](./privacy-policy).
