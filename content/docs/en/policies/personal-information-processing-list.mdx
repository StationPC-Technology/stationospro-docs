## General Description

This list describes the personal information processing scenarios of StationPC StationNAS App, Web and PC clients. We strictly distinguish between **local offline account mode** and **cloud account mode**.

For users outside Mainland China, only email registration is supported. No phone number or advertising identifiers will be collected. Precise location is never collected or stored; location is used temporarily only during device network setup to read the Wi-Fi name and derive the country code. Product analytics and crash diagnostics data are processed as described in this list.

Local account data is fully stored on the local NAS hardware. No personal data will be collected or stored by StationPC StationNAS cloud servers.

Without explicit user authorization, we will not read, scan or upload any private files stored in your NAS local storage.

## 1. Registration and Login

| Scenario | Purpose | Collected Fields |
| --- | --- | --- |
| Create and log in with local offline account | Implement local device management without relying on cloud services | Local account name, local password (stored only on NAS local device) |
| Local account two-factor authentication (optional) | Receive verification codes to improve local account security | Emergency email address (stored locally) |
| Cloud account registration and login | Complete identity verification, account management and secure login | Phone number (Mainland China only) / Email (non-Mainland China), verification code, password, nickname, avatar |
| Password reset verification | Verify user identity to ensure account security | Account information, device SN |

## Important Supplementary Notes

1. Local offline accounts do not upload any personal data to the cloud. All data is stored locally on the user NAS.

2. User private files stored in NAS will not be read, uploaded or analyzed by StationPC StationNAS without explicit authorization.

3. Overseas versions do not collect advertising identifiers. Precise location is never collected or stored; location is used temporarily only during device network setup to derive the country code. Crash logs and the product analytics data described in Section 4 are retained for fault repair and product improvement.

4. Users may query, correct, delete personal information or cancel accounts through app settings.
