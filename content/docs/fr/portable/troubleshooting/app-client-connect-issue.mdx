## 1. Consulter l'état du réseau sur le petit écran
Petit écran : Paramètres de l'appareil -> Informations sur l'appareil -> consulter l'état réseau de l'appareil

## 2. Connexion directe
### 2.1 Consulter sur le petit écran
2.1.1 Faites pivoter et faites défiler jusqu'au mode AP
2.1.2 Consultez l'IP, le nom et le mot de passe

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/2-1.jpg" width="80%" />

### 2.2 Opérations dans l'application
#### 2.2.1 Se connecter directement via le Wi-Fi du système du téléphone
Connectez-vous dans la liste Wi-Fi du système à l'aide du nom (nom du Wi-Fi) et du mot de passe du mode AP

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/2-2-1.jpg" width="80%" />

#### 2.2.2 Saisir l'IP de connexion directe pour se connecter
Lors de la connexion, utilisez l'IP du mode AP ainsi que le compte et le mot de passe correspondants

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/2-2-2.jpg" width="80%" />

## 3. Non connecté
### 3.1 Consulter sur le petit écran
Paramètres de l'appareil -> Informations sur l'appareil
Faites défiler pour consulter le nom

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/3-1.jpg" width="80%" />

### 3.2 Opérations dans l'application
#### 3.2.1 Se connecter via la configuration réseau de l'appareil
En fonction du nom figurant dans les informations sur l'appareil, trouvez le nom correspondant dans la liste des appareils et appuyez sur Connexion

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/3-2-1-1.jpg" width="40%" />
<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/3-2-1-2.jpg" width="40%" />

#### 3.2.2 Saisir l'IP de configuration réseau pour se connecter
Une fois la configuration réseau réussie, revenez à la page de connexion
Connectez-vous à l'aide de l'IP préremplie ou de l'IP des informations sur l'appareil du petit écran, ainsi que du compte et du mot de passe correspondants

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/3-2-2-1.jpg" width="80%" />
<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/3-2-2-2.jpg" width="80%" />

## 4. Réseau déjà connecté
### 4.1 Connexion par IP
Assurez-vous que le téléphone et l'appareil sont sur le même réseau
Saisissez le compte et le mot de passe correspondants en fonction de l'IP des informations sur l'appareil du petit écran pour vous connecter
Identique à l'étape 3.2.2

### 4.2 Connexion par Station ID
En fonction des informations Station ID définies lors de l'activation, généralement un numéro de téléphone ou une adresse e-mail
Sur la page de connexion, saisissez le Station ID ainsi que le mot de passe pour vous connecter

<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/4-2-1.jpg" width="40%" />
<img src="/images/fr/portable/troubleshooting/app-client-connect-issue/4-2-2.jpg" width="40%" />

#### 4.2.1 Attention
Vérifiez qu'il n'y a pas d'espace avant ou après le Station ID, et qu'il est identique à celui utilisé lors de l'activation de la connexion à distance

## 5. Toujours impossible de se connecter
Sur la page d'échec de connexion de l'appareil, accédez à « Retour d'information » et téléversez les journaux
