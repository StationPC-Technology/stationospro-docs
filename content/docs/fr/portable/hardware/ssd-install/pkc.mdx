title: "Installation d'un SSD M.2 dans l'unité principale"
---

L'unité principale PocketCloud peut accueillir un SSD M.2 NVMe 2280.

## Procédure

1. Éteignez l'appareil jusqu'à ce que les voyants s'éteignent.

![](/images/fr/portable/hardware/ssd-install/pkc/pkc-ssd-install_1.png)

2. À l'aide du tournevis fourni, dévissez la vis dans le sens antihoraire et retirez le capot.

![](/images/fr/portable/hardware/ssd-install/pkc/pkc-ssd-install_2.png)

3. Insérez le SSD dans l'emplacement M.2 NVMe, puis serrez la vis pour le fixer.

![](/images/fr/portable/hardware/ssd-install/pkc/pkc-ssd-install_3.png)

4. Réinstallez le capot.

![](/images/fr/portable/hardware/ssd-install/pkc/pkc-ssd-install_4.png)
