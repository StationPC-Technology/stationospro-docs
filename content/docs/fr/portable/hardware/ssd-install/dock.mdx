title: "Installation d'un SSD M.2 dans la station d'accueil"
---

La station d'accueil PocketCloud peut accueillir un SSD M.2 NVMe 2280.

## Procédure

1. Débranchez la station d'accueil de l'alimentation.

2. À l'aide du tournevis fourni, dévissez la vis dans le sens antihoraire et retirez la plaque inférieure.

![](/images/fr/portable/hardware/ssd-install/dock/dock-ssd-install_1.png)

3. Insérez le SSD dans l'emplacement M.2 NVMe, puis serrez la vis pour le fixer.

![](/images/fr/portable/hardware/ssd-install/dock/dock-ssd-install_2.png)

4. Réinstallez la plaque inférieure.

![](/images/fr/portable/hardware/ssd-install/dock/dock-ssd-install_3.png)
