title: "Comment initialiser PocketCloud ?"
---

Cet article explique comment initialiser PocketCloud.

> Remarque :
> * Lors de l'enregistrement d'un nouvel appareil, celui-ci doit se trouver dans le même environnement réseau ; les environnements Wi-Fi / filaires sont pris en charge, mais la connexion directe Wi-Fi n'est pas encore disponible ;
> * L'enregistrement d'un nouvel appareil est possible depuis l'application mobile ou l'application de bureau ;
> * Lors de l'initialisation depuis l'application mobile, le Bluetooth doit être activé et certaines autorisations de connexion doivent être accordées ; suivez simplement les instructions.

1. Installez l'application mobile, puis ouvrez-la et sélectionnez l'enregistrement d'un nouvel appareil.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-1.jpg" width="30%" />

2. Accédez à la liste des appareils détectés, sélectionnez votre appareil et confirmez le début de l'initialisation sur l'appareil PocketCloud.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-2_1.jpg" width="30%" />
<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-2_2.jpg" width="30%" />

3. Pendant l'initialisation, le téléphone et l'appareil doivent se trouver dans le même réseau local. L'unité principale peut être initialisée via une connexion filaire à la station d'accueil ou via le Wi-Fi : si vous initialisez via le Wi-Fi, configurez le réseau Wi-Fi en suivant les instructions.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-3.jpg" width="30%" />

4. Une fois la configuration réseau terminée, le système vérifie automatiquement les mises à jour du micrologiciel et propose de passer à la dernière version ; s'il n'y a pas de mise à jour, cette étape est ignorée automatiquement.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-4.jpg" width="30%" />

5. Créez un compte administrateur.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-5.jpg" width="30%" />

6. Configurez l'accès à distance (cette étape peut être ignorée ; elle pourra être activée ultérieurement dans **Appareil > Gestion des utilisateurs**).

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-6.jpg" width="30%" />

7. La configuration est terminée : vous pouvez commencer à utiliser PocketCloud.

<img src="/images/fr/portable/guides/initialize-pocketcloud/initialize-pocketcloud-7.jpg" width="30%" />
