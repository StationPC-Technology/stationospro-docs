title: "Comment effectuer un accès à distance ?"
---

PocketCloud intègre un service d'accès à distance qui vous permet de bénéficier d'un accès à distance sécurisé. Avant d'utiliser ce service, vous devez associer un numéro de téléphone / une adresse e-mail et créer un Station ID unique (destiné à identifier votre appareil) ; le Station ID vous permet d'accéder rapidement à votre PocketCloud.

> Remarque :
> * L'utilisation du service d'accès à distance nécessite l'association d'un numéro de téléphone / d'une adresse e-mail ;
> * Le service crée automatiquement un Station ID unique pour votre PocketCloud ; cet ID permet d'accéder à l'appareil en toute sécurité ;
> * Selon l'environnement réseau actuel, le système choisit automatiquement le meilleur mode d'accès ;
> * Le Station ID peut être personnalisé.

## Activer le service d'accès à distance
Méthode 1 :
Lors de la première configuration de l'appareil, il suffit de cocher l'option « Activer l'accès à distance » en suivant les instructions.

Méthode 2 :
1. Ouvrez le client et accédez à la page **Appareil** ;
2. Recherchez **Connexion de l'appareil**, où vous pouvez activer ou désactiver manuellement le service d'accès à distance.

## Dissocier le service d'accès à distance

Lors d'une restauration des paramètres d'usine, le système dissocie automatiquement le service d'accès à distance.
> Lorsque l'appareil est associé au service d'accès à distance, la restauration des paramètres d'usine nécessite une connexion réseau ;
