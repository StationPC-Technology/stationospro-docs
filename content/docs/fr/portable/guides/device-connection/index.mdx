title: "Comment se connecter à PocketCloud ?"
---

Vous pouvez vous connecter à PocketCloud de plusieurs façons ; choisissez celle qui correspond à vos besoins.

## Avec accès à Internet
Lorsque l'appareil est connecté à Internet, vous pouvez vous connecter à PocketCloud des manières suivantes.
### Méthode 1 : saisir l'adresse IP
Une fois PocketCloud connecté au réseau, vous pouvez consulter son adresse IP comme suit :
* Recherchez l'adresse IP de PocketCloud dans l'interface d'administration du routeur.
* Consultez l'adresse IP de PocketCloud sur son petit écran.

<img src="/images/fr/portable/guides/device-connection/1-1.jpg" width="30%" />
<img src="/images/fr/portable/guides/device-connection/1-2.jpg" width="30%" />

### Méthode 2 : saisir le Station ID
Si vous avez activé le service d'accès à distance, vous pouvez vous connecter à PocketCloud en saisissant le Station ID.

### Méthode 3 : découvrir les appareils du réseau local
Après avoir ouvert l'application, appuyez sur **Découvrir les appareils du réseau local** (indiqué par le cadre rouge) pour accéder à la liste de recherche : l'application détecte et affiche automatiquement tous les appareils PocketCloud du même réseau local. Sélectionnez l'appareil PocketCloud auquel vous souhaitez vous connecter.

<img src="/images/fr/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/fr/portable/guides/device-connection/1-5.jpg" width="30%" />

### Méthode 4 : connexion historique
Après avoir ouvert l'application, appuyez sur **Découvrir les appareils du réseau local** (indiqué par le cadre rouge) pour accéder à la liste de recherche. Si l'appareil possède un historique de connexion, la fonction **Connexion historique** permet de préremplir rapidement les informations d'accès et de compte.

<img src="/images/fr/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/fr/portable/guides/device-connection/1-7.jpg" width="30%" />

Après avoir trouvé l'appareil, saisissez votre nom d'utilisateur et votre mot de passe pour vous connecter.

## Sans accès à Internet
Si vous vous trouvez dans un environnement sans réseau, vous pouvez vous connecter à PocketCloud des manières suivantes.

### Méthode 1 : connexion directe Wi-Fi
> Une fois que votre téléphone est connecté directement à PocketCloud en Wi-Fi, vous n'avez pas besoin de couper cette connexion : vous pouvez simultanément activer les données mobiles pour accéder aux réseaux externes (naviguer sur le Web, recevoir des messages, etc.), afin de concilier l'accès aux données de l'appareil et les besoins du réseau externe.
Après avoir ouvert l'application, appuyez sur **Connexion directe à l'appareil** pour accéder à la liste de recherche : l'application détecte et affiche automatiquement via Bluetooth tous les appareils PocketCloud à proximité. Sélectionnez l'appareil PocketCloud auquel vous souhaitez vous connecter.

<img src="/images/fr/portable/guides/device-connection/2-1-2.jpg" width="30%" />

### Méthode 2 : accès via le point d'accès mobile du téléphone
> Remarque : avec cette méthode, lorsque vous accédez à des données externes (accès au stockage cloud, téléchargements hors ligne, etc.), PocketCloud se connecte à Internet via les données mobiles du point d'accès ; surveillez votre consommation de données afin d'éviter tout dépassement et des frais supplémentaires.
Si vous souhaitez accéder à Internet via les données mobiles, vous pouvez créer un environnement réseau temporaire à l'aide du point d'accès mobile du téléphone. Étapes :
1. Activez le point d'accès mobile et définissez son nom (SSID) et son mot de passe ;
2. Ouvrez l'application, appuyez sur « Configuration réseau » et suivez les instructions pour accéder à la page de configuration ; saisissez manuellement le nom et le mot de passe du point d'accès mobile pour connecter PocketCloud au point d'accès ;

<img src="/images/fr/portable/guides/device-connection/2-2-1.jpg" width="30%" />
<img src="/images/fr/portable/guides/device-connection/2-2-2.jpg" width="30%" />
<img src="/images/fr/portable/guides/device-connection/2-2-3.jpg" width="30%" />

3. Une fois la connexion établie, ouvrez l'application et appuyez sur **Découvrir les appareils du réseau local** : l'application identifie automatiquement les appareils PocketCloud du même réseau de point d'accès. Sélectionnez l'appareil correspondant et saisissez votre nom d'utilisateur et votre mot de passe pour vous connecter.
