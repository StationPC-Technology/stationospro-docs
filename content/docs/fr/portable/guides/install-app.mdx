---

Cet article explique comment installer le client PocketNAS sur les différentes plateformes.

## Mobile
<Tabs items={["iOS","Android"]}>

<Tab>

1. Ouvrez l'App Store et recherchez « PocketNAS » ;
2. Téléchargez l'application PocketNAS et suivez les instructions pour terminer son installation.

\* Ce client prend uniquement en charge iOS 12 et les versions ultérieures.

</Tab>

<Tab>

* Méthode 1 :
1. Ouvrez le Google Play Store et recherchez « PocketNAS » ;
2. Téléchargez l'application PocketNAS et suivez les instructions pour terminer son installation.

* Méthode 2 :
1. Rendez-vous sur le site officiel de StationPC et téléchargez le [package d'installation du client Android](https://www.stationpc.com/pages/download) ;
2. Une fois le téléchargement terminé, exécutez le package d'installation et suivez les instructions pour terminer l'installation du client Android.

\* Ce client prend uniquement en charge Android 10 et les versions ultérieures.

</Tab>

</Tabs>

## Bureau
<Tabs items={["MacOS","Windows"]}>

<Tab>

1. Rendez-vous sur le site officiel de StationPC, sélectionnez la plateforme correspondant au type de puce de votre appareil (X86 ou puce M) et téléchargez le [package d'installation du client MacOS](https://www.stationpc.com/pages/download) ;
2. Une fois le téléchargement terminé, exécutez le package d'installation et suivez les instructions pour terminer l'installation du client macOS.

\* Ce client prend uniquement en charge macOS 14.0 et les versions ultérieures.

</Tab>

<Tab>

1. Rendez-vous sur le site officiel de StationPC et téléchargez le [package d'installation du client Windows](https://www.stationpc.com/pages/download) ;
2. Une fois le téléchargement terminé, exécutez le package d'installation et suivez les instructions pour terminer l'installation du client Windows.

\* Ce client prend uniquement en charge Windows 10 et les versions ultérieures.

</Tab>

</Tabs>

## Téléviseur
<Tabs items={["AndroidTV","AppleTV"]}>

<Tab>

* Méthode 1 :
1. Ouvrez le Google Play Store et recherchez « StationCloudTV » ;
2. Téléchargez l'application StationCloudTV et suivez les instructions pour terminer son installation.

* Méthode 2 :
1. Rendez-vous sur le site officiel de StationPC et téléchargez le [package d'installation du client TV](https://www.stationpc.com/pages/download) ;
2. Vous devez transférer le package d'installation sur une clé USB ;
3. Insérez la clé USB contenant le package d'installation dans le téléviseur, puis installez le client TV sur l'appareil.

\* Ce client prend uniquement en charge Android TV 6.0 et les versions ultérieures.

</Tab>

<Tab>

Le client AppleTV est en cours de développement.

</Tab>

</Tabs>
