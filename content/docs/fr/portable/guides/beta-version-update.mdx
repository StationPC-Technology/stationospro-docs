## Introduction

La version bêta est une version d'expérience ouverte aux utilisateurs bêta avant la mise en ligne officielle de l'application. Elle permet aux testeurs de découvrir en avant-première les nouvelles fonctionnalités du micrologiciel système et des logiciels clients qui ne sont pas encore publiées, tout en servant à recueillir les retours des utilisateurs et à détecter les problèmes potentiels, afin de soutenir l'optimisation et l'amélioration de la version officielle.

## Étapes de mise à jour du client iOS vers la version bêta
### 1. Installer TestFlight
Cliquez sur le lien pour accéder à [TestFlight](https://testflight.apple.com/join/kH1Fmjby), puis cliquez sur **View in App Store** pour télécharger ou mettre à jour TestFlight.

<img src="/images/fr/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/fr/portable/guides/beta-version-update/1-2.png" width="30%" />

### 2. Accéder à la page de test TestFlight
Cliquez à nouveau sur le lien [TestFlight](https://testflight.apple.com/join/kH1Fmjby), puis cliquez sur **View in TestFlight** pour ouvrir l'application.

<img src="/images/fr/portable/guides/beta-version-update/2-1.png" width="30%" />
<img src="/images/fr/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3. Installer la version bêta
Lorsque la fenêtre de version bêta s'affiche, cliquez sur « Accepter » pour installer la dernière version bêta.

## Étapes de mise à jour du client Android vers la version bêta
Si le client Android a été téléchargé depuis le site officiel, aucune opération supplémentaire n'est nécessaire : lorsqu'une version bêta est disponible, une notification de mise à jour s'affiche dans l'application. S'il a été téléchargé depuis Google Play, suivez les étapes ci-dessous.
### 1. Accéder au lien de test ouvert
Cliquez sur le lien pour accéder à [GooglePlay](https://play.google.com/apps/testing/com.stationpc.nas), puis cliquez sur **Devenir testeur** pour rejoindre le test.

<img src="/images/fr/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/fr/portable/guides/beta-version-update/1-2.png" width="30%" />
<img src="/images/fr/portable/guides/beta-version-update/1-3.png" width="30%" />

### 2. Installer la version de test
Vous devez d'abord désinstaller la version officielle avant de pouvoir installer la version de test.

<img src="/images/fr/portable/guides/beta-version-update/2-1.jpg" width="30%" />
<img src="/images/fr/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3. Quitter le test
Pour réinstaller la version officielle, cliquez sur le lien pour accéder à [GooglePlay](https://play.google.com/apps/testing/com.stationpc.nas), puis cliquez sur **Quitter** pour quitter le programme de test.

<img src="/images/fr/portable/guides/beta-version-update/3-1.jpg" width="30%" />
