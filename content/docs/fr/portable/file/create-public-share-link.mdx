title: "Comment créer un lien de partage externe pour un fichier ?"
---

PocketCloud permet de créer des liens de partage externe pour des fichiers ; des tiers peuvent accéder à ces liens et télécharger les fichiers que vous partagez.
> Remarque : 
> L'accès à distance doit être activé pour créer un lien de partage externe distant ; si l'accès à distance est désactivé, seuls des liens de partage externes au sein du réseau local peuvent être créés.

## Comment créer un lien de partage externe ?

Dans **Fichiers**, trouvez le fichier/dossier à partager, cliquez sur le menu Plus à droite, puis créez un lien de partage externe.

<img src="/images/fr/portable/file/create-public-share-link/1-0.jpg" width="30%" />
<img src="/images/fr/portable/file/create-public-share-link/1-1.jpg" width="30%" />

Lors de la création d'un lien de partage externe, vous pouvez définir la date d'expiration et le mot de passe de ce lien. Cliquez sur OK pour créer le lien de partage externe. Un même fichier peut disposer de plusieurs liens de partage différents, avec des paramètres différents.

* Date d'expiration : 3 jours, 7 jours, 30 jours ou permanent ; par défaut 30 jours.
* Mot de passe : si vous ne cochez pas l'option, le partage est sans mot de passe ; si vous la cochez, saisissez un mot de passe d'au moins 4 caractères.
> Les liens de partage ci-dessous ont été créés respectivement avec l'accès à distance désactivé et avec l'accès à distance activé

## Comment gérer les liens de partage externes ?

Vous pouvez consulter et gérer tous les liens de partage externe que vous avez créés dans **Fichiers > Partage par lien externe**.
