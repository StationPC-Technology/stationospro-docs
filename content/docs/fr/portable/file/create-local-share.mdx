title: "Comment partager des fichiers avec d'autres utilisateurs locaux ?"
---

Les espaces des différents utilisateurs sont indépendants et ne sont pas directement accessibles. Vous pouvez partager des fichiers avec d'autres utilisateurs en configurant un partage de fichiers.
> Remarque : 
> Au moins 2 utilisateurs doivent exister pour pouvoir créer un partage local.
## Comment créer un partage local ?

Dans **Fichiers**, trouvez le fichier/dossier à partager, cliquez sur le menu Plus à droite, puis créez un partage local.

## Comment gérer un partage local ?

Vous pouvez effectuer les opérations suivantes dans **Fichiers > Partage local** :
* Consulter les fichiers partagés avec vous par d'autres utilisateurs ;
* Gérer tous les partages locaux que vous avez créés.
