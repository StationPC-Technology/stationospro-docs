title: "Comment accéder aux fichiers de PocketCloud via FTP ?"
---

FTP (File Transfer Protocol) est un protocole de transfert de fichiers réseau couramment utilisé, qui permet de transférer des fichiers entre un appareil et un serveur.
Grâce à FTP, les utilisateurs peuvent se connecter à distance à PocketCloud pour parcourir, téléverser, télécharger et gérer des fichiers.

**Il offre principalement les fonctions suivantes :**
1. Téléversement et téléchargement de fichiers : transférer des fichiers entre l'appareil local et PocketCloud.
2. Gestion de fichiers à distance : créer, renommer, déplacer et supprimer des fichiers ou dossiers sur PocketCloud.
3. Accès avec authentification utilisateur : contrôle d'accès par compte et mot de passe, pour renforcer la sécurité.
4. Accès multiplateforme : connexion possible via des clients Windows et macOS prenant en charge FTP.

## Activer FTP

FTP est désactivé par défaut et doit être activé manuellement. Suivez les étapes ci-dessous :
1. Ouvrez la page **Protocoles de partage de fichiers** de l'application.<br />
2. Cliquez sur **Service FTP**.<br />
3. Activez le **bouton bascule** pour activer le **service FTP**.<br />

## Accès sur Windows

1. Appuyez sur **Win + E** pour ouvrir l'**Explorateur de fichiers**.
2. Saisissez `ftp://NAS_IP_Address:21` ou `ftps://NAS_IP_Address:21` dans la barre d'adresse, puis appuyez sur **Entrée**.
<img src="/images/fr/portable/file-service/access-ftp-service/3-1.png" width="100%" height="100%" />
3. Dans l'invite de connexion, saisissez le **nom d'utilisateur** et le **mot de passe**, puis cliquez sur **Se connecter**
<img src="/images/fr/portable/file-service/access-ftp-service/3-2.png" width="100%" height="100%" />
4. Vous pouvez maintenant parcourir et gérer les fichiers PocketCloud dans l'Explorateur de fichiers.
<img src="/images/fr/portable/file-service/access-ftp-service/3-3.png" width="100%" height="100%" />

## Accès sur macOS

1. Faites un clic droit sur **Finder**, puis sélectionnez **Se connecter au serveur**.
<img src="/images/fr/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. Saisissez `ftp://NAS_IP_Address:21` ou `ftps://NAS_IP_Address:21`, puis cliquez sur **Se connecter**.
<img src="/images/fr/portable/file-service/access-ftp-service/4-1.png" width="100%" height="100%" />
3. Saisissez le **nom** et le **mot de passe**, puis cliquez sur **Se connecter**.
<img src="/images/fr/portable/file-service/access-ftp-service/4-2.png" width="100%" height="100%" />
4. Vous pouvez maintenant accéder aux fichiers PocketCloud dans le Finder.  
<img src="/images/fr/portable/file-service/access-ftp-service/4-3.png" width="100%" height="100%" />

## Accès depuis d'autres clients
- Informations de connexion
    - IP : IP de l'appareil NAS
    - Port : 21 par défaut
    - Compte : nom d'utilisateur de connexion à l'appareil NAS
    - Mot de passe : mot de passe de connexion à l'appareil NAS
- Description du répertoire de montage
    - SSD principal : `/nom_utilisateur`
      - Exemple 1 : tous les répertoires. L'utilisateur actuel est test ; le répertoire de montage est `/test`
      - Exemple 2 : répertoire spécifié. L'utilisateur actuel est test ; le répertoire de montage est `/test/Pictures`
      - Autres : plusieurs utilisateurs sont pris en charge ; chaque utilisateur correspond à un répertoire de montage
    - Stockage externe : `/nom_du_stockage_externe`
      - Exemple 1 : tous les répertoires. Le nom de la carte SD externe est SD 60GB BA26 ; le répertoire de montage est `/SD_60GB_BA26`
      - Exemple 2 : répertoire spécifié. Le nom de la carte SD externe est SD 60GB BA26 ; le répertoire de montage est `/SD_60GB_BA26/Pictures`
    - ⚠️ Remarque :
      - Certains clients ne permettent pas de saisir uniquement le répertoire racine `/` ; il faut indiquer le répertoire de montage spécifique correspondant ci-dessus
      - Après la mise à jour du micrologiciel &lt;= 3.1.0.16 vers la dernière version, le répertoire de montage a été ajusté ; référez-vous à la méthode de montage de la nouvelle version
