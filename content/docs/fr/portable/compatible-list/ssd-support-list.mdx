Remarques sur la compatibilité des SSD PocketCloud :
* Spécifications : prise en charge uniquement du format M.2 NVMe 2280 ;
* Protocole et vitesse : compatible avec les protocoles PCIe 3.0/4.0, vitesse de fonctionnement réelle PCIe 3.0 x2 ;
* Alimentation : 3,3 V, jusqu'à 3 A ;
* Capacité : capacité maximale de 8 To, des capacités supérieures étant théoriquement prises en charge ; des tests réels ont montré que certains modèles de plus de 8 To de certaines marques fonctionnent normalement, voir la liste de compatibilité pour plus de détails ;
* Installation et refroidissement : les SSD équipés d'un dissipateur doivent être retirés de leur dissipateur avant l'installation (valable pour l'unité principale comme pour le dock) ; l'unité principale intègre un ventilateur de refroidissement actif et le dock est fourni avec un dissipateur, aucun accessoire de refroidissement supplémentaire n'est nécessaire pour un fonctionnement stable à long terme.
