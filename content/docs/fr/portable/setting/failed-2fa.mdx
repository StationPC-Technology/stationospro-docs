title: "Impossible de terminer la double authentification du compte (2FA)"
---

Si, en raison d'un changement ou d'une perte de téléphone, vous ne pouvez pas obtenir le code de vérification dynamique, vous pouvez désactiver la double authentification de la manière suivante pour rétablir la connexion à votre compte.

## Méthode 1 : obtenir un code de vérification d'urgence via l'adresse e-mail de sécurité
Si vous avez lié une adresse e-mail de sécurité, appuyez sur **Impossible d'obtenir le code** dans l'écran de vérification de connexion ; le système envoie alors un code de vérification d'urgence à usage unique à votre adresse e-mail de sécurité, et sa saisie suffit pour vous connecter.
<img src="/images/fr/portable/setting/failed-2fa/1-1-1.png" width="30%" />

## Méthode 2 : agir depuis un appareil de confiance
Si vous avez déjà défini un appareil de confiance, vous pouvez vous connecter normalement à votre compte sur cet appareil, puis désactiver manuellement la double authentification.

## Méthode 3 : contacter l'administrateur système
Si vous utilisez un compte non administrateur, contactez l'administrateur pour qu'il désactive la double authentification pour vous.
