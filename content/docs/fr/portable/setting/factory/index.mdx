title: "Réinitialisation d'usine"
---

La réinitialisation d'usine permet de restaurer l'appareil dans son état initial ; l'opération doit être effectuée depuis l'application.  

> Remarque : si l'appareil est déjà lié à un service d'accès à distance, la réinitialisation d'usine dissocie automatiquement ce service, et une connexion Internet est nécessaire pour mener l'opération à bien ;

## Comment réinitialiser l'appareil
1. Ouvrez le client, accédez à la page **Appareil**, puis trouvez l'option **Matériel et système > Réinitialisation d'usine** ;  
2. Appuyez sur **Réinitialisation d'usine** et saisissez le mot de passe pour lancer le processus de restauration.  
> * Formatage du disque : si vous choisissez « Ne pas formater », le système crée automatiquement un répertoire « olduserdata » ; une fois la restauration terminée, les fichiers de données d'origine sont enregistrés dans ce répertoire.
