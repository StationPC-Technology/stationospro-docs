---

Le service de notification par e-mail autorise le système à envoyer des e-mails, par exemple les e-mails de code d'urgence de double authentification et les e-mails de réinitialisation du mot de passe.

> Fournisseurs de messagerie actuellement pris en charge : Gmail, Yahoo, Apple, QQ, 163, ainsi que les serveurs SMTP personnalisés.

## Activer le service de notification par e-mail

1. Vous pouvez activer le service de notification par e-mail dans **Appareil > Notifications > Notification par e-mail**.
2. Selon votre situation, choisissez le fournisseur de messagerie approprié, obtenez le code d'autorisation du service de messagerie correspondant de la manière décrite ci-dessous, puis validez la configuration.
3. Une fois la configuration terminée, envoyez un e-mail de test pour vérifier que le service de messagerie est bien autorisé.

## Comment obtenir le code d'autorisation de la boîte e-mail
### Gmail
1. Rendez-vous sur [myaccount.google.com](myaccount.google.com) pour accéder à la page de gestion du compte Google. Cliquez sur l'icône de recherche, saisissez **Mots de passe des applications**, puis cliquez sur le résultat pour accéder à la page de paramètres.
<img src="/images/fr/portable/setting/setup-smtp/2-1-1.png" width="100%" />

2. Saisissez un nom d'application personnalisé, puis cliquez sur « Créer » pour générer le code d'autorisation.
<img src="/images/fr/portable/setting/setup-smtp/2-1-2.png" width="100%" />

### Apple
1. Rendez-vous sur le site officiel d'Apple ID : [appleid.apple.com](appleid.apple.com), puis connectez-vous à votre compte Apple ID.

2. Accédez à la page « Connexion et sécurité > Mots de passe d'application ».
<img src="/images/fr/portable/setting/setup-smtp/2-2-1.png" width="100%" />

3. Cliquez sur « Générer un mot de passe d'application ».
<img src="/images/fr/portable/setting/setup-smtp/2-2-2.png" width="100%" />

4. Saisissez un libellé pour nommer ce mot de passe (par exemple StationPC), puis cliquez sur « Créer ».

### Yahoo
1. Connectez-vous à votre [page de sécurité du compte Yahoo](https://login.yahoo.com/?done=https%3A%2F%2Flogin.yahoo.com%2Fmyaccount%2Fsecurity%3F.lang%3Den-US%26.intl%3Dus%26.src%3Dyhelp%26.scrumb%3D0&src=mc&.intl=us&.lang=en-US).
2. Dans la rubrique « Connexions externes », cliquez sur « Créer un mot de passe d'application ».
3. Saisissez le nom de l'application dans le champ de texte.
4. Cliquez sur « Générer un mot de passe ».
5. Utilisez le mot de passe à usage unique généré pour vous connecter à l'application tierce.
