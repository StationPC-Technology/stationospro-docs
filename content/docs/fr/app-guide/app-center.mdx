Le Centre d'applications est la boutique d'applications de StationOS Pro. Il permet d'installer, de mettre à jour et de gérer en un seul endroit les applications officielles et tierces. Comme sur la boutique d'applications de votre téléphone, vous pouvez ainsi ajouter au NAS des fonctionnalités de téléchargement, de lecture audio-vidéo, de synchronisation, de productivité et de développement/exploitation.

## Présentation de l'interface

Après avoir ouvert le Centre d'applications, la partie supérieure propose la navigation suivante :

- **Toutes les applications** : parcourir toutes les applications installables de la boutique ;
- **Installées** : consulter et gérer les applications actuellement installées sur l'appareil ;
- **Filtre par catégorie** : filtrer rapidement les applications par synchronisation, vidéo, enregistrement vidéo, téléchargement, productivité, outils de développement, etc. ;
- **Champ de recherche** : rechercher rapidement une application par son nom.

La liste des applications est divisée en une zone « Applications officielles » et une zone d'applications tierces. Chaque carte d'application affiche son nom, sa description/étiquette de catégorie et un bouton d'installation.

![App Center](/images/fr/app-guide/app-center-img/all-apps.png)

## Installer une application

1. Dans le Centre d'applications, trouvez l'application souhaitée par catégorie ou via le champ de recherche.
2. Cliquez sur la carte de l'application pour ouvrir sa page de détails.
3. Après avoir vérifié les informations de l'application, cliquez sur **Installer** ; le système télécharge et installe automatiquement l'application.
4. Une fois l'installation terminée, l'application apparaît dans le lanceur d'applications ; si la création automatique d'un raccourci sur le bureau est activée, un raccourci est également créé sur le bureau.

## Page de détails de l'application

La page de détails présente les informations suivantes pour vous aider à comprendre et à évaluer l'application :

| Champ | Description |
| --- | --- |
| Développeur | Développeur ou équipe de l'application |
| Éditeur | Éditeur de l'application |
| Téléchargements | Nombre cumulé de téléchargements de l'application |
| Taille | Taille du paquet d'installation |
| Version actuelle | Numéro de la dernière version proposée dans la boutique |
| Présentation de l'application | Points forts et instructions d'utilisation |

![App Detail](/images/fr/app-guide/app-center-img/app-detail.png)

## Paramètres du Centre d'applications

Cliquez sur le bouton **Paramètres** en haut à droite du Centre d'applications pour configurer les options suivantes :

- **Emplacement d'installation par défaut** :
  - **Demander à chaque fois** : choisir manuellement l'emplacement de stockage lors de l'installation ;
  - **Emplacement de stockage fixe** : désigner un espace de stockage unique pour l'installation des applications.
- **Créer automatiquement un raccourci sur le bureau** : une fois activée, cette option crée automatiquement un raccourci sur le bureau pour les applications nouvellement installées.

![App Center Settings](/images/fr/app-guide/app-center-img/settings.png)

<Callout title="Attention" type="warn">
  - Avant d'installer une application, assurez-vous que l'espace de stockage sélectionné dispose d'une capacité suffisante ; sinon, l'installation peut échouer.
  - Certaines applications tierces sont fournies par des développeurs externes ; avant l'installation, vérifiez la source de l'application et les autorisations demandées.
  - L'emplacement d'installation d'une application ne peut pas toujours être modifié ; si vous devez la déplacer, désinstallez-la puis réinstallez-la.
</Callout>
