## Présentation générale

La présente liste décrit les scénarios de traitement des informations personnelles de StationPC StationNAS sur mobile, sur le portail web et dans le client PC, en distinguant strictement le « mode de compte local hors ligne » et le « mode de compte cloud ».

Les utilisateurs situés hors de Chine continentale peuvent uniquement s'inscrire avec une adresse e-mail ; nous ne collectons ni numéro de téléphone ni identifiant publicitaire. Nous ne collectons ni ne stockons de position précise : les informations de position ne sont utilisées que temporairement lors de la configuration réseau de l'appareil (lecture du nom du WiFi, déduction du code pays). Les données d'analyse d'utilisation du produit et de diagnostic des plantages sont traitées comme décrit dans la présente liste.

Les données du compte local sont entièrement stockées sur le matériel local du NAS de l'utilisateur ; le cloud ne collecte ni ne stocke aucune information personnelle.

Sans votre autorisation explicite, nous ne lisons, n'analysons ni ne téléversons les fichiers privés stockés sur votre NAS.

## Informations complémentaires importantes

Le compte local hors ligne ne téléverse aucune donnée personnelle vers le cloud ; toutes les données sont conservées uniquement localement sur le NAS de l'utilisateur.

Sans votre autorisation active, nous ne lisons, ne téléversons ni n'analysons les fichiers privés stockés sur votre NAS.

Les versions internationales ne collectent pas d'identifiant publicitaire. Nous ne collectons ni ne stockons de position précise : les informations de position ne sont utilisées que temporairement lors de la configuration réseau de l'appareil pour déduire le code pays. Les journaux de plantage et les données d'analyse du produit sont conservés comme indiqué à la section 4, aux fins de correction des pannes et d'amélioration du produit.

Vous pouvez consulter, corriger et supprimer vos informations personnelles et résilier votre compte de manière autonome dans les paramètres de l'application.
