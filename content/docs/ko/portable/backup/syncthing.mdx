---

PocketCloud는 여러 대의 컴퓨터와 파일 동기화를 지원하며, 파일 추가, 수정, 삭제가 모두 실시간으로 동기화되며, 전 과정에서 수동 조작이 필요 없고, 여러 장치의 파일 버전이 항상 일치합니다.

> 주의:
> * 동기화 전략의 실행은 **PocketCloud PC 클라이언트의 지속적인 실행**에 의존합니다. 클라이언트를 종료하면 동기화가 중단됩니다.
> * 같은 네트워크 환경에서만 동기화를 지원하며, 원격 동기화는 지원하지 않습니다
---

## 설치 및 로그인

- 컴퓨터에 **PocketCloud 클라이언트** 설치
- 클라이언트를 사용하여 IP 방식으로 **PocketCloud** 장치에 로그인 연결
- 왼쪽 메뉴에서 '애플리케이션'을 클릭하고, **【파일 동기화】** 메뉴를 선택합니다.
- **‘새로 추가’** 클릭 → 경로 및 동기화 전략 선택 후, 동기화 작업 생성

---

## 동기화 경로 설정

‘동기 경로’ 화면에서 다음 내용을 구성합니다:

<img src="/images/common/portable/backup/syncthing/1.png" />

### 경로 설정

- **컴퓨터 경로**：동기화할 로컬 폴더 위치 선택
- **PocketCloud 경로**: NAS에서 동기화 파일을 저장할 대상 위치를 선택

### 동기 방식(하나 선택)

- **양방향 동기화**：컴퓨터 ↔ NAS 양방향으로 서로 동기화하여 일치 상태를 유지
- **단방향 다운로드**：NAS → 컴퓨터로만 다운로드
- **단방향 업로드**: PC → NAS로만 업로드

### 예시(양방향 동기화)

만약 로컬 데이터를 NAS로 동기화하고 다음 사용 시 양쪽을 일치시키고 싶다면:

- 컴퓨터 경로: 폴더 **B**
- **PocketCloud 경로**：공유 폴더 **A**
- 동기화 방식: **양방향 동기화**

효과: 컴퓨터와 NAS의 파일은 지속적으로 일치하게 유지됩니다.

### 여러 대의 컴퓨터가 동일한 데이터를 동기화하기 (확장)

다른 컴퓨터에서도 동일한 데이터를 동기화하려면:

- 다른 컴퓨터에 PocketCloud 클라이언트를 설치하고 로그인
- 동기화 작업 생성:
- 컴퓨터 경로: 이 컴퓨터의 지정된 폴더
- **PocketCloud 경로**: 여전히 공유 폴더 **A** 선택

효과: 여러 대의 컴퓨터 + NAS 세 단말 데이터 동기화 유지.

## 동기화 정책 설정

‘동기 경로 설정’을 완료한 후 **‘다음’**을 클릭하여 **【동기 규칙】**으로 들어갑니다:

<img src="/images/common/portable/backup/syncthing/2.png" />

- **실시간 동기화**: 파일 변경 감지 시 자동으로 동기화
- **수동 동기화**: **'지금 동기화'**를 클릭할 때만 동기화
- **파일 필터링**: 동기화할 필요가 없는 파일 또는 폴더를 필터링

### 파일 필터링

- **'.'로 시작하는 파일/폴더 동기화 여부**

- 기본값: 숨김 파일/폴더 동기화하지 않음
- 동기화 필요: 수동으로 체크하여 활성화

- **지정된 파일 이름 또는 확장자 필터링**
- **‘다음 파일 이름 또는 파일 확장자 필터링’** 선택
- 조정 가능/새로운 필터 규칙 추가
- 규칙 삭제: 규칙 오른쪽의 **“X”** 클릭
- 새 규칙 추가: **'새로 만들기'** 클릭 → 파일 이름 또는 확장자 입력
- 여러 규칙은 **`;`** 로 구분

**필터 예시:**

- 특정 파일 이름 필터링: `abc.doc`, `test*.doc`, `tmp.*`
- 특정 파일 유형 필터링: `*.jpg`

**기본 필터 형식:**

- `*.tmp`
- `*.temp`
- `*.swp`
- `*.link`
- `*.pst`
- `~*.*`
- `@eadir`
- `.SynologyWorkingDirectory`
- `#recycle`
- `desktop.ini`
- `.DS_STORE`
- `lcon\r`
- `thumbs.db`
- `$Recycle.Bin`
- `@sharebin`
- `System Volume Information`
- `Program Files`
- `Program Files (x86)`
- `ProgramData`
- `#snapshot`

## 고급 설정

【고급 설정】에서 동기화 세부 정보를 더 구성할 수 있습니다.

<img src="/images/common/portable/backup/syncthing/set.png" />

### 파일 삭제 로직

- 기본값: **휴지통으로 이동**
- '완전히 삭제'로 설정할 수 있습니다

### 파일 충돌 처리

- 기본값: **덮어쓰기**
- '둘 다 유지'로 설정할 수 있으며, 이름이 변경될 것입니다

---

선택한 후 **‘다음’**을 클릭하여 미리보기로 이동합니다.

---

## 미리보기 및 작업 생성

**【미리보기】** 화면에서:

<img src="/images/common/portable/backup/syncthing/3.png" />

- **동기화 작업 이름**을 사용자 정의할 수 있습니다
- 모든 설정 항목을 확인
- 수정이 필요하면: **‘이전 단계’**를 클릭하여 돌아가서 조정하세요
- 확인 완료: **‘생성’**을 클릭하여 작업을 생성

---

## 작업 관리

생성이 완료되면, **【동기화】** 화면에서 장치와 작업을 관리할 수 있습니다:

<img src="/images/common/portable/backup/syncthing/list-edit.png" />

- **동기화 일시 중지**：**"동기화 일시 중지"**를 클릭
- **더 많은 작업**：마우스를 **'더 보기'** 위에 올려 동기화 기록을 확인하거나, 작업을 편집 또는 삭제합니다
- **빠르게 작업 생성**: 동기화 작업 오른쪽에서 **“+”**를 클릭하여 해당 장치의 새 동기화 작업을 빠르게 생성
