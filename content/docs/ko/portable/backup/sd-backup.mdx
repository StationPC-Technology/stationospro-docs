PocketCloud 내장 SD 카드 슬롯을 갖추고 있으며, SD 카드 데이터 백업 기능을 지원합니다. 구체적인 설명과 조작 단계는 다음과 같습니다:

- SD 카드 데이터는 기본적으로 경로 **“My Backup/Backup From xxx”**에 백업됩니다（“xxx”는 SD 카드識別 이름）。
- 백업 작업은 두 가지 방식으로 지원됩니다: 장치의 작은 화면을 통해 빠르게 백업하거나, 클라이언트를 통해 모든 매개변수를 설정한 후 백업할 수 있습니다.

> 주의:
> 만약 클라이언트를 통해 SD 카드 백업의 기본 설정(예: 백업 소스, 백업 목적지 등)을 이미 변경한 경우, 이후 소형 화면에서 백업을 실행하거나 클라이언트 빠른 백업을 사용할 때, 변경된 새 설정이 자동으로 적용되며, 반복해서 설정할 필요가 없습니다.

## 클라이언트를 통해 백업
클라이언트는 '빠른 백업'과 '고급 백업' 두 가지 모드를 제공하며, 필요에 따라 선택할 수 있습니다:

### 방법1: 빠른 백업(원클릭 시작, 설정 불필요)
1. 클라이언트를 열고, **홈 > 내 장치** 페이지로 들어갑니다；
2. 장치 목록에서 삽입된 SD 카드를 찾아 해당 '백업' 버튼을 클릭하면 빠른 백업을 시작할 수 있습니다.

### 방법 2：고급 백업（사용자 정의 매개변수, 유연한 설정）
1. 클라이언트를 열고, **홈 > 내 장치** 페이지로 들어갑니다；
2. 식별된 SD 카드를 클릭하여 'SD 카드 백업 설정' 화면으로 들어갑니다;
3. 요구에 따라 다음 백업 매개변수를 조정하고 설정을 완료한 후 백업을 시작합니다:
- **백업 소스**: '전체 백업'(기본값) 또는 '지정 폴더 백업'을 지원하며, 필요에 따라 백업할 파일 경로를 선택할 수 있습니다;
- **백업 목적지**：백업 파일의 저장 디렉토리를 사용자 정의할 수 있습니다；
- **백업 방식**：‘수동 백업’(기본), ‘정기 백업’, ‘삽입 시 자동 백업’ 제공;
- **파일 필터링**：파일 크기에 따라 백업 파일을 필터링하는 것을 지원합니다.

## 작은 화면을 통한 백업(빠른 조작, 클라이언트 없는 환경에 적합)
1. SD 카드 슬롯에 SD 카드를 삽입합니다.
2. 작은 화면에 SD 카드가 삽입된 인터페이스가 표시됩니다.
![](/images/common/portable/backup/sd-backup/sd-card-has-been-inserted.png)
3. 다이얼에서 **Backup**을 선택한 후, 다이얼을 클릭하여 백업을 시작합니다.
4. 백업이 완료되면, 장치는 '삐' 소리를 두 번 내고, 작은 화면에 백업 성공이 표시됩니다.
![](/images/common/portable/backup/sd-backup/sd-card-backup-finish.png)
