작은 화면: 장치 설정 -> 장치 정보 -> 장치 네트워크 상태 확인

## 2. 직접 연결
### 2.1 작은 화면에서 확인
2.1.1 회전하여 AP 모드로 이동
2.1.2 IP, 이름 및 비밀번호 확인

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/2-1.jpg" width="80%" />

### 2.2 App에서 조작
#### 2.2.1 휴대폰의 시스템 Wi-Fi로 직접 연결
AP 모드의 이름(Wi-Fi 이름)과 비밀번호에 따라 시스템 Wi-Fi 목록에서 연결합니다

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/2-2-1.jpg" width="80%" />

#### 2.2.2 직접 연결 IP를 입력하여 로그인
로그인 시 AP 모드의 IP와 해당 계정 및 비밀번호로 로그인합니다

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/2-2-2.jpg" width="80%" />

## 3. 연결되지 않음
### 3.1 작은 화면에서 확인
장치 설정 -> 장치 정보
스와이프하여 이름 확인

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/3-1.jpg" width="80%" />

### 3.2 App에서 조작
#### 3.2.1 장치 네트워크 설정에서 연결
장치 정보의 이름에 따라 장치 목록에서 해당 이름을 찾아 클릭하여 연결합니다

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/3-2-1-1.jpg" width="40%" />
<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/3-2-1-2.jpg" width="40%" />

#### 3.2.2 설정된 네트워크 IP를 입력하여 로그인
설정 완료 후 로그인 화면으로 돌아갑니다
자동 입력된 IP 또는 작은 화면의 장치 정보 IP와 해당 계정 및 비밀번호로 로그인합니다

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/3-2-2-1.jpg" width="80%" />
<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/3-2-2-2.jpg" width="80%" />

## 4. 네트워크에 연결됨
### 4.1 IP 로그인
휴대폰과 장치가 동일한 네트워크에 있는지 확인합니다
작은 화면의 장치 정보 IP를 사용하여 해당 계정과 비밀번호를 입력하고 로그인합니다
3.2.2 단계와 동일합니다

### 4.2 StationID 로그인
활성화 시의 StationID 정보(일반적으로 휴대폰 번호 또는 이메일)를 사용합니다
로그인 화면에서 StationID와 비밀번호를 입력하여 로그인합니다

<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/4-2-1.jpg" width="40%" />
<img src="/images/ko/portable/troubleshooting/app-client-connect-issue/4-2-2.jpg" width="40%" />

#### 4.2.1 주의
StationID 앞뒤에 공백이 없는지, 원격 로그인 활성화 시와 일치하는지 확인하세요

## 5. 여전히 연결할 수 없는 경우
장치 연결 실패 화면에서 피드백으로 이동하여 로그를 업로드합니다
