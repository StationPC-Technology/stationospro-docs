PocketCloud에 연결을 시도할 때 실패 문제가 발생하면, '먼저 장치 상태를 확인하고, 그 다음 네트워크 환경을 점검'하는 단계에 따라 원인을 파악하여 문제를 효율적으로 해결할 수 있습니다.

> 문제를 해결할 때는 모바일 앱을 우선 사용하도록 권장합니다

## 1. 장비 하드웨어 상태 확인
- **PocketCloud 켜기 및 배터리 잔량**
장치가 정상적으로 켜져 있는지 확인하십시오(화면이 켜져 있으며, 검은 화면이나 깜박임 등의 이상 현상이 없음). 배터리 잔량이 20% 이상일 때 연결을 시도하는 것이 좋으며, 배터리가 부족할 경우 먼저 전원을 연결한 다음 조작하여 배터리 부족으로 인해 장치가 절전 모드로 들어가는 것을 방지하십시오.

- **PocketCloud 네트워크 상태 확인**
- WIFI에 연결된 경우: 기기 작은 화면을 통해 네트워크 연결 상태(예: '연결됨', '신호 강도') 및 해당 IP 주소를 확인하여 WIFI가 끊기지 않았는지 확인합니다.
- 유선 네트워크에 연결된 경우: 장치 상태 표시등으로 확인 (녹색 불이 계속 켜짐=네트워크 정상, 빨간 불이 깜빡임=케이블이 제대로 연결되지 않았거나 네트워크 이상), 케이블을 다시 끼웠다 뺐다 하며 확인할 수 있습니다.

## 2. 네트워크 환경 기본 점검

### 1. 문제 상황: PocketCloud을(를) 스캔할 수 없음
- WIFI 직결 모드
- 장치의 'WIFI 직접 연결 기능'이 켜져 있는지 확인: 장치 화면에서 [설정]-[연결 방식]으로 이동하여 'WIFI 직접 연결 스캔 허용'을 선택하십시오(일부 기종은 기본적으로 꺼져 있음).
- 연결 거리 제어: 휴대폰과 PocketCloud는 1미터 범위 내에 있어야 하며, 거리가 멀어지면 신호가 약해질 수 있습니다. 동시에 휴대폰의 '블루투스'와 '핫스팟 공유'를 꺼서 신호 간섭을 방지하세요.
- 클라이언트 재시작: PocketCloud APP을 종료하고, 휴대폰 백그라운드에서 프로세스를 완전히 제거한 후, 다시 열고【Direct Device】를 클릭하여 스캔하고, APP 캐시 문제를 해결합니다.

- 로컬 영역 네트워크 모드
- IP 주소 유효성 검사:
① 장치의 작은 화면을 통해 공식 IP(경로: 【장치 정보】-【네트워크 설정】-【로컬 네트워크 IP】, 예: 192.168.1.40)을 확인합니다；
② 라우터 백엔드나 서드파티 도구를 통해 IP를 획득한 경우, 공식 IP와 비교해야 하며, '장치 현재 IP가 아닌 것'을 사용하지 않도록 해야 합니다(라우터 재부팅 시 IP가 변경될 수 있습니다).
- VPN/프록시 끄기: 휴대폰이나 컴퓨터의 VPN/프록시는 네트워크 경로를 변경하여 로컬 네트워크 내 장치에 접근할 수 없게 할 수 있으므로, 완전히 끈 후 다시 시도해야 합니다.
- 동일한 로컬 네트워크 확인: 휴대폰/컴퓨터가 PocketCloud와 동일한 로컬 네트워크에 연결되어 있는지 확인하세요(주파수 혼선 연결을 피하세요. 예: 휴대폰은 5G Wi-Fi, 장치는 2.4G Wi-Fi 연결).

### 2. 문제 상황: 장치는 찾을 수 있지만 연결 시간 초과/실패
- 계정 비밀번호 인증 문제
- 계정 비밀번호 확인: 입력한 계정 비밀번호가 PocketCloud에 연결된 계정과 일치하는지 확인하세요. 비밀번호를 잊으셨다면 APP 로그인 페이지에서 '비밀번호를 잊으셨나요'를 클릭하여, 연결된 이메일/휴대폰으로 전송된 인증 코드를 통해 비밀번호를 재설정할 수 있습니다. 재설정 후 5분 이내에 다시 시도하는 것이 좋습니다.
- 계정 권한 구분: '장치 관리자 계정'만 최초 연결을 시작할 권한이 있습니다; '방문자 계정'은 관리자에 의해 장치의 【권한 설정】에서 먼저 승인되어야 하며, 승인 후에야 정상적으로 연결할 수 있습니다.

- 포트와 주소 충돌
- IP 주소 입력을 확인하세요:
① IP(예: 192.168.1.40)를 수동으로 입력할 때, 입력 오류가 없는지(예: 잘못 입력하여 192.168.0.40이 된 경우) 확인하고, 추가 문자가 없도록 합니다;
② 주소에 포트 번호가 포함된 경우(예: 192.168.1.40:8080), 포트 번호가 장치 기본 포트인지 확인해야 합니다(【네트워크 설정】-【포트 구성】에서 확인 가능). 기본 포트가 아닌 경우 APP 연결 페이지에서 수동으로 입력해야 합니다.
- 포트 사용 여부 확인: 만약 로컬 네트워크 내 다른 장치가 '32400', '8096', '8080' 등의 일반 포트를 사용 중이라면, 장치의 [네트워크 설정]-[포트 구성]에 들어가 기본 포트를 사용되지 않은 포트로 변경합니다(예: 8080을 8081로 변경). 변경 후 장치를 재시작한 다음 연결을 시도합니다.
