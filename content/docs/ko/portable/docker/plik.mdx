## 소개
Plik은 오픈 소스, 경량, 안전한 임시 파일 공유 서비스로, **순수 웹 사용을 지원**하며, 브라우저를 열면 파일 업로드, 공유, 전송을 완료할 수 있습니다. Docker와 함께 사용하면 복잡한 설정 없이 빠르게 개인 임시 파일 중계 서버를 구축할 수 있으며, 간단하고 사용하기 쉬우면서도 개인정보 보호를 보장합니다.

## 사용 시나리오
- 장치 간 임시 파일 전송, 휴대폰과 컴퓨터가 바로 연결, 클라이언트 설치 불필요
- 동료, 친구 사이에 파일을 빠르게 공유하고, 바로 사용 후 떠날 수 있어 효율적이고 편리합니다
- 개인 문서를 공용 클라우드에 업로드하고 싶지 않다면, 자체 서버를 구축하는 것이 더 안전하고 통제 가능합니다
- 임시로 작업 자료인 로그, 설치 패키지, 설정 파일 등을 공유

## 기능 특징
- 순수 웹 접근, 모든 플랫폼에서 사용 가능, APP 설치 불필요, 조작 난이도 낮음
- CLI 클라이언트 조작을 지원하며, 명령어로 파일 업로드 및 관리를 완료할 수 있습니다
- 파일 암호화를 지원하며, 공유 비밀번호를 설정하여 파일 보안을 보장할 수 있습니다
- 파일 만료 시간과 다운로드 횟수를 사용자 정의할 수 있으며, '열람 후 즉시 삭제'(OneShot)를 지원합니다
- 원클릭으로 공유 링크 생성, 언제든지 공유를 비활성화할 수 있어 유연하게 제어 가능
- 자원 점유가 낮고, Docker 원클릭 배포, 유지 관리 비용이 낮음

## 배포 튜토리얼
### Plik 컨테이너 생성
1. Docker 화면에 들어가서 'Images'(이미지)를 클릭하고, 검색창에 'plik'을 입력한 후 해당 이미지를 찾아 다운로드를 클릭합니다.
    <img src="/images/common/portable/docker/plik/1-2.png" width="100%" />

2. 이미지 다운로드가 완료되면 'Containers'(컨테이너) 페이지로 이동하여 '컨테이너 생성'을 클릭하고 'rootgg/plik' 이미지를 선택한 후 '다음'을 클릭합니다.
> 따뜻한 알림: 컨테이너가 장치 부팅 시 자동으로 시작되도록 하려면, 페이지에서 '부팅 시 시작' 옵션을 선택하면 됩니다.
    <img src="/images/common/portable/docker/plik/1-3.png" width="100%" />

3. 경로 매핑 설정, 경로 매핑 추가를 클릭
* 업로드 파일 저장: 로컬 저장 경로 'My Files/upload'를 생성하고, 컨테이너 내 경로 '/root/files'를 로컬 경로 'My Files/upload'에 매핑
    

4. 모든 설정을 확인한 후, 『확인』을 클릭하고 『생성 후 시작』을 선택하면 Plik 컨테이너의 생성과 시작이 완료됩니다.
    <img src="/images/common/portable/docker/plik/1-4.png" width="100%" />

## Plik의 기본 사용
### 1. Plik 방문:

<img src="/images/common/portable/docker/plik/1-6.png" width="100%" />

접속 주소: http://IP:8080/，将IP替换为自己的服务器（或PocketCloud设备）IP地址；
> 주의: PocketCloud 장치인 경우, 장치 자체의 IP를 직접 사용하면 됩니다;
> 배포 시 포트를 변경했다면, 접근 주소의 포트 번호도 이에 맞게 조정해야 합니다.

### 2. Plik 설정:
필요에 따라 관련 구성을 할 수 있습니다.
<img src="/images/common/portable/docker/plik/1-7.png" width="100%" />

| 설정 항목 | 설명 |
| ---- | ---- |
| 다운로드 후 파기 | 파일은 한 번 다운로드되면 영구적으로 삭제됩니다 |
| 스트리밍 | 파일을 서버에 저장하지 않고 다운로드자에게 바로 스트리밍 |
| 삭제 가능 | 링크를 가진 사람은 업로드된 파일을 삭제할 수 있음 |
| 종단 간 암호화 | 업로드 전에 파일이 암호화되며, 비밀번호를 가진 사람만 해독할 수 있음 |
| 비밀번호 보호 | HTTP 기본 인증을 통해 접근 비밀번호를 설정하여 안전을 보장 |
| 비고 | 업로드한 내용에 댓글 추가를 지원 |
| 만료 시간 | 파일 유효 기간을 설정하며, 만료되면 자동으로 무효화 |

#### 3.  파일 업로드
파일을 웹페이지 업로드 영역으로 직접 드래그하거나 '파일 선택'을 클릭하여 업로드하세요.
#### 4.  파일 공유
업로드가 완료된 후, 페이지에서 생성된 공유 링크를 복사하고, 링크를 클릭하면 다운로드할 수 있습니다.
