사용자가 Docker 컨테이너의 배포 및 사용 과정을 간소화하기 위해, 사용자는 복잡한 Docker 이미지 선택, 구성 및 호환성 테스트를 스스로 연구할 필요 없이, 애플리케이션 센터를 통해 적합한 컨테이너 애플리케이션을 신속하게 얻어 손쉽게 배포 및 사용을 완료할 수 있으며, Docker 애플리케이션 사용 장벽을 크게 낮출 수 있습니다.

> 주의: 컨테이너 응용 프로그램은 로컬 네트워크 환경에서만 열 수 있습니다. PocketCloud와 클라이언트 장치가 동일한 로컬 네트워크에 있는지 확인하십시오.

## 컨테이너 애플리케이션 설치
### 설치 전 준비
컨테이너 애플리케이션을 처음 설치할 때, Docker의 관련 설정을 초기화하고 저장 공간을 할당해야 합니다.
1. 앱을 열고, **홈 > 자주 사용하는 기능 > Docker**으로 이동합니다；
2. 안내에 따라 조작하여 저장 공간을 할당합니다.

> 주의:
> * 사용 가능한 저장 공간은 20GB 이상이어야 하며, 이 용량보다 적으면 설치를 완료할 수 없습니다;
> * 저장 공간은 할당 후 용량 확장만 가능하며 축소는 지원되지 않습니다. 실제 사용 요구에 따라 합리적으로 분배하고 여유 공간을 남겨두는 것을 권장합니다；
> * 공간 할당 과정이 시간이 오래 걸릴 수 있으니 잠시 기다려 주세요. 다른 업무를 임시로 처리해야 할 경우 할당 화면을 나가도 할당 작업은 백그라운드에서 계속 진행됩니다.

### 앱 설치
1. **앱 센터**에 들어갑니다；
2. 설치해야 할 애플리케이션 컨테이너를 찾습니다；
3. '설치'를 클릭하고 시스템이 자동으로 설치 및 배포를 완료할 때까지 기다립니다. 설치가 완료되면 컨테이너 애플리케이션은 Docker에 해당 컨테이너를 생성합니다.

## 컨테이너 애플리케이션 방문
### 여는 방법
* 클라이언트를 통해 접근: 컨테이너 애플리케이션은 **애플리케이션 센터**를 통해 접근할 수 있습니다;
* 웹을 통해 접속: 동일한 로컬 네트워크 내에서, 장치 IP와 애플리케이션 포트 번호를 통해 접속할 수 있습니다.

> 주의:
> * 애플리케이션 포트는 애플리케이션 상세 정보에서 확인할 수 있습니다；
> * 그림에 표시된 IP 주소는 예시이며, 귀하의 장치 IP로 교체해야 합니다.

### 주의 사항
#### 애플리케이션 접근 가능 디렉토리
* 실제 디렉토리: 주 디스크의 @docker 디렉토리에 위치합니다. Jellyfin를 예로 들면, 실제 디렉토리는 @docker/jellyfin/data/입니다.;
* 매핑 디렉토리:
* 애플리케이션 디렉토리를 /data로 매핑합니다;
* 메인 디스크 디렉토리는 /pocketcloud로 매핑됩니다. 응용 프로그램이 메인 디스크 디렉토리를 마운트할 때 메인 디스크 루트 디렉토리를 마운트하지 않도록 주의하세요.
> 주의: 애플리케이션이 주 디스크 디렉토리를 마운트할 때, 주 디스크 루트 디렉토리를 직접 마운트하지 마십시오. 장치의 정상 작동에 영향을 줄 수 있습니다.
  
#### Jellyfin 주의사항
1. 미디어 라이브러리 추가
* 콘솔에 들어가 → 미디어 라이브러리 → 미디어 라이브러리 추가;
* '폴더 추가'를 클릭하고 경로를 선택합니다:
* 애플리케이션 매핑 디렉터리: / → data 선택；
* 주 드라이브 매핑 디렉토리: / → pocketcloud 선택 → 대상 폴더 선택.

2. 삭제 후 다시 설치할 때 서버 선택 연결 문제를提示
Jellyfin를 제거한 후 다시 설치하면 등록 화면이 표시되지 않을 수 있으며, 진입하면 서버를 선택하여 연결하라는 메시지가 표시됩니다.
해결 방법:
* 서버 아이콘을 길게 눌러 작업 메뉴를 불러옵니다；
* “삭제”를 클릭하여 Jellyfin에서 나갑니다；
* Jellyfin를 다시 열면 등록 화면이 나타나며, 새로운 계정을 생성할 수 있습니다.

3. 제거 후 다시 설치했을 때 사용자 등록이 되지 않는 문제
Jellyfin를 제거한 후 다시 설치하면 등록 화면이 표시되지 않고 바로 로그인 화면으로 들어갈 수 있습니다(하지만 계정 비밀번호는 설정되지 않았습니다).
해결 방법:
* 시크릿 브라우저를 사용하여 장치 IP+ 포트 번호(예: 192.168.10.140:35000)에 접속합니다;
* 이때 등록 화면을 볼 수 있으며, 새 계정을 만들면 됩니다.

#### Syncthing 주의사항
* 폴더를 추가할 때 경로는 반드시 data로 입력해야 하며, 그렇지 않으면 인식되지 않습니다;
* @/docker/syncthing/data에서 동기화된 데이터를 확인합니다.

#### 전송 주의 사항
* 시드 파일이나 시드 링크 추가를 지원합니다;
* 다운로드한 파일은 @docker/transmission에 해당하는 폴더에 저장됩니다.
