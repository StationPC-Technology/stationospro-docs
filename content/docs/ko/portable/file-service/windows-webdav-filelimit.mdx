title: "Windows 서비스에 접속할 때, 50M 이상의 파일은 오류가 발생합니다(오류:0x800700DF)"
---

Windows에서 WebDAV를 사용할 때, 50MB를 초과하는 파일을 열거나 복사하려고 하면 ```0x800700DF``` 오류가 표시됩니다. 이는 Windows WebDAV 클라이언트의 기본 파일 크기 제한이 50MB이기 때문입니다. 레지스트리를 수정하여 제한을 높일 수 있습니다:

1. Win + R을 눌러 '실행' 대화 상자를 열고, 입력란에 ```regedit```를 입력한 다음 '엔터' 키를 누릅니다.

2. 레지스트리 편집기에서 ```HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters``` 경로로 이동합니다.

<img src="/images/common/portable/file-service/windows-webdav-filelimit/1-1.png" width="100%" />

3. 오른쪽 창에서 ```FileSizeLimitInBytes``` 항목을 찾습니다. 항목이 존재하지 않으면, 빈 곳에서 마우스 오른쪽 버튼을 클릭하고 '새로 만들기' > 'DWORD(32비트) 값'을 선택합니다.

4. 그 중 수치 데이터에 해당하는 텍스트 상자를 ```ffffffff```로 바꾸거나, '십진법'을 선택하고 4294967295(최대값 약 4GB)를 입력합니다. 그런 다음 '확인'을 클릭하여 변경 사항을 저장합니다.

5. 컴퓨터를 재시작하여 변경 사항을 적용합니다.

6. 재시작한 후 대용량 파일을 다시 복사하거나 편집하여 변경 사항이 적용되었는지 확인합니다.
