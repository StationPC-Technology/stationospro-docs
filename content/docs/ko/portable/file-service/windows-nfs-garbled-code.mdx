---

> 중국어 깨짐 현상은 일반적으로 인코딩 불일치 또는 시스템 지역 설정 문제로 인해 발생하며, Windows에서 NFS로 매핑된 디스크의 중국어 깨짐 문제에 대해, 테스트 결과 다음 방법으로 해결할 수 있습니다:

> 단계：

1. **제어판** → **시계 및 지역** → **지역**을 엽니다.
2. **관리** 탭으로 전환하고, **시스템 지역 설정 변경**을 클릭합니다.
3. **“중국어(간체, 중국)”**를 선택했는지 확인하세요. 목록 맨 아래의 **Beta 옵션**을 선택하세요.
<img src="/images/common/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. 수정 후 시스템을 재시작하고, NFS 디스크를 다시 마운트한 후, 중국어가 정상적으로 표시되는지 확인합니다.
