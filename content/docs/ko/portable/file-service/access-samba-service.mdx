Samba은 SMB/CIFS(서버 메시지 블록 / 공용 인터넷 파일 시스템) 프로토콜을 기반으로 한 파일 공유 서비스로, Linux, macOS 및 Windows 시스템 간의 파일 및 프린터 공유에 널리 사용됩니다.
Samba를 통해 사용자는 로컬 파일에 접근하듯 원격 서버의 공유 디렉토리에 접근하여 크로스 플랫폼 파일 공유와 협업을 실현할 수 있습니다.

**주요 기능은 다음과 같습니다:**
1. 파일 공유: 사용자가 네트워크에서 공유 파일이나 폴더에 접근하고, 업로드하며, 다운로드하고, 관리할 수 있도록 허용합니다.
2. 프린터 공유: 네트워크를 통해 프린터를 공유할 수 있어 여러 장치가 동일한 프린터 자원을 편리하게 사용할 수 있습니다.
3. 사용자 권한 제어: 서로 다른 사용자 또는 사용자 그룹의 접근 권한을 설정하여 데이터 보안을 보장할 수 있습니다.
4. 크로스 플랫폼 접근: Windows, Linux, macOS 등 주요 운영 체제를 호환하며, 다양한 클라이언트 접속을 지원합니다.

## Samba 활성화

Samba 기본적으로 꺼져 있으며 수동으로 활성화해야 합니다. 다음 단계를 따라 주세요:

1. App의 **파일 공유 프로토콜** 페이지를 엽니다. <br />
2. **Samba 서비스**를 클릭합니다. <br />
3. **스위치 버튼**을 켜면 **Samba 서비스**를 사용할 수 있습니다. <br />

## Windows에서 방문

### 방법 1

1. **Win + R** 조합 키를 누릅니다.
2. `\\NAS设备IP`를 입력한 후, **확인**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/1-1.png" width="100%" height="100%" />
3. 사용자 이름과 비밀번호를 입력하고, **확인**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-nfs-service/5-3.png" width="100%" height="100%" />
4. 이제 **파일 탐색기**에서 로컬 폴더를 탐색하듯 NAS의 파일을 탐색하고 관리할 수 있습니다.
   <img src="/images/common/portable/file-service/access-samba-service/1-3.png" width="100%" height="100%" />

### 방법 2

1. **파일 탐색기**를 엽니다.
2. **네트워크**를 마우스 오른쪽 버튼으로 클릭하고 **네트워크 드라이브 연결**을 선택합니다.
   <img src="/images/common/portable/file-service/access-samba-service/9-1.png" width="100%" height="100%" />
3. `\\NAS_장치_IP\관리자_이름`을 입력한 후 **마침**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/9-2.png" width="100%" height="100%" />
4. 사용자 이름과 비밀번호를 입력하고, **확인**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/9-3.png" width="100%" height="100%" />
5. 이제 **파일 탐색기**에서 로컬 폴더를 탐색하듯 NAS의 파일을 탐색하고 관리할 수 있습니다.
   <img src="/images/common/portable/file-service/access-samba-service/9-4.png" width="100%" height="100%" />

## iOS에서 방문

1. **파일** App를 엽니다.
2. 오른쪽 상단의 **“...”** 아이콘을 클릭하고, **서버 연결**을 선택합니다.
   <img src="/images/common/portable/file-service/access-samba-service/2-1.png" width="240" height="500" />
3. `smb://NAS设备IP`를 입력하고 **연결**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/2-2.png" width="240" height="500" />
4. 사용자 이름과 비밀번호를 입력하고, **다음**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/2-3.png" width="240" height="500" />
5. 이제, 당신은 **파일** App에서 로컬 폴더에 접근하듯이 NAS의 파일을 탐색하고 관리할 수 있습니다.
   <img src="/images/common/portable/file-service/access-samba-service/2-4.png" width="240" height="500" />

## macOS에서 방문

1. 오른쪽 클릭으로 **파인더(Finder)**를 선택하고, 메뉴 막대에서 **이동 → 서버에 연결**을 선택합니다.
   <img src="/images/common/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. 서버 주소 입력란에 `smb://NAS设备IP`를 입력한 다음, **연결**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/3-2.png" width="100%" height="100%" />
3. 사용자 이름과 비밀번호를 입력하고 **연결**을 클릭합니다.
   <img src="/images/common/portable/file-service/access-samba-service/3-3.png" width="100%" height="100%" />
4. 이제 Finder에서 로컬 폴더를 탐색하듯이 NAS의 파일을 탐색하고 관리할 수 있습니다.
   <img src="/images/common/portable/file-service/access-samba-service/3-4.png" width="100%" height="100%" />

## 리눅스에서 접근

**cifs-utils**를 사용하여 Samba 공유를 마운트:

```bash
# 安装 cifs-utils
sudo apt-get install cifs-utils

# 创建挂载点
# 示例：将 /mnt/samba_share 作为挂载目录
sudo mkdir -p /mnt/samba_share

# 挂载 Samba 共享目录
sudo mount -t cifs //NAS设备IP/共享目录 /mnt/samba_share -o username=用户名,password=密码

# 挂载成功后，你可以在 /mnt/samba_share 目录中访问和管理 NAS 上的文件
```

## 기타 클라이언트에서 접근
- 연결 정보
    - IP: NAS 장치 IP
    - 포트: 기본값은 445
    - 계정: NAS 장치 로그인 사용자 이름
    - 비밀번호: NAS 장치 로그인 비밀번호
- 마운트 디렉터리 설명
    - 메인 SSD: `/로그인 사용자 이름`
      - 예 1: 모든 디렉터리. 현재 사용자가 test인 경우 마운트 디렉터리는 `/test`
      - 예 2: 지정 디렉터리. 현재 사용자가 test인 경우 마운트 디렉터리는 `/test/Pictures`
      - 기타: 다중 사용자를 지원하며 각 사용자는 하나의 마운트 디렉터리에 대응합니다
    - 외부 저장소: `/외부 저장소 이름`
      - 예 1: 모든 디렉터리. 외부 SD 카드 이름이 SD 60GB BA26인 경우 마운트 디렉터리는 `/SD_60GB_BA26`
      - 예 2: 지정 디렉터리. 외부 SD 카드 이름이 SD 60GB BA26인 경우 마운트 디렉터리는 `/SD_60GB_BA26/Pictures`
    - ⚠️ 주의:
      - 일부 클라이언트는 루트 디렉터리 `/` 만 입력할 수 없으므로 위의 해당 구체적인 마운트 디렉터리를 지정해야 합니다
      - 펌웨어 &lt;= 3.1.0.16에서 최신 펌웨어로 업그레이드한 후에는 마운트 디렉터리가 조정됩니다. 새 버전의 마운트 방식을 기준으로 사용하세요
