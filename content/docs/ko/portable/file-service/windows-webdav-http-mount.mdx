- 위 문제를 일으킨 원인은 사실 매우 간단합니다. Windows 기본 WebClient 서비스는 https 프로토콜만 지원하며, 로컬에 구축된 WebDAV 서비스와 링크는 모두 http 프로토콜을 기반으로 하고 있기 때문에 마운트 실패 상황이 발생한 것입니다.

## WebClient 설정, http 링크 마운트 허용

1. '윈도우 로고 키' + 'R'을 눌러 실행 창을 열고, regedit를 입력한 후 확인을 클릭하면 레지스트리 편집기 창이 열립니다.
2. 경로를 다음 경로로 이동합니다: 컴퓨터\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters. 오른쪽 창에서 BasicAuthLevel 항목을 두 번 클릭하고, 값 데이터를 "2"로 변경한 후 확인을 클릭하고 레지스트리 편집기를 닫습니다.

<img src="/images/common/portable/file-service/windows-webdav-http-mount/1-2.png" width="60%" />

3. “윈도우 로고 키” + “R”을 눌러 실행 창을 열고, services.msc를 입력한 후 확인을 클릭하여 “서비스” 화면을 엽니다. 그런 다음 “WebClient”를 찾습니다.
서비스에서 마우스 오른쪽 버튼을 클릭하여 옵션 메뉴를 열고, '다시 시작'을 선택한 후, 잠시 몇 초 기다립니다. 완료되면 '서비스' 화면을 닫습니다.

<img src="/images/common/portable/file-service/windows-webdav-http-mount/1-3.png" width="60%" />

위의 세 단계를 완료한 후, WebClient 서비스는 이미 HTTP 프로토콜을 사용한 마운트를 허용합니다.
