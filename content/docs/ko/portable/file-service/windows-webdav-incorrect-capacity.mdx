title: "Windows가 WebDAV 서비스에 접속할 때, 마운트 후 용량이 비정상적으로 표시됩니다"
---

이 문제는 Windows 자체 내장 WebClient 구성 요소가 WebDAV 서버의 실제 저장 용량을 가져올 수 없기 때문에 발생합니다. WebDAV 네트워크 드라이브를 마운트할 때, 시스템이 원격 저장 공간 할당량 데이터를 가져올 수 없으면 기본적으로 로컬 시스템 드라이브(C 드라이브) 용량 정보를 읽어 매핑된 드라이브 문자에 표시하게 되며, 결과적으로 디스크 용량 표시가 비정상적으로 나타납니다.

용량 표시 문제를 해결해야 하는 경우, 타사 도구인 RaiDrive, CloudMounter 등을 사용하는 것이 좋습니다.
