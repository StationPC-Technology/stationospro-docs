이메일 알림 서비스는 시스템이 이메일을 보낼 수 있는 권한을 부여할 수 있으며, 예를 들어 이중 인증 긴급 인증 코드 이메일 및 비밀번호 재설정 이메일 등을 보낼 수 있습니다.

>현재 지원되는 이메일 서비스 제공업체: Gmail, Yahoo, Apple, QQ, 163, 및 사용자 정의 SMTP 서버.

## 이메일 알림 서비스 활성화

1. 당신은 **장치 > 메시지 알림 > 이메일 알림**에서 이메일 알림 서비스를 켤 수 있습니다.
2. 자신의 실제 상황에 따라 적합한 이메일 서비스 제공업체를 선택하고, 아래 방식에 따라 해당 이메일 서비스의 인증 코드를 받아 제출하여 설정을 완료합니다.
3. 설정이 완료된 후, 테스트 메일을 보내 이메일 서비스가 성공적으로 승인되었는지 확인합니다.

## 이메일 인증 코드 받는 방법
### Gmail
1. [myaccount.google.com](myaccount.google.com)에 접속하여 Google 계정 관리 페이지로 이동합니다. 검색 아이콘을 클릭하고 **앱 전용 비밀번호**를 입력한 후, 검색 결과를 클릭하여 설정 페이지로 이동합니다.
<img src="/images/common/portable/setting/setup-smtp/2-1-1.png" width="100%" />

2. 사용자 지정 앱 이름을 입력하고, '생성'을 클릭하면 인증 코드를 생성할 수 있습니다.
<img src="/images/common/portable/setting/setup-smtp/2-1-2.png" width="100%" />

### Apple
1. Apple ID 공식 웹사이트 방문: [appleid.apple.com](appleid.apple.com), 당신의 Apple ID 계정으로 로그인하세요.

2. 「로그인 및 보안 > App 전용 비밀번호」 페이지로 들어갑니다.
<img src="/images/common/portable/setting/setup-smtp/2-2-1.png" width="100%" />

3. 「App 전용 비밀번호 생성」을 클릭합니다.
<img src="/images/common/portable/setting/setup-smtp/2-2-2.png" width="100%" />

4. 레이블에 해당 비밀번호 이름을 입력합니다(예: StationPC), 그리고 '생성'을 클릭합니다.

### Yahoo
1. 당신의 [Yahoo 계정 보안 페이지](https://login.yahoo.com/?done=https%3A%2F%2Flogin.yahoo.com%2Fmyaccount%2Fsecurity%3F.lang%3Den-US%26.intl%3Dus%26.src%3Dyhelp%26.scrumb%3D0&src=mc&.intl=us&.lang=en-US)에 로그인하세요.
2. '외부 연결' 항목에서 '앱 비밀번호 생성'을 클릭합니다.
3. 텍스트 상자에 애플리케이션 이름을 입력합니다.
4. 「비밀번호 생성」을 클릭합니다.
5. 생성된 일회용 비밀번호를 사용하여 제3자 애플리케이션에 로그인합니다.
