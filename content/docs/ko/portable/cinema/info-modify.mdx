영화관 섹션에서, 만약 영화 정보 자동 스크래핑에 오류가 발생하면, 수동 매칭 기능을 통해 영화 정보를 수정할 수 있습니다.

## 수동 매칭 작업 단계
1. 잘못된 정보가 있는 영상을 찾아서 상세 페이지를 클릭합니다.
2. 페이지 오른쪽 상단의 메뉴 버튼을 클릭하고 **수동 인식** 옵션을 선택합니다.
3. 올바른 영화 제목을 입력하고 검색을 클릭하세요. 검색 결과에는 여러 유사한 영화가 포함될 수 있으므로, 해당하는 올바른 영화를 선택한 후 **확인**을 클릭하면 정보 수정이 완료됩니다.
