새로운 영화 파일이 표시되지 않거나, 영화 메타데이터가 혼란스러우며, 영화를 삭제한 후에도 기록이 남아 있는 경우에는 **미디어 라이브러리 새로고침**을 통해 최신 상태를 동기화하여 영화관 기능이 영화 콘텐츠를 정확하게 인식하고 표시할 수 있도록 할 수 있습니다.
> 주의:
> * U 디스크 모드를 통해 미디어 라이브러리 파일을 추가, 삭제, 수정한 후에는 변경 사항을 동기화하기 위해 수동으로 미디어 라이브러리를 새로 고쳐야 합니다.

## 미디어 라이브러리를 수동으로 새로 고치는 방법?
1. 클라이언트를 열고, **영화관** 모듈로 들어갑니다;
2. **설정 > 시네마 라이브러리 설정** 페이지로 들어가서, 새로 고침이 필요한 시네마 라이브러리를 찾습니다;
3. 더보기 아이콘을 클릭하면 기능 메뉴가 나타납니다；
4. 미디어 라이브러리 파일 스캔을 클릭하면, 시스템이 자동으로 해당 미디어 라이브러리의 모든 파일을 스캔하고, 새로 추가, 삭제, 수정된 영화 및 TV 자료를 동기화하며, 영화/TV 메타데이터를 다시 검증/보완합니다.

## 미디어 라이브러리 새로 고침 시 주의 사항
- 자동 새로고침 메커니즘: 컴퓨터/휴대폰을 통해 미디어 라이브러리의 해당 폴더에 새로운 영화 파일을 업로드하면, 시스템은 기본적으로 '자동 새로고침'을 트리거하며, 일반적으로 수동으로 조작할 필요가 없습니다. 단, 자동 동기화가 실패할 경우(예: USB 모드 업로드), 그때 수동으로 새로고침을 실행하면 됩니다.
- 새로 고침 소요 시간은 영상 리소스 규모와 관련 있음: 스캔 과정은 백그라운드에서 계속 진행되며, 소요 시간은 비디오 리소스의 규모와 관련이 있음(비디오가 많을수록 소요 시간이 길어짐). 진행 상황을 확인하려면 **영화관 홈 > 상단 메뉴**를 통해 처리 상태를 확인할 수 있음.
