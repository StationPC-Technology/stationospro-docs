title: "하위 사용자는 어떻게 생성하나요?"
---

PocketCloud에서, 당신은 여러 하위 사용자 계정을 생성할 수 있어, 여러 사람이 함께 사용하기 편리합니다.

> 주의:
> * 서로 다른 하위 사용자는 독립적인 공간을 가지며, 서로 직접 접근할 수 없습니다.
> * 서로 다른 하위 사용자는 로컬 공유를 통해 데이터 접근을 실현할 수 있습니다
> * 관리자는 하위 사용자 데이터를 볼 수 없습니다
> * 하위 사용자는 영화관 기능을 지원합니다

1. 관리자 계정으로 클라이언트에 로그인한 후 **장치** 페이지로 이동하고, **사용자 관리 > 사용자**를 열어 '+'를 클릭하여 사용자를 새로 추가합니다.

<img src="/images/common/portable/guides/create-user/create-user-1.jpg" width="30%" />
<img src="/images/common/portable/guides/create-user/create-user-2.jpg" width="30%" />

2. 하위 사용자 계정을 생성하고, 필요에 따라 사용자 권한을 설정합니다.

<img src="/images/common/portable/guides/create-user/create-user-3.jpg" width="30%" />
<img src="/images/common/portable/guides/create-user/create-user-4.jpg" width="30%" />

3. 하위 사용자를 새로 만들고 나면, 빨간 테두리 부분을 클릭하여 편집하거나 삭제할 수 있습니다.
