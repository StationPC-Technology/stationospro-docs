웹 클라이언트(Beta)는 브라우저를 통해 직접 장치를 액세스하고 관리할 수 있게 해주며, 데스크탑 또는 모바일 애플리케이션을 설치할 필요가 없습니다. 두 가지 액세스 방식을 지원합니다: **로컬 네트워크 액세스**와 **원격 액세스**, 이는 다양한 상황에서의 사용 요구를 충족시킵니다.

## 전제 조건
1. 장치가 켜져 있고 정상적으로 네트워크에 연결되어 있는지 확인하세요.
2. 원격 접속이 필요한 경우, 먼저 클라이언트 애플리케이션에서 [원격 접속 기능 활성화](/portable/pocketcloud/remote-access)하고 Station ID 설정을 완료하십시오.

## 방문 방법
### 방법 1: 로컬 네트워크 접근
컴퓨터와 장치가 동일한 로컬 네트워크(동일한 WiFi / 유선 네트워크)에 있는 환경에 적합하며, 접근 속도가 더 빠르고 안정성이 더 높습니다.

조작 단계:
1. 장치의 로컬 네트워크 IP 주소 가져오기: 장치 자체 화면에서 확인하거나 클라이언트 애플리케이션의 **장치 정보** 페이지에서 확인할 수 있습니다.
2. 브라우저를 열고 주소창에 `http://设备IP:9500` 형식의 주소를 입력합니다.
3. 로그인 페이지에서 사용자 이름과 비밀번호를 입력하면 웹 관리 인터페이스에 들어갈 수 있습니다.

> 예시: 장치 IP가 `192.168.3.10`인 경우, 주소 창에 `http://192.168.3.10:9500`를 입력합니다.

### 방법 2: 원격 접속
출장, 외근 사무 등 외부 네트워크 환경에 적합합니다. 공식 원격 접속 포털을 통해 집이나 사무실의 장비에 접속할 수 있습니다.

조작 단계:
1. 원격 액세스 기능을 활성화합니다.
2. 브라우저를 열고 공식 원격 접속 주소를 입력하세요: `https://login.stationpc.com/`
3. 로그인 페이지에서 귀하의 Station ID, 사용자 이름 및 비밀번호를 입력하고, 인증이 통과되면 장치에 액세스할 수 있습니다.

## 지원하는 브라우저
기능의 완전성과 최적의 사용 경험을 보장하기 위해, 다음 브라우저(또는 그 이상의 버전)를 사용하여 웹 클라이언트에 접속하는 것을 권장합니다:
1. Chrome 50 이상 버전
2. Microsoft Edge 78 이상 버전
3. QQ 브라우저 속도버전, 360 브라우저 속도버전
4. Firefox 54 이상 버전
5. Safari 10 이상 버전(Mac)

## 주의 사항
1. 웹 클라이언트는 현재 베타 테스트 단계에 있으며 일부 기능은 일시적으로 사용할 수 없을 수 있습니다. 전체 기능을 이용하려면 클라이언트 애플리케이션과 함께 사용하는 것이 좋습니다.
2. LAN에 접속할 때, 컴퓨터와 장치가 동일한 네트워크에 연결되어 있는지 확인하세요. 그렇지 않으면 IP 주소로 접근할 수 없습니다.
3. 원격으로 액세스할 때는 장치가 인터넷에 연결되어 있는지 확인하십시오. 그렇지 않으면 원격 포털을 통해 연결할 수 없습니다.
4. 페이지 로딩이 비정상일 경우, 권장 브라우저로 전환하거나 브라우저 캐시를 지운 후 다시 시도하세요.
