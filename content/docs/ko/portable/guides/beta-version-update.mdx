## 소개

내부 테스트 버전은 정식 애플리케이션 출시 전에 내부 테스트 사용자에게 오픈되는 체험 버전으로, 내부 테스트 사용자가 아직 외부에 공개되지 않은 시스템 펌웨어와 클라이언트 소프트웨어의 신규 기능을 먼저 체험할 수 있도록 하며, 동시에 사용자의 피드백을 수집하고 잠재적인 문제를 점검하여 정식 버전의 최적화와 개선을 지원합니다.

## iOS 클라이언트 내부 테스트 업데이트 단계
### 1. TestFlight 설치
링크를 클릭하여 [TestFlight](https://testflight.apple.com/join/kH1Fmjby)로 이동한 후, **App 스토어에서 보기**를 클릭하여 TestFlight를 다운로드하거나 업데이트하세요.

<img src="/images/common/portable/guides/beta-version-update/1-1.png" width="30%" /> 
<img src="/images/common/portable/guides/beta-version-update/1-2.png" width="30%" />

### 2. TestFlight 베타 테스트 페이지로 이동
링크 [TestFlight](https://testflight.apple.com/join/kH1Fmjby)를 다시 클릭하고, **View in TestFlight**를 클릭하여 앱에 들어갑니다.

<img src="/images/common/portable/guides/beta-version-update/2-1.png" width="30%" /> 
<img src="/images/common/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3.베타 버전 설치
페이지에서 내부 테스트 버전 알림이 나타나면, '수락'을 클릭하면 최신 내부 테스트 버전을 설치할 수 있습니다.

## Android 클라이언트 내부 테스트 업데이트 단계
만약 Android 클라이언트를 공식 홈페이지에서 다운로드했다면, 추가 조치를 할 필요가 없으며, 내부 테스트 버전 업데이트가 있을 경우 앱에서 업데이트 알림이 표시됩니다. 만약 Google Play에서 다운로드했다면, 다음 단계를 따라주세요.
### 1. 오픈 테스트 링크로 이동
링크를 클릭하여 [GooglePlay](https://play.google.com/apps/testing/com.stationpc.nas)로 이동하고, **테스터 되기**를 클릭하여 테스트에 참여하세요.

<img src="/images/common/portable/guides/beta-version-update/1-1.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-2.png" width="30%" />
<img src="/images/common/portable/guides/beta-version-update/1-3.png" width="30%" />

### 2. 테스트 버전 설치
정식 버전을 먼저 제거한 후에야 테스트 버전을 설치할 수 있습니다.

<img src="/images/common/portable/guides/beta-version-update/2-1.jpg" width="30%" /> 
<img src="/images/common/portable/guides/beta-version-update/2-2.jpg" width="30%" />

### 3.테스트 종료
정식 버전을 다시 설치해야 하는 경우, 링크를 클릭하여 [GooglePlay](https://play.google.com/apps/testing/com.stationpc.nas)로 이동하고, **나가기**를 클릭하여 테스트 프로그램에서 나가세요.
