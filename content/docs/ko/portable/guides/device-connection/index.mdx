title: "PocketCloud에 어떻게 연결합니까?"

다음 여러 가지 접근 방식을 통해 PocketCloud에 연결할 수 있으며, 필요에 따라 선택할 수 있습니다.

## 인터넷 환경에서
인터넷에 연결된 상태에서 다음 방법으로 PocketCloud에 연결할 수 있습니다.
### 방법 1: IP 주소 입력
PocketCloud가 네트워크에 성공적으로 연결된 후, 다음 방법으로 IP 주소를 확인할 수 있습니다
* IP 주소는 라우터 관리에서 PocketCloud를 통해 찾을 수 있습니다.
* 작은 화면을 통해 PocketCloud의 IP 주소를 확인할 수 있습니다.

<img src="/images/common/portable/guides/device-connection/1-1.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-2.jpg" width="30%" />

### 방법 2：Station ID 입력
만약 원격 접속 서비스를 켰다면, Station ID를 입력하여 PocketCloud에 연결할 수 있습니다.

### 방법 3: 로컬 네트워크 내 장치 발견
App에 들어간 후, 발견된 LAN 내 장치(빨간 상자로 표시)를 클릭하면 검색 목록에 들어갈 수 있으며, 동일 LAN 내 모든 PocketCloud 장치를 자동으로 발견하고 표시합니다. 연결할 PocketCloud 장치를 선택하세요.

<img src="/images/common/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-5.jpg" width="30%" />

### 방법 4: 역사 로그인
App에 들어간 후, '로컬 네트워크 내 장치 발견'(빨간 상자로 표시)을 클릭하면 검색 목록에 들어갈 수 있습니다. 해당 장치에 이전 로그인 기록이 있는 경우, '이전 로그인'을 통해 접근 정보와 계정 정보를 빠르게 채울 수 있습니다.

<img src="/images/common/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-7.jpg" width="30%" />

장치를 발견한 후, 계정과 비밀번호를 입력하여 로그인합니다.

## 오프라인 환경에서
만약 네트워크 환경이 없는 경우, 다음 방법으로 PocketCloud에 연결할 수 있습니다.

### 방법 1: WiFi 직결
> 휴대폰이 WIFI를 통해 PocketCloud에 직접 연결된 상태에서도, 해당 연결을 끊지 않고 동시에 휴대폰 데이터로 외부 네트워크 접근(예: 웹 브라우징, 메시지 수신)이 가능하며, 장치 데이터 접근과 외부 네트워크 필요를 동시에 충족할 수 있습니다.
App에 들어간 후, '장치 직접 연결'을 클릭하면 검색 목록에 들어갈 수 있으며, 블루투스를 통해 주변의 모든 PocketCloud 장치를 자동으로 발견하고 표시합니다. 연결할 PocketCloud 장치를 선택하세요.

<img src="/images/common/portable/guides/device-connection/2-1-1.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/2-1-2.jpg" width="30%" />

### 방법 2: 휴대폰 핫스팟을 통해 접속
> 주의: 이 방식에서는 외부 데이터를 방문할 때(예: 클라우드 드라이브 접속, 오프라인 다운로드 등), PocketCloud가 휴대폰 핫스팟을 통해 데이터 요금을 사용하여 인터넷에 연결합니다. 데이터 사용량을 조절하여 추가 비용 발생을 방지하시기 바랍니다.
휴대폰 데이터로 접속해야 하는 경우, 휴대폰 핫스팟을 통해 임시 네트워크 환경을 구축할 수 있으며, 조작 단계는 다음과 같습니다:
1. 휴대폰 핫스팟 기능을 켜고, 핫스팟 이름(SSID)과 비밀번호를 설정합니다;
2. App를 열고 '배치 네트워크'를 클릭한 후, 안내에 따라 배치 네트워크 페이지로 이동하여 핸드폰 핫스팟 이름과 비밀번호를 수동으로 입력하여 PocketCloud와 핫스팟의 연결을 완료합니다.

<img src="/images/common/portable/guides/device-connection/2-2-1.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/2-2-2.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/2-2-3.jpg" width="30%" />

3. 연결에 성공한 후, App에 들어가서 '로컬 네트워크 내 장치 발견'을 클릭하면, 동일한 핫스팟 네트워크에 있는 PocketCloud 장치를 자동으로 인식하며, 해당 장치를 선택하고 계정과 비밀번호를 입력하여 로그인합니다.
