PocketCloud은 원격 접속 서비스를 제공하여 사용자에게 안정적이고 안전하며 편리한 원격 접속 경험을 제공합니다. 사용자가 공인 IP IP, 포트 포워딩 또는 DDNS 설정과 같은 전문 기술 지식을 습득할 필요 없이 사용 장벽을 크게 낮추어 비기술 사용자도 원격 조작을 손쉽게 실현할 수 있습니다.
> 사용자는 휴대폰 번호/이메일을 연결하여 Station ID를 받을 수 있으며, Station ID를 통해 원격으로 접근할 수 있습니다.

## 1. 연결 원리 설명
원격 접속은 P2P(피어 투 피어, 점대점) 연결 방식을 사용하며, 핵심 원리는 다음과 같다:
공식 중계 서버와 사용자의 자체 네트워크 협력으로 '펀칭'을 통해 네트워크 경계 제한을 깨고, 궁극적으로 PocketCloud와 클라이언트(휴대폰/PC) 간에 직접 통신 연결을 구축하며, 제3자 서버를 거쳐 데이터를 전달할 필요가 없습니다.

## 2. P2P 연결 방식의 장점
| 특징 | 설명 |
|------|------|
| 제로 구성 | 시작 장벽이 매우 낮아, 사용자가 직접 네트워크 매개변수를 설정할 필요 없이 기능을 켜기만 하면 연결을 시도할 수 있음 |
| 고효율 전송 | 직연결 조건이 충족될 때, 데이터가 PocketCloud와 클라이언트 간에 직접 전송되며, 대역폭이 중계 서버의 제한을 받지 않아 접속 속도가 더 빠릅니다 |
| 다중 플랫폼 호환 | 모바일 클라이언트(휴대폰/태블릿)와 PC 클라이언트를 동시에 지원하며, 다양한 사용 환경(예: 외출 시 업무, 자택 원격 관리)에 맞게 적응 |

## 삼, 주의 사항
1. 장치와 클라이언트가 동일한 로컬 네트워크에 있을 경우, 자동으로 로컬 네트워크 연결로 전환됩니다.
2. P2P 직접 연결이 설정되지 않으면 자동으로 StationPC 중계 서버 전달 모드로 전환되어 원격 액세스 기능을 보장합니다；
3. 중계 모드에서는 접속 속도와 대역폭이 중계 서버에 의해 제한됩니다.
