Pocketcloud 호스트에는 M.2 NVMe 2280 SSD를 설치할 수 있습니다.

## 조작 방법

1. 전원 버튼을 눌러 지시등이 꺼질 때까지 기다립니다.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_1.png)

2. 제공된 드라이버를 사용하여 나사를 시계 반대 방향으로 돌려 외장을 제거합니다.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_2.png)

3. SSD를 M.2 NVMe 슬롯에 삽입하고 나사를 돌려 고정합니다.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_3.png)

4. 외장을 다시 설치합니다.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_4.png)
