## 내장 저장소가 지원하는 파일 시스템 형식

내장 저장소는 주로 exFAT, NTFS 및 FAT32를 지원하며, 공식적으로는 exFAT 사용을 권장합니다.

exFAT, NTFS 및 FAT32 파일 시스템 비교:

| 특징          | exFAT(추천)                          | NTFS                  | FAT32                   |
| :------------ | :------------------------------------- | :------------------------------------ | :------------------------------------ |
| **최대 파일**  | **초대형 파일 지원** | **초대형 파일 지원** | **단일 파일은 4GB를 초과할 수 없음** |
| **최대 파티션**  | **초대형 파티션 지원** | **초대형 파티션 지원**     | **최대 2TB만 가능**      |
| **시스템 호환성** | **Windows, Mac, Linux 모두 지원** | **Mac는 읽기 전용** | **Windows, Mac, Linux 모두 지원** |
| **안전성**    | **보통**               | **높음**        | **낮음**                |
| **안정성**    | **좋음**             | **최고**              | **나쁨**               |
| **속도**      | **빠름**         | **빠름**            | **느림**         |
