## 해상도

| 해상도 | iOS、Android 단 |
| -------- | ---------- |
| 4K | 네트워크가 좋은 경우(예: 로컬 네트워크 또는 직접 연결된 장치)에는 정상적으로 재생 가능, 셀룰러 네트워크 연결 시에는 끊김이 발생하기 쉬움 |
| 8K     | 지원하지 않음 |
