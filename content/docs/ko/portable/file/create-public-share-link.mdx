PocketCloud는 파일의 외부 공유 링크 생성을 지원하며, 제3자는 이 링크를 통해 당신이 공유한 파일에 접근하고 다운로드할 수 있습니다.
> 주의:
> 원격 액세스를 활성화해야 원격 외부 공유 링크를 생성할 수 있습니다. 원격 액세스를 비활성화하면 로컬 네트워크 내에서만 외부 공유 링크를 생성할 수 있습니다.

## 외부 공유 링크를 어떻게 만들까요?

**파일**에서 공유할 파일/폴더를 찾아, 오른쪽 더보기 메뉴를 클릭하고 외부 공유 링크를 생성합니다.

<img src="/images/common/portable/file/create-public-share-link/1-0.jpg" width="30%" />
<img src="/images/common/portable/file/create-public-share-link/1-1.jpg" width="30%" />

외부 공유 링크를 생성할 때, 외부 공유 링크의 만료 시간과 비밀번호를 설정할 수 있습니다. 확인을 클릭하면 외부 공유 링크가 생성됩니다. 동일한 파일에 대해 여러 개의 서로 다른 공유 링크를 각각 생성할 수 있으며, 서로 다른 외부 링크 설정을 가질 수 있습니다.

* 만료 시간: 3일, 7일, 30일, 영구 중 선택 가능하며, 기본값은 30일입니다.
* 비밀번호: 선택하지 않으면 비밀번호 없음, 선택하면 최소 4자리의 비밀번호를 입력하세요.

## 외부 공유 링크를 어떻게 관리하나요?

당신은 **파일 > 외부 링크 공유**에서 당신이 만든 모든 파일의 외부 공유 링크를 확인하고 관리할 수 있습니다.
