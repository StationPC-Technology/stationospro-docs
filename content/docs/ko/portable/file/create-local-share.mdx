---

서로 다른 사용자 간의 공간은 독립적이며 직접 접근할 수 없습니다. 공유 파일 설정을 통해 다른 사용자와 공유할 수 있습니다.
> 주의:
> 최소 2명의 사용자가 있어야 로컬 공유를 만들 수 있습니다.
## 공유 파일을 어떻게 만들까요?

**파일**에서 공유할 파일/폴더를 찾아 오른쪽의 더보기 메뉴를 클릭하고, 로컬 공유를 생성합니다.

## 로컬 공유를 어떻게 관리합니까?

당신은 **파일 > 로컬 공유**에서 다음과 같은 작업을 수행할 수 있습니다:
* 다른 사용자가 공유한 파일을 확인합니다.
* 자신이 생성한 모든 로컬 공유 관리.
