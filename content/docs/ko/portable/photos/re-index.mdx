새로운 사진이 표시되지 않거나, 사진 메타데이터(예: 촬영 시간, 장소)가 혼란스러워지거나, 사진을 삭제한 후에도 기록이 남아 있는 경우, **앨범 인덱스 새로 고침**을 통해 최신 상태를 동기화하여 앨범 기능이 사진 내용을 정확하게 인식하고 표시할 수 있도록 할 수 있습니다.
> 주의:
> * USB 드라이브 모드로 앨범 파일을 추가, 삭제, 수정한 후에는 변경 사항을 동기화하기 위해 수동으로 앨범 색인을 새로 고쳐야 합니다.

## 사진첩 인덱스를 수동으로 새로 고치는 방법은?
1. 클라이언트를 열고 **앨범** 모듈에 들어갑니다;
2. **설정 > 일반 설정** 페이지로 이동합니다;
3. **인덱스 재설정**을 클릭하면 시스템이 자동으로 앨범 내 모든 파일을 스캔하기 시작합니다.

## 앨범 색인 새로 고침 시 주의 사항
- 자동 새로고침 메커니즘: 컴퓨터/모바일 클라이언트를 통해 앨범에 해당하는 폴더에 새 사진 파일을 업로드하면, 시스템은 기본적으로 '자동 새로고침'을 트리거하며, 일반적으로 수동으로 조작할 필요가 없습니다. 단, 자동 동기화가 실패할 경우(예: USB 모드 업로드), 그때 수동으로 새로고침을 실행하면 됩니다.
- 새로고침 소요 시간은 사진 리소스 규모와 관련 있음: 스캔 과정은 백그라운드에서 계속 진행되며, 소요 시간은 사진 리소스의 규모와 관련이 있음(사진이 많을수록 시간이 더 걸림). 진행 상황을 확인하려면 **앨범 홈 > 상단 메뉴**를 통해 처리 상태를 확인할 수 있음.
