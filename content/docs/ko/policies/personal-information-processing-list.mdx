## 총칙

본 목록은 StationPC StationNAS 모바일, 웹, PC 클라이언트의 개인정보 처리 시나리오를 설명하며 「로컬 오프라인 계정 모드」와 「클라우드 계정 모드」를 엄격히 구분합니다.

중국 본토 외 사용자는 이메일 등록만 지원하며 휴대폰 번호와 광고 식별자를 수집하지 않습니다. 정확한 위치를 수집하거나 저장하지 않습니다. 위치 정보는 기기 네트워크 구성 시에만 임시로 사용됩니다(WiFi 이름 읽기, 국가 코드 추론). 제품 사용 분석 및 충돌 진단 데이터는 본 목록에 설명된 대로 처리됩니다.

로컬 계정 데이터는 전적으로 사용자 NAS 로컬 하드웨어에 저장되며 클라우드에서는 어떠한 개인정보도 수집하거나 저장하지 않습니다.

사용자의 명시적 승인 없이 당사는 NAS 내의 사설 파일 데이터를 읽거나 스캔하거나 업로드하지 않습니다.

## 중요 추가 설명

로컬 오프라인 계정은 어떠한 개인 데이터도 클라우드로 업로드하지 않으며 모든 데이터는 사용자 NAS 로컬에만 저장됩니다.

사용자의 자발적 승인 없이 당사는 사용자 NAS 내 사설 파일 데이터를 읽거나 업로드하거나 분석하지 않습니다.

해외 버전은 광고 식별자를 수집하지 않습니다. 정확한 위치를 수집하거나 저장하지 않습니다. 위치 정보는 기기 네트워크 구성 시 국가 코드를 추론하기 위해서만 임시로 사용됩니다. 제4절에 설명된 대로 충돌 로그와 제품 분석 데이터를 보관하여 장애 수정과 제품 개선에 사용합니다.

사용자는 앱 설정에서 개인정보를 자유롭게 조회, 정정, 삭제하고 계정을 해지할 수 있습니다.
