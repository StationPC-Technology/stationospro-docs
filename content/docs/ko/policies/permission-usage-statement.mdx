업데이트 날짜: 2026년 10월 20일

StationHub는 해당 기능을 사용할 때 필요한 권한만 신청합니다. 시스템 팝업에 표시되는 권한 이름은 iOS, Android, Windows 또는 macOS 버전에 따라 다를 수 있습니다. 권한 허용 여부는 귀하가 결정하며, 권한을 거부해도 해당 권한과 관계없는 기본 기능에는 영향을 주지 않습니다.

## 1. 권한 처리 원칙

- 권한이 필요한 기능을 처음 사용할 때만 권한을 요청하며, 시작할 때 모든 권한을 한 번에 요청하지 않습니다.
- 권한은 현재 기능의 명확한 목적에 사용합니다. 권한을 끄면 관련 기능을 이용하지 못할 수 있지만, 그로 인해 다른 데이터를 자동으로 읽지는 않습니다.
- 제3자 플러그인 또는 시스템 서비스에서 추가 권한을 요청할 수 있으나, 허용 여부는 계속 귀하가 결정합니다.
- 위치 권한은 네트워크 설정 단계에서 WiFi 이름을 읽고 국가 코드를 추정하는 데만 사용합니다. 백그라운드 위치 추적을 하지 않으며 좌표를 전송하거나 저장하지 않습니다.

## 2. iPhone 및 iPad

| 시스템 권한 | 기능이 실행되는 경우 | 당사가 하는 일 | 끈 경우의 영향 |
| --- | --- | --- | --- |
| 카메라 | QR 코드로 연결, 빠른 로그인, 아바타 설정 | 기기에서 카메라 화면을 읽어 QR 코드를 인식하거나 아바타를 촬영합니다 | QR 코드를 스캔하거나 아바타를 촬영할 수 없습니다 |
| 사진 및 동영상 | 앨범 백업, 미디어 선택 및 업로드, 아바타 설정 | 귀하가 선택한 미디어를 읽습니다. iOS의 제한된 사진 범위를 지원합니다 | 해당 미디어를 백업하거나 업로드할 수 없습니다 |
| 로컬 네트워크 | 같은 LAN의 NAS 검색 및 연결 | LAN 기기를 발견하고 로컬 연결을 설정합니다 | LAN NAS를 발견하거나 연결할 수 없습니다 |
| 알림 | 기기 상태, 백업 진행 상황 및 계정 보안 알림 | 귀하가 허용한 시스템 알림을 보냅니다 | 관련 알림을 받을 수 없습니다 |
| Bluetooth | 기기 연결 및 네트워크 설정 | 주변 기기를 발견하고 네트워크 설정 정보를 전달합니다 | Bluetooth로 연결하거나 네트워크를 설정할 수 없습니다 |
| 사용 중 위치 | 네트워크 설정 시 WiFi 지역 확인 | WiFi 이름을 일시적으로 읽고 국가 코드를 추정합니다 | WiFi와 지역을 수동으로 선택해야 합니다 |

## 3. Android 휴대전화 및 태블릿

| 시스템 권한 | 기능이 실행되는 경우 | 사용 범위 | 끈 경우의 영향 |
| --- | --- | --- | --- |
| 카메라 | QR 코드로 연결 및 빠른 로그인 | 기기에서 QR 코드를 인식합니다 | QR 코드로 연결하거나 로그인할 수 없습니다 |
| 사진, 동영상 또는 로컬 저장소 | 파일 업로드·다운로드, 앨범 자동 백업 | 귀하가 선택한 파일과 미디어에 접근합니다 | 해당 파일 작업을 완료할 수 없습니다 |
| 주변 기기, LAN 및 WiFi | 기기 발견, 로컬 연결 및 네트워크 설정 | 연결에 필요한 네트워크 상태를 읽습니다 | 기기를 발견하거나 로컬 연결을 설정할 수 없습니다 |
| 알림 | 작업 진행 상황, 기기 이상 및 계정 보안 알림 | 푸시 또는 로컬 알림을 보냅니다 | 관련 알림을 받을 수 없습니다 |
| Bluetooth | 기기 페어링 및 네트워크 초기화 | 네트워크 설정 기기를 발견하고 연결합니다 | Bluetooth로 네트워크 설정을 완료할 수 없습니다 |
| 네트워크 위치 정보 | 네트워크 설정 식별 보조 | 네트워크 설정 때 WiFi 지역 판단을 보조합니다 | 지역을 수동으로 선택해야 합니다 |
| 백그라운드 자동 시작 | 사용자가 켠 지속적인 백업 | 백업 작업을 계속 실행합니다 | 백업이 시스템에 의해 중단될 수 있습니다 |
| 클립보드 | 공유 링크 인식 및 파일 전송 열기 | 공유 링크 기능을 실행할 때만 읽습니다 | 공유 링크를 자동으로 인식할 수 없습니다 |

## 4. Windows 및 macOS 클라이언트

| 플랫폼 | 권한 또는 시스템 기능 | 용도 | 끈 경우의 영향 |
| --- | --- | --- | --- |
| Windows | 데스크톱 알림 | 작업 진행 상황, 기기 상태 및 이상을 표시합니다 | 데스크톱 알림을 표시할 수 없습니다 |
| Windows | 로컬 파일 시스템 | 업로드, 다운로드 및 폴더 동기화를 수행합니다 | 로컬 파일 작업을 완료할 수 없습니다 |
| macOS | 시스템 알림 | 백업 진행 상황과 기기 작동 상태를 알립니다 | 시스템 알림을 받을 수 없습니다 |
| macOS | 로컬 디렉터리 | 파일 관리, 업로드, 다운로드 및 동기화를 수행합니다 | 해당 파일 작업을 완료할 수 없습니다 |

## 5. 기타 안내

권한을 허용했다고 해서 개인정보를 계속 수집한다는 의미는 아닙니다. 귀하의 명시적인 허가 없이 당사는 NAS의 개인 파일을 능동적으로 읽거나 업로드하지 않습니다. 백그라운드 위치 권한을 요청하거나 광고용 기기 식별자를 수집하지도 않습니다. 기기 시스템 설정에서 언제든지 권한을 취소할 수 있으며, 취소 후 관련 기능을 다음에 사용할 때 이유와 대체 작업이 안내됩니다.

어떤 기능이 제3자 앱 또는 서비스에서 제공되는 경우 [《제3자 개인정보 공유 목록》](./third-party-sdk-list)과 해당 서비스 제공자의 개인정보 처리방침도 확인해 주십시오. 전체 정보 처리 방식은 [《개인정보 처리방침》](./privacy-policy)을 참조하십시오.
