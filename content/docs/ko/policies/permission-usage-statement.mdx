## 머리말

본 안내는 StationPC 전용 앱과 PC/Mac 클라이언트가 운영 체제 권한을 신청하고 사용하는 상황을 설명합니다. 당사는 **최소 필요, 필요 시 신청** 원칙을 따르며 해당 기능을 사용할 때만 동적으로 권한을 신청합니다.

언제든지 시스템 설정에서 권한 부여를 관리할 수 있으며 권한을 끄면 해당 기능에만 영향을 주고 제품의 기본 핵심 서비스에는 영향을 주지 않습니다.

제3자 플러그인 및 서비스가 추가 권한을 신청할 수 있으며 권한 부여가 지속적인 개인정보 수집을 의미하지는 않습니다.

## iOS 권한

| 시나리오 | 목적 | 권한 거부 또는 끄기의 영향 |
| --- | --- | --- |
| 기기 카메라 호출 | QR 코드로 NAS 기기 바인딩, 빠른 로그인, 사진 촬영으로 아바타 설정 | QR 코드로 기기를 바인딩하거나 사진을 촬영하여 아바타를 설정할 수 없습니다. |
| 사진 및 동영상 앨범 접근 | 휴대폰 앨범 콘텐츠를 NAS에 백업, 이미지·동영상 선택 업로드, 계정 아바타 설정, iOS 제한 사진 접근(선택한 사진만 허용) 지원 | 앨범을 백업하거나 이미지·동영상을 업로드할 수 없습니다. |
| 로컬 네트워크 접근 | LAN에서 StationPC 기기를 검색하고 연결 | LAN 내 NAS 기기를 검색하고 연결할 수 없습니다. |
| 시스템 알림 수신 | 기기 상태, 백업 진행률, 계정 보안 알림(시효성 알림 포함) 수신 | 관련 알림을 받을 수 없습니다. |
| 블루투스 기기 접근 | 기기 바인딩 및 네트워크 구성: 주변 기기 검색, 네트워크 구성 정보 전송 | 블루투스로 기기를 바인딩하고 구성할 수 없습니다. |
| 위치 정보 가져오기(사용 중에만) | 네트워크 구성 시 현재 WiFi 이름을 읽고 한 번 임시로 위치를 가져와 국가 코드를 추론하여 기기 WiFi 지역 설정에 사용합니다. 백그라운드 위치 확인은 하지 않으며 좌표는 업로드하거나 저장하지 않습니다. | 현재 WiFi와 지역을 자동으로 인식할 수 없어 수동으로 선택해야 합니다. |

| 클립보드 내용 읽기 | 공유 링크를 인식하여 파일 전송 기능 실행 | 공유 링크를 인식하여 파일 전송 기능을 실행할 수 없습니다. |

## 추가 설명

모든 권한은 필요 시 신청하며 시작 시 일괄적으로 권한을 부여하지 않습니다.

권한을 끄면 일부 기능만 비활성화되며 로그인, 기기 연결, 파일 탐색 등 기본 서비스에는 영향을 주지 않습니다.

사용자의 명시적 승인 없이 당사는 NAS 내의 어떠한 사설 사용자 데이터도 주도적으로 읽거나 업로드하지 않습니다.

백그라운드 위치 권한을 신청하지 않으며 광고용 기기 식별자를 수집하지 않습니다. 위치 정보는 기기 네트워크 구성 시에만 임시로 사용되며(WiFi 이름 읽기, 국가 코드 추론) 좌표는 업로드하거나 저장하지 않아 글로벌 개인정보 보호 규정을 준수합니다.
