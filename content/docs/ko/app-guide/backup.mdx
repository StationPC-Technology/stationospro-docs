백업 앱은 통합 백업 작업 관리를 제공하며, 데이터를 기기 내 다른 저장 위치, 원격 NAS 또는 클라우드 드라이브에 백업할 수 있고, 외장 장치의 원클릭 백업을 통해 데이터를 빠르게 보호할 수도 있습니다.

앱 왼쪽 탐색에는 세 가지 모듈이 있습니다:

- **로컬로 백업**: 백업 원본 데이터를 기기 내 스토리지 공간에 저장합니다.
- **원격으로 백업**: 데이터를 원격 NAS, 클라우드 드라이브 또는 기타 서버에 백업합니다.
- **원클릭 백업**: 외장 스토리지 장치와 기기 전원 버튼으로 백업을 빠르게 실행합니다.

![Backup to Local](/images/ko/app-guide/backup-img/local-backup.png)

## 백업 작업 생성

1. '로컬로 백업' 또는 '원격으로 백업' 페이지로 이동하여 **백업 작업 생성**을 클릭합니다.
2. '백업 원본 선택' 대화 상자에서 백업 원본을 선택합니다:
   - **로컬 장치**: NAS 내부 경로 또는 외장 스토리지
   - **클라우드 스토리지**: Google Drive, Dropbox, Microsoft OneDrive
   - **파일 프로토콜**: SMB, WebDAV, FTP 등 원격 파일 서비스
3. **확인**을 클릭하고 마법사에 따라 백업 원본 경로, 백업 대상 위치 및 작업 일정을 차례로 선택합니다.
4. 구성을 확인한 후 작업을 생성합니다. 작업 목록에서 실행 상태와 이력을 확인할 수 있습니다.

![Create Backup Task](/images/ko/app-guide/backup-img/create-task.png)

<Callout title="팁" type="info">
  클라우드 스토리지를 백업 원본으로 사용할 때는 먼저 해당 클라우드 드라이브의 계정 인증을 완료해야 합니다. SMB/WebDAV/FTP 프로토콜을 사용할 때는 서버 주소, 계정 및 비밀번호를 입력해야 합니다.
</Callout>

## 백업 작업 관리

작업 목록에서 다음을 수행할 수 있습니다:

- 작업 상태, 마지막 실행 시간 및 결과 확인
- 작업 수동 시작, 일시 중지 또는 삭제
- 작업의 원본 경로, 대상 위치 및 실행 일정 수정

## 원클릭 백업

'원클릭 백업'은 외장 스토리지 장치의 빠른 백업에 적합합니다:

1. 원클릭 백업 스위치가 켜져 있는지 확인합니다.
2. 외장 스토리지 장치(USB 드라이브/휴대용 하드 디스크)를 NAS에 연결합니다.
3. 기기 전원 버튼을 짧게 누르면 시스템이 외장 장치의 데이터를 NAS에 자동으로 백업합니다.

![One-touch Backup](/images/ko/app-guide/backup-img/one-touch.png)

<Callout title="주의" type="warn">
  - 원클릭 백업의 실행 방향은 기기 설정에 따릅니다. 실행 전에 백업 방향을 확인하여 데이터가 역방향으로 덮어쓰이지 않도록 하십시오.
  - 백업 작업의 실행 결과를 정기적으로 확인하여 백업이 지속적으로 유효한지 확인하십시오.
  - 중요한 데이터는 '3-2-1 백업 원칙'을 따르는 것이 좋습니다: 최소 3개의 데이터 사본, 2가지 매체, 1개의 오프사이트 사본.
</Callout>
