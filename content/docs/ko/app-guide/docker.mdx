Docker 앱은 StationOS Pro의 컨테이너 관리 플랫폼으로, 컨테이너, 프로젝트(Compose), 이미지 및 네트워크를 그래픽 방식으로 관리할 수 있어 명령줄 없이도 일반적인 컨테이너 기반 앱의 배포와 운영을 완료할 수 있습니다.

## Docker 서비스 활성화

Docker 앱을 처음 열면 초기 구성을 완료해야 합니다:

1. **저장 위치**에서 Docker 데이터를 저장할 스토리지 공간을 선택합니다.
2. 필요에 따라 **부팅 시 자동 시작**을 선택합니다:
   - **자동 시작**: 기기 부팅 후 Docker 서비스가 자동으로 시작됩니다.
   - **시작 안 함**: 필요할 때 수동으로 시작합니다.
3. **Docker 시작**을 클릭하면 시스템이 스토리지를 준비하고 서비스를 시작합니다.

![Docker Setup](/images/ko/app-guide/docker-img/setup.png)

<Callout title="주의" type="warn">
  Docker 서비스를 시작하면 선택한 스토리지 공간에 Docker 데이터 디렉터리가 생성됩니다. 이 과정에서 전원을 끄거나 강제 종료하지 마십시오.
</Callout>

## 개요

서비스가 시작되면 개요 페이지로 이동하여 Docker 실행 상태를 빠르게 파악할 수 있습니다:

- **서비스 상태**: 서비스가 정상인지 표시합니다.
- **프로젝트**: 실행 중/전체 프로젝트 수
- **컨테이너**: 실행 중/전체 컨테이너 수
- **로컬 이미지**: 사용 중/전체 이미지 수
- **데이터 크기**: Docker 데이터가 차지하는 공간

![Docker Overview](/images/ko/app-guide/docker-img/overview.png)

## 컨테이너 관리

**컨테이너** 페이지에서 전체 컨테이너의 이름, 이미지, 상태, CPU/메모리 사용량 등의 정보를 확인할 수 있으며 다음을 지원합니다:

- 컨테이너 검색
- **컨테이너 생성**을 클릭하여 마법사에서 이미지, 포트, 마운트 디렉터리, 환경 변수 등 매개변수를 구성하고 컨테이너를 생성
- 컨테이너 시작, 중지, 재시작 또는 삭제
- 컨테이너 로그 및 리소스 사용량 상세 확인

![Containers](/images/ko/app-guide/docker-img/containers.png)

## 프로젝트 관리

**프로젝트** 페이지는 Docker Compose 방식으로 앱을 배포하는 것을 지원합니다:

1. 프로젝트 생성을 클릭하고 프로젝트 이름을 입력합니다.
2. `docker-compose.yml`을 편집하거나 파일에서 오케스트레이션 내용을 가져옵니다.
3. 저장하면 시스템이 이미지를 자동으로 가져오고 프로젝트에 정의된 모든 서비스를 시작합니다.

프로젝트 목록에서 프로젝트 실행 상태와 포함된 서비스를 확인하고 프로젝트에 대해 시작, 중지, 재빌드 등의 작업을 수행할 수 있습니다.

![Docker Project](/images/ko/app-guide/docker-img/project.png)

## 이미지 관리

**이미지** 페이지는 두 가지 보기로 나뉩니다:

- **이미지 저장소**: 온라인에서 필요한 이미지를 검색하고 가져오며 Tag 선택을 지원합니다.
- **로컬 이미지**: 이미 로컬로 가져온 이미지를 관리하며 보기, 삭제, 이미지로 컨테이너 생성 등의 작업을 지원합니다.

![Docker Images](/images/ko/app-guide/docker-img/images.png)

<Callout title="팁" type="info">
  온라인으로 이미지를 가져오려면 기기가 이미지 저장소 네트워크에 접근할 수 있어야 합니다. 가져오기에 실패하면 네트워크 연결을 확인하거나 Docker 설정에서 사용 가능한 이미지 가속 주소를 구성하십시오.
</Callout>

## 네트워크 관리

**네트워크** 페이지는 Docker의 네트워크 목록(기본적으로 `bridge`, `host` 등 네트워크 제공)을 표시하며 다음을 지원합니다:

- **새로 고침**: 네트워크 목록을 새로 고칩니다.
- **네트워크 추가**: 컨테이너 간 통신에 사용할 사용자 지정 네트워크를 생성합니다.

![Docker Networks](/images/ko/app-guide/docker-img/networks.png)

## Docker 설정

**설정** 페이지에서 Docker의 저장 위치, 부팅 시 자동 시작 등 전역 구성을 수정할 수 있습니다. 일부 구성은 수정 후 Docker 서비스를 재시작해야 적용됩니다.
