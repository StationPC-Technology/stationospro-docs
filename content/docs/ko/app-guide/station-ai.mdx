Station AI는 StationOS Pro에 내장된 AI 스마트 어시스턴트로, 로컬에 배포된 대규모 언어 모델(기본값 Qwen3-8B)을 기반으로 자연어 대화, 지식 베이스 질의응답, 문서 번역 및 문서 요약을 지원하며, 대화를 통해 기기 상태를 직접 조회하고 시스템 작업을 실행할 수 있습니다.

## 인터페이스 소개

Station AI 창 왼쪽은 탐색 영역으로 다음을 포함합니다:

- **새 대화**: 새 대화를 시작합니다.
- **지식 베이스**: 지식 베이스를 관리하고 검색합니다.
- **기록**: 이전 세션을 확인합니다.
- **설정**: 모델과 대화 매개변수를 구성합니다.

![Station AI Chat](/images/ko/app-guide/station-ai-img/chat.png)

## AI와 대화

1. 입력창에 질문을 입력하고 전송 버튼을 클릭합니다(또는 `Enter`를 누릅니다).
2. AI는 내장 모델을 기반으로 답변을 생성하며, 기기 상태나 작업과 관련된 경우 시스템 기능을 자동으로 호출합니다.

새 대화 페이지에는 자주 사용하는 바로가기 명령이 제공되며, 클릭하면 빠르게 실행할 수 있습니다:

- **NAS 기능 소개**: NAS 기능을 소개합니다.
- **기기 재시작**: 기기를 재시작합니다.
- **기기 종료**: 기기를 종료합니다.
- **현재 기기 하드 디스크 정보와 상태 조회**: 하드 디스크 정보와 상태를 조회합니다.

입력창 아래에서도 다음 기능을 제공합니다:

- **추가**: 파일을 대화 컨텍스트로 업로드합니다.
- **모델 선택**: 현재 사용 중인 모델(예: Qwen3-8B)을 표시합니다.
- **문서 번역**: 문서를 업로드하여 번역합니다.
- **문서 요약**: 문서를 업로드하면 요약을 자동으로 생성합니다.

<Callout title="주의" type="warn">
  AI를 통해 재시작, 종료 등 민감한 작업을 실행하기 전에 기기에서 실행 중인 중요한 작업이 없는지 확인하여 데이터 손실을 방지하십시오.
</Callout>

## 지식 베이스

지식 베이스 기능을 사용하면 문서 자료를 NAS로 가져오고 AI가 인덱스를 구축한 후 정확한 질의응답을 수행할 수 있습니다:

1. **지식 베이스** 탭으로 전환합니다.
2. **지식 베이스 생성**을 클릭합니다.
3. 문서 파일을 업로드하면(일반적인 문서 형식 지원) 시스템이 자동으로 분석하고 인덱스를 구축합니다.
4. 지식 베이스 목록에서 이름, 크기 및 파일 수를 확인할 수 있으며 **채팅**을 클릭하면 해당 지식 베이스를 기반으로 질의응답을 시작합니다.

![Knowledge Base](/images/ko/app-guide/station-ai-img/knowledge-base.png)

<Callout title="팁" type="info">
  - 지식 베이스 파일이 크거나 수량이 많으면 인덱스 구축에 시간이 걸릴 수 있으니 기다려 주십시오.
  - 모델은 '시스템 설정 → AI 모델'에서 확인하고 관리할 수 있습니다. 로컬 추론은 NPU/CPU 리소스를 사용하므로 대량 문서는 유휴 시간대에 처리하는 것이 좋습니다.
</Callout>
