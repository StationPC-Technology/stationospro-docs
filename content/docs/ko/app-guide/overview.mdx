StationOS Pro는 StationNAS 기기에 탑재된 운영 체제로, 데이터 저장, 파일 공유, 백업 재해 복구, 컨테이너 앱 및 AI 서비스를 중심으로 완전한 앱 중앙 관리 환경을 제공합니다. 본 장에서는 시스템에 내장된 앱의 기능과 사용 방법을 하나씩 소개하여 빠르게 익히고 기기 성능을 충분히 활용할 수 있도록 돕습니다.

## 데스크톱 소개

시스템에 로그인하면 데스크톱으로 진입합니다. 데스크톱은 상단 상태 표시줄, 데스크톱 아이콘 영역 및 하단 Dock 바로 구성됩니다:

- **상단 상태 표시줄**: 왼쪽에 「데스크톱으로 돌아가기」와 「앱 시작 관리자」 버튼이 있고, 가운데에 CPU, RAM, 네트워크 속도 등 실시간 리소스 정보가 떠 있으며, 오른쪽에 알림 센터와 개인 설정 진입점이 있습니다.
- **Dock 바**: 자주 사용하는 앱을 모아 두며 아이콘을 클릭하면 해당 앱 창을 열 수 있습니다.
- **창 관리**: 앱 창 오른쪽 위에 최소화, 최대화/복원, 닫기 버튼이 있어 기존 데스크톱 시스템처럼 창을 자유롭게 전환하고 배치할 수 있습니다.

![Desktop](/images/ko/app-guide/overview-img/desktop.png)

## 앱 시작 관리자

상단 상태 표시줄 왼쪽의 시작 관리자 버튼을 클릭하면 앱 시작 관리자가 열립니다. 시작 관리자는 다음을 지원합니다:

- 상단 검색 상자에서 이름으로 앱을 빠르게 검색합니다.
- 시스템의 모든 내장 앱을 확인하고 아이콘을 클릭하여 실행합니다.

![App Launcher](/images/ko/app-guide/overview-img/app-launcher.png)

## 내장 앱 목록

| 앱 | 설명 |
| --- | --- |
| 파일 관리자 | 개인 및 팀 파일을 관리하며 업로드·다운로드, 외부 링크 공유, 휴지통, 중복 파일 정리 및 SMB/WebDAV/FTP/NFS 등 파일 서비스 구성을 지원합니다. |
| 백업 | 로컬 백업, 원격 백업 및 원터치 백업 기능을 제공하며 NAS, 외장 스토리지, 클라우드 드라이브 및 파일 프로토콜 등 다양한 백업 원본을 지원합니다. |
| Docker | 컨테이너 관리 콘솔로 컨테이너, 프로젝트(Compose), 이미지 및 네트워크의 전체 수명 주기 관리를 지원합니다. |
| 로그 센터 | 시스템 실행 로그를 한곳에서 확인하며 키워드 검색과 다중 조건 필터링을 지원합니다. |
| 리소스 관리 | CPU, 메모리, 네트워크, NPU 및 하드 디스크 상태를 실시간으로 모니터링하고 시스템 서비스와 프로세스를 관리합니다. |
| 시스템 설정 | 기기 정보, 사용자, 스토리지, 네트워크, 원격 액세스, 하드웨어 전원, 보안 및 시스템 업데이트 등 핵심 구성을 관리합니다. |
| 앱 센터 | 원스톱 앱 스토어로 공식 앱과 제3자 앱의 설치, 업데이트 및 관리를 제공합니다. |
| Station AI | 내장 AI 스마트 어시스턴트로 대화형 질의응답, 지식 베이스 검색, 문서 번역 및 요약을 지원합니다. |
| 도움말 센터 | 본 도움말 문서 사이트를 빠르게 열어 설치, 앱 튜토리얼 및 자주 묻는 질문을 확인합니다. |

<Callout title="팁" type="info">
  일부 기능과 앱은 기기 모델, 펌웨어 버전 또는 설치된 앱에 따라 다를 수 있으므로 기기의 실제 화면을 기준으로 하십시오.
</Callout>
