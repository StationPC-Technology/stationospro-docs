앱 센터는 StationOS Pro의 앱 스토어로, 공식 앱과 서드파티 앱을 한곳에서 설치, 업데이트 및 관리할 수 있습니다. 앱 센터를 통해 스마트폰 앱 스토어를 사용하듯이 NAS에 다운로드, 미디어, 동기화, 생산성, 개발 및 운영 등 다양한 기능을 추가할 수 있습니다.

## 인터페이스 소개

앱 센터를 열면 상단에 다음 탐색 메뉴가 제공됩니다:

- **모든 앱**: 스토어에서 설치 가능한 모든 앱을 탐색합니다.
- **설치됨**: 현재 기기에 설치된 앱을 확인하고 관리합니다.
- **카테고리 필터**: 동기화, 미디어, 영상 녹화, 다운로드, 생산성, 개발 도구 등의 카테고리로 앱을 빠르게 필터링합니다.
- **검색창**: 앱 이름으로 앱을 빠르게 찾습니다.

앱 목록은 '공식 앱'과 서드파티 앱 영역으로 나뉘며, 각 앱 카드에는 이름, 소개/카테고리 태그 및 설치 버튼이 표시됩니다.

![App Center](/images/ko/app-guide/app-center-img/all-apps.png)

## 앱 설치

1. 앱 센터에서 카테고리 또는 검색창을 통해 대상 앱을 찾습니다.
2. 앱 카드를 클릭하여 상세 페이지로 이동합니다.
3. 앱 정보를 확인한 후 **설치**를 클릭하면 시스템이 앱을 자동으로 다운로드하고 설치합니다.
4. 설치가 완료되면 앱이 앱 런처에 표시됩니다. 바탕 화면 바로가기 자동 생성이 켜져 있으면 바탕 화면에도 바로가기가 생성됩니다.

## 앱 상세 페이지

앱 상세 페이지에는 다음 정보가 표시되어 앱을 이해하고 평가하는 데 도움이 됩니다:

| 필드 | 설명 |
| --- | --- |
| 개발자 | 앱의 개발자 또는 팀 |
| 게시자 | 앱의 배포 주체 |
| 다운로드 수 | 해당 앱의 누적 다운로드 횟수 |
| 크기 | 앱 설치 패키지 용량 |
| 현재 버전 | 스토어에서 제공하는 최신 버전 번호 |
| 앱 소개 | 기능 하이라이트 및 사용 설명 |

![App Detail](/images/ko/app-guide/app-center-img/app-detail.png)

## 앱 센터 설정

앱 센터 오른쪽 상단의 **설정** 버튼을 클릭하면 다음을 구성할 수 있습니다:

- **기본 설치 위치**:
  - **매번 묻기**: 설치 시 저장 위치를 직접 선택합니다.
  - **고정 저장 위치**: 앱 설치에 사용할 스토리지 공간을 통일하여 지정합니다.
- **바탕 화면 바로가기 자동 생성**: 켜면 새로 설치된 앱의 바로가기가 바탕 화면에 자동으로 생성됩니다.

![App Center Settings](/images/ko/app-guide/app-center-img/settings.png)

<Callout title="주의" type="warn">
  - 앱을 설치하기 전에 선택한 스토리지 공간에 충분한 용량이 있는지 확인하십시오. 그렇지 않으면 설치가 실패할 수 있습니다.
  - 일부 서드파티 앱은 외부 개발자가 제공합니다. 설치 전에 앱 출처와 권한 요구 사항을 확인하십시오.
  - 앱 설치 위치는 일부 상황에서 변경할 수 없습니다. 이전이 필요한 경우 먼저 제거한 후 다시 설치하십시오.
</Callout>
