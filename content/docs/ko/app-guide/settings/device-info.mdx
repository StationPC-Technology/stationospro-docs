기기 정보 페이지는 기기 정체성과 실행 상태를 확인하는 데 사용됩니다. 이 페이지에서 시스템 버전, 하드웨어 사양, 일련번호 및 각 네트워크 포트의 주소를 확인할 수 있으며, 기기 이름을 수정하거나 Station ID와 IP 주소를 복사할 수도 있습니다.

## 기기 기본 정보

| 필드/작업 | 설명 |
| --- | --- |
| 기기 이름 | 현재 기기 이름을 표시합니다. 이름 오른쪽의 편집 아이콘을 클릭하여 수정할 수 있으며, 이름은 1~15자의 영문자, 숫자 및 `-`를 지원하고 `-`는 시작이나 끝에 올 수 없습니다. |
| Station ID | 기기의 원격 액세스 식별자입니다. 원격 액세스 서비스를 활성화하면 생성되며 클릭하여 복사할 수 있습니다. 수정이 필요하면 ID를 클릭하여 수정 절차로 들어갑니다. |
| 시스템 버전 | 현재 StationOS Pro 버전 번호입니다. 예: `v1.1.0.17`. 새 버전이 감지되면 새 버전 안내가 표시될 수 있습니다. |
| 시스템 가동 시간 | 최근 부팅 이후 계속 실행된 시간입니다. |
| 마지막 부팅 시간 | 최근 부팅한 시스템 시간입니다. |

## 하드웨어 정보

하드웨어 정보는 세 구역으로 나뉩니다:

| 구역 | 필드 | 용도 |
| --- | --- | --- |
| CPU | CPU 모델, 클럭 속도, 코어 수, 스레드 수 | 프로세서 성능과 병렬 작업 능력을 판단합니다. |
| 메모리 | 메모리 용량 | 앱, 컨테이너, 인덱스 및 AI 작업에 사용할 수 있는 실행 공간을 판단합니다. |
| AI 모듈 확장 | AI 모듈 모델과 연산 성능. 예: RK1828, 20 TOPS INT8 | 기기에 AI 가속 하드웨어가 있는지와 연산 성능 등급을 확인합니다. |

## 기기 상세 정보

| 필드 | 설명 |
| --- | --- |
| 기기 모델 | 기기의 제품 모델입니다. 예: DA400. |
| 일련번호 | 기기의 고유 식별자 중 하나입니다. 복사 버튼을 클릭하면 빠르게 복사할 수 있으며 등록, 보증 및 기술 지원에 자주 사용됩니다. |

## 네트워크 정보

네트워크 정보는 네트워크 포트별로 표시됩니다. 예: '유선 연결 1', '유선 연결 2'. 네트워크 포트를 선택하면 다음을 확인할 수 있습니다:

| 필드 | 설명 |
| --- | --- |
| 포트 이름 | 시스템이 인식한 인터페이스 이름입니다. 예: `enP2p33s0`. |
| 네트워크 구성 | 듀플렉스 모드와 MTU입니다. 예: Full-duplex, MTU1500. |
| IPv4 주소 | 현재 IPv4 주소입니다. 복사 버튼을 클릭하여 복사할 수 있습니다. |
| IPv4 연결 상태 | IPv4가 연결되었는지 표시합니다. |
| IPv6 주소 | 현재 IPv6 주소입니다. 주소가 없으면 `-`로 표시됩니다. |
| IPv6 연결 상태 | IPv6가 연결되었는지 표시합니다. |

<Callout title="팁" type="info">
  기기 정보의 IP가 현재 접속 주소와 일치하지 않으면 여러 네트워크 포트가 동시에 여러 링크에 연결된 기기일 수 있습니다. 클라이언트가 실제로 연결된 네트워크 대역을 기준으로 하거나 네트워크 설정에서 각 인터페이스의 게이트웨이와 DNS를 추가로 확인하십시오.
</Callout>

## 필드 활용 권장 사항

| 시나리오 | 권장 확인 필드 |
| --- | --- |
| 브라우저에서 기기에 접근할 수 없음 | 네트워크 정보의 IPv4/IPv6 주소, 연결 상태, 포트 이름. |
| 원격 클라이언트에서 기기를 추가할 수 없음 | Station ID, 시스템 버전, 원격 액세스 스위치 상태. |
| AI 또는 컨테이너 실행 가능 여부 판단 | CPU 코어/스레드, 메모리 용량, AI 모듈 연산 성능. |
| 기술 지원 또는 보증 문의 | 기기 모델, 일련번호, 시스템 버전, 가동 시간. |
| 반복 재시작 문제 해결 | 마지막 부팅 시간, 시스템 가동 시간 및 로그 센터의 시스템 로그. |
| 다중 네트워크 포트 링크 확인 | 각 네트워크 포트 탭의 주소, 듀플렉스 모드, MTU 및 연결 상태. |

## 상태 해석

| 상태/현상 | 의미 | 권장 처리 |
| --- | --- | --- |
| IPv4 연결은 정상이나 IPv6가 `-`로 표시됨 | 현재 링크에서 IPv6를 가져오지 못했으며 IPv4 접근에 반드시 영향을 주는 것은 아닙니다. | IPv6가 필요할 때만 라우터의 SLAAC/DHCPv6를 확인하십시오. |
| 특정 포트가 연결되지 않음으로 표시됨 | 네트워크 케이블 미연결, 스위치 포트 이상 또는 링크 협상 실패. | 네트워크 케이블/포트를 교체한 후 네트워크 설정에서 인터페이스 상태를 확인하십시오. |
| 가동 시간이 매우 짧음 | 기기가 방금 부팅되었거나 비정상 재시작이 발생했습니다. | 로그 센터에서 System 사용자로 필터링하여 종료, 재시작 및 업데이트 기록을 확인하십시오. |
| 새 버전 안내가 표시됨 | 업데이트 서버가 새 펌웨어를 반환했습니다. | 업데이트 및 복원에서 버전 설명을 확인하고 먼저 백업한 후 업그레이드하십시오. |

## 자주 묻는 질문

### 기기 이름을 수정하면 파일 접근에 영향을 주나요?

기기 이름은 주로 기기 식별과 일부 알림 시나리오에 사용되며 일반적으로 저장 경로나 계정을 변경하지 않습니다. 클라이언트가 호스트 이름으로 서비스에 접근하는 경우 수정 후 새 호스트 이름으로 다시 연결해야 하며, IP로 접근하는 경우에는 일반적으로 영향을 받지 않습니다.

### 여러 네트워크 포트에 모두 IP가 있는 이유는 무엇인가요?

다중 네트워크 포트 기기는 여러 링크에 동시에 연결할 수 있습니다. 각 포트의 정보는 독립적으로 표시되며 클라이언트는 같은 네트워크 대역의 주소를 사용해야 합니다. 대역폭 집계나 링크 이중화가 필요하면 네트워크 설정에서 브리지 또는 링크 집계를 검토하십시오.

### Station ID를 계정으로 사용할 수 있나요?

아니요. Station ID는 기기 원격 액세스 식별자이며 로그인 계정이 아닙니다. 원격 액세스 시에도 기기 로컬 사용자와 비밀번호를 입력해야 하며, 이메일 바인딩은 원격 액세스 계정과 신원 인증을 연결하는 데 사용됩니다.
