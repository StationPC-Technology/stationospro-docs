하드웨어 및 전원 페이지는 **일반**과 **전원**으로 나뉩니다. 일반 페이지는 소리, 냉각 및 메모리 압축을 제어하고, 전원 페이지는 전원 복구, 네트워크 깨우기, 예약 전원 켜기/끄기 및 하드 디스크 절전을 제어합니다.

## 일반

![Hardware General](/images/ko/app-guide/settings-img/hardware-general.png)

### 부저

부저 설정 버튼을 클릭한 후 어떤 이벤트에서 부저 알림을 울릴지 선택할 수 있습니다:

| 분류 | 이벤트 | 설명 |
| --- | --- | --- |
| 일반 | 기기 켜기 | 부팅 과정에서 알림음을 냅니다. |
| 일반 | 기기 끄기 | 종료 과정에서 알림음을 냅니다. |
| 일반 | 원클릭 백업 성공 | 원클릭 백업 작업이 완료될 때 알립니다. |
| 기기 오류 | 온도 과열 | 기기 온도가 안전 범위를 초과할 때 경보를 울립니다. |
| 기기 오류 | 스토리지 공간 오류 | 스토리지 볼륨 또는 하드 디스크 상태가 비정상일 때 경보를 울립니다. |
| 기기 오류 | 팬 오류 | 팬이 멈추거나 이상이 있을 때 경보를 울립니다. |

저장하면 선택한 이벤트만 부저를 울립니다. 기기를 침실이나 조용한 환경에 두는 경우 고위험 오류 알림만 유지할 수 있습니다.

### 냉각 팬

| 모드 | 설명 |
| --- | --- |
| 일반 | 기기 온도에 따라 회전 속도를 자동 조절하여 냉각과 소음을 균형 있게 유지하며 대부분의 시나리오에 적합합니다. |
| 저소음 | 낮은 소음과 낮은 회전 속도로 동작하지만 기기 온도가 상승할 수 있습니다. 소음에 민감하고 부하가 낮은 환경에 적합합니다. |
| 최대 속도 | 최대 회전 속도를 강제하여 최상의 냉각을 보장하지만 소음이 큽니다. 고부하, 고온 환경 또는 냉각 이상 시 임시로 사용하는 데 적합합니다. |

페이지 카드에는 현재 모드가 표시됩니다. 예: '현재 모드: 일반'.

### 메모리 압축

| 옵션 | 설명 |
| --- | --- |
| 메모리 압축 스위치 | 켜면 메모리 공간을 확보하고 데이터 읽기를 가속하여 시스템이 더 효율적으로 동작합니다. |

메모리 압축은 소량의 CPU를 사용하여 더 큰 사용 가능 메모리 공간을 확보합니다. 일반 사용자는 기본값을 유지하는 것이 좋으며, CPU 부하가 높은 작업을 실행하고 메모리 압박이 낮을 때는 실제 성능 테스트 결과에 따라 조정할 수 있습니다.

## 전원

![Power](/images/ko/app-guide/settings-img/power.png)

### 전원 복구 시 자동 켜기

| 옵션 | 설명 |
| --- | --- |
| Power On When Power Returns | 외부 전원이 복구되면 기기가 자동으로 시작됩니다. 안정적인 UPS와 함께 사용하거나 무인 재시작이 필요한 시나리오에 적합합니다. |

### 네트워크 깨우기

| 옵션 | 설명 |
| --- | --- |
| Wake On LAN (WOL) | 기기가 꺼져 있거나 절전 상태일 때 LAN 매직 패킷으로 깨울 수 있습니다. 네트워크 카드, 메인보드 및 라우터 환경의 지원이 필요합니다. |

### 예약 전원 켜기/끄기

| 옵션 | 설명 |
| --- | --- |
| Scheduled Power On / Off 스위치 | 켜면 일정에 따라 자동으로 전원을 켜거나 끕니다. 처음 켤 때 첫 번째 일정 추가를 안내합니다. |
| Add Schedule | 새 일정을 추가합니다. |
| Day | 매일 또는 월요일~일요일을 선택할 수 있습니다. |
| Time | 일정 실행 시간입니다. |
| Action | 전원 켜기 또는 끄기입니다. |
| Actions | 기존 일정을 편집하거나 삭제합니다. |

여러 일정은 주 단위로 반복 실행되며 중복되거나 유효하지 않은 일정은 시스템에서 검증합니다. 자동 전원 켜기를 사용할 때는 기기 전원 공급과 BIOS/펌웨어 정책이 예약 시작을 지원하는지 확인하십시오.

### 하드 디스크 절전

하드 디스크 절전은 절전을 지원하는 기계식 하드 디스크에만 적용되며 내장 하드 디스크와 외장 하드 디스크를 각각 설정할 수 있습니다. 시스템 디스크는 절전을 지원하지 않을 수 있습니다.

| 옵션 | 설명 |
| --- | --- |
| Enable Internal Disk Sleep | 내장 하드 디스크 절전을 켭니다. |
| Enable External Disk Sleep | 외장 하드 디스크 절전을 켭니다. |
| Wake Internal Disks When a User Logs In | 사용자가 로그인하면 내장 하드 디스크를 자동으로 깨웁니다. |
| Wake External Disks When a User Logs In | 사용자가 로그인하면 외장 하드 디스크를 자동으로 깨웁니다. |
| Idle Time | 유휴 후 절전까지의 시간으로 10분, 20분, 30분, 1시간, 2시간, 3시간을 선택할 수 있습니다. |

<Callout title="주의" type="info">
  빈번한 접근은 하드 디스크가 절전 상태로 들어가기 어렵게 만듭니다. 백업, 인덱싱, 다운로드, 감시 녹화 또는 컨테이너 앱이 하드 디스크를 지속적으로 읽고 쓴다면 유휴 시간을 적절히 늘리거나 중요하지 않은 하드 디스크에만 절전을 켜십시오.
</Callout>

## 부저 정책

| 시나리오 | 권장 사항 |
| --- | --- |
| 서버실 또는 사무실 | 온도 과열, 팬 오류, 스토리지 오류를 유지합니다. |
| 침실 또는 조용한 거실 | 심각한 오류만 유지하고 전원 켜기/끄기 알림은 끕니다. |
| 무인 원격 배포 | 모든 오류 알림을 켜서 고온/스토리지 이상을 즉시 발견할 수 있게 합니다. |
| 원클릭 백업이 중요함 | 백업 성공 알림을 유지합니다. |

## 팬 모드 선택

| 조건 | 권장 사항 |
| --- | --- |
| 일반 가정 | 일반. |
| 야간 저부하 | 저소음. 단, 다음 날 일반으로 다시 전환할 수 있습니다. |
| 고온 환경, 다운로드 최대 부하, 컨테이너/AI 작업 | 최대 속도. |
| 팬 오류 경고 | 먼저 전원을 끄고 팬을 점검하며 최대 속도로 고장을 장기간 숨기지 마십시오. |

## 전원 정책 조합

| 목표 | 권장 조합 |
| --- | --- |
| 가정에서 예약으로 전력 절약 | 예약 종료 + 수동/네트워크 깨우기. |
| 정전 복구 후 자동 사용 | 전원 복구 시 자동 켜기. |
| 원격 유지 관리 | WOL + 안정적인 LAN/VPN + 고정 IP 또는 DHCP 예약. |
| 중요 서비스 지속 실행 | 예약 계획을 신중히 사용하고 UPS와 중복 스토리지를 구성합니다. |

## 예약 전원 켜기/끄기 주의 사항

- 자동 전원 켜기는 기기 하드웨어/펌웨어 지원에도 의존합니다.
- 종료 전에 백업, 동기화, 다운로드, 인덱싱, 녹화 및 컨테이너 작업이 중단 가능한지 확인해야 합니다.
- 같은 시간에 전원 켜기와 끄기를 동시에 설정하지 마십시오.
- 여러 일정이 중복되면 시스템이 검증하지만 여전히 수동으로 재확인해야 합니다.
- NTP를 사용하여 시간을 정확하게 유지하십시오. 그렇지 않으면 일정 실행 시간이 어긋날 수 있습니다.

## 하드 디스크 절전 문제 해결

| 현상 | 확인 |
| --- | --- |
| 하드 디스크가 절전 상태로 들어가지 않음 | 로그 센터, 백업, 인덱싱, 컨테이너, 감시, 다운로드 작업이 지속적으로 접근하는지 확인하십시오. |
| 빈번한 깨우기/절전 | 유휴 시간이 너무 짧은지, 클라이언트가 SMB/WebDAV를 폴링하는지 확인하십시오. |
| 절전 후 접근이 느림 | 깨우기 대기 시간이므로 유휴 시간을 줄이거나 절전을 끌 수 있습니다. |
| 외장 하드 디스크가 절전되지 않음 | 외장 디스크/USB 브리지가 절전을 지원하는지 확인하십시오. |
| 시스템 디스크가 절전되지 않음 | 시스템 디스크는 일반적으로 지속적인 서비스가 필요하여 절전을 지원하지 않을 수 있습니다. |
