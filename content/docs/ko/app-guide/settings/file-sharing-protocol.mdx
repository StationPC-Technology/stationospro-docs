파일 공유 프로토콜 페이지는 **SMB**, **WebDAV**, **FTP**, **NFS** 네 개의 탭을 제공합니다. 해당 서비스를 켜면 컴퓨터, 스마트폰, NAS, TV 박스 등 클라이언트가 프로토콜을 통해 기기의 파일에 접근할 수 있습니다. 각 프로토콜 페이지에는 연결 방법 안내가 제공되어 주소를 복사하고 단계에 따라 마운트할 수 있습니다.

![File Sharing](/images/ko/app-guide/settings-img/file-sharing.png)

## 표시되는 폴더 범위

SMB, WebDAV, FTP의 서비스 카드에는 **표시되는 디렉터리 범위 설정**이 제공됩니다. 이 설정은 각 파일 영역이 해당 프로토콜을 통해 표시되는지 결정합니다:

| 영역 | 설명 |
| --- | --- |
| 내 파일, 다른 사용자 공유 | 현재 사용자의 개인 디렉터리와 공유받은 파일. |
| 팀 파일 | 팀 공유 디렉터리. |
| 외장 스토리지 | USB 등 외장 스토리지의 파일. |
| 원격 마운트 | 원격 NAS, 서버 또는 클라우드 드라이브에서 마운트한 디렉터리. |
| 앱 파일 | 앱에서 생성된 데이터 디렉터리. |

각 영역에서는 다음을 선택할 수 있습니다:

| 모드 | 효과 |
| --- | --- |
| 모두 표시 | 현재 및 향후 추가되는 폴더를 모두 해당 프로토콜로 접근할 수 있습니다. |
| 사용자 지정 폴더 | 지정한 1차 폴더만 표시되며 카드에 사용자 지정 수량이 표시됩니다. |
| 모두 금지/없음 | 해당 영역의 어떤 폴더도 해당 프로토콜로 볼 수 없습니다. |

<Callout title="이름 제한" type="info">
  1차 폴더 이름에 공백 또는 `! " # % & ' ( ) * + , / : ; < = > ? @ [ ] ^ { } | ~` 등의 특수 문자가 포함되면 파일 공유 프로토콜로 접근할 수 없습니다. 1차 디렉터리는 영문자, 숫자, 중국어, 밑줄 또는 하이픈으로 이름을 지정하는 것이 좋습니다.
</Callout>

## SMB

SMB는 Windows, macOS 및 대부분의 클라이언트에서 가장 널리 사용되는 파일 공유 프로토콜로, 일상적인 LAN 파일 접근에 적합합니다.

| 기능 | 설명 |
| --- | --- |
| SMB 서비스 스위치 | 켜면 기기가 LAN에서 SMB를 통해 파일을 공유하고 접근할 수 있습니다. |
| 고급 설정 | SMB3 다중 채널, SMB1, NTLMv1 및 macOS 파일 이름 호환성을 구성합니다. |
| 표시되는 디렉터리 범위 설정 | 파일 관리자 설정으로 이동하여 각 디렉터리가 파일 서비스를 통해 표시되는 범위를 구성합니다. |
| Time Machine 서비스 | 켜면 Mac이 Time Machine으로 이 NAS에 백업할 수 있습니다. |
| Time Machine 폴더 | Time Machine 백업 디렉터리를 표시하거나 설정합니다. |
| 폴더 보기 | 현재 Time Machine 백업 디렉터리를 엽니다. |
| 연결 방법 | macOS Finder, Windows 실행 창의 연결 단계와 `smb://IP`, `\\IP` 주소를 제공합니다. |
| 기타 연결 정보 | 기기 IP, 기본 포트 445 및 호스트 이름을 표시합니다. |

### SMB 고급 설정

| 옵션 | 설명 | 권장 사항 |
| --- | --- | --- |
| SMB3 다중 채널 지원 | 여러 네트워크 연결을 병렬로 전송하여 속도와 신뢰성을 높입니다. | 다중 네트워크 포트 또는 고동시성 전송 시나리오에서는 켜는 것이 좋습니다. |
| SMB1 지원 | 구형 장치와 호환되지만 프로토콜 보안이 약합니다. | 구형 장치가 연결되지 않을 때만 임시로 켜십시오. |
| NTLMv1 지원 | NTLMv1만 지원하는 일부 TV 박스, 플레이어 등의 단말과 호환되지만 인증 프로토콜이 안전하지 않습니다. | 필요한 장치에만 켜고 접근 범위를 제한하십시오. |
| macOS 파일 이름의 특수 문자 변환 | macOS와의 파일 이름 호환성을 높입니다. | Mac 접근에 이상이 있을 때 켤 수 있습니다. |

### Time Machine 설정

| 옵션 | 설명 |
| --- | --- |
| Time Machine 서비스 스위치 | SMB 서비스를 먼저 켜야 합니다. |
| 저장 위치 | Mac 백업을 저장할 스토리지 볼륨을 선택합니다. |
| 백업 용량 제한 | '크기 제한'을 선택하고 용량을 입력하거나 '크기 제한 없음'을 선택합니다. |
| 용량 단위 | GB와 TB를 지원하며 제한은 선택한 스토리지 공간의 총 용량을 초과할 수 없습니다. |

![SMB](/images/ko/app-guide/settings-img/file-sharing.png)

## WebDAV

WebDAV는 HTTP/HTTPS 기반 파일 접근을 제공하며 서드파티 클라이언트, 모바일 앱 및 일부 마운트 도구에서 널리 사용됩니다.

![WebDAV](/images/ko/app-guide/settings-img/file-sharing-webdav.png)

| 기능 | 설명 |
| --- | --- |
| WebDAV 서비스 스위치 | 켜면 LAN에서 WebDAV를 통해 파일에 접근할 수 있습니다. |
| 고급 설정 | HTTP/HTTPS 프로토콜과 수신 포트를 구성합니다. |
| 표시되는 디렉터리 범위 설정 | WebDAV에서 표시되는 파일 디렉터리를 구성합니다. |
| 연결 방법 | macOS와 Windows의 매핑/연결 단계를 제공하며 주소 형식은 `http://IP:端口`입니다. |

### WebDAV 고급 설정

| 옵션 | 설명 |
| --- | --- |
| HTTP 활성화 | 일반 텍스트 HTTP 프로토콜을 사용하며 기본 일반 포트는 5005입니다. |
| HTTP 포트 | HTTP 서비스 수신 포트이며 범위는 1~65535입니다. |
| HTTPS 활성화 | 암호화 전송을 사용하며 신뢰할 수 없는 네트워크 또는 계정 데이터 보호가 필요할 때 켜는 것이 좋습니다. |
| HTTPS 포트 | HTTPS 서비스 수신 포트이며 HTTP 포트와 같을 수 없습니다. |
| 디버그 모드 | 상세 로그를 출력하며 성능에 영향을 줄 수 있으므로 문제 해결 시에만 임시로 켜십시오. |

## FTP

FTP는 운영 체제 간 대량 파일 전송에 적합합니다. 시스템은 암호화되지 않은 FTP와 FTPS를 모두 지원합니다.

![FTP](/images/ko/app-guide/settings-img/file-sharing-ftp.png)

| 기능 | 설명 |
| --- | --- |
| FTP 서비스 스위치 | 켜면 FTP/FTPS 클라이언트 연결을 허용합니다. |
| 고급 설정 | 프로토콜, 포트, 패시브 포트 범위 및 유휴 시간 초과를 구성합니다. |
| 표시되는 디렉터리 범위 설정 | FTP에서 표시되는 파일 디렉터리를 구성합니다. |
| 연결 방법 | macOS Finder, Windows 파일 탐색기의 연결 단계를 제공하며 주소 형식은 `ftp://IP:21`입니다. |

### FTP 고급 설정

| 옵션 | 설명 |
| --- | --- |
| FTP 서비스 활성화(암호화 없음) | 표준 FTP를 활성화합니다. 전송 내용이 암호화되지 않으므로 신뢰할 수 없는 네트워크에서는 사용하지 않는 것이 좋습니다. |
| FTPS 서비스 활성화(보안 암호화) | FTP over SSL/TLS를 활성화하여 암호화 전송을 제공합니다. |
| FTP 포트 | 서비스 수신 포트로 기본값은 21이며 유효 범위는 1~65535입니다. |
| 패시브 FTP 포트 범위 | 기본 또는 사용자 지정을 선택할 수 있습니다. 사용자 지정 범위는 55536~65535 내에 있어야 하며 상한은 하한보다 작을 수 없습니다. |
| 유휴 시간 초과 | 클라이언트가 조작하지 않으면 자동으로 연결을 끊으며 1~120분을 지원합니다. |

## NFS

NFS는 Linux, Unix, 가상 머신 또는 일부 플레이어 장치에서 공유 디렉터리를 직접 마운트하는 데 자주 사용됩니다. 현재 페이지 설명에는 켜면 LAN 장치가 공유 폴더를 로컬로 마운트하고 계정 인증 없이 파일에 직접 접근할 수 있다고 안내되어 있습니다.

![NFS](/images/ko/app-guide/settings-img/file-sharing-nfs.png)

| 기능 | 설명 |
| --- | --- |
| NFS 서비스 스위치 | 켜야 NFS 주소로 마운트할 수 있습니다. |
| 표시되는 디렉터리 범위 설정 | 서비스가 꺼져 있으면 사용할 수 없으며, 켜면 NFS에서 표시되는 디렉터리를 구성할 수 있습니다. |
| 연결 방법 | macOS `nfs://IP/路径` 및 Windows `\\IP\路径` 예시를 제공합니다. |

<Callout title="보안 안내" type="warn">
  - NFS는 계정 비밀번호 인증을 수행하지 않을 수 있으므로 신뢰할 수 있는 LAN에서만 켜고 표시되는 디렉터리 범위와 클라이언트 권한으로 접근을 제한하십시오.
  - SMB1, NTLMv1, 일반 텍스트 FTP/HTTP는 모두 보안 위험이 있습니다. 기기가 호환되면 SMB3, HTTPS, FTPS 또는 SFTP를 우선 사용하십시오.
  - 서비스 포트를 수정한 후에는 방화벽 아웃바운드/인바운드 규칙과 클라이언트 주소를 함께 조정하십시오.
</Callout>

## 서비스 스위치 영향

| 작업 | 클라이언트 영향 | 데이터 영향 |
| --- | --- | --- |
| 프로토콜 활성화 | 해당 클라이언트가 연결을 시도할 수 있습니다. | 파일 권한을 변경하지 않습니다. |
| 프로토콜 비활성화 | 기존 프로토콜 연결이 실패하거나 끊깁니다. | 파일을 삭제하지 않습니다. |
| 포트 수정 | 기존 주소가 즉시 무효화됩니다. | 파일을 삭제하지 않습니다. |
| 표시 범위 수정 | 일부 디렉터리가 프로토콜 클라이언트에서 사라집니다. | 표시 및 접근 경로에만 영향을 주며 디렉터리를 삭제하지 않습니다. |
| 프로토콜이 위치한 스토리지 볼륨 포맷 | 프로토콜 자체는 계속 켤 수 있지만 원본 데이터가 삭제됩니다. | 볼륨 내 파일이 모두 삭제됩니다. |

## 계정 및 권한 관계

파일 프로토콜은 기기 로컬 계정으로 인증하며, 최종적으로 표시되고 쓰기 가능한 내용은 다음 구성의 영향을 받습니다:

1. 사용자 활성화 여부
2. 사용자가 접근할 수 있는 스토리지 공간 및 할당량
3. 사용자 그룹 권한 부여
4. 파일/디렉터리 자체 권한
5. 프로토콜 표시 디렉터리 범위
6. 방화벽 및 IP 목록
7. 스토리지 볼륨 읽기 전용 여부

## 기본 주소 및 포트

| 프로토콜 | 기본 포트 | 일반 주소 |
| --- | --- | --- |
| SMB | 445 | `smb://IP`, `\\IP` |
| WebDAV | 5005, 고급 설정에서 수정 가능 | `http://IP:端口` |
| FTP/FTPS | 21, 고급 설정에서 수정 가능 | `ftp://IP:端口` |
| NFS | 시스템 내보내기 경로에 따라 결정 | `nfs://IP/共享路径` |

## 연결 문제 해결

| 현상 | 확인 순서 |
| --- | --- |
| 클라이언트가 연결할 수 없음 | 서비스 스위치, IP/포트, 방화벽, 스위치 라우팅, 클라이언트 네트워크 대역. |
| 연결되지만 디렉터리가 보이지 않음 | 표시되는 디렉터리 범위, 계정 권한, 폴더 이름 특수 문자. |
| 계정 비밀번호 오류 표시 | 사용자 활성화 여부, 비밀번호 수정 여부, 프로토콜이 로컬 계정을 요구하는지 여부. |
| 전송 속도가 느림 | 링크 속도/듀플렉스, SMB 다중 채널, 집계 모드, 하드 디스크 부하, CPU/메모리 사용량. |
| 포트 수정 후 접근 불가 | 클라이언트 주소 포트, 방화벽 규칙, 라우터 포트 포워딩. |
| Mac 특수 파일 이름 이상 | macOS 파일 이름 특수 문자 변환을 켜고 디렉터리 이름을 확인하십시오. |

<Callout title="최소 노출 원칙" type="warn">
  실제로 필요한 프로토콜만 켜고, NFS는 신뢰할 수 있는 네트워크에서만 사용하십시오. 공용 인터넷 접근은 원격 액세스 또는 VPN을 우선 사용하고 SMB, FTP 또는 관리 포트를 직접 노출하지 마십시오.
</Callout>
