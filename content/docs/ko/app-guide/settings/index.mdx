시스템 설정은 StationOS Pro의 제어 센터로, 기기 정보, 사용자, 스토리지, 네트워크, 원격 액세스, 보안 정책, 하드웨어 전원 및 시스템 업데이트 등 핵심 구성을 중앙에서 관리합니다. 이 앱은 일반적으로 관리자 권한이 필요하며, 모델, 펌웨어 버전 및 설치된 하드웨어에 따라 표시되는 옵션이 다를 수 있으므로 기기의 실제 인터페이스를 기준으로 하십시오.

## 시스템 설정 열기

1. StationOS Pro 데스크톱에 로그인합니다.
2. Dock 또는 앱 런처에서 **시스템 설정**을 엽니다.
3. 왼쪽 탭 바에서 구성할 기능 모듈을 선택합니다.

![Settings window](/images/ko/app-guide/settings-img/device-info.png)

왼쪽 탭 바는 기능별로 다음 14개 모듈로 나뉩니다:

| 모듈 | 주요 용도 | 적용 시나리오 |
| --- | --- | --- |
| 기기 정보 | 기기 이름, Station ID, 버전, 하드웨어, 일련번호 및 네트워크 정보 확인 | 기기 확인, 연결 문제 해결, 애프터서비스 문의 |
| 사용자 관리 | 로컬 사용자, 역할, 상태, 사용자 그룹 및 스토리지 할당량 관리 | 가족 또는 팀 구성원에게 계정과 공간 할당 |
| 스토리지 공간 | 스토리지 볼륨, RAID, 핫 스페어 및 SSD 캐시 생성 및 관리 | 하드 디스크 초기화, 용량 확장, 읽기/쓰기 성능 향상 |
| 하드 디스크 | 하드 디스크 상세 정보와 상태 확인, 포맷 또는 안전하게 분리 | 하드 디스크 점검, 교체, 문제 해결 |
| 파일 공유 프로토콜 | SMB, WebDAV, FTP, NFS 및 Time Machine 구성 | 컴퓨터, 스마트폰, TV 박스 등에서 NAS 파일 접근 |
| AI 모델 | 기본 AI 기능, 로컬 모델 및 인덱스 데이터 저장 위치 관리 | 얼굴/문자/파일/시각 인식 활성화, 모델 공간 제어 |
| 네트워크 설정 | 게이트웨이, DNS, 네트워크 카드, 브리지 및 링크 집계 구성 | IP 변경, 다중 포트 부하 분산, 네트워크 이중화 |
| 원격 액세스 | Station ID 원격 액세스 및 DDNS 구성 | 인터넷 또는 자체 도메인으로 기기 접근 |
| SSH | SSH/SFTP 원격 터미널 서비스 켜기 또는 끄기 | 원격 유지 관리, 명령줄 관리, 보안 제어 |
| 보안 | 접근 포트, 2단계 인증, IP 보호, 방화벽, 인증서 및 데이터 분석 구성 | 시스템 진입점 강화, 의심스러운 접근 차단, HTTPS 활성화 |
| 알림 설정 | 이메일 알림 서비스 및 알림 언어 구성 | 인증 코드, 비밀번호 재설정 및 시스템 알림 이메일 수신 |
| 하드웨어 및 전원 | 부저, 팬, 메모리 압축, 전원 계획 및 하드 디스크 절전 관리 | 소음, 냉각, 자동 전원 켜기/끄기 및 전력 소비 제어 |
| 시간 및 시간대 | 시간대, NTP 자동 동기화 또는 수동 시간 설정 | 로그, 인증서, 작업 예약 시간의 정확성 보장 |
| 업데이트 및 복원 | 시스템 업데이트 확인/설치, 업데이트 로그 확인, 공장 초기화 또는 네트워크 초기화 | 시스템 업그레이드, 네트워크 구성 복구, 기본 설정 복원 |

<Callout title="작업 권장 사항" type="info">
  스토리지 볼륨, RAID, 포맷, 방화벽, 포트, 공장 초기화 및 네트워크 초기화와 관련된 작업은 데이터나 연결에 영향을 줄 수 있습니다. 수정 전에 업무 영향을 확인하고 중요한 데이터의 백업을 유지하십시오.
</Callout>

## 기능 그룹 및 작업 위험

| 분류 | 모듈 | 주요 위험 |
| --- | --- | --- |
| 읽기 전용 정보 | 기기 정보 | 기본적으로 위험이 없으며, 기기 이름 수정은 식별 방식에 영향을 줍니다. |
| 계정 및 권한 | 사용자 관리 | 사용자 삭제 시 개인 데이터가 삭제되며, 관리자 승격은 시스템 제어 권한을 확대합니다. |
| 데이터 구조 | 스토리지 공간, 하드 디스크 | 생성, 수정, 포맷, 하드 디스크 교체 시 데이터가 삭제되거나 이중화가 저하될 수 있습니다. |
| 서비스 진입점 | 파일 공유 프로토콜, SSH, 보안 | 프로토콜이나 포트를 켜면 노출 범위가 늘어나며, 잘못된 방화벽/포트 구성은 관리 연결을 끊을 수 있습니다. |
| 네트워크 및 원격 액세스 | 네트워크 설정, 원격 액세스 | IP, 브리지, 집계, DDNS 수정 시 현재 연결이 중단될 수 있습니다. |
| 시스템 유지 관리 | 하드웨어 및 전원, 시간 및 시간대, 업데이트 및 복원 | 재시작, 초기화, 잘못된 시간 또는 중단된 업데이트는 서비스 가용성에 영향을 줄 수 있습니다. |

## 관리자 작업 체크리스트

고위험 작업을 실행하기 전에 다음을 확인하는 것이 좋습니다:

1. 중요한 데이터에 별도의 백업이 있고 백업을 복구할 수 있습니다.
2. 현재 LAN 또는 콘솔 복구 경로가 있으며, 수정 중인 원격 연결에만 의존하지 않습니다.
3. 스토리지 볼륨 상태가 정상이고 하드 디스크에 저하, 손상 또는 읽기 전용 경고가 없습니다.
4. 관련 사용자에게 파일 쓰기, 백업, 다운로드, 컨테이너 및 인덱싱 작업 중지를 알렸습니다.
5. 기기 전원이 안정적이며, 기계식 하드 디스크, SSD 캐시 및 시스템 업데이트 중에는 강제 전원 차단을 하지 않습니다.
6. 수정 전의 IP, 포트, DNS, 방화벽 규칙, Station ID 및 버전 번호를 기록합니다.
