원격 액세스 페이지는 **원격 액세스**와 **DDNS**로 나뉩니다. Station ID는 공식 중계 서비스를 사용하여 빠르게 접근하는 데 적합하고, DDNS는 이미 도메인이 있으며 자체 도메인으로 공인 IP를 확인하려는 사용자에게 적합합니다.

## Station ID 원격 액세스

![Remote Access](/images/ko/app-guide/settings-img/remote-access.png)

### 기본 설정

| 기능/필드 | 설명 |
| --- | --- |
| Station ID 원격 액세스 스위치 | 켜면 기기에 인터넷을 통해 원격으로 접근할 수 있습니다. 켜거나 끄기 전에 신원 인증이 필요하며 사용자 계약과 개인정보 처리방침에 동의해야 합니다. |
| Station ID | 원격 액세스 식별자입니다. 규칙은 4~30자이며 숫자, 소문자 및 하이픈만 사용할 수 있고 하이픈은 시작이나 끝에 올 수 없습니다. |
| 연결된 이메일 | 현재 연결된 원격 액세스 계정 이메일을 표시합니다. 원격 액세스를 켜려면 먼저 이메일을 연결해야 합니다. |
| 수정/편집 | Station ID 또는 편집 항목을 클릭하여 ID를 변경할 수 있으며, ID가 이미 사용 중이면 변경해야 합니다. |

### 원격 액세스 방식

| 방식 | 사용 방법 |
| --- | --- |
| 웹 | 브라우저에서 `https://scnas.cloud/<Station ID>/web`에 접속합니다. |
| 클라이언트 | StationCloud 클라이언트에 Station ID를 입력하여 기기를 추가하고 접근합니다. |

### 계정 연결 해제

계정 보안을 위해 연결 해제 시 연결된 StationCloud 계정에 로그인해야 합니다:

1. 브라우저에서 `login.stationpc.com`을 엽니다.
2. 기기에 연결된 계정으로 로그인합니다.
3. '내 기기' 또는 앱의 기기 관리로 이동합니다.
4. 현재 기기를 선택하고 연결을 해제합니다.

<Callout title="주의" type="warn">
  원격 액세스를 끄면 현재 원격 연결이 끊깁니다. 계정 연결을 해제하면 원격 액세스를 사용할 수 없으며 다시 사용하려면 다시 연결하고 인증을 완료해야 합니다.
</Callout>

## DDNS

DDNS는 주기적으로 공인 IP를 감지하고 변경 사항을 도메인 확인 서비스 제공업체에 동기화합니다. 구성이 없으면 페이지에 빈 상태가 표시되며 **새 구성**을 클릭할 수 있습니다.

![DDNS](/images/ko/app-guide/settings-img/ddns.png)

### 구성 목록

| 필드 | 설명 |
| --- | --- |
| 제공업체 | DNS 서비스 제공업체입니다. 예: Cloudflare, DNSPod.cn, No-IP.com, Duck DNS, FreeDNS, ChangeIP.com, DynDNS 등. 실제 목록은 서버에서 반환됩니다. |
| 도메인 | 현재 DDNS 레코드에 연결된 도메인입니다. |
| 상태 | 업데이트됨, 비활성화됨, 연결되지 않음, 연결 중, 이상. |
| 마지막 업데이트 시간 | 최근 IP를 감지하거나 동기화한 시간입니다. |
| 작업 | 구성 편집, 즉시 새로 고침/업데이트, 활성화/비활성화, 삭제. 삭제 후에는 복구할 수 없습니다. |

### 새 구성/편집

#### 기본 설정

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| 제공업체 | 예 | 도메인 확인 서비스 제공업체를 선택합니다. 추가 후에는 제공업체를 직접 변경할 수 없습니다. |
| 도메인 | 예 | 전체 도메인을 입력합니다. 도메인은 형식을 준수해야 하며 기존 DDNS 구성과 중복될 수 없습니다. |
| AccessKey/API Token/계정 | 제공업체에 따라 다름 | 제공업체가 요구하는 계정 또는 AccessKey입니다. 필드 이름은 제공업체에 따라 달라집니다. |
| SecretKey/API Secret/비밀번호 | 제공업체에 따라 다름 | 제공업체 키입니다. 편집 시 비워 두면 저장된 키를 계속 사용합니다. |
| IPv4 | 예 또는 IPv6 중 하나 이상 | 기본값은 '자동'이며 감지된 공인 IPv4를 표시합니다. 인터페이스 주소 또는 사용자 지정 감지 주소를 선택할 수도 있습니다. |
| IPv6 | 예 또는 IPv4 중 하나 이상 | 기본값은 꺼짐입니다. 자동 공인 IPv6, 인터페이스 IPv6 또는 사용자 지정 감지 주소를 선택할 수 있습니다. |

<Callout title="VPN 안내" type="info">
  페이지 안내: VPN을 켜면 외부 IP 주소 확인이 부정확할 수 있습니다. VPN을 잠시 끄고 다시 구성하거나 올바른 외부 IP 주소를 수동으로 입력할 수 있습니다.
</Callout>

#### 추가 설정

| 필드 | 설명 |
| --- | --- |
| 업데이트 시간 | 1, 5, 10, 15, 30 또는 60분마다 IP 업데이트를 주기적으로 확인합니다. |
| 연결 테스트 | 구성을 즉시 검증합니다. 결과는 연결되지 않음, 연결 중, 업데이트됨 또는 이상으로 표시됩니다. |

#### 하단 옵션

| 옵션 | 설명 |
| --- | --- |
| 구성 활성화 | 해당 DDNS 구성을 활성화할지 제어합니다. |

<Callout title="사용 전제 조건" type="warn">
  DDNS는 도메인 확인만 담당하며 라우터 NAT를 자동으로 통과하지 않습니다. 인터넷에서 NAS에 접근하려면 라우터에서 포트 포워딩을 완료하거나 Station ID 원격 액세스를 사용해야 합니다. 공개 서비스에는 반드시 HTTPS, 강력한 비밀번호 및 2단계 인증을 사용하십시오.
</Callout>

## Station ID 사용 규칙

| 항목 | 설명 |
| --- | --- |
| 문자 규칙 | 4–30자, 소문자, 숫자, 하이픈. 하이픈은 시작과 끝에 올 수 없습니다. |
| 고유성 | 다른 기기에서 이미 사용 중인 ID는 중복 사용할 수 없습니다. |
| 생성 조건 | 원격 액세스 서비스를 켜고 연결을 완료해야 합니다. |
| 수정 영향 | 기존 웹/클라이언트 주소가 즉시 무효화되며 새 ID를 사용해야 합니다. |
| 보안 관계 | Station ID는 비밀번호가 아니며 기기 로컬 계정 로그인이 여전히 필요합니다. |
| 연결 해제 영향 | 원격 액세스를 사용할 수 없으며 다시 사용하려면 다시 연결해야 합니다. |

## 원격 액세스 활성화의 일반적인 절차

1. 알림 설정에서 사용 가능한 이메일을 구성합니다.
2. 원격 액세스 페이지에서 이메일을 연결하고 인증을 완료합니다.
3. 규칙에 맞는 Station ID를 설정합니다.
4. 사용자 계약과 개인정보 처리방침에 동의합니다.
5. 원격 액세스 서비스를 켭니다.
6. 외부 네트워크 브라우저 또는 클라이언트에서 접근을 테스트합니다.
7. HTTPS/강력한 비밀번호/2단계 인증을 사용하는 것이 좋습니다.

## DDNS 필드 상세 설명

| 필드 | 설명 |
| --- | --- |
| 제공업체 | DNS API 주소와 인증 필드를 결정합니다. 추가 후에는 함부로 다시 생성하지 않는 것이 좋으며 편집 시 제공업체를 직접 변경할 수 없습니다. |
| 도메인 | 해당 제공업체에 이미 호스팅된 전체 도메인이어야 합니다. |
| AccessKey/API Token | 제공업체가 DNS 작업 권한을 부여한 자격 증명으로 최소 DNS 권한만 부여하는 것이 좋습니다. |
| SecretKey/API Secret | AccessKey와 쌍을 이루며, 편집 시 비워 두면 저장된 키를 계속 사용할 수 있습니다. |
| IPv4 자동 감지 | 공인 감지 서비스를 사용하여 공인 IPv4를 가져옵니다. |
| IPv4 인터페이스 주소 | 기기의 지정 인터페이스 주소를 사용하며 고정 공인 IP가 있는 환경에 적합합니다. |
| IPv4 사용자 지정 URL | 사용자 지정 서비스가 반환하는 IP를 사용하며 NAT/프록시 환경에 적합합니다. |
| IPv6 | 기본적으로 꺼져 있으며 자동 감지 또는 인터페이스 주소를 사용할 수 있습니다. |
| 업데이트 시간 | 짧을수록 적용이 빠르지만 요청이 더 빈번합니다. |

## DDNS 문제 해결

| 현상 | 확인 |
| --- | --- |
| 연결 테스트 이상 | AccessKey/Secret, 도메인 호스팅업체, API 권한, 서버 네트워크. |
| 도메인 확인 IP가 변경되지 않음 | 로컬 DNS 캐시, TTL, 감지 서비스가 올바른 공인 IP를 가져오는지 확인하십시오. |
| 도메인 확인은 정상이지만 접근 불가 | 라우터 포트 포워딩, 방화벽, 서비스 포트, ISP 차단 여부. |
| VPN 환경 감지 오류 | VPN을 잠시 끄거나 사용자 지정 IP 감지 주소를 사용하십시오. |
| IPv6 사용 불가 | 라우터/통신사 IPv6 프리픽스, 인터페이스 주소, 방화벽 허용. |
