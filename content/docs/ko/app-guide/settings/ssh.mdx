SSH 페이지는 원격 명령줄 서비스를 켜거나 끄는 데 사용됩니다. 관리자는 SSH를 통해 진단 명령을 실행하고 시스템 문제를 해결할 수 있으며, SFTP를 켜면 SSH 채널을 통해 파일을 전송할 수도 있습니다.

![SSH](/images/ko/app-guide/settings-img/ssh.png)

## 기본 설정

| 옵션 | 설명 |
| --- | --- |
| 활성화 | SSH 서비스를 켭니다. 끄면 SSH/SFTP로 기기에 연결할 수 없습니다. |
| 포트 | SSH 수신 포트로 기본값은 22입니다. 스캔 노출을 줄이기 위해 사용되지 않는 다른 포트로 변경할 수 있습니다. |
| 유효 기간 | 서비스를 켜 두는 시간으로 10분, 30분, 1시간, 3시간, 6시간 또는 영구를 선택할 수 있습니다. 단기 활성화는 임시 문제 해결에 적합하며 만료 후 자동으로 꺼집니다. |
| 고급 설정 | 암호화 알고리즘 강도, 접근 범위 및 SFTP를 구성합니다. |
| 적용 | 포트, 유효 기간 및 고급 설정 수정 사항을 저장합니다. |

## 고급 설정

| 옵션 | 설명 |
| --- | --- |
| 암호화 알고리즘 | 높음, 중간, 낮음을 선택할 수 있습니다. '높음'을 사용하는 것이 좋으며 구형 클라이언트가 연결을 협상하지 못할 때만 강도를 낮추십시오. |
| 접근 제한 | **LAN만**을 켜면 SSH가 LAN 연결만 허용하고 인터넷에서의 원격 SSH 접근을 금지합니다. |
| SFTP | 켜면 SFTP 클라이언트로 SSH 계정을 사용하여 파일을 전송할 수 있습니다. 끄면 명령줄 SSH만 유지됩니다. |

## 연결 예시

1. 컴퓨터에서 터미널 또는 SSH 클라이언트를 엽니다.
2. `ssh 用户名@设备IP -p 端口`를 입력합니다.
3. 기기 로컬 계정 비밀번호로 로그인합니다.
4. SFTP를 사용하는 경우 클라이언트 프로토콜에서 SFTP를 선택하고 주소에 기기 IP, 포트에 현재 SSH 포트를 입력합니다.

<Callout title="보안 권장 사항" type="warn">
  - SSH를 공용 인터넷에 장기간 개방하지 마십시오. 원격 유지 관리가 꼭 필요하면 단기 유효 기간을 사용하고 LAN만 또는 VPN 접근을 켜십시오.
  - 22 등 기본 포트, 약한 비밀번호를 사용하거나 관리자 비밀번호를 신뢰할 수 없는 사람과 공유하지 마십시오.
  - SSH 명령은 시스템 상태를 직접 변경할 수 있으므로 출처를 알 수 없는 명령을 실행하면 서비스 이상이나 데이터 손실이 발생할 수 있습니다.
</Callout>

## 사용 모드 권장 사항

| 시나리오 | 권장 구성 |
| --- | --- |
| 임시 기술 지원 | 10/30분, LAN만. |
| 일상적인 내부 네트워크 유지 관리 | 영구 + LAN만, 높은 암호화 강도 유지. |
| 원격 문제 해결 | VPN 또는 Station ID 원격 액세스로 내부 네트워크에 접속한 후 단기 SSH를 켭니다. |
| 파일 전송 필요 | SFTP를 켜고 통제된 계정과 명확한 디렉터리를 사용합니다. |
| 구형 클라이언트가 연결 불가 | 먼저 계정 비밀번호와 포트를 확인하고, 새 알고리즘을 지원하지 않는 것이 확실할 때만 암호화 수준을 임시로 낮춥니다. |

## 작업 절차

1. 반드시 명령줄 유지 관리가 필요한지 확인하고 웹 관리 인터페이스를 우선 고려합니다.
2. 기본이 아닌 포트와 단기 유효 기간을 설정합니다.
3. 고급 설정을 열고 높은 암호화 알고리즘을 유지합니다.
4. LAN만을 켜고 필요에 따라 SFTP를 켭니다.
5. 적용을 클릭하고 클라이언트로 테스트합니다.
6. 유지 관리가 끝나면 SSH를 끕니다.

## 문제 해결

| 현상 | 확인 |
| --- | --- |
| Connection refused | SSH가 꺼져 있음, 포트 오류, 서비스가 수신 중이 아님. |
| Timeout | 방화벽, 라우팅, LAN만 제한, IP 불통. |
| Auth failed | 사용자 이름/비밀번호 오류, 사용자 비활성화, 권한 부족. |
| 알고리즘 협상 실패 | 클라이언트가 너무 오래되었거나 암호화 알고리즘이 호환되지 않음. |
| SFTP 연결은 되지만 쓰기 불가 | 디렉터리 권한, 스토리지 볼륨 읽기 전용, 사용자 할당량 초과. |
