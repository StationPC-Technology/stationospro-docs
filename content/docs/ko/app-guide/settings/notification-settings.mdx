알림 설정 페이지는 **이메일**과 **알림 언어**로 나뉩니다. 이메일 알림 서비스는 2단계 인증 긴급 인증 코드, 비밀번호 재설정 이메일 등 계정 보안 이메일을 보내는 데 사용되며, 알림 언어는 이메일, SMS 등 푸시 콘텐츠에 사용할 언어를 결정합니다.

## 이메일

![Email Notification](/images/ko/app-guide/settings-img/notifications.png)

### 이메일 알림 서비스

| 기능/필드 | 설명 |
| --- | --- |
| 서비스 스위치 | 켜면 시스템이 지정된 SMTP 서비스를 통해 보안 이메일을 보낼 수 있습니다. |
| 발신 이메일 | 현재 발신 이메일을 표시하며 구성되지 않았으면 '구성되지 않음'으로 표시됩니다. |
| 편집 | 이메일 설정 팝업을 열어 서비스 제공업체, 발신 이메일 및 인증 정보를 구성합니다. |
| 이메일 제목 접두사 | 시스템 이메일 제목 접두사를 설정하여 사서함에서 출처 기기를 쉽게 식별할 수 있습니다. |
| 테스트 이메일 보내기 | 지정된 수신 이메일로 테스트 이메일을 보내 SMTP 구성이 사용 가능한지 확인합니다. |

<Callout title="2단계 인증 의존성" type="warn">
  2단계 인증은 이메일 알림 서비스의 지원이 필요합니다. 시스템이 2단계 인증을 강제로 사용하는 경우 이메일 서비스를 직접 끄면 로그인 인증 코드를 보내지 못할 수 있습니다. 페이지에서는 먼저 계정 보안 설정으로 이동하여 2단계 인증을 끄라고 안내합니다.
</Callout>

### 이메일 설정

#### 사전 설정 이메일

Gmail, QQ 메일, 126 메일, 163 메일을 선택할 때는 다음을 구성해야 합니다:

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| 이메일 서비스 제공업체 | 예 | 시스템에 사전 설정된 제공업체를 선택합니다. |
| 발신 이메일 | 예 | 시스템 이메일 발송에 사용할 이메일 주소입니다. |
| 인증 코드 | 예 | 이메일 서비스 제공업체에서 생성한 SMTP 인증 코드로, 일반적으로 이메일 로그인 비밀번호가 아닙니다. |

사전 설정 이메일은 일반적으로 SSL 465 포트를 사용합니다. 페이지에서는 방화벽 아웃바운드 규칙이 해당 포트를 차단하지 않는지 확인하라고 안내합니다.

#### 사용자 지정 이메일

사용자 지정 이메일을 선택한 후에는 다음을 구성해야 합니다:

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| SMTP 서버 | 예 | 이메일 서비스 제공업체의 SMTP 주소입니다. 예: `smtp.example.com`. |
| 포트 | 예 | SMTP 서비스에 따라 입력합니다. 일반적인 기본 포트: 암호화 없음 25, SSL 465, TLS 587. |
| 보안 유형 | 예 | 없음, SSL, TLS 중 선택할 수 있으며 SSL 또는 TLS 사용을 권장합니다. |
| 사용자 이름 | 예 | SMTP 인증 사용자 이름으로 일반적으로 이메일 계정입니다. |
| 비밀번호 | 예 | SMTP 비밀번호 또는 인증 코드입니다. |
| 발신자 이름 | 아니요 | 이메일 발신자 이름에 표시됩니다. |
| 발신 이메일 | 예 | 실제로 외부에 발송하는 이메일 주소입니다. |

### 이메일 제목 접두사

| 옵션 | 설명 |
| --- | --- |
| 기기 이름 사용 | 현재 기기 이름을 이메일 제목 접두사로 자동 사용합니다. |
| 사용자 지정 | 접두사를 직접 입력하며 이 방식을 선택하면 접두사가 필수입니다. |

이메일 제목 접두사는 여러 기기가 하나의 이메일로 알림을 수신할 때 출처 기기를 빠르게 구분하는 데 적합합니다.

### 테스트 이메일 보내기

1. 이메일 서비스가 구성되고 켜져 있는지 확인합니다.
2. **테스트 이메일 보내기**를 클릭합니다.
3. 수신 이메일을 입력합니다.
4. **보내기**를 클릭합니다.
5. 받은편지함에서 테스트 이메일을 확인합니다. 수신하지 못하면 인증 코드, SMTP 포트, 보안 유형 및 방화벽 아웃바운드 규칙을 확인하십시오.

## 알림 언어

![Notification Language](/images/ko/app-guide/settings-img/notification-language.png)

| 옵션 | 설명 |
| --- | --- |
| 알림 언어 | 이메일, SMS 등 푸시 콘텐츠의 언어를 제어합니다. |
| 선택 가능한 언어 | 简体中文, 繁體中文, English, 日本語, 한국어, Deutsch, Français, Español. |
| 적용 | 언어 수정 사항을 저장합니다. |

<Callout title="팁" type="info">
  알림 언어는 시스템 푸시 콘텐츠에만 영향을 주며 웹 데스크톱 인터페이스 언어를 직접 전환하지는 않습니다. 데스크톱 언어는 개인 설정에서 조정할 수 있습니다.
</Callout>

## 이메일 구성 문제 해결

| 현상 | 확인 |
| --- | --- |
| 인증 코드 오류 | 서비스 제공업체에서 SMTP를 활성화했는지, 인증 코드를 완전히 복사했는지, 로그인 비밀번호를 인증 코드 대신 사용하지 않았는지 확인하십시오. |
| SMTP 연결 시간 초과 | SMTP 주소, 포트, 보안 유형, 방화벽 아웃바운드 규칙. |
| SSL 포트를 사용하지만 TLS 선택 | 서비스 제공업체 문서를 확인하십시오. 일반적으로 465/SSL, 587/TLS입니다. |
| 이메일이 스팸함으로 이동 | 발신자 이름, SPF/DKIM/DMARC, 사용자 지정 도메인 DNS. |
| 테스트 이메일은 성공하지만 인증 코드를 받지 못함 | 받은편지함 스팸, 알림 언어, 계정 보안 정책, 이메일 지연. |
| 이메일 서비스 종료가 차단됨 | 시스템이 2단계 인증의 이메일 의존성을 감지했으므로 관련 정책을 먼저 꺼야 합니다. |

## 사용자 지정 SMTP 체크리스트

1. SMTP 서버 주소가 서비스 제공업체 권장 주소인지 확인합니다.
2. 포트와 보안 유형이 일치하는지 확인합니다.
3. 사용자 이름이 전체 이메일 또는 제공업체가 요구하는 계정인지 확인합니다.
4. 비밀번호/인증 코드에 공백이나 줄바꿈이 없는지 확인합니다.
5. 발신 이메일이 SMTP 계정과 일치하거나 제공업체가 별칭을 명확히 허용하는지 확인합니다.
6. 방화벽이 해당 아웃바운드 포트를 차단하지 않는지 확인합니다.
7. 테스트 이메일을 보내고 스팸함을 확인합니다.

## 언어 및 다중 기기 알림

- 알림 언어는 시스템이 보내는 이메일 또는 SMS 콘텐츠에 적용됩니다.
- 이미 발송된 이메일은 이후 수정으로 다시 번역되지 않습니다.
- 여러 기기가 동일한 발신 이메일을 사용할 때는 기기 이름, 위치 또는 용도 등 서로 다른 제목 접두사를 설정하는 것이 좋습니다.
