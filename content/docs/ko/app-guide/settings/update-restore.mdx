업데이트 및 복원 페이지는 **시스템 업데이트**와 **복원 및 재설정**으로 나뉩니다. 시스템 업데이트 페이지는 온라인에서 펌웨어를 확인하고 다운로드하여 설치하거나 로컬 펌웨어를 수동으로 설치하는 데 사용되며, 복원 및 재설정 페이지는 시스템 기본 설정을 복원하거나 네트워크를 재설정하는 데 사용됩니다.

## 시스템 업데이트

![System Update](/images/ko/app-guide/settings-img/update.png)

### 현재 버전 정보

| 필드 | 설명 |
| --- | --- |
| 현재 버전 | 현재 시스템 버전 번호입니다. 예: `v1.1.0.17`. |
| 업데이트 확인 | 수동으로 업데이트 서버에 새 버전을 문의합니다. 확인 결과에 최신 버전 여부가 표시됩니다. |
| 마지막 확인 시간 | 일부 버전에서는 최근 업데이트 확인 시간이 표시됩니다. |

### 자동 업데이트

| 옵션 | 설명 |
| --- | --- |
| 업데이트 자동 설치 | 켜면 시스템이 업데이트를 자동으로 다운로드하고 설치하며 필요할 때 자동으로 재시작할 수 있습니다. 끄면 새 버전 알림은 계속 받지만 **재시작 및 업그레이드**를 수동으로 클릭해야 업그레이드됩니다. |

<Callout title="작업 권장 사항" type="warn">
  업데이트는 시스템 서비스와 모든 앱 서비스에 영향을 줍니다. 먼저 백업, 동기화, 다운로드, 인덱싱 및 컨테이너 쓰기 작업을 중지하고 전원이 안정적인지 확인하는 것이 좋습니다. 업데이트 중에는 전원을 끄거나 페이지를 새로 고치거나 강제로 종료하지 마십시오.
</Callout>

### 수동 설치

| 옵션 | 설명 |
| --- | --- |
| Click to select | 로컬에 다운로드한 펌웨어 파일을 선택합니다. 현재 화면 안내에서는 현재 버전보다 높은 펌웨어 패키지를 선택해야 합니다. |
| 파일 형식 | 시스템 안내에 따라 지원되는 펌웨어 형식을 업로드합니다. 업로드 후 시스템이 체크섬을 계산하고 버전을 검증합니다. |
| 버전 검증 | 설치 패키지 버전이 현재 버전보다 낮거나 같으면 시스템이 설치를 차단하거나 설치할 수 없다고 안내합니다. |
| 설치 절차 | 펌웨어 업로드 → 검증 → 업데이트 안내 확인 → 시스템 설치 및 재시작 대기. |

### 업데이트 로그

| 기능 | 설명 |
| --- | --- |
| View details | 버전 업데이트 기록을 엽니다. 버전 번호, 버전 유형, 릴리스 시간 및 기능/버그 수정 내용을 확인할 수 있습니다. |

## 복원 및 재설정

![Restore and Reset](/images/ko/app-guide/settings-img/restore.png)

### 공장 초기화

| 항목 | 설명 |
| --- | --- |
| 영향 범위 | 시스템 설정이 공장 기본값으로 복원되며 하드 디스크 데이터는 유지됩니다. |
| 검증 | 관리자 신원을 검증해야 합니다. |
| 재시작 | 기기가 자동으로 재시작되며 복원 과정에서 전원을 끄지 마십시오. |
| 네트워크/IP | 재설정 후 기존 IP로 접근할 수 없으면 기기 화면에서 새 IP를 확인하고 다시 등록하십시오. |
| 계정 연결 해제 | 계정 연결을 해제해야 하는 경우 안내에 따라 StationCloud 계정 센터로 이동하여 작업하십시오. |

### 네트워크 재설정

| 항목 | 설명 |
| --- | --- |
| 영향 범위 | 모든 네트워크 연결 설정과 방화벽 설정이 초기 상태로 복원됩니다. |
| 전제 조건 | 유선 네트워크가 최소 하나 사용 가능한지 확인하십시오. |
| 연결 영향 | 재설정 과정과 완료 후 현재 연결이 끊길 수 있으며 IP를 다시 가져와야 할 수 있습니다. |
| 검증 | 관리자 신원을 검증해야 합니다. |

<Callout title="위험 작업" type="error">
  공장 초기화와 네트워크 재설정은 모두 시스템 서비스를 중단하고 재시작이 필요합니다. 실행 전에 네트워크 매개변수를 기록하고 구성을 백업하며 로컬에서 연결을 복구할 수 있는 경로가 있는지 확인하십시오.
</Callout>

## 온라인 업데이트 절차

1. **업데이트 확인**을 클릭합니다.
2. 새 버전이 발견되면 버전 번호, 패키지 크기 및 업데이트 설명을 확인합니다.
3. 업데이트 안내를 읽고 고위험 쓰기 작업을 중지했는지 확인합니다.
4. 지금 업데이트 또는 계속 업데이트를 클릭합니다.
5. 시스템이 업데이트 조건을 확인하며 차단 작업이 있으면 먼저 처리해야 합니다.
6. 다운로드, 설치 및 자동 재시작을 기다립니다.
7. 업데이트 완료 후 다시 로그인하여 버전, 스토리지, 앱 및 네트워크 상태를 확인합니다.

## 업데이트 조건 및 차단 작업

시스템은 업데이트 전에 실행 중인 작업을 확인할 수 있습니다. 일부 작업은 업데이트를 직접 차단하고, 일부 작업은 먼저 중지할 것을 권장합니다:

- 백업, 동기화 및 다운로드 작업
- 컨테이너 쓰기 또는 데이터베이스 서비스
- 파일 인덱싱 또는 AI 모델 작업
- 스토리지 볼륨 동기화, 복구 또는 포맷
- 기타 하드 디스크에 지속적으로 쓰기 가능한 서비스

차단 항목을 처리한 후 업데이트를 계속하면 업그레이드 중단으로 인한 데이터 위험을 줄일 수 있습니다.

## Beta 버전 업데이트

페이지에 **Beta 버전 업데이트**가 표시되면 켜서 테스트 버전 내부 테스트에 참여하고 미완성 기능을 미리 체험할 수 있습니다. 테스트 버전은 안정성, 호환성 및 기능 불완전 문제가 있을 수 있습니다:

- 중요한 데이터가 있는 기기에서는 켜지 않는 것이 좋습니다.
- 운영 환경 또는 무인 기기에서는 켜지 않는 것이 좋습니다.
- 업데이트 전에 전체 백업을 수행해야 합니다.
- 문제가 발생하면 로그 센터와 피드백 채널을 통해 제출할 수 있습니다.

## 수동 설치 세부 규칙

- `.zip` 펌웨어 패키지만 선택할 수 있습니다.
- 설치 패키지 버전은 현재 버전보다 높아야 하며, 낮거나 같으면 거부됩니다.
- 업로드 중에 일시 중지, 계속 또는 취소할 수 있습니다.
- 업로드 완료 후 시스템이 체크섬을 계산하고 펌웨어 정보를 분석합니다.
- 확인 후 업데이트 조건 확인 및 업그레이드 확인 단계로 진행합니다.
- 업데이트 중에는 브라우저 전원을 끄거나 시스템을 새로 고치거나 전원 공급을 차단하지 마십시오.

## 복원과 재설정 비교

| 작업 | 공장 초기화 | 네트워크 재설정 |
| --- | --- | --- |
| 시스템 설정 | 기본값으로 복원 | 네트워크 및 방화벽 설정이 기본값으로 복원 |
| 하드 디스크 데이터 | 유지 | 유지 |
| 관리자 검증 | 필요 | 필요 |
| 네트워크 | IP가 변경될 수 있음 | IP/연결이 반드시 변경될 수 있음 |
| 앱 구성 | 기본값으로 복원되거나 재구성 필요 | 일반적으로 네트워크 관련 구성에만 영향 |
| 적용 시나리오 | 구성을 비우고 이전/재초기화 | 네트워크 구성이 혼란스럽고 복구할 수 없을 때 |
