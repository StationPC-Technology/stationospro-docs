하드 디스크 페이지는 기기에서 인식된 내장 하드 디스크와 외장 하드 디스크를 확인하는 데 사용됩니다. 이곳에서 하드 디스크 용량, 인터페이스, 온도 및 전원 인가 시간을 확인할 수 있으며, 상태 상세로 들어가 S.M.A.R.T 검사를 실행하거나 사용하지 않는 하드 디스크에 포맷, 안전하게 분리 등의 유지 관리 작업을 수행할 수 있습니다.

## 하드 디스크 목록

페이지 상단에는 세 개의 필터 탭이 있습니다:

| 탭 | 설명 |
| --- | --- |
| 전체 | 내장 하드 디스크와 외장 하드 디스크를 함께 표시합니다. '전체' 보기에서는 내장 하드 디스크와 외장 하드 디스크로 그룹화됩니다. |
| 내장 | 기기 내부에 설치된 하드 디스크만 표시합니다. |
| 외장 | USB 등 외장 스토리지 장치만 표시합니다. |

![Disk](/images/ko/app-guide/settings-img/disk.png)

## 하드 디스크 카드 정보

각 하드 디스크 카드에는 다음이 표시됩니다:

| 필드 | 설명 |
| --- | --- |
| 하드 디스크 이름 | 시스템이 할당한 식별 이름입니다. 예: DiskA, Disknvme0n1. |
| 용도/소속 스토리지 공간 | 사용 가능, 마운트되지 않음, 소속 스토리지 볼륨, 캐시 풀 등의 용도를 표시합니다. |
| 총 용량 | 하드 디스크의 사용 가능한 총 용량입니다. |
| 하드 디스크 유형 | HDD, SSD 등. |
| 상태 | 정상, 이상, 경고 또는 알 수 없음. |
| 모델 | 하드 디스크 제조사 모델입니다. |
| 인터페이스 | SATA, NVMe, USB 등. |
| 일련번호 | 하드 디스크 고유 일련번호이며 클릭하여 복사할 수 있습니다. |
| 공급업체 | 하드 디스크 브랜드 또는 제조사입니다. |
| 온도 | 현재 하드 디스크 온도입니다. 온도가 지속적으로 높으면 고장 위험이 증가합니다. |
| 전원 인가 시간 | 하드 디스크의 누적 전원 인가 시간으로 사용 연한을 평가하는 데 사용할 수 있습니다. |
| 파티션 | 외장 또는 완전히 사용되지 않은 하드 디스크에는 파티션 정보가 표시될 수 있습니다. |

## 하드 디스크 작업

하드 디스크 카드 오른쪽의 더 보기 버튼을 클릭하면 사용 가능한 작업은 하드 디스크의 현재 용도에 따라 달라집니다:

| 작업 | 적용 대상 | 설명 |
| --- | --- | --- |
| 하드 디스크 포맷 | 사용 가능한 하드 디스크, 외장 하드 디스크 또는 사용하지 않는 파티션 | 하드 디스크 데이터를 지우고 파일 시스템을 다시 생성합니다. 전체 하드 디스크 또는 지정된 파티션을 포맷할 수 있습니다. |
| 안전하게 분리 | 외장 하드 디스크 | 관련 서비스를 중지한 후 하드 디스크를 안전하게 제거하여 데이터 손상 위험을 줄입니다. |
| 상태 상세 | 상태 검사를 지원하는 하드 디스크 | S.M.A.R.T 검사 및 상태 속성 페이지를 엽니다. |
| 하드 디스크 비활성화 | 비활성화를 지원하는 내장 구성원 디스크 | 하드 디스크를 연결된 스토리지 공간에서 제거합니다. 비활성화는 스토리지 이중화에 영향을 줄 수 있으므로 신중하게 실행해야 합니다. |
| 읽기 전용 표시 | 읽기 전용 하드 디스크 | 하드 디스크가 읽기 전용 상태일 때 포맷 등 쓰기 작업이 비활성화됩니다. |

### 포맷 설정

| 옵션 | 선택 값 | 설명 |
| --- | --- | --- |
| 포맷 대상 | 전체 하드 디스크 / 파티션 | 전체 디스크를 지울지 특정 파티션만 지울지 선택합니다. |
| 포맷 후 파일 시스템 | exFAT / EXT4 | exFAT은 Windows와 macOS 간 크로스 플랫폼 사용에 적합하고, EXT4는 Linux에서 일반적으로 사용되는 파일 시스템으로 NAS에 장기간 연결하여 사용하는 데 적합합니다. |

<Callout title="위험 작업" type="error">
  포맷은 대상 하드 디스크 또는 파티션의 모든 데이터를 삭제하며 작업이 시작되면 중단할 수 없습니다. 포맷 중에는 전원을 끄거나 재시작하거나 하드 디스크를 분리·삽입하지 마십시오.
</Callout>

## 하드 디스크 상태 상세

**상태 상세**를 클릭하면 하드 디스크 상태 정보를 확인하고 검사를 실행할 수 있습니다.

![Disk Health](/images/ko/app-guide/settings-img/disk-health.png)

### 검사 방식

| 검사 방식 | 예상 시간 | 설명 |
| --- | --- | --- |
| 빠른 검사 | 약 2분 | 기본 진단 테스트로 기계적·전기적 오류를 검사하며 일상 점검에 적합합니다. |
| 전체 검사 | 약 2시간 30분 | 하드 디스크를 전면 스캔하여 결과가 더 정확하지만 시간이 더 오래 걸립니다. 두 검사 모두 하드 디스크의 정상 사용에 영향을 주지 않습니다. |

### 검사 상태 및 결과

- **검사 시작**: 검사 작업을 제출합니다.
- **검사 중**: 현재 진행률을 확인할 수 있으며 필요하면 검사를 중지할 수 있습니다.
- **검사 결과**: 현재 검사 결론을 표시합니다.
- **S.M.A.R.T 속성 표**: 번호, 지표, 결과, 현재 값, 최악 값, 참조 값 및 원시 데이터를 표시합니다. 임계값은 하드 디스크 제조사가 정의하며, 이상 항목이 곧바로 하드 디스크 손상을 의미하지는 않지만 지속적인 관찰이 필요합니다.

<Callout title="유지 관리 권장 사항" type="warn">
  상태가 비정상이거나 온도가 지속적으로 높거나 여러 S.M.A.R.T 지표가 임계값에 가까워지면 즉시 해당 하드 디스크와 연결된 스토리지 볼륨의 중요한 데이터를 백업하고 가능한 한 빨리 하드 디스크를 교체하십시오.
</Callout>

## 상태 및 용도 표시 해석

| 표시 | 의미 | 권장 사항 |
| --- | --- | --- |
| Normal | 하드 디스크 상태 검사가 정상입니다. | 정기적인 검사와 백업을 유지하십시오. |
| Warning | 의심스러운 속성이 있거나 온도가 높습니다. | 즉시 데이터를 백업하고 계속 관찰하십시오. |
| Abnormal/Serious | 검사 결과가 비정상입니다. | 불필요한 쓰기를 중지하고 가능한 한 빨리 하드 디스크를 교체하십시오. |
| Unknown | 유효한 상태 데이터를 가져오지 못했거나 하드 디스크/브리지 장치가 전체 S.M.A.R.T를 지원하지 않습니다. | 연결 방식을 변경하거나 하드 디스크 상세 정보를 확인하십시오. |
| Storage volume N | 하드 디스크가 해당 스토리지 볼륨에 속합니다. | 작업 전에 볼륨 상태와 이중화 능력을 확인하십시오. |
| Cache pool | 하드 디스크가 SSD 캐시에 사용됩니다. | 먼저 스토리지 공간에서 캐시를 삭제한 후 하드 디스크를 제거하십시오. |
| Unused | 하드 디스크가 스토리지 구조에 사용되지 않습니다. | 볼륨, 캐시 또는 기타 구성 생성에 사용할 수 있습니다. |
| Not mounted | 외장 하드 디스크가 마운트되지 않았습니다. | 파일 시스템, 연결 상태 및 하드 디스크 상태를 확인하십시오. |
| Read-only | 하드 디스크 또는 파일 시스템이 보호를 위해 쓰기 금지되었습니다. | 먼저 데이터를 백업하고 강제로 포맷하지 마십시오. |
| Formatting | 하드 디스크가 포맷 중입니다. | 완료될 때까지 기다리고 전원을 끄거나 분리하지 마십시오. |

## 포맷 결정

| 목표 | 권장 사항 |
| --- | --- |
| Windows와 macOS 모두에서 직접 읽기/쓰기 | exFAT. |
| NAS에서만 장기간 사용, 안정성 우선 | EXT4. |
| 하드 디스크에 이전에 이상이 있었음 | 먼저 상태 검사를 실행하고 데이터를 백업한 후 포맷 여부를 결정하십시오. |
| 파티션만 정리하려는 경우 | 파티션 포맷을 선택하여 전체 디스크를 실수로 삭제하지 마십시오. |
| 하드 디스크에 시스템 또는 스토리지 구성원 데이터가 포함됨 | 포맷하지 말고 먼저 소속 볼륨과 용도를 확인하십시오. |

## S.M.A.R.T 주요 항목

- **Reallocated Sectors Count**: 재할당 섹터가 계속 증가하면 매체가 불안정함을 의미합니다.
- **Current Pending Sector**: 재매핑 대기 섹터가 증가하면 불량 섹터를 예고할 수 있습니다.
- **Offline Uncorrectable**: 오류를 수정할 수 없으므로 가능한 한 빨리 데이터를 백업해야 합니다.
- **Temperature**: 장기간 고온은 노화를 가속합니다.
- **Power-On Time**: 사용 연한과 함께 보증 및 교체 계획을 평가합니다.
- **Raw Data**: 제조사마다 인코딩 방식이 다르므로 수치 크기만 비교해서는 안 됩니다.

<Callout title="검사 권장 사항" type="info">
  빠른 검사는 일상 점검에 적합합니다. 하드 디스크 교체, 볼륨 저하, 빈번한 연결 끊김 또는 I/O 오류가 발생하면 전체 검사를 실행하는 것이 좋습니다. 검사는 일반적인 사용에 영향을 주지 않지만 고부하 기간에는 결과가 방해받을 수 있습니다.
</Callout>
