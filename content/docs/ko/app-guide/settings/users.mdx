사용자 관리 페이지는 **사용자**와 **사용자 그룹** 두 개의 탭으로 나뉩니다. 관리자는 이곳에서 로컬 계정을 생성하고 계정 상태를 제어하며 역할과 접근 가능한 스토리지 공간을 설정할 수 있고, 사용자 그룹을 통해 구성원을 일괄적으로 구성할 수도 있습니다.

## 사용자 탭

### 페이지 레이아웃

- **왼쪽 사용자 목록**: 모든 사용자를 표시하며 사용자 이름으로 검색할 수 있습니다. 목록에는 아바타, 사용자 이름, 역할 및 상태가 표시됩니다.
- **오른쪽 사용자 상세 정보**: 선택한 사용자의 기본 정보, 접근 가능한 스토리지 공간 및 소속 사용자 그룹을 표시합니다.
- **사용자 추가**: 왼쪽 목록 위의 추가 버튼을 클릭하여 로컬 계정을 생성합니다.

![Users](/images/ko/app-guide/settings-img/users.png)

### 사용자 역할 및 상태

| 옵션 | 값 | 권한/영향 |
| --- | --- | --- |
| 역할 | 관리자 | 시스템 설정에 로그인하여 시스템 구성, 사용자, 스토리지, 보안 및 앱을 관리할 수 있습니다. |
| 역할 | 일반 사용자 | 권한이 부여된 범위 내에서 파일과 앱 기능을 사용하며 시스템 설정은 관리할 수 없습니다. |
| 상태 | 활성화 | 사용자가 정상적으로 로그인할 수 있습니다. |
| 상태 | 비활성화 | 사용자가 기기에 로그인할 수 없습니다. 기존 공유, 작업 또는 파일 권한이 즉시 데이터 삭제를 의미하지는 않습니다. |

### 사용자 생성 또는 편집

사용자를 생성하고 편집할 때 다음 정보가 포함될 수 있습니다:

| 필드/기능 | 설명 |
| --- | --- |
| 사용자 이름 | 지정된 길이 내의 영문자, 숫자 및 `-`를 사용할 수 있습니다. `-`는 시작이나 끝에 올 수 없으며 일부 예약 이름은 사용할 수 없습니다. |
| 아바타 | 사용자 아바타를 업로드하거나 변경합니다. 이미지는 형식과 크기 제한을 충족해야 합니다. |
| 로그인 비밀번호/새 비밀번호 | 6~30자의 영문자, 숫자 및 `@#*-_`를 지원하며 영문자와 숫자를 모두 포함해야 합니다. |
| 비밀번호 확인 | 비밀번호를 다시 입력하며 두 입력이 일치해야 합니다. |
| 사용자 정보 편집 | 아바타, 사용자 이름, 역할, 상태 등 기본 정보를 수정합니다. |
| 비밀번호 변경 | 사용자에게 새 비밀번호를 설정합니다. 변경 후에는 새 비밀번호로 로그인해야 합니다. |
| 관리자로 설정 | 일반 사용자를 관리자로 승격합니다. 승격 전 시스템이 확인을 요청합니다. |
| 비활성화/활성화 | 사용자 로그인을 일시적으로 금지하거나 복구하며 사용자 삭제와는 다릅니다. |
| 사용자 삭제 | 계정과 개인 폴더의 데이터를 삭제합니다. 시스템이 복구할 수 없다고 안내하므로 해당 사용자에 의존하는 작업이나 공유가 없는지 먼저 확인하십시오. |

### 접근 가능한 스토리지 공간

사용자 상세 정보의 **접근 가능한 스토리지 공간**에서 **편집**을 클릭하여 사용자가 사용할 수 있는 스토리지 볼륨과 용량을 설정할 수 있습니다:

| 필드 | 설명 |
| --- | --- |
| 스토리지 공간 | 볼륨 이름, 사용된 용량, 전체 용량 및 해당 사용자의 최대 사용 가능 용량을 표시합니다. |
| 최대 사용 가능 용량 | `Unlimited`를 선택하거나 구체적인 할당량을 입력할 수 있습니다. 할당량은 스토리지 볼륨의 사용 가능 범위를 초과할 수 없습니다. |
| 저장 | 저장 후 사용자의 쓰기 가능 범위가 즉시 업데이트됩니다. 할당량은 해당 사용자의 쓰기 가능 용량만 제한하며 데이터가 이미 점유되었음을 의미하지는 않습니다. |

<Callout title="주의" type="warn">
  사용자를 삭제하면 해당 사용자 개인 폴더의 데이터도 함께 삭제되며 작업은 복구할 수 없습니다. 삭제 전에 팀 파일을 이전하고 개인 데이터를 백업하며 백업 작업, 공유 링크, 동기화 작업 및 앱 권한이 해당 계정에 더 이상 의존하지 않는지 확인하십시오.
</Callout>

## 사용자 그룹 탭

### 페이지 레이아웃

- **왼쪽 그룹 목록**: 모든 사용자 그룹과 구성원 수를 표시하며 검색을 지원합니다. Admin, Standard User 등 기본 제공 그룹은 임의로 삭제할 수 없습니다.
- **오른쪽 그룹 상세 정보**: 그룹 이름, 비고, 구성원 목록 및 구성원 역할을 표시합니다.
- **사용자 그룹 추가**: 사용자 지정 사용자 그룹을 생성합니다.
- **구성원 추가**: 기존 사용자 중 하나 이상을 선택하여 그룹에 추가합니다.
- **사용자 그룹 편집**: 그룹 이름, 비고 또는 구성원을 수정합니다.
- **사용자 그룹 삭제**: 사용자 지정 그룹을 삭제합니다. 그룹 삭제는 일반적으로 구성원 계정을 삭제하지 않지만 그룹 기반 권한이 부여된 리소스 접근에 영향을 줍니다.

### 주요 필드

| 필드 | 설명 |
| --- | --- |
| 사용자 그룹 이름 | 그룹을 식별하는 데 사용하며 부서, 가족 역할 또는 프로젝트별로 이름을 지정하는 것이 좋습니다. |
| 비고 | 선택 사항이며 그룹 용도나 권한 범위를 기록합니다. |
| 구성원 | 그룹 내 사용자 목록이며 검색할 수 있습니다. |
| 구성원 역할 | 시스템에서 구성원의 역할을 표시합니다. 예: Admin. |

<Callout title="권장 사항" type="info">
  여러 사용자에게 동일한 파일 또는 앱 권한이 필요할 때는 사용자 그룹 권한 부여를 우선 사용하십시오. 이후에는 그룹 구성원만 조정하면 되며 각 계정을 하나씩 수정할 필요가 없습니다.
</Callout>

## 사용자 추가 전체 절차

| 단계 | 작업 | 핵심 확인 |
| --- | --- | --- |
| 1 | **사용자 추가** 클릭 | 사용자 추가 마법사를 엽니다. |
| 2 | 기본 정보 입력 | 사용자 이름이 형식에 맞는지, 비밀번호에 영문자와 숫자가 모두 포함되는지, 두 비밀번호가 일치하는지 확인합니다. |
| 3 | 아바타 설정 | 이미지 파일만 선택하며 크기는 2MB를 초과할 수 없습니다. |
| 4 | 사용자 유형/역할 선택 | 일상적인 사용에는 일반 사용자를 우선하며 모든 사용자가 관리자 권한을 갖지 않도록 합니다. |
| 5 | 접근 가능한 스토리지 공간 구성 | 어떤 볼륨에 쓸 수 있는지 명확히 하고 용량 제한 여부를 결정합니다. |
| 6 | 소속 사용자 그룹 설정 | 부서, 가족 역할 또는 프로젝트별로 구분된 그룹에 사용자를 추가합니다. |
| 7 | 확인 및 생성 | 할당량, 역할 및 개인 데이터 삭제 안내를 확인합니다. |

## 권한 및 데이터 영향

| 작업 | 즉시 영향 | 데이터 영향 | 복구 가능성 |
| --- | --- | --- | --- |
| 비밀번호 변경 | 해당 계정의 모든 기기에서 로그아웃됩니다. | 데이터를 삭제하지 않습니다. | 다시 변경할 수 있습니다. |
| 사용자 비활성화 | 사용자가 로그인할 수 없으며 관련 세션을 계속 사용할 수 없습니다. | 사용자 데이터를 유지합니다. | 다시 활성화할 수 있습니다. |
| 관리자로 설정 | 시스템 설정에 접근하여 시스템을 관리할 수 있습니다. | 데이터를 삭제하지 않지만 권한이 크게 확대됩니다. | 관리자 자격을 제거할 수 있습니다. |
| 사용자 그룹에서 제거 | 그룹 권한으로 부여된 공유 또는 앱 권한이 함께 변경됩니다. | 개인 폴더를 삭제하지 않습니다. | 그룹에 다시 추가할 수 있습니다. |
| 사용자 삭제 | 계정으로 로그인할 수 없습니다. | 개인 폴더의 모든 데이터가 삭제됩니다. | 복구할 수 없습니다. |
| 사용자 그룹 삭제 | 그룹 구성원이 해제됩니다. | 일반적으로 구성원 계정을 삭제하지 않지만 그룹 권한이 무효화됩니다. | 그룹을 다시 생성하고 권한을 다시 부여해야 합니다. |

## 스토리지 할당량 권장 사항

- **가정용 기기**: 구성원별로 할당량을 설정하여 개인 사진과 동영상이 공유 볼륨을 가득 채우지 않도록 합니다.
- **팀 기기**: 부서 또는 프로젝트 그룹별로 용량 정책을 통일하고 특수한 경우에만 개별 조정합니다.
- **백업 사용자**: 백업 원본 데이터 크기에 따라 여유 공간을 확보하고 사용된 용량을 정기적으로 확인합니다.
- **앱 전용 계정**: 앱 로그나 캐시가 무한히 증가하지 않도록 용량을 제한하는 것이 좋습니다.

할당량은 해당 사용자가 이 스토리지 볼륨에서 쓸 수 있는 용량만 제한하며, 기존 파일, 팀 파일 및 시스템 데이터는 각각 집계될 수 있습니다. 페이지에 표시되는 사용된 용량은 실제 스토리지 통계를 기준으로 합니다.

## 문제 해결 권장 사항

| 문제 | 확인 방향 |
| --- | --- |
| 사용자가 로그인할 수 없음 | 계정이 비활성화되었는지, 비밀번호가 변경되었는지, IP가 보안의 보호 규칙에 의해 차단되었는지 확인합니다. |
| 사용자가 공유 디렉터리를 볼 수 없음 | 접근 가능한 스토리지 공간, 사용자 그룹 구성원 관계, 파일 공유 프로토콜의 표시 디렉터리 범위를 확인합니다. |
| 쓰기 시 공간 부족 안내 | 사용자 할당량, 스토리지 볼륨의 남은 용량, 하드 디스크가 읽기 전용 또는 저하 상태인지 확인합니다. |
| 그룹 변경 후 권한이 적용되지 않음 | 클라이언트 캐시 또는 세션이 새로 고쳐지지 않았을 수 있으므로 다시 로그인하거나 파일 서비스에 다시 연결합니다. |
