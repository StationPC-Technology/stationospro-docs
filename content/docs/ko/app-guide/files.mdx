파일 관리자는 StationOS Pro의 핵심 앱으로, 기기의 모든 파일을 중앙에서 관리하는 데 사용됩니다. 브라우저에서 파일 업로드/다운로드, 디렉터리 관리, 권한 공유, 휴지통 복원 및 중복 파일 정리를 완료할 수 있으며, SMB, WebDAV, FTP, NFS 등의 파일 서비스를 구성하여 컴퓨터와 스마트폰이 NAS의 파일에 직접 접속할 수 있도록 할 수 있습니다.

## 인터페이스 소개

파일 관리자 상단은 기능별로 다음 탭으로 나뉩니다:

| 탭 | 설명 |
| --- | --- |
| 내 파일 | 현재 사용자의 개인 파일 공간 |
| 팀 파일 | 여러 사람이 협업하여 접근할 수 있는 팀 공유 공간 |
| 외장 스토리지 | USB 드라이브, 휴대용 하드 디스크 등 외장 장치의 파일 관리 |
| 원격 마운트 | 원격 NAS 또는 서버의 공유 디렉터리 마운트 |
| 앱 파일 | 각 앱에서 생성된 데이터 파일 확인 |
| 내 즐겨찾기 | 즐겨찾기한 파일과 폴더에 빠르게 접근 |
| 외부 링크 공유 | 생성한 외부 공유 링크 관리 |
| 휴지통 | 삭제된 파일 복원 또는 완전 삭제 |
| 중복 파일 | 중복 파일을 검사하고 정리하여 스토리지 공간 확보 |
| 관리자 보기 | 관리자가 사용자별로 모든 파일을 볼 수 있음(관리자만 표시) |

파일 목록은 목록/그리드 보기 전환을 지원하며 파일 이름, 크기, 유형, 수정 시간, 저장 위치, 생성 시간 및 소유자 등의 정보를 표시합니다. 열 머리글을 클릭하면 정렬됩니다.

![My Files](/images/ko/app-guide/files-img/my-files.png)

## 파일 기본 작업

도구 모음에서 다음의 일반적인 작업을 제공합니다:

- **업로드**: 파일 또는 전체 폴더 업로드
- **새 폴더**: 새 디렉터리 생성
- **정렬**: 이름, 크기, 시간 등으로 정렬
- **보기 전환**: 목록 보기와 그리드 보기 간 전환

### 새 폴더

1. 대상 디렉터리로 이동하여 도구 모음의 **새 폴더**를 클릭합니다.
2. 폴더 이름을 입력합니다(최대 180자).
3. 폴더가 위치할 스토리지 공간(예: 스토리지 공간 1)을 선택합니다.
4. **확인**을 클릭하여 생성을 완료합니다.

![New Folder](/images/ko/app-guide/files-img/new-folder.png)

### 오른쪽 클릭 메뉴

파일 또는 폴더를 오른쪽 클릭하면 다음 작업을 수행할 수 있습니다:

| 메뉴 항목 | 설명 |
| --- | --- |
| 새 창에서 열기 | 새 창에서 열기(폴더) |
| 다운로드 | 로컬 컴퓨터로 다운로드 |
| 복사 위치/이동 위치 | 다른 디렉터리로 복사 또는 이동 |
| 잘라내기/복사 | 잘라내기 또는 복사 |
| 삭제 | 삭제(휴지통으로 이동) |
| 이름 바꾸기 | 이름 바꾸기 |
| 즐겨찾기 | 즐겨찾기에 추가 |
| 외부 링크 공유 | 외부 링크 공유 생성 |
| 상세 정보 | 파일 상세 정보 확인 |

![Context Menu](/images/ko/app-guide/files-img/context-menu.png)

## 외부 링크 공유

외부 링크 공유를 통해 파일 또는 폴더를 NAS 계정이 없는 외부 사용자에게 공유할 수 있습니다:

1. 대상 파일 또는 폴더를 오른쪽 클릭하고 **외부 링크 공유**를 선택합니다.
2. 공유 매개변수를 설정합니다:
   - **공유 이름**: 외부 링크에 표시되는 이름
   - **유효 기간**: 영구 유효 또는 사용자 지정 만료 시간
   - **다운로드 허용**: 방문자의 파일 다운로드 허용 여부
   - **암호 보호**: 링크에 접근 암호 설정
   - **접근 횟수 제한**: 링크의 최대 접근 횟수 제한
3. **링크 생성**을 클릭하여 공유 링크를 생성합니다.

생성한 공유는 '외부 링크 공유' 탭에서 일괄 관리할 수 있으며, 링크 확인, 규칙 수정 또는 공유 취소가 포함됩니다.

![Share Link](/images/ko/app-guide/files-img/share-link.png)

<Callout title="보안 안내" type="warn">
  민감한 파일을 공유할 때는 암호 보호를 켜고 유효 기간을 설정하는 것이 좋습니다. 공유가 끝난 후에는 더 이상 사용하지 않는 링크를 즉시 닫아 데이터 유출을 방지하십시오.
</Callout>

## 파일 서비스 설정

파일 관리자 오른쪽 상단의 **설정**을 클릭하여 파일 서비스를 구성할 수 있습니다. 설정 창에는 다음 탭이 포함됩니다:

- **파일 공유 프로토콜**: SMB, WebDAV, FTP, NFS 서비스를 각각 구성합니다.
- **파일 규칙**: 파일 이름 지정 등의 규칙을 구성합니다.
- **원격 마운트**: 원격 마운트 관련 매개변수를 구성합니다.
- **외부 공유**: 외부 링크 공유의 전역 규칙을 구성합니다.

SMB를 예로 들면, 설정 페이지에서 다음을 제공합니다:

- **표시되는 디렉터리 범위**: 내 파일, 팀 파일, 앱 파일의 프로토콜 접근 표시 여부를 각각 설정합니다.
- **연결 방법**: Windows와 macOS에서 NAS에 연결하는 그림 안내와 접근 주소를 제공합니다.
- **기타 연결 정보**: 기기 IP 주소와 기본 포트(SMB는 445)를 표시하며 원클릭으로 복사할 수 있습니다.

![File Settings](/images/ko/app-guide/files-img/settings.png)

### 컴퓨터에서 NAS 파일에 접근

- **macOS**: Finder → 이동 → 서버에 연결을 열고 `smb://设备IP`를 입력한 다음 NAS 로컬 계정 비밀번호를 입력하면 접근할 수 있습니다.
- **Windows**: `Win + R`을 누르고 `\\设备IP`를 입력한 다음 NAS 로컬 계정 비밀번호를 입력하면 접근할 수 있습니다.

## 휴지통

삭제된 파일은 휴지통으로 이동하여 실수로 삭제할 때 데이터 손실을 방지합니다:

- **복원**: 파일을 삭제 전 원래 위치로 복원합니다.
- **완전 삭제**: 선택한 파일을 영구 삭제하며 복구할 수 없습니다.
- **휴지통 비우기**: 휴지통의 모든 파일을 원클릭으로 비웁니다.

휴지통은 내 파일과 팀 파일로 개인 및 팀 삭제 내용을 구분하며, 관리자는 모든 사용자의 휴지통을 볼 수 있습니다.
