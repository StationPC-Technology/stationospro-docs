로그 센터는 시스템 실행, 로그인 연결, 파일 전송 및 하드 디스크 스토리지 등의 이벤트를 중앙에서 기록합니다. 키워드, 등급, 모듈, 사용자 및 시간 범위별로 로그를 검색하여 보안 감사, 작업 추적 및 문제 해결에 활용할 수 있습니다.

## 페이지 레이아웃

로그 센터는 상단 도구 모음, 로그 표 및 하단 페이지 영역으로 나뉩니다:

| 영역 | 기능 |
| --- | --- |
| 키워드 검색창 | 로그 내용 키워드로 검색합니다. 입력 후 Enter를 누르거나 입력창에서 포커스가 벗어나면 적용됩니다. |
| 필터 | 등급, 모듈, 사용자, 시간 범위를 조합하여 필터링합니다. |
| 비우기 | 시간 범위에 따라 로그를 삭제합니다. |
| 로그 내보내기 | 선택한 시간 범위의 로그를 CSV 파일로 내보냅니다. |
| 로그 아카이브 | 자동 아카이브 조건과 아카이브 저장 위치를 구성합니다. |
| 로그 표 | 등급, 모듈, 시간, 사용자 및 이벤트를 표시합니다. |
| 페이지 영역 | 전체 로그 수를 표시하며 새로 고침, 페이지 전환, 페이지당 항목 수 조정 및 페이지 번호 이동을 지원합니다. |

## 시스템 사용자 로그 보기

시스템에서 생성된 로그만 보려면 **사용자** 필터를 `system`으로 설정할 수 있습니다:

1. 상단의 **필터**를 클릭합니다.
2. **사용자** 드롭다운에서 `system`을 선택합니다.
3. **확인**을 클릭합니다.

필터 결과의 사용자 열은 모두 `system`이며, 시스템 전원 켜기/끄기, 시스템 업데이트, 네트워크 인터페이스 상태, 하드 디스크 인식, 하드 디스크 S.M.A.R.T 상태 및 스토리지 볼륨 이상 등 시스템 이벤트를 중점적으로 확인하는 데 적합합니다.

![system 사용자로 필터링한 로그 목록](/images/ko/app-guide/log-center-img/logs.png)

## 로그 필드

| 필드 | 설명 |
| --- | --- |
| 등급 | 로그 심각도: 일반, 경고, 심각. 일반은 일상적인 실행 정보이고, 경고는 주의가 필요함을 의미하며, 심각은 기능 또는 하드웨어에 높은 위험이 있음을 의미합니다. |
| 모듈 | 이벤트 출처: 시스템, 로그인 연결, 파일 전송, 하드 디스크 스토리지. |
| 시간 | 이벤트 발생 시간. |
| 사용자 | 이벤트를 발생시킨 사용자. `system`은 시스템에서 자동으로 생성된 이벤트를, 일반 사용자 이름은 사용자 작업 또는 사용자 세션 관련 이벤트를 의미합니다. |
| 이벤트 | 이벤트 상세 내용. 예: 시스템 종료, 하드 디스크 제거, 스토리지 볼륨 저하, 시스템 버전 업데이트 등. |

## 검색 및 필터링

### 키워드 검색

검색창에 이벤트 내용 키워드(예: 하드 디스크 모델, 스토리지 볼륨 이름, 시스템 버전 또는 오류 설명)를 입력한 후 Enter를 누릅니다. 검색은 조건 필터와 함께 적용됩니다.

### 조건 필터링

**필터**를 클릭한 후 다음 조건을 조합할 수 있습니다:

| 조건 | 선택 값/설명 |
| --- | --- |
| 등급 | 일반, 경고, 심각. 다중 선택과 전체 선택을 지원합니다. |
| 모듈 | 시스템, 로그인 연결, 파일 전송, 하드 디스크 스토리지. 다중 선택과 전체 선택을 지원합니다. |
| 사용자 | 선택 항목은 현재 로그에 나타난 사용자이며 다중 선택과 전체 선택을 지원합니다. 본문 예시에서는 `system`을 선택합니다. |
| 시간 | 시작 및 종료 날짜를 선택하여 지정된 시간 범위의 로그만 확인합니다. |

필터 조건은 먼저 팝업에 저장되며 **확인**을 클릭한 후에 목록에 적용됩니다. **재설정**을 클릭하면 필터 조건을 지우고 기본 보기로 돌아갑니다.

![사용자 필터에서 system 선택](/images/ko/app-guide/log-center-img/filter.png)

## 페이지 및 새로 고침

- **전체 수**: 페이지 영역에 현재 필터 조건의 전체 로그 수가 표시됩니다.
- **새로 고침**: 전체 수 왼쪽의 새로 고침 아이콘을 클릭하면 현재 목록을 다시 불러옵니다.
- **페이지당 항목 수**: 50, 100, 500 중에서 선택할 수 있습니다.
- **페이지 이동**: 페이지 번호를 입력한 후 Enter를 누르거나 이전 페이지/다음 페이지로 전환합니다.

## 로그 내보내기

상단의 다운로드 아이콘을 클릭하면 로그를 내보낼 수 있습니다:

1. 시간 범위를 선택합니다: 전체, 최근 1주, 최근 1개월, 최근 3개월, 최근 6개월, 최근 1년.
2. **확인**을 클릭합니다.
3. 로그 파일 생성이 완료될 때까지 기다리면 내보낸 CSV가 로컬 브라우저 다운로드 디렉터리에 저장됩니다.

내보내기는 감사 기록을 장기 보관하거나 기기에 직접 접근할 수 없을 때 기술 담당자에게 분석을 요청하는 데 적합합니다.

## 로그 비우기

**비우기**를 클릭한 후:

1. 삭제할 시간 범위를 선택합니다: 전체, 1년 전, 6개월 전, 3개월 전, 1개월 전, 1주 전.
2. 정리 범위를 확인합니다.
3. 정리 진행이 완료될 때까지 기다립니다.

<Callout title="주의" type="warn">
  로그 비우기는 복구할 수 없습니다. 정리 전에 보관이 필요한 기록 로그를 먼저 내보내는 것이 좋습니다. 보안 사고나 하드웨어 이상이 발생한 경우 관련 시간대의 로그를 성급히 삭제하지 마십시오.
</Callout>

## 로그 아카이브

상단의 설정 아이콘을 클릭하여 **로그 아카이브**를 엽니다. 시스템은 기본적으로 최근 300만 건의 전송 로그를 보관하며 자동으로 아카이브하지 않습니다. 자동 아카이브를 켜면 다음 조건 중 하나로 실행할 수 있습니다:

| 조건 | 선택 값 |
| --- | --- |
| 로그 데이터 크기 초과 | 500 MB, 1 GB, 3 GB |
| 로그 시간 이전 | 1주 전, 1개월 전, 3개월 전, 6개월 전, 1년 전 |

또한 팀 파일에서 아카이브 저장 위치를 선택해야 합니다. 아카이브 조건을 하나 이상 활성화해야 저장할 수 있습니다.

<Callout title="권장 사항" type="info">
  - 로그인 이상을 점검할 때는 '로그인 연결'을 우선 필터링하고 경고 및 심각 수준에 주목하십시오.
  - 하드 디스크 또는 스토리지 볼륨 장애를 점검할 때는 사용자를 `system`으로, 모듈을 '시스템' 또는 '하드 디스크 스토리지'로 필터링할 수 있습니다.
  - 중요한 로그를 정기적으로 내보내거나 아카이브하여 비운 후 추적할 수 없게 되는 상황을 방지하십시오.
</Callout>
