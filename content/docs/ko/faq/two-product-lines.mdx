StationPC는 현재 **데스크톱 NAS**와 **휴대용 NAS**라는 두 개의 병렬 NAS 제품 라인을 보유하고 있습니다. 사용 환경이 다르고 하드웨어 형태, 시스템 기반, 클라이언트도 각각 별도로 설계되었습니다. 같은 기기의 '표준판'과 '휴대용판'이 아니라 독립된 두 제품이자 두 시스템입니다. 그래서 도움말 센터도 제품 라인별로 두 벌의 문서로 나뉘어 있습니다.

## 두 제품 라인은 무엇인가요?

| | 데스크톱 NAS | 휴대용 NAS |
| --- | --- | --- |
| 모델 | DA400, DA400 Air | PA100, PA100 Pro |
| 시스템 | StationOS Pro | StationOS |
| 시스템 기반 | Debian | OpenWrt |
| 하드웨어 형태 | 고정 설치, 여러 드라이브 베이, 주로 고정 전원과 유선 네트워크 | 내장 배터리, 휴대 가능, 무선 / AP 연결 지원 |
| 주요 용도 | 가정이나 스튜디오의 장기 저장, RAID, Station AI | 출장, 모바일 작업 |
| 클라이언트 | StationNAS(Windows / macOS), StationHub(iOS / Android) | PocketNAS(Windows / macOS / Linux / iOS / Android) |

## 왜 시스템 하나로는 안 되나요?

1. **하드웨어 한계가 다릅니다.** 데스크톱 NAS는 여러 드라이브와 RAID, 더 높은 지속 처리량을 장시간 감당해야 하고, 휴대용 NAS는 배터리, 발열, 크기 제약 안에서 동작해야 합니다. 드라이버, 전원 관리, 드라이브 관리, 발열 제어를 하나로 공유하기 어렵습니다.
2. **시스템 기반이 다릅니다.** StationOS Pro는 Debian, StationOS는 OpenWrt를 기반으로 합니다. 패키지 관리, 서비스 관리, 업데이트 방식, 기본 도구 체인이 달라 같은 시스템 이미지를 다른 제품 라인에 설치할 수 없습니다.
3. **기능과 클라이언트가 다릅니다.** 데스크톱 NAS는 Station AI, RAID 등을 제공하고, 휴대용 NAS는 배터리, AP 모드, SD / USB 백업, PocketNAS를 중심으로 설계되었습니다. 둘 다 Docker와 파일 공유를 지원하지만 메뉴 위치, 화면, 제한은 같지 않습니다.
4. **릴리스 계보가 독립적입니다.** 두 시스템은 각각 업데이트되며 변경 내역과 버전 번호도 별도로 관리됩니다. 휴대용 NAS의 업데이트 패키지를 데스크톱 NAS에 설치할 수 없고, 그 반대도 마찬가지입니다.

## 사용자에게 어떤 영향이 있나요?

- **먼저 모델을 확인하세요.** 기기 라벨이나 구매 기록을 보세요. DA400 / DA400 Air이면 데스크톱 NAS, PA100 / PA100 Pro이면 휴대용 NAS입니다.
- **해당 제품 라인의 문서를 보세요.** 메뉴, 스크린샷, 제한이 다르므로 해당하는 '데스크톱 NAS' 또는 '휴대용 NAS' 입구로 들어가고, 다른 제품 라인의 절차를 따라 하지 마세요.
- **클라이언트와 업데이트 패키지를 혼용하지 마세요.** 데스크톱 NAS는 StationNAS / StationHub, 휴대용 NAS는 PocketNAS를 사용합니다. 업데이트 패키지도 호환되지 않습니다.
- **같은 기능 이름이라도 제품 라인을 확인하세요.** 같은 기능 이름(예: 백업, 원격 접속)이라도 제품 라인에 따라 위치와 방법이 다를 수 있습니다.

## 도움말 센터도 두 벌의 문서로 나뉜 이유는 무엇인가요?

두 시스템은 메뉴, 스크린샷, 제한, 업데이트 주기가 다르기 때문에 내용을 섞으면 같은 질문에 두 가지 답이 생기고, 검색이 사용자를 잘못된 제품 라인의 절차로 안내할 수 있습니다. 그래서 이 사이트는 '하나의 사이트, 두 개의 병렬 제품 영역' 구성을 채택했습니다. 공통 콘텐츠(법률, 문의, 사이트 전체 검색)는 공유하고, 구체적인 절차는 데스크톱과 휴대용 문서에 각각 나누어 싣습니다.

기기가 어느 제품 라인에 속하는지 확실하지 않다면 기기 라벨의 모델을 확인하거나 [문의하기](../contact)를 이용하세요.
