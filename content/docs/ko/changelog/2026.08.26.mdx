## 업데이트 전 참고 사항
적용 제품
이번 업데이트는 StationOS Pro 시스템이 실행 중인 제품에 적용됩니다. 업그레이드 전에 제품 모델에 따라 해당하는 프로세서 아키텍처를 확인해 주십시오.

● DA 시리즈: DA400 시리즈

업그레이드 안내
1. 본문에서 소개하는 기능을 사용하려면 시스템 펌웨어, 앱 스위트 또는 클라이언트를 해당 버전 이상으로 업그레이드해 주십시오.
2. 일부 앱 스위트의 새로운 기능은 지정된 시스템 펌웨어 버전과 함께 사용해야 합니다. 시스템 펌웨어 버전이 최소 호환 버전보다 낮으면 앱 업데이트 푸시를 받지 못하거나 관련 기능을 정상적으로 사용하지 못할 수 있습니다.

## StationOS Pro 시스템 펌웨어
### 버전 정보
시스템 펌웨어 버전: v0.32.2.11

이번 업데이트에는 인터페이스 조정이 포함되어 있습니다. 기능을 정상적으로 사용하기 위해 펌웨어, 클라이언트 및 관련 앱을 모두 최신 버전으로 업그레이드하는 것을 권장합니다.

### 스토리지 관리
- 수정: SSD 캐시 디스크 분리 후 스토리지 공간 이상 문제
- 수정: RAID5 동기화 중 재부팅 후 스토리지 이상, 초기화 후 NVMe 스토리지 공간 이상
- 수정: 하드 디스크 건강 상태 표시가 SMART와 일치하지 않는 문제

### 외장 스토리지
- 추가: 외장 기기 통합 명명, 각 모듈에서 일관되게 표시되어 구분이 쉬움
- 추가: 삽입 시간, 읽기 전용 상태, 마운트되지 않은 상태 표시
- 수정: 마운트되지 않은 USB 꺼내기 실패, 포맷 후 목록이 새로 고침되지 않는 문제, 파티션 용량 표시 부정확
- 수정: 대용량 파일 업로드 시 용량 부족 오류 표시, 폴더 더블클릭 시 목록 첫 페이지로 이동하는 문제

### 파일 관리
- 수정: 작업 일시정지 후 재개 시 진행률 이상, 작업 수 표시 불일치
- 수정: 앨범에서 폴더 이름 변경 후 썸네일이 표시되지 않는 문제

### 비디오 인코딩/디코딩
- 추가: 비디오 정보에 오디오 트랙 사양, HDR, 프레임 레이트 등 표시, 오디오 트랙 트랜스코딩 파라미터 자동 조정
- 최적화: 트랜스코딩 캐시를 스토리지 볼륨에 저장하도록 변경하여 시스템 스토리지 부족 방지
- 수정: 트랜스코딩 실패 시 계속 멈춰 있던 문제, 이제 실패를 명확히 알림

### Docker
- 추가: 스토리지 공간 변경 전 사전 점검, 기존 데이터 덮어쓰기 확인, 마이그레이션 진행률 표시
- 수정: 마이그레이션 팝업을 닫은 후 상태 손실, 서비스 자동 중지
- 수정: 이미지 레지스트리 중복 요청 및 오류 메시지 중첩

### 앱 센터
- 추가: 설치 패키지 MD5 검증으로 더 안정적인 설치
- 추가: 앱 활성화/비활성화 상태 멀티 디바이스 동기화
- 최적화: Compose 앱 라이프사이클 관리
- 수정: 원격 접속 시 커뮤니티 앱 오탐, 설치/비활성화 알림 이상

### AI 어시스턴트
- 수정: 초기화 후 로컬 모델 로드 실패, CLIP 인덱스 조회 무한 루프
- 최적화: 인덱스 공간 부족 안내 및 마이그레이션 가이드

### 백업
- 수정: 사진 촬영 시간 손실, 외부 기기 목록 새로 고침 이상

### 리소스 모니터
- 수정: 모니터링 데이터 기준 통일, 꺾은선 그래프 왼쪽 끝 표시 이상

## 클라이언트
### iOS & Android 클라이언트
앱 버전: v0.32.0

#### 새로운 기능

- Docker 컨테이너 스토리지 마이그레이션 기능 추가, 마이그레이션 상태 추적, 확인 절차, 마이그레이션 완료 후 구성 및 스토리지 목록 자동 새로 고침 지원
- 앨범 스마트 분류 및 유사 사진 감지 작업 진행률 표시 추가, 단계별 진행률, 상태 애니메이션 및 아이콘 포함

#### 사용성 개선

- IP 로그인 시 기본 포트(HTTP 80 / HTTPS 443) 자동 리디렉션 지원, 포트를 생략하고 바로 로그인 가능
- 앱 센터에서 앱 "활성화 중 / 비활성화 중" 상태 실시간 동기화 지원, 조작 중 깜빡임 및 오판 감소
- 외장 하드 디스크 상세 페이지에 파일 시스템, 공급업체, 시리얼 번호 정보 보완, 마운트되지 않은 경우 호환성 안내 추가
- SSD 캐시 페이지 레이아웃 및 사용 가능한 SSD가 없을 때의 빈 상태 표시 개선
- 수동 설정 시간과 표준 시간의 편차가 클 때 2차 확인 추가, 오조작 방지
- 설정 모듈 입력창 및 팝업 스타일 통일, 원격 마운트 비밀번호 입력창 표시 이상 수정
- 앨범 백업 진행률 표시에 단조 보호 추가, 진행률 숫자가 되돌아가는 현상 방지
- 로그 업로드 시 현재 NAS의 기기 시리얼 번호, 이름, 모델 및 펌웨어 버전 정보 보완
- 비홈 페이지 헤더 아이콘 버튼 규격 통일, 클릭 영역 확대

#### 문제 수정

- iPad에서 포인터 이벤트로 인해 팝업이 잘못 닫히는 문제 수정, 대화면 기기의 팝업은 전체 폭으로 표시하도록 변경
- 기기 연결 실패 안내가 현지화되지 않은 문제 수정, 6개 언어 번역 보완
- SSD 캐시 상세 페이지에서 페이지가 파괴된 후에도 객체에 접근하여 발생하는 예외 수정
- 스마트 분류 작업 종료 시 팝업 닫기 로직 수정
- 공장 초기화 팝업 안내 문구 수정
- 정식 패키지 업로드 후 백엔드 기본값을 "미출시"로 설정, 심사 통과 전 자동 출시 방지
- 외장 스토리지 경로 표시 이름 통일
