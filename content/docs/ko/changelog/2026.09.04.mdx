## 업데이트 전 참고 사항
적용 제품
이번 업데이트는 StationOS Pro 시스템이 실행 중인 제품에 적용됩니다. 업그레이드 전에 제품 모델에 따라 해당하는 프로세서 아키텍처를 확인해 주십시오.

● DA 시리즈: DA400 시리즈

업그레이드 안내
1. 본문에서 소개하는 기능을 사용하려면 시스템 펌웨어, 앱 스위트 또는 클라이언트를 해당 버전 이상으로 업그레이드해 주십시오.
2. 일부 앱 스위트의 새로운 기능은 지정된 시스템 펌웨어 버전과 함께 사용해야 합니다. 시스템 펌웨어 버전이 최소 호환 버전보다 낮으면 앱 업데이트 푸시를 받지 못하거나 관련 기능을 정상적으로 사용하지 못할 수 있습니다.

## StationOS Pro 시스템 펌웨어
### 버전 정보
시스템 펌웨어 버전: v0.33.0.8

이번 업데이트에는 인터페이스 조정이 포함되어 있습니다. 기능을 정상적으로 사용하기 위해 펌웨어, 클라이언트 및 관련 앱을 모두 최신 버전으로 업그레이드하는 것을 권장합니다.

### 시스템
- AI 가속 카드 모니터링 및 데스크톱 위젯 추가.
- AI 가속 카드 온도 제어, 팬 떨림 방지 및 동적 모니터링 데이터 수집 최적화.
- 프로세스 CPU 모니터링 기준 최적화, 통계 정확도 향상.
- 부팅 시 SSH 활성화 상태 유지, 기기 모델 접미사 표시 개선.
- 간헐적으로 전원 끄기가 실패하는 문제, 시스템 업데이트 새로 고침 배너가 표시되지 않는 문제 등 수정.
- 베타 업데이트 항목 숨김, 업데이트 상세 문서 진입점 추가.

### 스토리지
- RAID 동기화 중 마운트 지원, 스토리지 공간 가용성 향상.
- 스토리지 공간 생성 단계 이벤트 푸시 및 진행률 팝업 추가.
- 스토리지 풀 상태와 스토리지 공간 상태 분리, 생성 흐름 최적화.
- 알 수 없는 파일 시스템 오류 분류 보완, 외장 스토리지 마운트 오류 안내 개선.
- 외장 스토리지 마운트 실패 원인 보고, 더 세분화된 오류 구분 지원.
- 강등된 어레이 오판, 외장 스토리지 마운트 상태 이상 등 문제 수정.

### 파일
- 폴더 업로드 사전 점검 지원, 업로드 흐름 최적화.
- 대량 파일 업로드, 업로드 진행률 동기화 및 작업 스케줄링 최적화.
- 파일 이름 정렬, 파일 중복 검사, 미리보기 EXIF 이동 아이콘 등 문제 수정.
- 외장 스토리지 파일 목록 페이지네이션, 이미지 썸네일 로딩 및 업로드 이미지 썸네일 표시 최적화.
- 파일 관리 테이블 헤더 및 상태 표시줄 표시 통일, 목록 조작 일관성 향상.

### 백업
- 앨범 백업 썸네일 처리 최적화.
- 외장 디스크 핫 플러그 후 원클릭 백업 게시 지원.
- 원클릭 백업 버튼 트리거 로직 강화, 오작동 확률 감소.
- 재시도에도 실패한 원클릭 디스크 삽입 게시 문제 수정.

### App Store / Docker
- 데이터 볼륨의 호스트 마운트 경로 구성 지원, 앱 접근 가능 경로 구성 확대.
- 재부팅 후 데스크톱 앱 상태 미동기화 문제 수정.
- Compose 배포 터미널 로그 표시 및 실시간 로그 표시 최적화.
- Docker 검색창 레이아웃, 네트워크 이름이 너무 길어 가려지는 문제, 스토리지 마이그레이션 진행률 등 문제 수정.
- 앱 설치/다운로드 상태 원형 진행률 바 및 배지 알림 추가.

### AI / Station AI
- 로컬 모델 로드, 다운로드 진행률, 온디맨드 로드 및 유휴 시 언로드 최적화.
- 사이트 내 AI 라우팅 및 벡터 모델 조정, 메모리 사용량 감소 및 적중 정확도 향상.
- 네트워크 질의 라우팅, 숫자 파라미터 누락, 요약 출력 및 서비스 가용성 오탐 문제 수정.
- 다국어 긍정 예제, 스킬 선언 및 보안 방어 정책 보완.

### 알림 / 기기
- 외부 기기 알림 조작 유형 및 삽입/분리 이벤트 유형 전달.
- 시스템 로그 노이즈 감소, 일부 디버그 출력 차단.
- 리소스 관리에서 전원 끄기 후 네트워크 오류 안내, 스토리지 공간 생성 디버그 로그 등 문제 수정.

- HTTPS 연결, 리디렉션, 포그라운드/백그라운드 복귀 및 WebSocket 재연결 최적화, 기기 연결 안정성 향상.
