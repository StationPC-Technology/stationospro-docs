## StationOS Pro 시스템 펌웨어
### 버전 정보
시스템 펌웨어 버전: v1.0.0.18

이번 업데이트에는 인터페이스 조정이 포함되어 있으므로 기능을 정상적으로 사용하려면 펌웨어, 클라이언트 및 관련 앱을 모두 최신 버전으로 업그레이드하는 것이 좋습니다.

### 시스템과 계정

- 추가: 기기 사용 개선 프로그램 설정이 추가되어 등록 시 참여 여부를 선택할 수 있습니다.
- 추가: 로그인 연결이 더 안전해지고 부저 알림 규칙이 더 통일되었습니다.
- 최적화: 시스템 로그가 더 간결해지고 공장 초기화 시 정리가 더 철저해졌습니다.
- 수정: 첫 부팅 시 기기 이름이 잘못 표시되는 문제, 시간 동기화 실패, 일요일 예약 종료가 하루 부족한 문제, 업데이트 알림이 사라지는 문제, 확인 팝업이 닫히지 않는 문제 등을 수정했습니다.

### AI와 검색

- 추가: AI 모델 상태가 실시간으로 업데이트되며 얼굴 인식 정확도를 조정할 수 있고 장소 인식이 더 정확해졌습니다.
- 최적화: AI 기능 설치, 로드 및 제거가 더 안정적이며 지원되지 않는 이미지는 자동으로 건너뜁니다.
- 수정: AI가 간헐적으로 네트워크 정보를 가져오지 못하는 문제, 모델 로드 실패를 잘못 보고하는 문제, 공장 초기화 후 얼굴 기능을 사용할 수 없는 문제, 검색이 멈추거나 결과가 이상한 문제 등을 수정했습니다.

### 스토리지와 하드 디스크

- 최적화: 하드 디스크 온도, 건강 상태 및 남은 공간 표시가 더 일관되고 신속해졌습니다.
- 최적화: 외장 하드 디스크 삽입 및 포맷 후 새로 고침 속도가 더 빨라졌습니다.
- 수정: 어레이 저하 후 복구 이상, 하드 디스크 교체 후 정상적으로 사용할 수 없는 문제, 하드 디스크 상태 표시가 부정확한 문제, 스토리지 공간 할당량 이상 등의 문제를 수정했습니다.

### 파일 관리자

- 추가: 외장 하드 디스크의 이미지 썸네일 표시를 지원합니다.
- 최적화: 파일 중복 검사가 더 빠르고 리소스를 덜 사용하며, 파일 복사·이동을 백그라운드에서 계속 처리할 수 있고 업로드 실패 안내가 더 명확해졌습니다.
- 수정: 파일 중복 검사 선택 이상, 즐겨찾기 상태 동기화 안 됨, 이미지/Word/Excel 미리보기 이상, 업로드 오류 시 기술 정보 표시 등의 문제를 수정했습니다.

### 앱 센터

- 추가: 앱 설치 위치와 다운로드 위치를 선택할 수 있으며 설치 진행 표시가 더 통일되었습니다.
- 최적화: 앱 설치, 구성 팝업 및 실행 상태 표시가 더 명확해졌습니다.
- 수정: 앱 재배포 충돌, 상태가 계속 배포 중으로 표시되는 문제, 배포 로그가 비어 있는 문제, 정상적으로 중지된 앱이 이상으로 잘못 보고되는 문제 등을 수정했습니다.

### 네트워크와 원격 액세스

- 추가: 원격 마운트에 문제가 있을 때 원인을 더 편리하게 확인할 수 있습니다.
- 최적화: 원격 연결 오류 안내가 더 명확해지고 네트워크 접근이 더 안정적입니다.
- 수정: 원격 마운트 잔여물, FTP 원격 마운트 불안정, 원격 디렉터리를 열 수 없는 문제, 네트워크 페이지 표시 오류 등의 문제를 수정했습니다.

### 백업과 복구

- 최적화: 앨범 백업이 더 안정적입니다.
- 수정: 팀 폴더 원터치 백업 권한 오류, 새 계정 공유 디렉터리 동기화 안 됨, 공장 초기화 후 일부 기능 데이터 누락 등의 문제를 수정했습니다.

## 클라이언트
### iOS & Android 클라이언트
앱 버전: v1.0.0

- 스토리지 공간 생성 흐름을 개선하여 초기화, 생성 및 포맷 세 단계의 애니메이션과 진행률을 제공하고 명확한 성공 또는 실패 결과를 표시합니다.
- 사진, 라이브 포토, 모션 포토 및 동영상의 미디어 상세 정보와 EXIF 표시를 재작업하여 장소, 촬영 시간 및 동영상 정보를 보강했습니다.
- 미디어 뷰어 상세 패널, 제스처 상호작용, 동영상 재생 제어 및 갤러리 미디어 작업을 최적화했습니다.
- 홈 화면 즐겨찾기 사진 미리보기 선명도를 높이고 장소와 촬영 날짜를 표시하며 백업 업데이트 후 앨범 새로 고침 효과를 개선했습니다.
- 앨범 백업 목록 순서, 업로드 진행률, 배치 로드 및 완료, 실패, 취소 상태를 안정화했습니다.
- 읽기 전용 하드 디스크와 외장 하드 디스크 상태 표시를 개선하고 읽기 전용 스토리지에서 업로드, 삭제, 이동 및 이름 변경 작업을 제한하며 쓰기 가능한 디렉터리로 복사하는 기능은 유지했습니다.
- 파일 복사, 이동 및 업로드의 대상 공간 선택을 개선하여 내 파일, 팀 파일, 외장 스토리지 및 내 즐겨찾기를 지원합니다.
- 리소스 모니터링 꺾은선형 차트 안내를 개선하여 샘플링 시간, CPU 사용률 세분화 및 더 명확한 경계 표시를 지원합니다.
- 포트를 입력하지 않은 IP 또는 DDNS 주소에서 HTTP 연결을 자동으로 시도하도록 지원하고 실시간 연결 인증 및 실패 폴백 메커니즘을 강화했습니다.
- 네트워크 재설정을 추가하고 보안 검증으로 작업을 보호하며 시스템 업데이트, 네트워크 웨이크업 및 전원 인가 시 자동 부팅 설정을 최적화했습니다.
- 이메일 알림 구성, 제목 접두사, 테스트 이메일, AI 가속 카드 및 리소스 모니터링 표시를 최적화했습니다.
- 원격 마운트, 파일 유형 인식, 페이지 상태 피드백 및 라이트/다크 테마의 생성 흐름 경험을 최적화했습니다.
