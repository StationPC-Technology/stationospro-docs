---
title: "如何通过 Samba 访问 PocketCloud 中的文件？"
---

Samba 是一种基于 SMB/CIFS（Server Message Block / Common Internet File System） 协议的文件共享服务，广泛用于 Linux、macOS 与 Windows 系统之间的文件和打印共享。
通过 Samba，用户可以像访问本地文件一样访问远程服务器上的共享目录，实现跨平台的文件共享与协作。

**主要具备以下功能：**
1. 文件共享：允许用户在网络中访问、上传、下载和管理共享文件或文件夹。
2. 打印共享：支持通过网络共享打印机，方便多台设备共用同一打印资源。
3. 用户权限控制：可设置不同用户或用户组的访问权限，确保数据安全。
4. 跨平台访问：兼容 Windows、Linux、macOS 等主流操作系统，支持多种客户端接入。

## 启用 Samba

Samba 默认处于关闭状态，需要手动启用。请按照以下步骤操作：

1. 打开 App 的 **文件共享协议** 页面。<br />
2. 点击 **Samba 服务**。<br />
3. 打开 **开关按钮**，即可启用 **Samba 服务**。<br />

## 在 Windows 上访问

### 方式一

1. 按下 **Win + R** 组合键。  
2. 输入 `\\NAS设备IP`，然后点击 **确定**。  
   <img src="/images/common/portable/file-service/access-samba-service/1-1.png" width="100%" height="100%" />
3. 输入用户名和密码，点击 **确定**。  
   <img src="/images/common/portable/file-service/access-samba-service/1-2.png" width="100%" height="100%" />
4. 现在，你可以在 **文件资源管理器** 中像访问本地文件夹一样浏览和管理 NAS 上的文件。  
   <img src="/images/common/portable/file-service/access-samba-service/1-3.png" width="100%" height="100%" />

### 方式二

1. 打开文件资源管理器
2. 右键 **网络**，选择 **映射网络驱动器**
   <img src="/images/common/portable/file-service/access-nfs-service/5-1.png" width="100%" height="100%" />
3. 输入 `\\NAS设备IP\管理员名称`，然后点击 **完成**。
   <img src="/images/common/portable/file-service/access-samba-service/9-2.png" width="100%" height="100%" />
4. 输入用户名和密码，点击 **确定**。  
   <img src="/images/common/portable/file-service/access-samba-service/9-3.png" width="100%" height="100%" />
5. 现在，你可以在 **文件资源管理器** 中像访问本地文件夹一样浏览和管理 NAS 上的文件。  
   <img src="/images/common/portable/file-service/access-samba-service/9-4.png" width="100%" height="100%" />

2. 点击右上角的 **“...”** 图标，选择 **连接服务器**。  
   <img src="/images/common/portable/file-service/access-samba-service/2-1.png" width="240" height="500" />

   <img src="/images/common/portable/file-service/access-samba-service/2-2.png" width="240" height="500" />
4. 输入用户名和密码，点击 **下一步**。  
   <img src="/images/common/portable/file-service/access-samba-service/2-3.png" width="240" height="500" />
5. 现在，你可以在 **文件** App 中像访问本地文件夹一样浏览和管理 NAS 上的文件。

2. 在服务器地址栏输入 `smb://NAS设备IP`，然后点击 **连接**。  
   <img src="/images/common/portable/file-service/access-samba-service/3-2.png" width="100%" height="100%" />
3. 输入用户名和密码，点击 **连接**。  
   <img src="/images/common/portable/file-service/access-samba-service/3-3.png" width="100%" height="100%" />

## 在 Linux 上访问

使用 **cifs-utils** 挂载 Samba 共享：

```bash
# 安装 cifs-utils
sudo apt-get install cifs-utils

# 创建挂载点
# 示例：将 /mnt/samba_share 作为挂载目录
sudo mkdir -p /mnt/samba_share

# 挂载 Samba 共享目录
sudo mount -t cifs //NAS设备IP/共享目录 /mnt/samba_share -o username=用户名,password=密码

# 挂载成功后，你可以在 /mnt/samba_share 目录中访问和管理 NAS 上的文件
```

## 在 其它客户端 上访问
- 连接信息
    - IP：NAS设备IP
    - 端口：默认为445
    - 账号：NAS设备登录用户名
    - 密码：NAS设备登录密码
- 挂载目录说明
    - 主盘SSD：`/登录用户名`
      - 示例1：所有目录，当前用户为 test，挂载目录为 `/test`
      - 示例2：指定目录，当前用户为 test，挂载目录为 `/test/Pictures`
      - 其它：支持多用户，每个用户对应一个挂载目录
    - 外接存储：`/外接存储名称`
      - 示例1：所有目录，外接SD卡名称为 SD 60GB BA26，挂载目录为 `/SD_60GB_BA26`
      - 示例2：指定目录，接SD卡名称为 SD 60GB BA26，挂载目录为 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分客户端无法仅填写根目录 `/`，需指定上面对应的具体挂载目录
      - 固件&lt;= 3.1.0.16升级到最新固件后，挂载目录有所调整，以新版本的挂载方式为准
