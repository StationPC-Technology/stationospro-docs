---
title: "Windows 访问 NFS 磁盘中文乱码问题"
---

> 出现中文乱码通常是由于编码不匹配或系统区域设置问题导致的，针对 Windows 上 NFS 映射磁盘中文乱码的问题，经过测试以下方法可以解决：

> 步骤：

1. 打开 **控制面板** → **时钟和区域** → **区域**。
2. 切换到 **“管理”** 选项卡，点击 **“更改系统区域设置”**。
3. 确保选择的是 **“中文(简体，中国)”**。 并勾选列表最下方的 **Beta 选项**。
<img src="/images/common/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. 修改后重启系统，再次挂载 NFS 磁盘，查看中文是否正常显示。
