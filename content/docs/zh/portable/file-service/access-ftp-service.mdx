---
title: "如何通过 FTP 访问 PocketCloud 中的文件？"
---

FTP（File Transfer Protocol）是一种常用的网络文件传输协议，可用于在设备与服务器之间传输文件。
通过 FTP，用户可以远程连接 PocketCloud，进行文件浏览、上传、下载和管理。

**主要具备以下功能：**
1. 文件上传与下载：在本地设备与 PocketCloud 之间传输文件。
2. 远程文件管理：可在 PocketCloud 上创建、重命名、移动和删除文件或文件夹。
3. 用户认证访问：通过账号和密码进行访问控制，提升安全性。
4. 跨平台访问：可通过支持 FTP 的 Windows 和 macOS 客户端进行连接。

## 启用 FTP

FTP 默认处于关闭状态，需要手动启用。请按照以下步骤操作：
1. 打开 App 的 **文件共享协议** 页面。<br />
2. 点击 **FTP 服务**。<br />
3. 打开 **开关按钮**，即可启用 **FTP 服务**。<br />

## 在 Windows 上访问

1. 按下 **Win + E** 打开 **文件资源管理器**。
2. 在地址栏输入 `ftp://NAS设备IP:21` 或者 `ftps://NAS_IP_Address:21`，然后按 **回车**。
<img src="/images/common/portable/file-service/access-ftp-service/3-1.png" width="100%" height="100%" />
3. 在登录提示中输入 **用户名** 和 **密码**，然后点击 **登陆**
<img src="/images/common/portable/file-service/access-ftp-service/3-2.png" width="100%" height="100%" />
4. 现在，你可以在文件资源管理器中浏览和管理 PocketCloud 文件。
<img src="/images/common/portable/file-service/access-ftp-service/3-3.png" width="100%" height="100%" />

---

## 在 macOS 上访问

1. 右键 **访达（Finder）**，选择 **连接服务器**。
<img src="/images/common/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. 输入 `ftp://NAS设备IP:21` 或者 `ftps://NAS_IP_Address:21`，然后点击 **连接**。
<img src="/images/common/portable/file-service/access-ftp-service/4-1.png" width="100%" height="100%" />
3. 输入 **名称** 和 **密码**，然后点击 **连接**。
<img src="/images/common/portable/file-service/access-ftp-service/4-2.png" width="100%" height="100%" />
4. 现在，你可以在访达中访问 PocketCloud 文件。  
<img src="/images/common/portable/file-service/access-ftp-service/4-3.png" width="100%" height="100%" />

## 在 其它客户端 上访问
- 连接信息
    - IP：NAS设备IP
    - 端口：默认为21
    - 账号：NAS设备登录用户名
    - 密码：NAS设备登录密码
- 挂载目录说明
    - 主盘SSD：`/登录用户名`
      - 示例1：所有目录，当前用户为 test，挂载目录为 `/test`
      - 示例2：指定目录，当前用户为 test，挂载目录为 `/test/Pictures`
      - 其它：支持多用户，每个用户对应一个挂载目录
    - 外接存储：`/外接存储名称`
      - 示例1：所有目录，外接SD卡名称为 SD 60GB BA26，挂载目录为 `/SD_60GB_BA26`
      - 示例2：指定目录，接SD卡名称为 SD 60GB BA26，挂载目录为 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分客户端无法仅填写根目录 `/`，需指定上面对应的具体挂载目录
      - 固件&lt;= 3.1.0.16升级到最新固件后，挂载目录有所调整，以新版本的挂载方式为准
