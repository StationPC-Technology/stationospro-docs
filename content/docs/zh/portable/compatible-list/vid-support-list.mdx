## 视频格式

| 格式 | iOS 端  | Android 端 |
| ------ | ------ | --------- |
| MP4  | 支持 | 支持    |
| MOV  | 支持 | 支持    |
| WMV  | 支持 | 支持    |
| WTV  | 支持 | 支持    |
| WEBM | 支持 | 支持    |
| VOB  | 支持 | 支持    |
| TS   | 支持 | 支持    |
| SWF  | 支持 | 支持    |
| RM   | 支持 | 支持    |
| RMVB | 支持 | 支持    |
| OGV  | 支持 | 支持    |
| MXF  | 支持 | 支持    |
| MTS  | 支持 | 支持    |
| MPG  | 支持 | 支持    |
| MPEG | 支持 | 支持    |
| MKV  | 支持 | 支持    |
| M2V  | 支持 | 支持    |
| HEVC | 支持 | 支持    |
| F4V  | 支持 | 支持    |
| AVI  | 支持 | 支持    |
| 3GP  | 支持 | 支持    |

## 分辨率

| 分辨率 | iOS、Android 端 |
| -------- | ---------- |
| 4K     | 网络较好情况下（例如局域网或直连设备），能正常播放使用蜂窝网络连接时，容易出现卡顿 |
| 8K     | 不支持 |
