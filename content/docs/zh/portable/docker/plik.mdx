## 简介
Plik 是一款开源、轻量、安全的临时文件分享服务，**支持纯网页使用**，打开浏览器就能完成文件上传、分享、传输，配合 Docker 可快速自建私有临时文件中转站，无需复杂配置，简洁易用且能保障隐私安全。

## 使用场景
- 跨设备临时传输文件，手机、电脑直接互通，无需安装客户端
- 同事、朋友之间快速分享文件，即用即走，高效便捷
- 私密文件不想上传公共云盘，自建服务更安全可控
- 临时分享日志、安装包、配置文件等工作资料

## 功能特点
- 纯网页访问，全平台通用，无需安装任何 APP，操作门槛低
- 支持 CLI 客户端操作，可通过命令行完成文件上传、管理
- 支持文件加密，可设置分享密码，保障文件安全
- 可自定义文件过期时间、下载次数，支持“阅后即焚”（OneShot）
- 一键生成分享链接，可随时禁用分享，灵活可控
- 资源占用低，Docker 一键部署，维护成本低

## 部署教程
### 创建Plik容器
1.  进入 Docker 界面，点击「Images」（镜像），在搜索框输入「plik」，找到对应镜像后点击下载。
    <img src="/images/common/portable/docker/plik/1-2.png" width="100%" />

2.  镜像下载完成后，进入「Containers」（容器）页面，点击「创建容器」，选择「rootgg/plik」镜像，点击「下一步」。
    > 温馨提示：若需要容器随设备开机自动启动，勾选页面中的「开机启动」选项即可。
    <img src="/images/common/portable/docker/plik/1-3.png" width="100%" />

3.  路径映射设置，点击添加路径映射
    * 存放上传文件:创建本地存储路径「My Files/upload」,将容器内路径「/root/files」映射到本地路径「My Files/upload」
    

4.  所有设置确认无误后，点击 「确认」，选择 「创建后启动」，即可完成Plik容器的创建与启动。
    <img src="/images/common/portable/docker/plik/1-4.png" width="100%" />

## Plik 的基本使用
### 1.  访问 Plik：

<img src="/images/common/portable/docker/plik/1-6.png" width="100%" />

访问地址：http://IP:8080/，将IP替换为自己的服务器（或PocketCloud设备）IP地址；
> 注意：若为PocketCloud设备，直接使用设备自身IP即可；
> 若部署时修改了端口，需对应调整访问地址的端口号。

### 2.  设置 Plik：
可根据需求进行相关配置。
<img src="/images/common/portable/docker/plik/1-7.png" width="100%" />

| 设置项 | 说明 |
| ---- | ---- |
| 下载后销毁 | 文件被下载一次后将永久删除 |
| 流式传输 | 文件直接流式传输给下载者，不存储在服务器 |
| 可删除 | 拥有链接者可删除已上传的文件 |
| 端到端加密 | 上传前文件已加密，仅持有密码者可解密 |
| 密码保护 | 通过 HTTP 基础认证设置访问密码，保障安全 |
| 备注说明 | 支持在上传的内容中添加评论 |
| 过期时间 | 设置文件有效时长，到期自动失效 |

#### 3.  上传文件
直接拖拽文件至网页上传区域，或点击“选择文件”上传。
#### 4.  分享文件
上传完成后，复制页面生成的分享链接，点击链接即可下载。
