---
title: "如何通过网页端访问设备?"
---

Web 客户端（Beta）允许您直接通过浏览器访问和管理设备，无需安装桌面端或移动端应用。它支持两种访问方式：**局域网访问**和**远程访问**，以满足不同场景下的使用需求。

## 前提条件
1. 确保设备已开机并正常连接网络。
2. 如需远程访问，请先在客户端应用中[启用远程访问功能](/portable/guides/remote-access)，并完成 Station ID 设置。

## 访问方式
### 方式一：局域网访问
适用于电脑与设备在同一局域网（同一 WiFi / 有线网络）的场景，访问速度更快、稳定性更高。

操作步骤：
1. 获取设备的局域网 IP 地址：可通过设备自带屏幕查看，或在客户端应用的**设备信息**页面中查看。
2. 打开浏览器，在地址栏输入 `http://设备IP:9500` 格式的地址。
3. 在登录页面输入用户名和密码，即可进入 Web 管理界面。

> 示例：如果设备 IP 为 `192.168.3.10`，则在地址栏输入 `http://192.168.3.10:9500`。

### 方式二：远程访问
适用于出差、外出办公等外网场景。您可以通过官方远程访问门户访问家中或办公室的设备。

操作步骤：
1. 启用远程访问功能。
2. 打开浏览器，输入官方远程访问地址：`https://login.stationpc.com/`
3. 在登录页面输入您的 Station ID、用户名和密码，验证通过后即可访问设备。

## 支持的浏览器
为确保功能完整和最佳使用体验，建议使用以下浏览器（或更高版本）访问 Web 客户端：
1. Chrome 50 及以上版本
2. Microsoft Edge 78 及以上版本
3. QQ 浏览器极速版、360 浏览器极速版
4. Firefox 54 及以上版本
5. Safari 10 及以上版本（Mac）

## 注意事项
1. Web 客户端目前处于 Beta 测试阶段，部分功能可能暂不可用。建议配合客户端应用使用以获得完整功能。
2. 局域网访问时，请确保电脑与设备连接在同一网络，否则无法通过 IP 地址访问。
3. 远程访问时，请确保设备已连接互联网，否则无法通过远程门户连接。
4. 如果页面加载异常，请尝试切换至推荐浏览器，或清除浏览器缓存后重试。
