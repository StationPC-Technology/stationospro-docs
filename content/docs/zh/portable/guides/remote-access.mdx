---
title: "如何进行远程访问？"
---

PocketCloud 内置远程访问服务，可为你提供安全的远程访问功能。使用该服务前，需先绑定手机号 / 邮箱并创建唯一的 Station ID（用于标识你的设备），通过 Station ID 即可快速访问你的 PocketCloud。

> 注意:
> * 使用远程访问服务需绑定手机号 / 邮箱；
> * 服务会为你的 PocketCloud 自动创建唯一 Station ID，通过该 ID 可安全访问设备；
> * 基于当前网络环境，系统会自动选择最优访问方式连接；
> * Station ID 支持自定义修改。

## 开启远程服务
方式1:
在设备首次初始化配置过程中，按照指引勾选 “开启远程访问” 选项即可。

方式2:
1. 打开客户端，进入**设备**页面；
2. 找到**设备连接**，在其中可手动开启或关闭远程服务

## 解绑远程服务

恢复出厂设置时,系统会自动解绑远程服务
> 设备已绑定远程服务时，恢复出厂设置需连接网络；
