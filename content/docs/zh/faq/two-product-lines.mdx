StationPC 目前有两条并列的 NAS 产品线：**桌面式 NAS** 和 **便携式 NAS**。它们面向的使用场景不同，硬件形态、系统底座和客户端也分别设计，所以不是同一台机器的「标准版 / 便携版」，而是两套独立的产品与系统。帮助中心也因此按产品线分成两套文档。

## 两条产品线分别是什么

| | 桌面式 NAS | 便携式 NAS |
| --- | --- | --- |
| 型号 | DA400、DA400 Air | PA100、PA100 Pro |
| 系统 | StationOS Pro | StationOS |
| 系统底座 | Debian | OpenWrt |
| 硬件形态 | 固定摆放，多硬盘位，以固定供电和有线网络为主 | 内置电池，可随身携带，支持无线 / AP 连接 |
| 典型用途 | 家庭或工作室的长期存储、RAID 阵列、Station AI | 出差旅行、移动办公 |
| 客户端 | StationNAS（Windows / macOS）、StationHub（iOS / Android） | PocketNAS（Windows / macOS / Linux / iOS / Android） |

## 为什么不能只用一套系统

1. **硬件边界不同。** 桌面式要长期承载多块硬盘、RAID 和更高的持续读写，便携式要在电池、散热和体积限制下工作。驱动、电源管理、硬盘管理和散热策略很难共用一套。
2. **系统底座不同。** StationOS Pro 基于 Debian，StationOS 基于 OpenWrt。两者的软件包、服务管理、升级方式和底层工具链都不一样，不能把同一个系统镜像安装到另一条产品线上。
3. **功能和客户端不同。** 桌面式提供 Station AI、RAID 等能力；便携式围绕电池、AP 模式、SD / USB 备份和 PocketNAS 设计。两边都有 Docker 和文件共享，但菜单路径、界面和限制并不相同。
4. **版本线独立。** 两套系统分别发布更新，更新日志和版本号各自独立。便携式的更新包不能装到桌面式，反之亦然。

## 对我的使用有什么影响

- **先确认型号。** 看设备标签或购买记录：型号是 DA400 / DA400 Air，就是桌面式；是 PA100 / PA100 Pro，就是便携式。
- **按产品线查文档。** 两条产品线的菜单、截图和限制不同，请从对应的「桌面式 NAS」或「便携式 NAS」入口进入，不要照着另一条产品线的步骤操作。
- **不要混用客户端和更新包。** 桌面式用 StationNAS / StationHub，便携式用 PocketNAS；更新包也不通用。
- **同名功能先看产品线。** 同样的功能名称（例如备份、远程访问）在两条产品线上的位置和做法可能不同。

## 为什么帮助中心也分成两套文档

因为两套系统的菜单、截图、限制和更新节奏都不同，如果把内容混在一起，同一个问题会出现两个答案，搜索也容易把用户带到另一条产品线的步骤上。所以本站采用「一个站点、两个并列产品域」：通用内容（法务、联系我们、全站搜索）共享，具体操作分别写在桌面式和便携式文档里。

如果你还不确定自己的设备属于哪条产品线，可以先看设备标签上的型号，或[联系我们](../contact)。
