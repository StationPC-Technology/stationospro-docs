StationOS Pro 是StationNAS设备搭载的操作系统，围绕数据存储、文件共享、备份容灾、容器应用与 AI 服务提供了完整的应用中心化管理体验。本章节将逐一介绍系统内置应用的功能与使用方法，帮助你快速上手并充分发挥设备能力。

## 桌面介绍

登录系统后即可进入桌面。桌面由顶部状态栏、桌面图标区域与底部 Dock 栏组成：

- **顶部状态栏**：左侧提供「回到桌面」与「应用启动器」按钮；中间悬浮显示 CPU、RAM、网络速率等实时资源信息；右侧提供通知中心与个人设置入口。
- **Dock 栏**：集中放置常用应用，点击图标即可打开对应应用窗口。
- **窗口管理**：应用窗口右上角提供最小化、最大化/还原、关闭按钮，可像传统桌面系统一样自由切换与排列窗口。

![Desktop](/images/common/app-guide/overview-img/desktop.png)

## 应用启动器

点击顶部状态栏左侧的启动器按钮，即可打开应用启动器。启动器支持：

- 通过顶部搜索框按名称快速查找应用；
- 查看系统全部内置应用，点击图标即可启动。

![App Launcher](/images/common/app-guide/overview-img/app-launcher.png)

## 内置应用一览

| 应用 | 说明 |
| --- | --- |
| 文件管理 | 管理个人与团队文件，支持上传下载、外链分享、回收站、重复文件清理，以及 SMB/WebDAV/FTP/NFS 等文件服务配置 |
| 备份 | 提供本地备份、远程备份与一键备份能力，支持 NAS、外接存储、云盘与文件协议等多种备份源 |
| Docker | 容器化管理台，支持容器、项目（Compose）、镜像、网络的全生命周期管理 |
| 日志中心 | 集中查看系统运行日志，支持关键字搜索与多条件筛选 |
| 资源管理 | 实时监控 CPU、内存、网络、NPU 与硬盘状态，并管理系统服务与进程 |
| 系统设置 | 管理设备信息、用户、存储、网络、远程访问、硬件电源、安全与系统更新等核心配置 |
| 应用中心 | 一站式应用商店，提供官方应用与第三方应用的安装、更新与管理 |
| Station AI | 内置 AI 智能助手，支持对话问答、知识库检索、文档翻译与总结 |
| 帮助中心 | 快速打开本帮助文档站点，查询安装、应用教程与常见问题 |

<Callout title="提示" type="info">
  部分功能与应用可能因设备型号、固件版本或安装的应用不同而有所差异，请以设备实际界面为准。
</Callout>
