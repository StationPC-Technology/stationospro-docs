文件管理是 StationOS Pro 的核心应用，用于集中管理设备上的所有文件。你可以在浏览器中完成文件上传下载、目录管理、权限分享、回收站恢复与重复文件清理，还可以配置 SMB、WebDAV、FTP、NFS 等文件服务，让电脑、手机直连访问 NAS 中的文件。

## 界面介绍

文件管理顶部按功能划分为以下标签页：

| 标签页 | 说明 |
| --- | --- |
| 我的文件 | 当前用户的个人文件空间 |
| 团队文件 | 团队共享空间，可多人协作访问 |
| 外接存储 | 管理 U 盘、移动硬盘等外接设备中的文件 |
| 远程挂载 | 挂载远程 NAS 或服务器上的共享目录 |
| 应用文件 | 查看各应用产生的数据文件 |
| 我的收藏 | 快速访问收藏的文件与文件夹 |
| 外链分享 | 管理已创建的外部分享链接 |
| 回收站 | 恢复或彻底删除已删除的文件 |
| 重复文件 | 扫描并清理重复文件，释放存储空间 |
| 管理员视角 | 管理员可按用户维度查看全部文件（仅管理员可见） |

文件列表支持列表/网格视图切换，并显示文件名、大小、类型、修改时间、存储位置、创建时间与所有者等信息，点击列头即可排序。

![My Files](/images/common/app-guide/files-img/my-files.png)

## 文件基础操作

工具栏提供以下常用操作：

- **上传**：上传文件或整个文件夹；
- **新建文件夹**：创建新的目录；
- **排序**：按名称、大小、时间等方式排序；
- **视图切换**：在列表视图与网格视图之间切换。

### 新建文件夹

1. 进入目标目录，点击工具栏的 **新建文件夹**。
2. 输入文件夹名称（最多 180 个字符）。
3. 选择文件夹所在的存储位置（如存储空间 1）。
4. 点击 **确认** 完成创建。

![New Folder](/images/common/app-guide/files-img/new-folder.png)

### 右键菜单

在文件或文件夹上点击右键，可执行以下操作：

| 菜单项 | 说明 |
| --- | --- |
| 在新窗口中打开 | 在新窗口中打开（文件夹） |
| 下载 | 下载到本地电脑 |
| 复制到 / 移动到 | 复制或移动到其他目录 |
| 剪切 / 复制 | 剪切或复制 |
| 删除 | 删除（进入回收站） |
| 重命名 | 重命名 |
| 收藏 | 添加到收藏 |
| 外链分享 | 创建外链分享 |
| 详情 | 查看文件详情 |

## 外链分享

通过外链分享，你可以将文件或文件夹分享给没有 NAS 账号的外部用户：

1. 右键点击目标文件或文件夹，选择 **外链分享**。
2. 设置分享参数：
   - **分享名称**：外链显示名称；
   - **有效期**：永久有效或自定义截止时间；
   - **允许下载**：是否允许访问者下载文件；
   - **密码保护**：为链接设置访问密码；
   - **访问次数限制**：限制链接的最大访问次数。
3. 点击 **创建链接** 生成分享链接。

已创建的分享可在「外链分享」标签页中统一管理，包括查看链接、修改规则或取消分享。

![Share Link](/images/common/app-guide/files-img/share-link.png)

<Callout title="安全提示" type="warn">
  分享敏感文件时建议开启密码保护并设置有效期，分享完成后请及时关闭不再使用的链接，避免数据泄露。
</Callout>

## 文件服务设置

点击文件管理右上角的 **设置**，可配置文件服务。设置窗口包含以下标签页：

- **文件共享协议**：分别配置 SMB、WebDAV、FTP、NFS 服务；
- **文件规则**：配置文件命名等规则；
- **远程挂载**：配置远程挂载相关参数；
- **外部分享**：配置外链分享的全局规则。

以 SMB 为例，设置页面提供：

- **可见目录范围**：分别设置我的文件、团队文件、应用文件通过协议访问的可见性；
- **连接方式**：提供 Windows 与 macOS 连接 NAS 的图文指引与访问地址；
- **其他连接信息**：展示设备 IP 地址与默认端口（SMB 为 445），可一键复制。

![File Settings](/images/common/app-guide/files-img/settings.png)

### 在电脑上访问 NAS 文件

- **macOS**：打开 Finder → 前往 → 连接服务器，输入 `smb://设备IP`，再输入 NAS 本地账号密码即可访问。
- **Windows**：按 `Win + R`，输入 `\\设备IP`，再输入 NAS 本地账号密码即可访问。

## 回收站

删除的文件会进入回收站，防止误删导致数据丢失：

- **恢复**：将文件恢复到删除前的原始位置；
- **彻底删除**：永久删除选中文件，不可恢复；
- **清空回收站**：一键清空回收站中的全部文件。

回收站按我的文件与团队文件区分个人与团队删除内容，管理员可查看所有用户的回收站。
