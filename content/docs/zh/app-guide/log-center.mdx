---
title: 日志中心
description: 日志中心使用指南
---

日志中心集中记录系统运行、登录连接、文件传输与硬盘存储等事件。你可以按关键字、等级、模块、用户和时间范围检索日志，用于安全审计、操作追溯和故障排查。

## 页面布局

日志中心分为顶部工具栏、日志表格和底部分页区：

| 区域 | 功能 |
| --- | --- |
| 关键字搜索框 | 按日志内容关键字检索。输入后按 Enter 或让输入框失焦生效。 |
| 筛选 | 按等级、模块、用户、时间范围组合筛选。 |
| 清空 | 按时间范围清除日志。 |
| 导出日志 | 将所选时间范围的日志导出为 CSV 文件。 |
| 日志归档 | 配置自动归档条件和归档保存位置。 |
| 日志表格 | 显示等级、模块、时间、用户和事件。 |
| 分页区 | 显示日志总数，支持刷新、切换页码、调整每页条数和跳转页码。 |

## 查看系统用户日志

如需只查看系统产生的日志，可将 **用户** 筛选为 `system`：

1. 点击顶部 **筛选**。
2. 在 **用户** 下拉框中选择 `system`。
3. 点击 **确认**。

筛选结果中的用户列均为 `system`，适合重点查看系统开关机、系统更新、网络接口状态、硬盘识别、硬盘 S.M.A.R.T 状态和存储卷异常等系统事件。

![按 system 用户筛选后的日志列表](/images/common/app-guide/log-center-img/logs.png)

## 日志字段

| 字段 | 说明 |
| --- | --- |
| 等级 | 日志严重程度：普通、警告、严重。普通为常规运行信息；警告表示需要关注；严重表示功能或硬件存在较高风险。 |
| 模块 | 事件来源：系统、登录连接、文件传输、硬盘存储。 |
| 时间 | 事件发生时间。 |
| 用户 | 触发事件的用户。`system` 表示系统自动产生的事件；普通用户名表示用户操作或用户会话相关事件。 |
| 事件 | 事件详情，例如系统关机、硬盘移除、存储卷降级、系统版本更新等。 |

## 搜索与筛选

### 关键字搜索

在搜索框输入事件内容关键字，例如硬盘型号、存储卷名称、系统版本或错误描述，然后按 Enter。搜索会与条件筛选叠加生效。

### 条件筛选

点击 **筛选** 后可组合以下条件：

| 条件 | 可选值/说明 |
| --- | --- |
| 等级 | 普通、警告、严重，支持多选和全选。 |
| 模块 | 系统、登录连接、文件传输、硬盘存储，支持多选和全选。 |
| 用户 | 选项来自当前日志中出现的用户，支持多选和全选。本文示例选择 `system`。 |
| 时间 | 选择起止日期，只查看指定时间范围内的日志。 |

筛选条件先保存在弹窗中，点击 **确认** 后才应用到列表；点击 **重置** 可清空筛选条件并恢复默认视图。

![筛选用户选择 system](/images/common/app-guide/log-center-img/filter.png)

## 分页与刷新

- **总数**：分页区显示当前筛选条件下的日志总数。
- **刷新**：点击总数左侧刷新图标可重新加载当前列表。
- **每页条数**：可选 50、100、500。
- **跳页**：输入页码后按 Enter，或使用上一页/下一页切换。

## 导出日志

点击顶部下载图标可导出日志：

1. 选择时间范围：全部、最近一周、最近一个月、最近三个月、最近半年、最近一年。
2. 点击 **确认**。
3. 等待日志文件生成，导出的 CSV 会保存到本地浏览器下载目录。

导出适合长期留存审计记录，或在无法直接访问设备时交给技术人员分析。

## 清空日志

点击 **清空** 后：

1. 选择要清除的时间范围：全部、一年前、半年前、三个月前、一个月前、一周前。
2. 确认清理范围。
3. 等待清理进度完成。

<Callout title="注意" type="warn">
  清空日志不可恢复。清理前建议先导出需要留存的历史日志；出现安全事件或硬件异常时，不要急于清除相关时间段日志。
</Callout>

## 日志归档

点击顶部设置图标打开 **日志归档**。系统默认保留近 300 万条传输日志且不自动归档；开启自动归档后，可按以下任一条件触发：

| 条件 | 可选值 |
| --- | --- |
| 日志数据量大于 | 500 MB、1 GB、3 GB |
| 日志时间早于 | 一周前、一个月前、三个月前、半年前、一年前 |

还需选择团队文件中的归档保存位置。至少启用一个归档条件后才能保存。

<Callout title="建议" type="info">
  - 排查登录异常时，优先筛选「登录连接」并关注警告与严重级别。
  - 排查硬盘或存储卷故障时，可筛选用户为 `system`、模块为「系统」或「硬盘存储」。
  - 定期导出或归档重要日志，避免清空后无法追溯。
</Callout>
