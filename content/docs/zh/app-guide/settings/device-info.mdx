title: 设备信息
description: 查看与修改设备基础信息、硬件信息和网络信息

设备信息页用于确认设备身份和运行状态。你可以在该页查看系统版本、硬件规格、序列号与每个网口的地址，也可以修改设备名称或复制 Station ID 与 IP 地址。

## 设备基础信息

| 字段/操作 | 说明 |
| --- | --- |
| 设备名称 | 显示当前设备名。点击名称右侧的编辑图标可修改；名称支持 1~15 位英文字母、数字和 `-`，且 `-` 不能在开头或结尾。 |
| Station ID | 设备的远程访问标识。开启远程访问服务后生成，可点击复制；如需修改，点击 ID 进入修改流程。 |
| 系统版本 | 当前 StationOS Pro 版本号，例如 `v1.1.0.17`。若检测到新版本，可能显示新版本提示。 |
| 系统运行时间 | 自最近一次启动以来持续运行的时长。 |
| 上次开机时间 | 最近一次启动的系统时间。 |

## 硬件信息

硬件信息分为三个区块：

| 区块 | 字段 | 用途 |
| --- | --- | --- |
| CPU | CPU 型号、主频、核心数、线程数 | 判断处理器性能与并行任务能力。 |
| 内存 | 内存容量 | 判断应用、容器、索引和 AI 任务可用的运行空间。 |
| AI 模组扩展 | AI 模组型号与算力，例如 RK1828、20 TOPS INT8 | 确认设备是否具备 AI 加速硬件及算力等级。 |

## 设备详情

| 字段 | 说明 |
| --- | --- |
| 设备型号 | 设备的产品型号，例如 DA400。 |
| 序列号 | 设备唯一标识之一。点击复制按钮可快速复制，常用于注册、保修和技术支持。 |

## 网络信息

网络信息按网口展示，例如「有线连接 1」「有线连接 2」。选择网口后可查看：

| 字段 | 说明 |
| --- | --- |
| 网口名称 | 系统识别的接口名，例如 `enP2p33s0`。 |
| 网络配置 | 双工模式与 MTU，例如 Full-duplex、MTU1500。 |
| IPv4 地址 | 当前 IPv4 地址；点击复制按钮可复制。 |
| IPv4 连接状态 | 显示 IPv4 是否已连接。 |
| IPv6 地址 | 当前 IPv6 地址；无地址时显示 `-`。 |
| IPv6 连接状态 | 显示 IPv6 是否已连接。 |

<Callout title="提示" type="info">
  如果设备信息中的 IP 与你当前访问地址不一致，可能是多网口设备同时连接多条链路。请以客户端实际连接的网段为准，或在网络设置中进一步查看每个接口的网关与 DNS。
</Callout>

## 字段使用建议

| 场景 | 建议查看字段 |
| --- | --- |
| 浏览器无法访问设备 | 网络信息中的 IPv4/IPv6 地址、连接状态、网口名称。 |
| 远程客户端无法添加设备 | Station ID、系统版本、远程访问开关状态。 |
| 判断是否能运行 AI 或容器 | CPU 核心线程、内存容量、AI 模组算力。 |
| 联系技术支持或保修 | 设备型号、序列号、系统版本、运行时间。 |
| 排查反复重启 | 上次开机时间、系统运行时间，并可结合日志中心系统日志。 |
| 多网口链路确认 | 每个网口标签下的地址、双工模式、MTU 和连接状态。 |

## 状态解读

| 状态/表现 | 含义 | 建议处理 |
| --- | --- | --- |
| IPv4 连接正常但 IPv6 显示 `-` | 当前链路未获取 IPv6，不一定影响 IPv4 访问。 | 仅在需要 IPv6 时检查路由器 SLAAC/DHCPv6。 |
| 某网口显示未连接 | 网线未插入、交换机端口异常或链路协商失败。 | 更换网线/端口，再到网络设置查看接口状态。 |
| 运行时间很短 | 设备刚开机或发生过异常重启。 | 到日志中心筛选 System 用户查看关机、重启和更新记录。 |
| 有新版本提示 | 更新服务器返回新固件。 | 到更新与还原查看版本说明，先备份再升级。 |

## 常见问题

### 修改设备名称会影响文件访问吗？

设备名称主要用于识别设备和部分通知场景，一般不会改变存储路径或账号。若客户端使用主机名访问服务，修改后需要按新主机名重新连接；使用 IP 访问则通常不受影响。

### 为什么多个网口都有 IP？

多网口设备可同时连接多条链路。每个网口的信息独立显示，客户端应使用与其同网段的地址。若需要带宽叠加或链路冗余，可在网络设置中评估网桥或链路聚合。

### Station ID 可以当作账号吗？

不可以。Station ID 是设备远程访问标识，不是登录账号。远程访问仍需输入设备本地用户和密码；绑定邮箱用于关联远程访问账号与身份验证。
