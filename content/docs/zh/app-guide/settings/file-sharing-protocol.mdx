文件共享协议页提供 **SMB**、**WebDAV**、**FTP**、**NFS** 四个标签。开启对应服务后，电脑、手机、NAS、电视盒子等客户端可通过协议访问设备中的文件。每个协议页面都提供连接方式指引，方便复制地址并按步骤挂载。

![File Sharing](/images/common/app-guide/settings-img/file-sharing.png)

## 可见文件夹范围

SMB、WebDAV、FTP 的服务卡片均提供 **设置可见目录范围**。该设置决定各文件区域通过对应协议是否可见：

| 区域 | 说明 |
| --- | --- |
| 我的文件、他人共享 | 当前用户个人目录与收到共享的文件。 |
| 团队文件 | 团队共享目录。 |
| 外接存储 | USB 等外接存储中的文件。 |
| 远程挂载 | 从远程 NAS、服务器或网盘挂载的目录。 |
| 应用文件 | 应用产生的数据目录。 |

每个区域可选择：

| 模式 | 效果 |
| --- | --- |
| 全部可见 | 当前及未来新增的文件夹都可通过该协议访问。 |
| 自定义文件夹 | 仅指定一级文件夹可见，卡片显示自定义数量。 |
| 全部禁止/无 | 该区域下任何文件夹都无法通过该协议查看。 |

<Callout title="命名限制" type="info">
  一级文件夹名称包含空格或 `! " # % & ' ( ) * + , / : ; < = > ? @ [ ] ^ { } | ~` 等特殊字符时，无法通过文件共享协议访问。建议一级目录使用字母、数字、中文、下划线或连字符命名。
</Callout>

## SMB

SMB 是 Windows、macOS 和大多数客户端最常用的文件共享协议，适合日常局域网文件访问。

| 功能 | 说明 |
| --- | --- |
| SMB 服务开关 | 开启后，设备可在局域网内通过 SMB 共享和访问文件。 |
| 高级设置 | 配置 SMB3 多通道、SMB1、NTLMv1 与 macOS 文件名兼容。 |
| 设置可见目录范围 | 跳转到文件管理设置，配置各目录通过文件服务可见的范围。 |
| Time Machine 服务 | 开启后，Mac 可通过 Time Machine 备份到此 NAS。 |
| Time Machine 文件夹 | 显示或设置 Time Machine 备份目录。 |
| 查看文件夹 | 打开当前 Time Machine 备份目录。 |
| 连接方式 | 提供 macOS Finder、Windows 运行窗口的连接步骤和 `smb://IP`、`\\IP` 地址。 |
| 其它连接信息 | 显示设备 IP、默认端口 445 与主机名。 |

### SMB 高级设置

| 选项 | 说明 | 建议 |
| --- | --- | --- |
| 支持 SMB3 多通道 | 允许多个网络连接并行传输，提高速度与可靠性。 | 多网口或高并发传输场景建议开启。 |
| 支持 SMB1 | 兼容旧设备，但协议安全性较弱。 | 仅在旧设备无法连接时临时开启。 |
| 支持 NTLMv1 | 兼容部分电视盒、播放机等仅支持 NTLMv1 的终端，但鉴权协议不安全。 | 仅对必要设备开启，并限制访问范围。 |
| 为 macOS 转换文件名中的特殊字符 | 增强与 macOS 的文件名兼容性。 | Mac 访问异常时可开启。 |

### Time Machine 设置

| 选项 | 说明 |
| --- | --- |
| Time Machine 服务开关 | 必须先开启 SMB 服务。 |
| 存储位置 | 选择用于保存 Mac 备份的存储卷。 |
| 备份容量限制 | 选择「限制大小」并输入容量，或选择「不限制大小」。 |
| 容量单位 | 支持 GB 与 TB；限制不能超过所选存储空间总容量。 |

![SMB](/images/common/app-guide/settings-img/file-sharing.png)

## WebDAV

WebDAV 基于 HTTP/HTTPS 提供文件访问，常见于第三方客户端、移动应用和部分挂载工具。

![WebDAV](/images/common/app-guide/settings-img/file-sharing-webdav.png)

| 功能 | 说明 |
| --- | --- |
| WebDAV 服务开关 | 开启后可在局域网通过 WebDAV 访问文件。 |
| 高级设置 | 配置 HTTP/HTTPS 协议与监听端口。 |
| 设置可见目录范围 | 配置 WebDAV 可见的文件目录。 |
| 连接方式 | 提供 macOS 与 Windows 的映射/连接步骤，地址格式为 `http://IP:端口`。 |

### WebDAV 高级设置

| 选项 | 说明 |
| --- | --- |
| 启用 HTTP | 使用明文 HTTP 协议，默认常见端口为 5005。 |
| HTTP 端口 | HTTP 服务监听端口，范围为 1~65535。 |
| 启用 HTTPS | 使用加密传输，推荐在不可信网络或需要保护账号数据时开启。 |
| HTTPS 端口 | HTTPS 服务监听端口，不能与 HTTP 端口相同。 |
| 调试模式 | 输出详细日志，可能影响性能，仅排障时临时开启。 |

## FTP

FTP 适合跨系统批量传输文件。系统同时支持无加密 FTP 与 FTPS。

![FTP](/images/common/app-guide/settings-img/file-sharing-ftp.png)

| 功能 | 说明 |
| --- | --- |
| FTP 服务开关 | 开启后允许 FTP/FTPS 客户端连接。 |
| 高级设置 | 配置协议、端口、被动端口范围与空闲超时。 |
| 设置可见目录范围 | 配置 FTP 可见的文件目录。 |
| 连接方式 | 提供 macOS Finder、Windows 文件资源管理器连接步骤，地址格式为 `ftp://IP:21`。 |

### FTP 高级设置

| 选项 | 说明 |
| --- | --- |
| 启用 FTP 服务（无加密） | 启用标准 FTP。传输内容未加密，不建议在不可信网络使用。 |
| 启用 FTPS 服务（安全加密） | 启用 FTP over SSL/TLS，提供加密传输。 |
| FTP 端口 | 服务监听端口，默认 21，有效范围 1~65535。 |
| 被动式 FTP 端口范围 | 可选默认或自定义。自定义范围必须在 55536~65535 内，且上限不能小于下限。 |
| 空闲超时时间 | 客户端无操作后自动断开连接，支持 1~120 分钟。 |

## NFS

NFS 常用于 Linux、Unix、虚拟机或部分播放设备直接挂载共享目录。当前页面说明中提示：开启后局域网设备可本地挂载共享文件夹并直接访问文件，无需账号验证。

![NFS](/images/common/app-guide/settings-img/file-sharing-nfs.png)

| 功能 | 说明 |
| --- | --- |
| NFS 服务开关 | 开启后才可使用 NFS 地址挂载。 |
| 设置可见目录范围 | 服务未开启时不可用；开启后可配置 NFS 可见目录。 |
| 连接方式 | 提供 macOS `nfs://IP/路径` 与 Windows `\\IP\路径` 示例。 |

<Callout title="安全提示" type="warn">
  - NFS 可能不进行账号密码验证，请只在可信局域网内开启，并通过可见目录范围和客户端权限限制访问。
  - SMB1、NTLMv1、明文 FTP/HTTP 均存在安全风险。设备兼容时优先使用 SMB3、HTTPS、FTPS 或 SFTP。
  - 修改服务端口后，请同步调整防火墙出站/入站规则和客户端地址。
</Callout>

## 服务开关影响

| 操作 | 客户端影响 | 数据影响 |
| --- | --- | --- |
| 开启协议 | 对应客户端可尝试连接。 | 不改变文件权限。 |
| 关闭协议 | 已有协议连接会失败或断开。 | 不删除文件。 |
| 修改端口 | 旧地址立即失效。 | 不删除文件。 |
| 修改可见范围 | 部分目录从协议客户端消失。 | 只影响显示与访问入口，不删除目录。 |
| 格式化协议所在存储卷 | 协议本身仍可开启，但源数据被清除。 | 卷内文件全部删除。 |

## 账号与权限关系

文件协议使用设备本地账号验证，最终可见和可写内容还受以下配置影响：

1. 用户是否启用；
2. 用户可访问存储空间和配额；
3. 用户组授权；
4. 文件/目录自身权限；
5. 协议可见目录范围；
6. 防火墙和 IP 名单；
7. 存储卷是否只读。

## 默认地址与端口

| 协议 | 默认端口 | 常见地址 |
| --- | --- | --- |
| SMB | 445 | `smb://IP`、`\\IP` |
| WebDAV | 5005，可在高级设置修改 | `http://IP:端口` |
| FTP/FTPS | 21，可在高级设置修改 | `ftp://IP:端口` |
| NFS | 由系统导出路径决定 | `nfs://IP/共享路径` |

## 连接排障

| 现象 | 检查顺序 |
| --- | --- |
| 客户端无法连接 | 服务开关、IP/端口、防火墙、交换机路由、客户端所在网段。 |
| 能连接但看不到目录 | 可见目录范围、账号权限、文件夹名称特殊字符。 |
| 提示账号密码错误 | 用户是否启用、密码是否修改、协议是否要求本地账号。 |
| 传输速度慢 | 链路速率/双工、SMB 多通道、聚合模式、硬盘负载、CPU/内存占用。 |
| 修改端口后无法访问 | 客户端地址端口、防火墙规则、路由器端口转发。 |
| Mac 特殊文件名异常 | 开启为 macOS 转换文件名特殊字符，并检查目录命名。 |

<Callout title="最小暴露原则" type="warn">
  只开启实际需要的协议；仅在可信网络使用 NFS；公网访问优先使用远程访问或 VPN，不要直接暴露 SMB、FTP 或管理端口。
</Callout>
