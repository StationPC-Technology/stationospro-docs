系统设置是 StationOS Pro 的控制中心，集中管理设备信息、用户、存储、网络、远程访问、安全策略、硬件电源与系统更新等核心配置。该应用通常需要管理员权限访问；不同型号、固件版本和已安装硬件不同，可见选项可能存在差异，请以设备实际界面为准。

## 进入系统设置

1. 登录 StationOS Pro 桌面。
2. 在 Dock 栏或应用启动器中打开 **系统设置**。
3. 在左侧标签栏选择需要配置的功能模块。

![Settings window](/images/common/app-guide/settings-img/device-info.png)

左侧标签栏按功能分为以下 14 个模块：

| 模块 | 主要用途 | 适用场景 |
| --- | --- | --- |
| 设备信息 | 查看设备名称、Station ID、版本、硬件、序列号与网络信息 | 确认设备身份、排查连接、联系售后 |
| 用户管理 | 管理本地用户、角色、状态、用户组与存储配额 | 为家人或团队成员分配账号与空间 |
| 存储空间 | 创建和管理存储卷、RAID、热备盘与 SSD 缓存 | 初始化硬盘、扩容、提升读写性能 |
| 硬盘 | 查看硬盘详情与健康状态，格式化或安全弹出硬盘 | 硬盘巡检、更换、故障排查 |
| 文件共享协议 | 配置 SMB、WebDAV、FTP、NFS 与 Time Machine | 让电脑、手机、电视盒等设备访问 NAS 文件 |
| AI 模型 | 管理基础 AI 能力、本地模型与索引数据存储位置 | 开启人脸/文字/文件/视觉识别，控制模型空间 |
| 网络设置 | 配置网关、DNS、网卡、网桥与链路聚合 | 修改 IP、多网口负载、网络冗余 |
| 远程访问 | 配置 Station ID 远程访问与 DDNS | 从互联网或自有域名访问设备 |
| SSH | 开启或关闭 SSH/SFTP 远程终端服务 | 远程维护、命令行管理、安全管控 |
| 安全性 | 配置访问端口、双重验证、IP 防护、防火墙、证书与数据分析 | 收紧系统入口、阻断可疑访问、启用 HTTPS |
| 通知设置 | 配置邮件通知服务与通知语言 | 接收验证码、重置密码与系统通知邮件 |
| 硬件与电源 | 管理蜂鸣器、风扇、内存压缩、电源计划与硬盘休眠 | 控制噪音、散热、自动开关机与能耗 |
| 时间与时区 | 设置时区、NTP 自动同步或手动时间 | 保证日志、证书、任务调度时间正确 |
| 更新与还原 | 检查/安装系统更新、查看更新日志、恢复出厂或重置网络 | 升级系统、修复网络配置、恢复默认设置 |

<Callout title="操作建议" type="info">
  涉及存储卷、RAID、格式化、防火墙、端口、恢复出厂和重置网络的操作可能影响数据或连接。修改前请确认业务影响，并为重要数据保留备份。
</Callout>

## 功能分组与操作风险

| 分类 | 模块 | 主要风险 |
| --- | --- | --- |
| 只读信息 | 设备信息 | 基本无风险；修改设备名称会影响识别方式。 |
| 账号与授权 | 用户管理 | 删除用户会删除个人数据；提升管理员会扩大系统控制权。 |
| 数据结构 | 存储空间、硬盘 | 创建、修改、格式化、更换硬盘可能删除数据或降低冗余。 |
| 服务入口 | 文件共享协议、SSH、安全性 | 开启协议或端口会增加暴露面；错误防火墙/端口配置可能断开管理连接。 |
| 网络与远程访问 | 网络设置、远程访问 | 修改 IP、网桥、聚合、DDNS 可能导致当前连接中断。 |
| 系统维护 | 硬件与电源、时间与时区、更新与还原 | 重启、重置、错误时间或中断更新可能影响服务可用性。 |

## 管理员操作清单

执行高风险操作前建议确认：

1. 重要数据已有独立备份，且备份可恢复。
2. 当前有局域网或控制台恢复路径，不只依赖正在修改的远程连接。
3. 存储卷健康状态正常，硬盘没有降级、损坏或只读告警。
4. 已通知相关用户停止写入文件、备份、下载、容器和索引任务。
5. 设备供电稳定；机械硬盘、SSD 缓存和系统更新期间不要强制断电。
6. 记录修改前的 IP、端口、DNS、防火墙规则、Station ID 和版本号。
