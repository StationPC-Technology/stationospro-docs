网络设置页分为 **常规** 与 **网络连接**。常规页负责全局网关、DNS 与高级解析策略；网络连接页负责每块网卡的 IP 参数、网桥和链路聚合。

## 常规

![Network General](/images/common/app-guide/settings-img/network-general.png)

### 默认网关

| 字段 | 说明 |
| --- | --- |
| 默认网关 | 当前 IPv4 默认网关，例如 `172.16.0.1`。设备访问其他网段或互联网时优先使用。 |
| IPv6 默认网关 | 当前 IPv6 默认网关；未配置或不可用时显示 `-`。 |

### DNS 服务器

| 选项 | 说明 |
| --- | --- |
| 手动配置 DNS 服务器 | 未勾选时使用 DHCP 等方式自动获取 DNS；勾选后可手动填写。 |
| 主 DNS 服务器 | 必填。域名解析的首选服务器，例如 `202.96.134.33`。 |
| 备用 DNS 服务器 | 选填。主 DNS 不可用时使用，例如 `202.96.128.86`。 |

### 高级设置

| 选项 | 说明 |
| --- | --- |
| 启用多网关 | 允许系统使用多个网关。适合设备连接多个网段或多个上行链路的场景。 |
| DNS 解析优先使用 IPv4 | 域名同时有 IPv4/IPv6 记录时优先选择 IPv4，可避免部分 IPv6 网络不通导致访问缓慢。 |
| 启用 IP 冲突检测 | 检测局域网内地址冲突，帮助发现静态 IP 与其他设备冲突的问题。 |
| 应用 | 点击后保存当前页修改；未修改时按钮不可用。 |

<Callout title="注意" type="warn">
  如果当前浏览器就是通过网络访问设备，修改网关、DNS 或网卡 IP 后连接可能中断。请确认新参数可路由，并准备通过新 IP 或控制台恢复连接。
</Callout>

## 网络连接

![Network Connections](/images/common/app-guide/settings-img/network-connections.png)

### 网卡列表

每个网卡卡片显示：

| 字段 | 说明 |
| --- | --- |
| 接口名称 | 例如 Port 1 (`enP2p33s0`)、Port 2 (`enP4p65s0`)。 |
| 速率 | 当前协商速率，例如 1Gbps。 |
| 双工模式 | 全双工或半双工。 |
| MTU | 当前最大传输单元，例如 MTU1500。 |
| 连接状态 | 已连接、未连接、不可用等。 |
| MAC 地址 | 网卡硬件地址。 |
| IPv4 地址 / 子网掩码 / 网关 | IPv4 连接参数，地址旁可复制。 |
| DNS | IPv4 DNS 服务器列表。 |
| IPv6 地址 / 网关 / DNS | IPv6 连接参数；未配置时显示 `-`。 |
| 网络类型 | 以太网、网桥、链路聚合等。 |

### 编辑网卡

点击网卡卡片上的编辑按钮后可修改：

| 设置 | 模式 | 字段与规则 |
| --- | --- | --- |
| IPv4 | 自动 | 由 DHCP 自动获取地址、掩码、网关与 DNS；手动输入框禁用。 |
| IPv4 | 手动 | 必填 IPv4 地址与子网掩码；可填网关、主 DNS、备用 DNS。地址必须为有效 IPv4 格式，子网掩码必须是连续掩码。 |
| MTU | 自动 | 使用系统默认 MTU。 |
| MTU | 手动 | 可输入 1280~9000。修改前请确认交换机与链路支持对应帧大小。 |

### 创建网桥

**Create Bridge** 可将两块或以上物理网卡加入同一个桥接网络：

1. 点击 **Create Bridge**。
2. 选择至少两块可用物理网卡。
3. 确认后系统创建网桥接口。
4. 创建后可像普通接口一样编辑 IP 参数。

<Callout title="提示" type="info">
  网桥常用于让虚拟机、容器或隔离网络直接接入物理局域网。创建网桥可能改变原网卡连接方式，请避免选错当前管理网卡。
</Callout>

### 创建链路聚合

**Create Link Aggregation** 可将多块网卡合并为一个逻辑接口，实现带宽叠加或链路备份。系统要求使用同规格网卡。

| 分类 | 模式 | 特点与要求 |
| --- | --- | --- |
| 无需交换机配置 | Adaptive Load Balancing – bond6 | 推荐。系统自动在多个网口间分发流量，不需要交换机支持聚合。 |
| 无需交换机配置 | Active/Backup – bond1 | 主备模式。备份口平时不活跃，主口故障后自动切换，可靠性高但不叠加带宽。 |
| 需要交换机配置 | Round Robin – bond0 | 轮询分发流量，两端口同时传输，可显著提高速度；要求交换机支持并正确配置静态聚合。 |
| 需要交换机配置 | Balance XOR – bond2 | 基于哈希分配链路；要求交换机支持静态聚合，多交换机场景需堆叠并正确配置。 |
| 需要交换机配置 | Dynamic Link Aggregation – bond4 | IEEE 802.3ad 动态聚合；要求交换机支持 LACP 并正确配置，多交换机需堆叠。 |

### 解除网络模式

对于网桥或链路聚合接口，可通过更多操作解除网络模式。系统会提示该操作影响对应逻辑接口，确认后恢复成员网卡。

<Callout title="操作建议" type="warn">
  链路聚合模式必须与交换机配置匹配。若选择了需要交换机支持的模式但交换机未配置，可能导致网络中断或聚合口反复异常。
</Callout>

## 修改网络前的准备

1. 记录当前 IP、掩码、网关、DNS、MTU 和接口名。
2. 确认有局域网、控制台或第二网口恢复路径。
3. 确认交换机 VLAN、端口速率、聚合和防火墙策略。
4. 确认新静态 IP 不与其他设备冲突。
5. 若使用链路聚合，先在交换机侧完成对应配置并核对模式。
6. 不要同时修改多个网络条件；每次修改后先验证连接。

## 接口状态解读

| 状态/字段 | 含义 |
| --- | --- |
| Connected | 链路已建立并可获取地址。 |
| Disconnected | 网线/链路未建立。 |
| 1Gbps / 2.5Gbps / 10Gbps | 当前协商速率，受两端设备和线材限制。 |
| Full Duplex | 可同时收发；半双工效率较低。 |
| MTU1500 | 标准以太网 MTU；Jumbo MTU 需全链路支持。 |
| `-` | 未获取到值或该协议栈未配置。 |
| Bridge | 由多块物理接口组成的网桥。 |
| Bond | 由多块网卡组成的链路聚合逻辑接口。 |

## 网桥与链路聚合选择

| 需求 | 选择 |
| --- | --- |
| 让虚拟机/容器直接进入物理局域网 | 网桥。 |
| 两块网卡带宽叠加，不需要交换机配置 | bond6。 |
| 主备容灾，切换优先 | bond1。 |
| 交换机已配置静态聚合，追求并发吞吐 | bond0 或 bond2。 |
| 交换机支持 LACP，需要标准动态聚合 | bond4。 |
| 只修改 NAS 的 IP/DNS | 普通接口编辑，不要创建网桥或聚合。 |

## 恢复连接的常用方法

- 使用另一个未修改网口的 IP 访问。
- 将电脑接入同 VLAN/同网段后重新扫描设备。
- 通过路由器 DHCP 租约列表查找新地址。
- 若仅 DNS 异常，暂时直接访问 IP。
- 若聚合口失联，断开成员口后使用单口恢复配置。
- 严重网络配置错误时，可在更新与还原中评估重置网络。
