---
title: 时间与时区
description: 设置系统时区、NTP 自动同步或手动时间
---

时间与时区页用于确保设备时间准确。正确时间对日志排序、定时任务、证书校验、双重验证和 HTTPS 通信都非常重要。

![Time](/images/common/app-guide/settings-img/time.png)

## 时区

| 选项 | 说明 |
| --- | --- |
| Timezone | 选择设备所在时区，例如 `(UTC+08:00) Beijing, Chongqing, Hong Kong, Urumqi`。 |
| 搜索/筛选 | 时区下拉框可搜索城市或 UTC 偏移，快速定位目标时区。 |

如果设备部署地区与使用者所在地不同，建议按设备实际所在地设置时区，避免任务执行时间与本地预期偏差。

## 时间

### 自动同步

| 选项 | 说明 |
| --- | --- |
| Auto Sync | 由 NTP 服务器定期校准系统时间。推荐日常使用。 |
| NTP 服务器 | 可选择 `pool.ntp.org`、`time.google.com`、`time.cloudflare.com`、`time.apple.com`、`time.windows.com`、`time.nist.gov`、`ntp.tencent.com`、`ntp.aliyun.com` 等，也可输入自定义 NTP 地址。 |
| 当前时间 | 页面实时显示当前系统时间。 |

<Callout title="提示" type="info">
  若设备无法访问所选 NTP 服务器，请检查 DNS、防火墙出站规则和 UDP 123 端口。中国大陆网络环境下可优先尝试 NTP 服务商提供的地址。
</Callout>

### 手动设置

| 选项 | 说明 |
| --- | --- |
| Manual Set | 手动指定日期和时间。 |
| Date | 选择日期，格式如 `2026-10-14`。 |
| Time | 输入时间，格式如 `17:46:26`。 |
| 警告提示 | 系统提醒确保时间准确；偏差过大可能导致网络请求失败或服务异常。 |

手动设置适合隔离网络或无法访问 NTP 的环境。设置完成后点击 **应用** 保存。

<Callout title="注意" type="warn">
  不要把时间设置到证书有效期之外或与真实时间相差过大，否则 HTTPS、远程访问、更新检查和二次验证可能出现失败。
</Callout>

## NTP 与手动选择

| 场景 | 推荐 |
| --- | --- |
| 可访问互联网 | 自动同步。 |
| 隔离内网 | 手动设置，或接入内网 NTP 服务器。 |
| 时间偏差导致证书失败 | 先切换可用 NTP，确认时间回到证书有效范围。 |
| 定时任务执行偏差 | 检查时区和 NTP，不要只改时间。 |
| 跨时区团队 | 按设备实际所在时区设置，日志时间保持一致。 |

## 时间异常影响

| 功能 | 可能影响 |
| --- | --- |
| HTTPS/证书 | 证书未生效或已过期验证失败。 |
| 双重验证/OTP | 动态码时间窗不匹配。 |
| 日志审计 | 事件顺序和发生时间不可靠。 |
| 定时任务 | 开关机、备份任务提前或延后。 |
| 云同步/API | 请求签名或令牌校验失败。 |
| 更新检查 | 更新源可能拒绝请求。 |

## 排障建议

1. 先确认时区，再确认时间；两个错误叠加会难以判断。
2. NTP 不生效时测试 DNS 和 UDP 123 出站。
3. 更换 NTP 服务商后等待一次同步周期。
4. 手动设置后立即应用，不要长时间停留在临时时间。
5. 修改时间后重新登录客户端，刷新会话和缓存。
