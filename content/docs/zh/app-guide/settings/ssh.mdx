SSH 页用于开启或关闭远程命令行服务。管理员可通过 SSH 执行诊断命令、排查系统问题；SFTP 开启后还可通过 SSH 通道传输文件。

![SSH](/images/common/app-guide/settings-img/ssh.png)

## 基础设置

| 选项 | 说明 |
| --- | --- |
| 启用 | 开启 SSH 服务。关闭后无法通过 SSH/SFTP 连接设备。 |
| 端口 | SSH 监听端口，默认 22。可改为其他未被占用的端口以减少扫描暴露。 |
| 有效期 | 服务保持开启的时间，可选 10 分钟、30 分钟、1 小时、3 小时、6 小时或永久。短期开启适合临时排障，到期后自动关闭。 |
| 高级设置 | 配置加密算法强度、访问范围与 SFTP。 |
| 应用 | 保存端口、有效期和高级设置修改。 |

## 高级设置

| 选项 | 说明 |
| --- | --- |
| 加密算法 | 可选高、中、低。建议使用「高」；仅在旧客户端无法协商连接时才降低强度。 |
| 访问限制 | **仅局域网**开启后，SSH 只接受局域网连接，禁止来自互联网的远程 SSH 访问。 |
| SFTP | 开启后可通过 SFTP 客户端使用 SSH 账号传输文件。关闭后仅保留命令行 SSH。 |

## 连接示例

1. 在电脑打开终端或 SSH 客户端。
2. 输入 `ssh 用户名@设备IP -p 端口`。
3. 使用设备本地账号密码登录。
4. 如使用 SFTP，客户端协议选择 SFTP，地址填写设备 IP，端口填写当前 SSH 端口。

<Callout title="安全建议" type="warn">
  - 不要长期对公网开放 SSH；确需远程维护时使用短期有效期，并开启仅局域网或通过 VPN 访问。
  - 避免使用 22 等默认端口、弱密码或将管理员密码共享给不可信人员。
  - SSH 命令可直接修改系统状态，执行来源不明的命令可能导致服务异常或数据丢失。
</Callout>

## 使用模式建议

| 场景 | 推荐配置 |
| --- | --- |
| 临时技术支持 | 10/30 分钟，仅局域网。 |
| 日常内网维护 | 永久 + 仅局域网，保持高加密强度。 |
| 远程排障 | 通过 VPN 或 Station ID 远程访问进入内网，再开启短期 SSH。 |
| 需要传文件 | 开启 SFTP，使用受控账号和明确目录。 |
| 旧客户端无法连接 | 先确认账号密码和端口；确实不支持新算法时再临时降低加密级别。 |

## 操作流程

1. 确认必须使用命令行维护，优先考虑网页管理界面。
2. 设置非默认端口和短期有效期。
3. 打开高级设置，保持高加密算法。
4. 开启仅局域网，按需开启 SFTP。
5. 点击应用并用客户端测试。
6. 完成维护后关闭 SSH。

## 排障

| 现象 | 检查 |
| --- | --- |
| Connection refused | SSH 未开启、端口错误、服务未监听。 |
| Timeout | 防火墙、路由、仅局域网限制、IP 不通。 |
| Auth failed | 用户名/密码错误、用户停用、权限不足。 |
| 算法协商失败 | 客户端过旧，或加密算法不兼容。 |
| SFTP 可连但无法写入 | 目录权限、存储卷只读、用户配额满。 |
