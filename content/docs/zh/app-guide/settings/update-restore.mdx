更新与还原页分为 **系统更新** 与 **还原与重置**。系统更新页用于在线检测、下载安装固件或手动安装本地固件；还原与重置页用于恢复系统默认设置或重置网络。

## 系统更新

![System Update](/images/common/app-guide/settings-img/update.png)

### 当前版本信息

| 字段 | 说明 |
| --- | --- |
| 当前版本 | 当前系统版本号，例如 `v1.1.0.17`。 |
| 检测更新 | 手动向更新服务器查询新版本。检查结果会显示是否已有最新版本。 |
| 上次检查时间 | 部分版本会显示最近一次检查更新的时间。 |

### 自动更新

| 选项 | 说明 |
| --- | --- |
| 自动安装更新 | 开启后，系统可自动下载并安装更新，并在需要时自动重启。关闭后仍会收到新版本提示，但必须手动点击「重启升级」后才会升级。 |

<Callout title="操作建议" type="warn">
  更新会影响系统服务和所有应用服务。建议先停止备份、同步、下载、索引和容器写入任务，并确保电量或供电稳定。更新过程中请勿断电、刷新页面或强制关机。
</Callout>

### 手动安装

| 选项 | 说明 |
| --- | --- |
| Click to select | 选择已下载到本地的固件文件。当前界面说明要求选择比当前版本更高的固件包。 |
| 文件格式 | 按系统提示上传支持的固件格式；上传后系统会计算校验值并校验版本。 |
| 版本校验 | 若安装包版本低于或等于当前版本，系统会阻止或提示无法安装。 |
| 安装流程 | 上传固件 → 校验 → 确认更新提示 → 等待系统安装并重启。 |

### 更新日志

| 功能 | 说明 |
| --- | --- |
| View details | 打开版本更新记录。可查看版本号、版本类型、发布时间和功能/Bug 修复内容。 |

## 还原与重置

![Restore and Reset](/images/common/app-guide/settings-img/restore.png)

### 恢复出厂设置

| 项目 | 说明 |
| --- | --- |
| 影响范围 | 系统设置恢复为出厂默认值，硬盘数据会保留。 |
| 验证 | 需要验证管理员身份。 |
| 重启 | 设备自动重启，恢复过程中请勿断电。 |
| 网络/IP | 重置后若无法用原 IP 访问，请在实体机屏幕查看新 IP 并重新注册。 |
| 解绑账号 | 如需解除账号绑定，按提示前往 StationCloud 账号中心操作。 |

### 重置网络

| 项目 | 说明 |
| --- | --- |
| 影响范围 | 恢复所有网络连接设置与防火墙设置为初始状态。 |
| 前提 | 确认至少有一条有线网络可用。 |
| 连接影响 | 重置过程和完成后，当前连接可能断开；可能需要重新获取 IP。 |
| 验证 | 需要验证管理员身份。 |

<Callout title="危险操作" type="error">
  恢复出厂设置和重置网络都会中断系统服务并需要重启。执行前请记录网络参数、备份配置，并确认有本地访问途径可恢复连接。
</Callout>

## 在线更新流程

1. 点击 **检测更新**。
2. 若发现新版本，查看版本号、包大小和更新说明。
3. 阅读更新提示，确认停止高风险写入任务。
4. 点击立即更新或继续更新。
5. 系统检查更新条件，如存在阻断任务需先处理。
6. 等待下载、安装和自动重启。
7. 更新完成后重新登录并检查版本、存储、应用和网络状态。

## 更新条件与阻断任务

系统可能在更新前检查正在运行的任务。某些任务会直接阻断更新，另一些任务建议先停止：

- 备份、同步和下载任务；
- 容器写入或数据库服务；
- 文件索引或 AI 模型任务；
- 存储卷同步、修复或格式化；
- 其他可能持续写入硬盘的服务。

处理完阻断项后再继续更新，可降低升级中断导致的数据风险。

## Beta 版本更新

若页面显示 **Beta版本更新**，开启后可参与测试版本内测，提前体验未完成功能。测试版本可能存在稳定性、兼容性和功能不完整问题：

- 重要数据设备不建议开启；
- 生产环境或无人值守设备不建议开启；
- 更新前应完整备份；
- 遇到问题可通过日志中心和反馈渠道提交。

## 手动安装详细规则

- 仅支持选择 `.zip` 固件包。
- 安装包版本必须高于当前版本；低于或等于当前版本会被拒绝。
- 上传过程中可暂停、继续或取消。
- 上传完成后系统计算校验值并解析固件信息。
- 确认后进入更新条件检查和升级确认。
- 更新过程中不要关闭浏览器电源、刷新系统或断开供电。

## 恢复与重置对比

| 操作 | 恢复出厂设置 | 重置网络 |
| --- | --- | --- |
| 系统设置 | 恢复默认 | 网络与防火墙设置恢复默认 |
| 硬盘数据 | 保留 | 保留 |
| 管理员验证 | 需要 | 需要 |
| 网络 | 可能改变 IP | 必然可能改变 IP/连接 |
| 应用配置 | 恢复默认或需重新配置 | 通常只影响网络相关配置 |
| 适用场景 | 清空配置移交/重新初始化 | 网络配置混乱且无法恢复时 |
