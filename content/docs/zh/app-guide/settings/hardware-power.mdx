硬件与电源页分为 **常规** 与 **电源**。常规页控制声音、散热与内存压缩；电源页控制供电恢复、网络唤醒、定时开关机与硬盘休眠。

## 常规

![Hardware General](/images/common/app-guide/settings-img/hardware-general.png)

### 蜂鸣器

点击蜂鸣器设置按钮后，可选择哪些事件触发蜂鸣提示：

| 分类 | 事件 | 说明 |
| --- | --- | --- |
| 常规 | 设备开机 | 开机过程发出提示音。 |
| 常规 | 设备关机 | 关机过程发出提示音。 |
| 常规 | 一键备份成功 | 一键备份任务完成时提示。 |
| 设备错误 | 温度过高 | 设备温度超过安全范围时报警。 |
| 设备错误 | 存储空间错误 | 存储卷或硬盘状态异常时报警。 |
| 设备错误 | 风扇错误 | 风扇停转或异常时报警。 |

保存后，仅勾选的事件会触发蜂鸣器。若设备放在卧室或安静环境，可只保留高风险错误提示。

### 冷却风扇

| 模式 | 说明 |
| --- | --- |
| 普通 | 根据设备温度自动调节转速，平衡散热与噪音，适合大多数场景。 |
| 静音 | 低噪低转速运行，但设备温度可能升高。适合噪音敏感且负载较低的环境。 |
| 全速 | 强制最大转速，确保极致散热，但噪音较大。适合高负载、高温环境或散热异常时临时使用。 |

页面卡片会显示当前模式，例如「当前模式：普通」。

### 内存压缩

| 选项 | 说明 |
| --- | --- |
| 内存压缩开关 | 开启后可释放内存空间、加速数据读取，让系统运行更高效。 |

内存压缩会消耗少量 CPU 换取更大的可用内存空间。普通用户建议保持默认；运行高 CPU 负载任务且内存压力较低时，可根据实际性能测试结果调整。

## 电源

![Power](/images/common/app-guide/settings-img/power.png)

### 通电自动开机

| 选项 | 说明 |
| --- | --- |
| Power On When Power Returns | 外部供电恢复后设备自动启动。适合搭配稳定 UPS 或需要无人值守重启的场景。 |

### 网络唤醒

| 选项 | 说明 |
| --- | --- |
| Wake On LAN (WOL) | 设备关机或休眠时，可由局域网魔术包唤醒。需网卡、主板和路由环境支持。 |

### 定时开关机

| 选项 | 说明 |
| --- | --- |
| Scheduled Power On / Off 开关 | 开启后按计划自动开机或关机。首次开启时会引导添加第一条计划。 |
| Add Schedule | 新增计划。 |
| Day | 可选择每天、周一至周日。 |
| Time | 计划执行时间。 |
| Action | 开机或关机。 |
| Actions | 编辑或删除已有计划。 |

多条计划按周重复执行；重复或无效计划会被系统校验。使用自动开机时，请确保设备供电和 BIOS/固件策略支持定时启动。

### 硬盘休眠

硬盘休眠仅适用于支持休眠的机械硬盘，内置硬盘与外接硬盘可分别设置。系统盘可能不支持休眠。

| 选项 | 说明 |
| --- | --- |
| Enable Internal Disk Sleep | 开启内置硬盘休眠。 |
| Enable External Disk Sleep | 开启外接硬盘休眠。 |
| Wake Internal Disks When a User Logs In | 用户登录时自动唤醒内置硬盘。 |
| Wake External Disks When a User Logs In | 用户登录时自动唤醒外接硬盘。 |
| Idle Time | 空闲多久后休眠，可选 10 分钟、20 分钟、30 分钟、1 小时、2 小时、3 小时。 |

<Callout title="注意" type="info">
  频繁访问会使硬盘难以进入休眠。若有备份、索引、下载、监控录像或容器应用持续读写硬盘，请适当延长空闲时间，或只为非关键硬盘开启休眠。
</Callout>

## 蜂鸣器策略

| 场景 | 建议 |
| --- | --- |
| 机房或办公室 | 保留温度过高、风扇错误、存储错误。 |
| 卧室或安静客厅 | 仅保留严重错误，关闭开关机提示。 |
| 无人值守远程部署 | 开启全部错误提示，便于第一时间发现高温/存储异常。 |
| 一键备份重要 | 保留备份成功提示。 |

## 风扇模式选择

| 条件 | 建议 |
| --- | --- |
| 常规家用 | 普通。 |
| 夜间低负载 | 静音，但次日可切回普通。 |
| 高温环境、满载下载、容器/AI任务 | 全速。 |
| 风扇错误告警 | 先关机检查风扇，不要长期依赖全速掩盖故障。 |

## 电源策略组合

| 目标 | 推荐组合 |
| --- | --- |
| 家庭定时节省功耗 | 定时关机 + 手动/网络唤醒。 |
| 断电恢复后自动可用 | 通电自动开机。 |
| 远程维护 | WOL + 可靠局域网/VPN + 固定 IP 或 DHCP 保留。 |
| 重要业务持续运行 | 定时计划谨慎使用，配置 UPS 和冗余存储。 |

## 定时开关机注意事项

- 自动开机还依赖设备硬件/固件支持。
- 关机前应确认备份、同步、下载、索引、录像和容器任务可中断。
- 不要设置同一时间既开机又关机。
- 多条计划重复时系统会校验，但仍应人工复核。
- 使用 NTP 保持时间准确，否则计划执行时间可能偏移。

## 硬盘休眠排障

| 现象 | 检查 |
| --- | --- |
| 硬盘从不休眠 | 日志中心、备份、索引、容器、监控、下载任务是否持续访问。 |
| 频繁唤醒/休眠 | 空闲时间是否过短，客户端是否轮询 SMB/WebDAV。 |
| 休眠后访问慢 | 属于唤醒等待，可缩短空闲时间或关闭休眠。 |
| 外接硬盘无法休眠 | 外接盘/USB 桥接是否支持休眠。 |
| 系统盘不休眠 | 系统盘通常需持续服务，可能不支持休眠。 |
