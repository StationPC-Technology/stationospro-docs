---
title: 远程访问
description: 配置 Station ID 远程访问、DDNS 与账号解绑
---

远程访问页分为 **远程访问** 与 **DDNS**。Station ID 适合使用官方中转服务快速访问；DDNS 适合已有域名并希望通过自有域名解析公网 IP 的用户。

## Station ID 远程访问

![Remote Access](/images/common/app-guide/settings-img/remote-access.png)

### 基础设置

| 功能/字段 | 说明 |
| --- | --- |
| Station ID 远程访问开关 | 开启后设备可通过互联网远程访问。开启或关闭前需要身份验证，并需同意用户协议与隐私政策。 |
| Station ID | 远程访问标识。规则为 4~30 个字符，只能使用数字、小写字母和连字符，且连字符不能在开头或结尾。 |
| 绑定邮箱 | 显示当前绑定的远程访问账号邮箱。必须先绑定邮箱才能开启远程访问。 |
| 修改/编辑 | 点击 Station ID 或编辑入口可更换 ID；ID 已被使用时需要更换。 |

### 远程访问方式

| 方式 | 使用方法 |
| --- | --- |
| 网页端 | 在浏览器访问 `https://scnas.cloud/<Station ID>/web`。 |
| 客户端 | 在 StationCloud 客户端中输入 Station ID 添加并访问设备。 |

### 账号解绑

为保障账号安全，解绑需登录已绑定的 StationCloud/思特云账号：

1. 浏览器打开 `login.stationpc.com`。
2. 登录设备绑定的账号。
3. 进入「我的设备」或 App 中的设备管理。
4. 选择当前设备并解绑。

<Callout title="注意" type="warn">
  关闭远程访问会断开当前远程连接。解绑账号后远程访问不可用，再次使用需要重新绑定并完成验证。
</Callout>

## DDNS

DDNS 会定期检测公网 IP，并把变化同步到域名解析服务商。没有配置时，页面显示空状态，可点击 **新增配置**。

![DDNS](/images/common/app-guide/settings-img/ddns.png)

### 配置列表

| 字段 | 说明 |
| --- | --- |
| 服务商 | DNS 服务提供方，例如 Cloudflare、DNSPod.cn、No-IP.com、Duck DNS、FreeDNS、ChangeIP.com、DynDNS 等；实际列表由服务端返回。 |
| 域名 | 当前 DDNS 记录绑定的域名。 |
| 状态 | 已更新、已停用、未连接、连接中、异常。 |
| 上次更新时间 | 最近一次检测或同步 IP 的时间。 |
| 操作 | 编辑配置、立即刷新/更新、启用/停用、删除。删除后不可恢复。 |

### 新增/编辑配置

#### 基础设置

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 服务商 | 是 | 选择域名解析服务商。新增后服务商不可直接更改。 |
| 域名 | 是 | 输入完整域名；域名需要符合格式，且不能与已有 DDNS 配置重复。 |
| AccessKey/API Token/账号 | 视服务商 | 服务商要求的账号或 AccessKey。字段名称随服务商变化。 |
| SecretKey/API Secret/密码 | 视服务商 | 服务商密钥。编辑时留空表示继续使用已保存密钥。 |
| IPv4 | 是或 IPv6 至少一项 | 默认「自动」，会显示检测到的公网 IPv4。也可选择接口地址或自定义检测地址。 |
| IPv6 | 是或 IPv4 至少一项 | 默认关闭。可选择自动公网 IPv6、接口 IPv6 或自定义检测地址。 |

<Callout title="VPN 提示" type="info">
  页面提示：若开启 VPN，外部 IP 地址检查可能不准确。可暂时关闭 VPN 后重新配置，或手动输入正确的外部 IP 地址。
</Callout>

#### 更多设置

| 字段 | 说明 |
| --- | --- |
| 更新时间 | 每 1、5、10、15、30 或 60 分钟定期检查 IP 更新。 |
| 测试连接 | 立即验证配置。结果显示未连接、连接中、已更新或异常。 |

#### 底部选项

| 选项 | 说明 |
| --- | --- |
| 开启配置 | 控制该 DDNS 配置是否启用。 |

<Callout title="使用前提" type="warn">
  DDNS 只负责域名解析，不会自动穿透路由器 NAT。若需从互联网访问 NAS，还需在路由器上完成端口转发，或使用 Station ID 远程访问。公开服务请务必启用 HTTPS、强密码和双重验证。
</Callout>

## Station ID 使用规则

| 项目 | 说明 |
| --- | --- |
| 字符规则 | 4–30 位，小写字母、数字、连字符；连字符不能在首尾。 |
| 唯一性 | 已被其他设备使用的 ID 不能重复使用。 |
| 生成条件 | 需开启远程访问服务并完成绑定。 |
| 修改影响 | 旧 Web/客户端地址立即失效，需要使用新 ID。 |
| 安全关系 | Station ID 不是密码；仍需设备本地账号登录。 |
| 解绑影响 | 远程访问不可用，再次使用需重新绑定。 |

## 开启远程访问的典型流程

1. 在通知设置中配置可用邮箱。
2. 在远程访问页绑定邮箱并完成验证。
3. 设置符合规则的 Station ID。
4. 同意用户协议和隐私政策。
5. 开启远程访问服务。
6. 在外网浏览器或客户端测试访问。
7. 建议开启 HTTPS/强密码/双重验证。

## DDNS 字段详解

| 字段 | 说明 |
| --- | --- |
| 服务商 | 决定 DNS API 地址和鉴权字段。新增后不建议随意重建，编辑时服务商不可直接改。 |
| 域名 | 必须是已托管在该服务商下的完整域名。 |
| AccessKey/API Token | 服务商授予 DNS 操作权限的凭据，建议只给最小 DNS 权限。 |
| SecretKey/API Secret | 与 AccessKey 配对；编辑时留空可沿用已保存密钥。 |
| IPv4 自动检测 | 使用公共检测服务获取公网 IPv4。 |
| IPv4 接口地址 | 使用设备指定接口地址，适合有固定公网 IP 的环境。 |
| IPv4 自定义 URL | 使用自定义服务返回 IP，适合 NAT/代理环境。 |
| IPv6 | 默认关闭；可自动检测或使用接口地址。 |
| 更新时间 | 越短生效越快，但请求更频繁。 |

## DDNS 排障

| 现象 | 检查 |
| --- | --- |
| 测试连接异常 | AccessKey/Secret、域名托管商、API 权限、服务器网络。 |
| 域名解析 IP 不变 | 本地 DNS 缓存、TTL、检测服务是否拿到正确公网 IP。 |
| 域名解析正确但无法访问 | 路由器端口转发、防火墙、服务端口、是否被 ISP 封禁。 |
| VPN 环境检测错误 | 暂时关闭 VPN 或使用自定义 IP 检测地址。 |
| IPv6 不可用 | 路由器/运营商 IPv6 前缀、接口地址、防火墙放行。 |
