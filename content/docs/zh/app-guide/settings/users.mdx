---
title: 用户管理
description: 管理用户账号、角色、用户组与存储配额
---

用户管理页分为 **用户** 与 **用户组** 两个标签。管理员可以在此创建本地账号、控制账号状态、设置角色和可访问存储空间，也可以通过用户组批量组织成员。

## 用户标签

### 页面布局

- **左侧用户列表**：显示所有用户，支持按用户名搜索；列表会显示头像、用户名、角色与状态。
- **右侧用户详情**：显示所选用户的基本信息、可访问存储空间与所属用户组。
- **新增用户**：在左侧列表上方点击新增按钮，创建本地账号。

![Users](/images/common/app-guide/settings-img/users.png)

### 用户角色与状态

| 选项 | 值 | 权限/影响 |
| --- | --- | --- |
| 角色 | 管理员 | 可登录系统设置并管理系统配置、用户、存储、安全与应用。 |
| 角色 | 普通用户 | 使用授权范围内的文件与应用功能，不能管理系统设置。 |
| 状态 | 启用 | 用户可以正常登录。 |
| 状态 | 停用 | 用户无法登录设备；已有共享、任务或文件权限不会立即代表数据被删除。 |

### 创建或编辑用户

创建和编辑用户时可能涉及以下信息：

| 字段/功能 | 说明 |
| --- | --- |
| 用户名 | 支持指定长度内的英文字母、数字和 `-`；`-` 不能放在开头或结尾，且部分保留名不可使用。 |
| 头像 | 上传或更换用户头像；图片需满足格式与大小限制。 |
| 登录密码/新密码 | 支持 6~30 位字母、数字及 `@#*-_`，需同时包含字母和数字。 |
| 确认密码 | 再次输入密码，两次输入必须一致。 |
| 编辑用户信息 | 修改头像、用户名、角色、状态等基础资料。 |
| 修改密码 | 为用户设置新密码；修改后需使用新密码登录。 |
| 设为管理员 | 将普通用户提升为管理员。提升前系统会要求确认。 |
| 停用/启用 | 临时禁止或恢复用户登录，不等于删除用户。 |
| 删除用户 | 删除账号及其个人文件夹中的数据。系统会提示不可恢复，请先确认没有依赖该用户的任务或共享。 |

### 可访问存储空间

在用户详情的 **可访问存储空间** 中点击 **编辑**，可设置用户可使用的存储卷和容量：

| 字段 | 说明 |
| --- | --- |
| 存储空间 | 显示卷名称、已使用容量、总容量与该用户的最大可用容量。 |
| 最大可用容量 | 可选择 `Unlimited`，或输入具体配额。配额不能超过存储卷可用范围。 |
| 保存 | 保存后立即更新用户可写入范围。配额只限制该用户的可写入容量，不代表数据已占用。 |

<Callout title="注意" type="warn">
  删除用户会同时删除该用户个人文件夹下的数据，且操作不可恢复。删除前请先迁移团队文件、备份个人数据，并确认备份任务、共享链接、同步任务和应用权限不再依赖该账号。
</Callout>

## 用户组标签

### 页面布局

- **左侧组列表**：显示所有用户组与成员数量，支持搜索；内置组如 Admin、Standard User 不可随意删除。
- **右侧组详情**：显示组名称、备注、成员列表与成员角色。
- **新增用户组**：创建自定义用户组。
- **添加成员**：从现有用户中选择一个或多个用户加入组。
- **编辑用户组**：修改组名称、备注或成员。
- **删除用户组**：删除自定义组；删除组通常不删除成员账号，但会影响基于组授权的资源访问。

### 常用字段

| 字段 | 说明 |
| --- | --- |
| 用户组名称 | 用于识别组，建议按部门、家庭角色或项目命名。 |
| 备注 | 选填，记录组用途或授权范围。 |
| 成员 | 组内用户列表，可搜索。 |
| 成员角色 | 显示成员在系统中的角色，例如 Admin。 |

<Callout title="建议" type="info">
  当多个用户需要相同文件或应用权限时，优先使用用户组授权。后续只需要调整组成员，不必逐个修改每个账号。
</Callout>

## 新增用户完整流程

| 步骤 | 操作 | 关键检查 |
| --- | --- | --- |
| 1 | 点击 **新增用户** | 打开新增用户向导。 |
| 2 | 填写基础信息 | 用户名符合格式；密码同时包含字母和数字；两次密码一致。 |
| 3 | 设置头像 | 仅选择图片文件，大小不超过 2 MB。 |
| 4 | 选择用户类型/角色 | 日常使用优先普通用户，避免所有人都拥有管理员权限。 |
| 5 | 配置可访问存储空间 | 明确哪些卷可写入，并决定是否限制容量。 |
| 6 | 设置所属用户组 | 将用户加入按部门、家庭角色或项目划分的组。 |
| 7 | 确认并创建 | 检查配额、角色和个人数据删除提示。 |

## 权限与数据影响

| 操作 | 立即影响 | 数据影响 | 可恢复性 |
| --- | --- | --- | --- |
| 修改密码 | 该账号所有设备退出登录。 | 不删除数据。 | 可再次修改。 |
| 停用用户 | 用户无法登录；相关会话不可继续使用。 | 保留用户数据。 | 可重新启用。 |
| 设为管理员 | 可访问系统设置并管理系统。 | 不删除数据，但权限显著扩大。 | 可移除管理员身份。 |
| 移出用户组 | 组授权的共享或应用权限随之变化。 | 不删除个人文件夹。 | 可重新加入组。 |
| 删除用户 | 账号不可登录。 | 个人文件夹下所有数据会被删除。 | 不可恢复。 |
| 删除用户组 | 组成员解散。 | 通常不删除成员账号，但组授权失效。 | 需重建组并重新授权。 |

## 存储配额建议

- **家庭设备**：可为每位成员设置配额，避免个人照片和视频占满共享卷。
- **团队设备**：按部门或项目组统一容量策略，再对特殊情况单独调整。
- **备份用户**：根据备份源数据大小预留余量，并定期检查已使用容量。
- **应用专用账号**：建议限制容量，防止应用日志或缓存无限增长。

配额只限制该用户在此存储卷上的可写入容量；已有文件、团队文件和系统数据可能分别统计，页面显示的已使用容量以实际存储统计为准。

## 排查建议

| 问题 | 检查方向 |
| --- | --- |
| 用户无法登录 | 账号是否停用、密码是否修改、IP 是否被安全性中的防护规则封禁。 |
| 用户看不到共享目录 | 可访问存储空间、用户组成员关系、文件共享协议可见目录范围。 |
| 写入提示空间不足 | 用户配额、存储卷剩余容量、硬盘是否只读或降级。 |
| 权限没有随组变化生效 | 客户端缓存或会话未刷新，可重新登录或重新连接文件服务。 |
