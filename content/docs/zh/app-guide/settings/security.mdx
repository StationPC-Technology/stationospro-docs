## 端口设置

![Port Settings](/images/common/app-guide/settings-img/security-port-settings.png)

### 当前信息

页面显示当前 Web 管理入口端口：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| HTTP 端口 | 9500 | 使用 HTTP 访问管理端。 |
| HTTPS 端口 | 9501 | 使用 HTTPS 访问管理端。 |

### 端口设置弹窗

| 选项 | 说明 |
| --- | --- |
| HTTP 端口号 | 必填，范围为 1~65535，不能与 HTTPS 端口相同。 |
| HTTPS 端口号 | 必填，范围为 1~65535。开启强制 HTTPS 或默认端口重定向时不能为 0。 |
| 强制 HTTPS 连接 | 将 HTTP 连接重定向为 HTTPS 连接。 |
| 重定向 80 与 443 端口 | 将 80 重定向到 HTTP 端口、443 重定向到 HTTPS 端口；启用后访问设备可不填端口号。 |

<Callout title="注意" type="warn">
  启用默认端口重定向时，HTTP/HTTPS 端口不能使用 80 或 443。修改端口后请使用新端口重新打开管理端，并确认防火墙或路由器转发规则已同步更新。
</Callout>

## 账号安全

账号安全页控制系统级双重验证策略。

![Account Security](/images/common/app-guide/settings-img/security-account-security.png)

| 选项 | 说明 |
| --- | --- |
| 强制使用双重验证 | 开启后，受策略约束的用户登录时必须完成第二步 OTP 验证。 |
| 所有用户 | 策略应用到全部用户。 |
| 仅管理员 | 只强制管理员账号使用双重验证。 |
| 指定用户 | 只强制所选用户或用户组使用双重验证。 |
| 编辑指定用户 | 在用户/用户组选择器中添加或移除策略对象。 |

<Callout title="前提条件" type="info">
  双重验证依赖邮件通知服务。开启前请先在「系统设置 → 通知设置」中配置发件邮箱。若关闭邮件服务，双重验证验证码可能无法发送。
</Callout>

## 防护

防护页用于自动封禁异常登录 IP，并维护允许名单与封禁名单。

![Protection](/images/common/app-guide/settings-img/security-protection.png)

### 封禁异常 IP

| 选项 | 说明 |
| --- | --- |
| 服务开关 | 开启后，系统按规则拦截异常 IP 登录。 |
| 编辑规则 | 配置自动封禁阈值、统计时间与解禁时间。 |

### 自动封禁规则

| 字段 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 尝试登录次数 | 10 次 | 1~100 | 触发封禁所需失败次数。 |
| 设定时间内 | 5 分钟 | 1~10080 分钟 | 统计失败次数的时间窗口。 |
| 自动解禁规则 | 1 小时 | 30 分钟/1 小时/1 天/7 天/30 天/永久 | 被封禁 IP 的解禁时间。 |

### 允许名单与封禁名单

| 名单 | 优先级与作用 |
| --- | --- |
| 允许名单 | 名单内 IP/CIDR 始终允许连接和登录，不受封禁规则影响，优先级高于封禁名单。 |
| 封禁名单 | 名单内 IP/CIDR 始终被限制连接和登录。 |

名单表格显示客户端 IP、最近访问时间、过期时间（封禁名单）、永久标识与备注。支持：

| 操作 | 说明 |
| --- | --- |
| 新增 | 输入一个或多个 IP/CIDR，多个地址用换行或逗号分隔；封禁名单可选择解禁时间。 |
| 备注 | 最多 180 个字符，用于标记来源或用途。 |
| 删除 | 选中一条或多条记录后删除，解除对应限制。 |

## 防火墙

防火墙页根据入站和出站规则控制网络流量。

![Firewall](/images/common/app-guide/settings-img/security-firewall.png)

### 基础设置

| 选项 | 说明 |
| --- | --- |
| 防火墙开关 | 开启后，系统按入站/出站规则控制流量。 |
| 高级设置 | 配置工作模式与局域网默认放行。 |

### 高级设置

| 选项 | 说明 |
| --- | --- |
| 工作模式 | Auto 优先选择 XDP native 模式；Generic 使用传统内核网络栈。出现兼容性问题时可切换。 |
| 局域网 | 「默认允许访问」开启后，局域网流量默认放行，可降低管理端被误拦截的概率。 |

### 入站规则与出站规则

| 字段 | 说明 |
| --- | --- |
| 网络连接 | 所有接口或指定网络接口。 |
| 端口 | 单个端口、逗号分隔端口或范围，例如 `80`、`443`、`1-65535`。 |
| 协议 | 全部、TCP、UDP、ICMP。 |
| 来源 IP / 目标 IP | 自定义 IP 或 CIDR；入站看来源 IP，出站看目标 IP。 |
| 权限 | 允许或拒绝。 |
| 状态 | 生效或禁用。 |
| 备注 | 规则用途说明。 |
| 顺序 | 规则可拖拽排序，越靠前优先级越高。 |
| 若下列规则均不符合时 | 设置默认允许访问或默认拒绝访问。 |

<Callout title="危险操作" type="error">
  错误的防火墙规则可能导致管理端、远程访问或应用服务不可达。配置前建议保留当前管理连接，并优先放行管理端口、SSH 端口和局域网。
</Callout>

## 证书

证书页用于管理系统 HTTPS、FTPS、WebDAV 与远程访问使用的证书。

![Certificate](/images/common/app-guide/settings-img/security-certificate.png)

### 证书列表

| 字段 | 说明 |
| --- | --- |
| 证书名称 | 用户可识别的名称。 |
| 证书类型 | 系统自签名证书、Let's Encrypt 证书或导入证书。 |
| 发证机构 | 证书签发者。 |
| 备用域名 | 证书覆盖的其他域名；无则显示 `-`。 |
| 有效期 | 到期时间。 |
| 自动续签 | 系统证书或 Let's Encrypt 证书可在到期前自动续签。 |
| 状态 | 有效、即将过期、已过期。 |
| 操作 | 查看/编辑详情、更新、下载、删除。删除后不可恢复。 |

### 新增证书

| 方式 | 说明 |
| --- | --- |
| 导入证书 | 从本地上传或 NAS 选择证书文件、私钥文件与可选中间证书。适合已有 CA 签发证书的用户。 |
| 获取证书 | 从 Let's Encrypt 获取免费证书，并自动续签。需填写邮箱，选择 DDNS 域名或自定义域名与服务商。 |

### 获取 Let's Encrypt 证书注意事项

- 免费证书存在申请频率与数量限制。
- HTTP 验证需将 80 端口转发到 NAS；DNS 验证需服务商支持。
- 域名必须正确指向当前公网 IP。
- 获取成功后系统会在证书到期前自动续签。

### 服务配置

**Service Config** 用于为 FTPS、WebDAV 和远程访问证书选择对应证书。确认后相关服务将使用所选证书建立加密连接。

## 设备分析

设备分析页包含两个隐私相关开关。

![Device Analytics](/images/common/app-guide/settings-img/security-device-analytics.png)

| 选项 | 说明 |
| --- | --- |
| 加入设备分析改进计划 | 系统会收集部分匿名使用数据，用于分析产品使用、提升稳定性与改进功能。可随时退出。 |
| 启用 webfind 服务 | 开启后可在局域网内发现 Station OS 设备。系统会收集 IP 地址和端口信息以提供该服务。 |

两项说明均链接隐私政策。若不希望参与数据收集或对外提供局域网发现能力，可关闭对应开关。

<Callout title="安全基线建议" type="info">
  建议启用 HTTPS/强制 HTTPS、双重验证、异常 IP 防护和防火墙；仅开放必要端口；为证书配置自动续签；外网访问优先使用 Station ID 或 VPN。
</Callout>

## 端口策略建议

| 场景 | 建议 |
| --- | --- |
| 家庭局域网 | 可保留 HTTP/HTTPS，仅在可信设备保存登录状态。 |
| 公网或共享网络 | 启用 HTTPS/强制 HTTPS，避免明文提交密码。 |
| 只想省略端口 | 启用 80/443 重定向，但确保路由器和防火器规则同步。 |
| 更换默认端口 | 选择 1024–65535 中未占用端口，不要与 SMB/FTP/SSH 冲突。 |
| 远程访问 | 优先使用 Station ID 或 VPN，不直接暴露管理端口。 |

## 双重验证策略对比

| 范围 | 优点 | 适用 |
| --- | --- | --- |
| 所有用户 | 安全基线最高。 | 存在敏感文件或多人使用的设备。 |
| 仅管理员 | 兼顾安全与普通用户便利。 | 家庭设备或普通账号权限较低。 |
| 指定用户 | 对高风险账号精准管控。 | 仅备份、财务、运维等特殊账号。 |

策略开启后，指定范围内的用户必须在个人设置中完成验证器或邮箱验证配置；管理员应先确认邮件服务可用。

## IP 防护设计建议

- **允许名单**：固定办公网、家庭出口、VPN 出口、堡垒机地址。
- **封禁名单**：反复尝试登录的来源、失陷网段、明确扫描来源。
- **阈值**：家庭设备可较严格；多人使用或代理出口环境应避免过小阈值。
- **解禁时间**：关键设备可设置较长；临时网络可选择短时间便于恢复。
- **VPN 提醒**：出口 IP 变化会影响检测结果，必要时用固定出口或自定义检测地址。

## 防火墙规则设计流程

1. 先放行管理端口、SSH 端口和局域网网段。
2. 明确入站服务及端口，例如 HTTPS、WebDAV、FTPS。
3. 按来源 IP、协议和端口创建最小范围规则。
4. 使用拒绝规则阻断明确不需要的来源。
5. 拖拽调整优先级，越靠前越先匹配。
6. 设置默认策略；不熟悉防火墙时先保持允许访问，验证规则后再收紧。
7. 保留一个已连接管理会话，直到确认新规则可靠。

## 证书排障

| 问题 | 检查 |
| --- | --- |
| 浏览器提示证书域名不匹配 | 访问域名与证书备用域名是否一致。 |
| Let's Encrypt 申请失败 | 域名解析、80 端口转发、API 权限、频率限制。 |
| HTTPS 无法访问 | HTTPS 端口、防火墙、服务配置是否选择证书。 |
| 证书未自动续签 | 系统时间、DNS 解析、80/443 可达性。 |
| 导入后客户端不信任 | 缺少中间证书或使用自签名证书。 |
