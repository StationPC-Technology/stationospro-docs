通知设置页分为 **电子邮件** 与 **通知语言**。邮件通知服务用于发送账号安全邮件，例如双重验证紧急验证码、密码重置邮件等；通知语言决定邮件、短信等推送内容使用的语言。

## 电子邮件

![Email Notification](/images/common/app-guide/settings-img/notifications.png)

### 邮件通知服务

| 功能/字段 | 说明 |
| --- | --- |
| 服务开关 | 开启后系统可通过指定 SMTP 服务发送安全邮件。 |
| 发件邮箱 | 显示当前发件邮箱；未配置时显示「未配置」。 |
| 编辑 | 打开邮件设置弹窗，配置服务商、发件邮箱和认证信息。 |
| 邮件主题前缀 | 设置系统邮件标题前缀，便于在邮箱中识别来源设备。 |
| 发送测试邮件 | 向指定收件邮箱发送一封测试邮件，验证 SMTP 配置是否可用。 |

<Callout title="双重验证依赖" type="warn">
  双重验证需要邮件通知服务支持。若系统已强制使用双重验证，直接关闭邮件服务可能导致登录验证码无法发送；页面会提示先前往账号安全设置关闭双重验证。
</Callout>

### 邮件设置

#### 预设邮箱

选择 Gmail、QQ 邮箱、126 邮箱、163 邮箱时需要配置：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 邮箱服务商 | 是 | 选择系统预设服务商。 |
| 发件邮箱 | 是 | 用于发送系统邮件的邮箱地址。 |
| 授权码 | 是 | 在邮箱服务商中生成的 SMTP 授权码，通常不是邮箱登录密码。 |

预设邮箱通常使用 SSL 465 端口。页面会提醒确保防火墙出站规则没有屏蔽对应端口。

#### 自定义邮箱

选择自定义邮箱后需要配置：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| SMTP 服务器 | 是 | 邮件服务商的 SMTP 地址，例如 `smtp.example.com`。 |
| 端口 | 是 | 根据 SMTP 服务填写。常见默认端口：无加密 25、SSL 465、TLS 587。 |
| 安全类型 | 是 | 可选无、SSL、TLS。建议使用 SSL 或 TLS。 |
| 用户名 | 是 | SMTP 认证用户名，通常为邮箱账号。 |
| 密码 | 是 | SMTP 密码或授权码。 |
| 发件人名称 | 否 | 显示在邮件发件人名称中。 |
| 发件邮箱 | 是 | 实际对外发信的邮箱地址。 |

### 邮件主题前缀

| 选项 | 说明 |
| --- | --- |
| 使用设备名称 | 自动使用当前设备名称作为邮件标题前缀。 |
| 自定义 | 手动输入前缀；选择该方式时前缀必填。 |

邮件主题前缀适合多台设备共用一个邮箱接收通知时快速区分来源设备。

### 发送测试邮件

1. 确认邮件服务已配置并开启。
2. 点击 **发送测试邮件**。
3. 输入收件邮箱。
4. 点击 **发送**。
5. 到收件箱查看测试邮件；若未收到，请检查授权码、SMTP 端口、安全类型和防火墙出站规则。

## 通知语言

![Notification Language](/images/common/app-guide/settings-img/notification-language.png)

| 选项 | 说明 |
| --- | --- |
| 通知语言 | 控制邮件、短信等推送内容语言。 |
| 可选语言 | 简体中文、繁体中文、English、日本語、한국어、Deutsch、Français、Español。 |
| 应用 | 保存语言修改。 |

<Callout title="提示" type="info">
  通知语言只影响系统推送内容，不会直接切换 Web 桌面界面语言。桌面语言可在个人设置中调整。
</Callout>

## 邮件配置排障

| 现象 | 检查 |
| --- | --- |
| 授权码错误 | 服务商是否开启 SMTP、授权码是否复制完整、是否使用登录密码代替授权码。 |
| 连接 SMTP 超时 | SMTP 地址、端口、安全类型、防火墙出站规则。 |
| 使用 SSL 端口但选择 TLS | 核对服务商文档；常见 465/SSL、587/TLS。 |
| 邮件进入垃圾箱 | 发件人名称、SPF/DKIM/DMARC、自定义域名 DNS。 |
| 测试邮件成功但验证码未收到 | 收件箱垃圾邮件、通知语言、账号安全策略、邮件延迟。 |
| 关闭邮件服务被拦截 | 系统检测到双重验证依赖邮件，需先关闭相关策略。 |

## 自定义 SMTP 检查清单

1. SMTP 服务器地址是否为服务商推荐地址。
2. 端口与安全类型匹配。
3. 用户名是否为完整邮箱或服务商要求的账号。
4. 密码/授权码不是空格或换行。
5. 发件邮箱与 SMTP 账号一致，或服务商明确允许别名。
6. 防火墙未屏蔽对应出站端口。
7. 发送测试邮件并检查垃圾邮件文件夹。

## 语言与多设备通知

- 通知语言作用于系统发送的邮件或短信内容。
- 已发送的历史邮件不会因后续修改而重新翻译。
- 多台设备使用同一个发件邮箱时，建议设置不同主题前缀，例如设备名、位置或用途。
