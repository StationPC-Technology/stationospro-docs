硬盘页用于查看设备识别到的内置硬盘与外接硬盘。你可以在这里确认硬盘容量、接口、温度和通电时间，也可以进入健康详情执行 S.M.A.R.T 检测，或对未使用硬盘执行格式化、安全弹出等维护操作。

## 硬盘列表

页面顶部提供三个筛选标签：

| 标签 | 说明 |
| --- | --- |
| 全部 | 同时显示内置硬盘与外接硬盘；「全部」视图中会按内置硬盘、外接硬盘分组。 |
| 内置 | 只显示设备内部安装的硬盘。 |
| 外接 | 只显示 USB 等外接存储设备。 |

![Disk](/images/common/app-guide/settings-img/disk.png)

## 硬盘卡片信息

每块硬盘卡片显示：

| 字段 | 说明 |
| --- | --- |
| 硬盘名称 | 系统分配的识别名，例如 DiskA、Disknvme0n1。 |
| 用途/所属存储空间 | 显示空闲、未挂载、所属存储卷、缓存池等用途。 |
| 总容量 | 硬盘可用总容量。 |
| 硬盘类型 | HDD、SSD 等。 |
| 健康状态 | 正常、异常、警告或未知。 |
| 型号 | 硬盘厂商型号。 |
| 接口 | SATA、NVMe、USB 等。 |
| 序列号 | 硬盘唯一序列号，可点击复制。 |
| 供应商 | 硬盘品牌或厂商。 |
| 温度 | 当前硬盘温度。温度持续过高会增加故障风险。 |
| 通电时间 | 硬盘累计通电时长，可用于评估使用年限。 |
| 分区 | 外接或未完全占用硬盘可能显示分区信息。 |

## 硬盘操作

在硬盘卡片右侧点击更多按钮，可用操作取决于硬盘当前用途：

| 操作 | 适用对象 | 说明 |
| --- | --- | --- |
| 格式化硬盘 | 空闲硬盘、外接硬盘或未使用分区 | 清除硬盘数据并重新创建文件系统。可选择格式化整个硬盘或指定分区。 |
| 安全拔出 | 外接硬盘 | 停止相关服务后安全移除硬盘，降低数据损坏风险。 |
| 健康详情 | 支持健康检测的硬盘 | 打开 S.M.A.R.T 检测与健康属性页。 |
| 停用硬盘 | 支持停用的内置成员盘 | 将硬盘从关联存储空间移除。停用可能影响存储冗余，需谨慎执行。 |
| 只读标识 | 只读硬盘 | 硬盘处于只读状态时，格式化等写入操作会被禁用。 |

### 格式化设置

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| 格式化对象 | 整个硬盘 / 分区 | 选择清除整盘或仅清除某个分区。 |
| 格式化后的文件系统 | exFAT / EXT4 | exFAT 适合 Windows 与 macOS 跨平台使用；EXT4 是 Linux 常用文件系统，适合长期连接 NAS 使用。 |

<Callout title="危险操作" type="error">
  格式化会删除目标硬盘或分区中的所有数据，操作开始后无法终止。请勿在格式化过程中断电、重启或拔插硬盘。
</Callout>

## 硬盘健康详情

点击 **健康详情** 后，可以查看硬盘健康状态信息并执行检测。

![Disk Health](/images/common/app-guide/settings-img/disk-health.png)

### 检测方式

| 检测方式 | 预计时间 | 说明 |
| --- | --- | --- |
| 快速检测 | 约 2 分钟 | 基本诊断测试，检测机械与电气误差，适合日常巡检。 |
| 完整检测 | 约 2 小时 30 分钟 | 全面扫描硬盘，结果更准确，耗时更长。两种检测均不影响硬盘正常使用。 |

### 检测状态与结果

- **开始检测**：提交检测任务。
- **检测中**：可查看当前进度，并可在需要时停止检测。
- **检查结果**：显示当前检测结论。
- **S.M.A.R.T 属性表**：展示编号、指标、结果、当前值、最差值、参考值与原始数据。临界值由硬盘厂商定义，异常项不一定立即代表硬盘损坏，但需要持续关注。

<Callout title="维护建议" type="warn">
  健康状态异常、温度持续偏高或多项 S.M.A.R.T 指标接近临界值时，请立即备份该硬盘及关联存储卷中的重要数据，并尽快更换硬盘。
</Callout>

## 健康与用途标识解读

| 标识 | 含义 | 建议 |
| --- | --- | --- |
| Normal | 硬盘健康检测正常。 | 保持定期检测和备份。 |
| Warning | 出现可疑属性或温度偏高。 | 立即备份数据并持续观察。 |
| Abnormal/Serious | 检测结果异常。 | 停止非必要写入，尽快更换硬盘。 |
| Unknown | 未获取到有效健康数据，或硬盘/桥接设备不支持完整 S.M.A.R.T。 | 更换连接方式或查看硬盘详情。 |
| Storage volume N | 硬盘属于该存储卷。 | 操作前确认卷状态和冗余能力。 |
| Cache pool | 硬盘用于 SSD 缓存。 | 先在存储空间删除缓存，再移除硬盘。 |
| Unused | 硬盘未被存储结构占用。 | 可用于创建卷、缓存或其他配置。 |
| Not mounted | 外接硬盘未挂载。 | 检查文件系统、连接状态和硬盘健康。 |
| Read-only | 硬盘或文件系统被保护性禁写。 | 先备份数据，不要强行格式化。 |
| Formatting | 硬盘正在格式化。 | 等待完成，不要断电或拔出。 |

## 格式化决策

| 目标 | 建议 |
| --- | --- |
| Windows 和 macOS 都要直接读写 | exFAT。 |
| 仅 NAS 长期使用、稳定优先 | EXT4。 |
| 硬盘曾出现异常 | 先执行健康检测并备份数据，再决定是否格式化。 |
| 只想清理分区 | 选择分区格式化，避免误删整盘。 |
| 硬盘包含系统或存储成员数据 | 不要格式化，先确认所属卷和用途。 |

## S.M.A.R.T 关注点

- **Reallocated Sectors Count**：重分配扇区持续增加说明介质不稳定。
- **Current Pending Sector**：等待重映射扇区增加可能预示坏扇区。
- **Offline Uncorrectable**：无法修正错误，应尽快备份数据。
- **Temperature**：长期高温会加速老化。
- **Power-On Time**：结合使用年限评估保修和更换计划。
- **Raw Data**：不同厂商编码方式不同，不能只比较数值大小。

<Callout title="检测建议" type="info">
  快速检测适合日常巡检；更换硬盘、卷降级、频繁掉线或出现 I/O 错误时建议执行完整检测。检测不影响普通使用，但高负载期间结果可能受干扰。
</Callout>
