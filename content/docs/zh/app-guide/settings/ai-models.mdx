AI 模型页分为 **基础能力**、**模型管理**、**存储位置** 三个标签。这里控制全局搜索与 Station AI 使用的本地识别能力、大语言模型文件，以及模型和索引数据的落盘位置。

## 基础能力

基础能力页管理全局搜索与内容识别所需的 AI 能力模块。

![AI Basic Capabilities](/images/common/app-guide/settings-img/ai-models.png)

### 能力模块

| 能力 | 功能 | 关闭影响 |
| --- | --- | --- |
| 人脸识别 | 识别人物并分组，支持人脸搜索和智能相册。 | 人脸搜索、人物分组等能力不可用。 |
| 文字识别 | 识别图片中的文字，可通过关键词定位图片内容。 | 图片 OCR 与图片文字搜索能力受限。 |
| 文件识别 | 索引文件名、路径、文档内容与语义，提升全局搜索效果。 | 文档内容与语义搜索能力受限。 |
| 视觉内容识别 | 识别图片/视频中的场景与物体，并用于内容匹配搜索。 | 以图搜图、场景/物体搜索能力受限。 |

### 状态与索引信息

文字识别、文件识别、视觉内容识别等模块会显示：

| 字段 | 说明 |
| --- | --- |
| 已识别文件 | 已完成索引的文件数量。 |
| 索引失败 | 无法建立索引的文件数量。可能是文件损坏、格式不支持、权限异常或存储暂不可用。 |
| 最近索引时间 | 最近一次完成索引的时间。 |
| 能力状态 | 正常、已停用、安装中、更新中、重建中、迁移中、异常、低空间暂停等。 |
| 维护操作 | 可按能力安装、更新、启用/停用、修复或重建索引。 |

<Callout title="提示" type="info">
  首次开启能力后需要建立索引，耗时取决于文件数量、文档类型和存储性能。索引期间可继续使用设备，但搜索结果可能不完整。
</Callout>

## 模型管理

模型管理页用于下载、启用、更新和卸载本地大模型，也可管理 OpenAI 兼容 API 访问。

![AI Model Management](/images/common/app-guide/settings-img/ai-model-management.png)

### 模型卡片

每个模型显示：

| 字段 | 说明 |
| --- | --- |
| 模型名称 | 例如 Qwen3.5-0.8B、Qwen3-8B、Gemma4-E4B 等。 |
| 类型 | Text Generation、Any-to-Any 等模型能力类型。 |
| 大小 | 模型文件预计占用空间。 |
| 状态 | 未下载、下载中、已下载、当前使用中等。 |
| 启用/停用 | 控制该模型是否出现在可用模型列表。 |
| 卸载/删除 | 删除本地模型文件；删除后需要时可重新下载。 |
| 配置模型 | 查看或修改模型相关配置。 |

### API 访问

点击 **API Access** 可以管理 OpenAI 兼容接口访问：

| 功能 | 说明 |
| --- | --- |
| API 地址 | 展示本地模型或服务的访问地址。 |
| API Key | 创建、查看、更新或删除访问密钥。 |
| 调用说明 | 可用于兼容 OpenAI API 的第三方应用或开发脚本。 |

<Callout title="注意" type="warn">
  删除本地模型会永久清除该模型全部本地文件。若当前正在使用该模型，系统可能切换到其他可用模型或 OpenAI 兼容 API。
</Callout>

## 存储位置

存储位置页管理本地模型和索引数据的落盘位置，并提供低空间保护。

![AI Storage](/images/common/app-guide/settings-img/ai-model-storage.png)

### 本地模型存储

| 字段/操作 | 说明 |
| --- | --- |
| 当前存储卷 | 显示卷名称、RAID 类型和可用容量。 |
| 更换存储 | 将本地大模型文件迁移到其他存储卷。迁移过程中本地模型暂时不可用。 |
| 状态 | 正常、空间偏低、只读、不可用、迁移中等。 |

### 索引数据存储

| 字段 | 说明 |
| --- | --- |
| 状态 | 索引池整体健康状态。 |
| 文件索引 | 文件名、路径等基础索引占用。 |
| 文本内容 | OCR 与文档文本/向量数据占用。 |
| 图片内容 | 图片视觉向量数据占用。 |
| 可用空间 | 当前索引存储剩余空间。 |
| 低空间阈值 | 触发保护的空间阈值，当前示例为低于 10 GB 时暂停任务。 |
| 更换存储 | 迁移索引数据到其他存储位置。 |

### 低空间保护

开启后，当可用空间低于设定阈值时，系统会自动暂停模型下载和索引重建任务，避免存储被写满导致服务异常。空间恢复后可手动继续任务。

<Callout title="建议" type="info">
  大模型和索引数据会随文件数量增长而增加。建议将模型和索引放在容量充足、状态健康的 SSD 存储卷上，并保持低空间保护开启。
</Callout>

## 能力状态与处理

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 正常 | 能力可用。 | 保持模型更新，定期重建索引。 |
| 已停用 | 管理员或用户关闭该能力。 | 需要时重新开启。 |
| 安装/更新中 | 正在下载或更新依赖与模型。 | 保持网络和存储可用。 |
| 重建中 | 正在重建索引数据。 | 等待完成，避免大量移动文件。 |
| 迁移中 | 模型或索引正在迁往新卷。 | 本地模型可能暂不可用。 |
| 低空间暂停 | 剩余空间低于阈值。 | 清理空间或迁移到更大卷。 |
| 只读 | 存储位置只读。 | 检查卷状态并更换存储位置。 |
| 异常/失败 | 依赖、存储或服务异常。 | 查看日志中心，尝试修复或重建。 |

## 索引维护建议

| 操作 | 适用情况 |
| --- | --- |
| 安装/更新全部 | 首次启用能力，或能力有新版本。 |
| 修复 | 索引状态异常、部分文件无法搜索。 |
| 重建索引 | 大量文件移动、索引存储迁移后结果不完整。 |
| 停用能力 | 不需要人脸、OCR、文档语义或视觉搜索。 |
| 迁移存储 | 当前卷空间不足或更换更快的 SSD。 |

<Callout title="索引范围" type="info">
  索引只作用于系统可读取且有权限访问的文件。加密文件、暂不支持的格式、损坏文件或权限不足的目录可能出现在索引失败统计中。
</Callout>

## 模型选择与维护

| 项目 | 建议 |
| --- | --- |
| 小参数模型 | 占用更小、响应更快，适合轻量问答和低配设备。 |
| 大参数模型 | 理解和生成能力更强，但占用内存/存储更多，响应可能更慢。 |
| Any-to-Any 模型 | 适合需要多种输入输出形态的场景，下载体积通常更大。 |
| 本地模型 | 数据不出设备，适合隐私场景；受硬件算力限制。 |
| OpenAI 兼容 API | 可接入外部服务，需配置 Base URL、模型名和 API Key。 |
| 删除模型 | 释放空间；后续可重新下载，但会消耗流量和时间。 |

## API Access 使用注意

- API Key 只保存必要凭据，不要提交到代码仓库或公开分享。
- 调用地址应只暴露给可信内网或经过反向代理/防火墙限制的客户端。
- 若 Key 泄露，立即删除或更新 Key。
- 外部调用仍受设备负载、模型状态和存储空间影响。

## 存储迁移注意事项

1. 迁移前确认目标卷容量大于模型与索引数据合计大小，并预留增长空间。
2. 迁移期间不要修改模型配置或重启设备。
3. 本地模型迁移完成前，聊天功能可能暂时不可用。
4. 索引迁移后建议执行一次搜索验证，必要时重建索引。
