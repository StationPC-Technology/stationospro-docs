应用中心是 StationOS Pro 的应用商店，提供官方应用与第三方应用的一站式安装、更新与管理。通过应用中心，你可以像使用手机应用商店一样，为 NAS 扩展下载、影音、同步、生产力与开发运维等各类能力。

## 界面介绍

打开应用中心后，顶部提供以下导航：

- **全部应用**：浏览商店内所有可安装应用；
- **已安装**：查看并管理当前设备已安装的应用；
- **分类筛选**：按同步、影视、视频录制、下载、生产力、开发工具等分类快速筛选应用；
- **搜索框**：按应用名称快速查找应用。

应用列表分为「官方应用」与第三方应用区域，每个应用卡片会展示名称、简介/分类标签及安装按钮。

![App Center](/images/common/app-guide/app-center-img/all-apps.png)

## 安装应用

1. 在应用中心通过分类或搜索框找到目标应用。
2. 点击应用卡片进入详情页。
3. 确认应用信息后，点击 **安装**，系统将自动下载并安装应用。
4. 安装完成后，应用会出现在应用启动器中；若开启了自动创建桌面快捷方式，还会在桌面生成快捷方式。

## 应用详情页

应用详情页展示以下信息，帮助你了解并评估应用：

| 字段 | 说明 |
| --- | --- |
| 开发者 | 应用的开发者或团队 |
| 发布者 | 应用的发布方 |
| 下载量 | 该应用的累计下载次数 |
| 大小 | 应用安装包体积 |
| 当前版本 | 商店中提供的最新版本号 |
| 应用介绍 | 功能亮点与使用说明 |

![App Detail](/images/common/app-guide/app-center-img/app-detail.png)

## 应用中心设置

点击应用中心右上角的 **设置** 按钮，可进行以下配置：

- **默认安装位置**：
  - **每次询问**：安装时手动选择存储位置；
  - **固定存储位置**：统一指定应用的安装存储空间。
- **自动创建桌面快捷方式**：开启后，新安装的应用会自动在桌面创建快捷方式。

![App Center Settings](/images/common/app-guide/app-center-img/settings.png)

<Callout title="注意" type="warn">
  - 安装应用前请确保所选存储空间有足够容量，否则安装可能失败。
  - 部分第三方应用由外部开发者提供，安装前请确认应用来源与权限需求。
  - 应用安装位置在部分情况下不可更改，如需迁移请先卸载后重新安装。
</Callout>
