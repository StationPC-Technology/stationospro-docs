## 前言

本说明向您说明 StationPC 配套 App、PC/Mac 客户端申请、使用操作系统权限的情况。我们遵循**最小必要、按需申请**原则，仅在使用对应功能时动态申请权限。

您可随时在系统设置中管理权限授权，关闭权限仅影响对应功能，不会影响产品基础核心服务。

第三方插件及服务可能申请额外权限，授权不代表持续采集个人信息。

## iOS 权限

| 场景 | 目的 | 拒绝或关闭权限的影响 |
| --- | --- | --- |
| 调用设备摄像头 | 扫码绑定 NAS 设备、快捷登录、拍照设置头像 | 无法扫码绑定设备、拍照设置头像 |
| 访问照片与视频相册 | 备份手机相册内容至 NAS、选取图片视频上传、设置账号头像；支持 iOS 受限照片访问（仅授权所选照片） | 无法备份相册、上传图片视频 |
| 访问本地网络 | 局域网发现并连接 StationPC 设备 | 无法发现与连接局域网内的 NAS 设备 |
| 接收系统通知 | 接收设备状态、备份进度、账号安全通知（含时效性通知） | 无法接收相关提醒通知 |
| 访问蓝牙设备 | 设备绑定与配网：发现附近设备、传输配网信息 | 无法通过蓝牙绑定与配置设备 |
| 获取位置信息（仅使用期间） | 配网时读取当前 WiFi 名称，并临时获取一次位置推导国家码用于设备 WiFi 地区设置；不做后台定位，坐标不上传、不存储 | 无法自动识别当前 WiFi 与地区，需手动选择 |

## Android 权限

| 场景 | 目的 | 拒绝或关闭权限的影响 |
| --- | --- | --- |
| 调用设备摄像头 | 扫码绑定设备、快捷登录 | 无法扫码绑定设备、快捷登录 |
| 访问本地存储 | 实现文件上传、下载、相册自动备份功能 | 无法上传、下载文件与自动备份相册 |
| 访问局域网与WiFi | 局域网设备发现与本地连接 | 无法发现局域网设备、无法建立本地连接 |
| 接收推送通知 | 任务进度、设备异常、账号安全提醒 | 无法接收任务进度、设备异常与安全提醒 |
| 访问蓝牙设备 | 设备配对与网络初始化辅助 | 无法通过蓝牙完成设备配对与配网 |
| 获取网络位置信息 | 辅助配网识别 | 无法自动识别当前 WiFi 与地区，需手动选择 |
| 后台自启动 | 维持后台备份任务（用户手动开启） | 后台备份任务可能被中断 |
| 读取剪贴板内容 | 识别分享链接，唤起文件传输功能 | 无法识别分享链接并唤起文件传输功能 |

## Windows 客户端权限

| 场景 | 目的 | 拒绝或关闭权限的影响 |
| --- | --- | --- |
| 接收桌面通知 | 展示任务进度、设备状态与异常提醒 | 无法接收任务进度、设备状态与异常提醒 |
| 访问本地文件系统 | 支持本地文件上传、下载、文件夹同步 | 无法上传、下载本地文件与同步文件夹 |

## Mac 客户端权限

| 场景 | 目的 | 拒绝或关闭权限的影响 |
| --- | --- | --- |
| 接收系统通知 | 反馈备份进度与设备运行状态 | 无法接收备份进度与设备状态通知 |
| 访问本地目录 | 完成文件管理、上传下载与同步任务 | 无法完成文件管理、上传下载与同步任务 |

## 补充说明

所有权限均为按需申请，不会在启动时批量授权。

关闭权限仅禁用部分功能，不影响登录、设备连接、文件浏览等基础服务。

未经用户明确授权，我们不会主动读取、上传 NAS 内任何私有用户数据。

不申请后台定位权限、不收集广告类设备标识符。位置信息仅在设备配网时临时使用（读取 WiFi 名称、推导国家码），坐标不上传、不存储，符合全球隐私合规要求。
