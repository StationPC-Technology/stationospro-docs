StationHub 只在您进入相应功能时申请所需权限。系统弹窗显示的权限名称可能因 iOS、Android、Windows 或 macOS 版本而不同；是否允许由您决定，拒绝权限不会影响与该权限无关的基础功能。

## 1. 权限处理原则

- 首次使用需要权限的功能时才发起申请，不在启动时一次性申请全部权限。
- 权限用于当前功能的明确目的。关闭权限后，相关功能可能不可用，但不会因此自动读取其他数据。
- 第三方插件或系统服务可能出现额外授权提示，是否授予仍由您控制。
- 位置权限只用于配网阶段读取 WiFi 名称并推导国家码；我们不进行后台定位，也不上报或保存坐标。

## 2. iPhone 和 iPad

| 系统权限 | 触发功能 | 我们会做什么 | 关闭后的影响 |
| --- | --- | --- | --- |
| 相机 | 扫码绑定、快捷登录、设置头像 | 在设备端读取相机画面以识别二维码或拍摄头像 | 无法扫码或拍摄头像 |
| 照片与视频 | 相册备份、选择媒体上传、设置头像 | 读取您选中的媒体；支持 iOS 受限照片范围 | 无法备份或上传对应媒体 |
| 本地网络 | 搜索并连接同一局域网的 NAS | 发现局域网设备并建立本地连接 | 无法发现或连接局域网 NAS |
| 通知 | 设备状态、备份进度和账号安全提醒 | 发送您允许的系统通知 | 无法收到相关提醒 |
| 蓝牙 | 设备绑定和配网 | 发现附近设备并传递配网信息 | 无法通过蓝牙绑定或配网 |
| 使用期间的位置 | 配网时确定 WiFi 地区 | 临时读取 WiFi 名称并推导国家码 | 需要手动选择 WiFi 与地区 |

## 3. Android 手机和平板

| 系统权限 | 触发功能 | 使用范围 | 关闭后的影响 |
| --- | --- | --- | --- |
| 相机 | 扫码绑定和快捷登录 | 设备端识别二维码 | 无法扫码绑定或登录 |
| 照片、视频或本地存储 | 文件上传下载、相册自动备份 | 访问您选择的文件和媒体 | 无法完成相应文件操作 |
| 附近设备、局域网和 WiFi | 发现设备、建立本地连接和配网 | 读取连接所需的网络状态 | 无法发现设备或建立本地连接 |
| 通知 | 任务进度、设备异常和账号安全提醒 | 发送推送或本地通知 | 无法收到相关提醒 |
| 蓝牙 | 设备配对和网络初始化 | 发现并连接配网设备 | 无法通过蓝牙完成配网 |
| 网络位置信息 | 辅助配网识别 | 仅在配网时辅助判断 WiFi 地区 | 需要手动选择地区 |
| 后台自启动 | 用户主动开启的持续备份 | 维持备份任务运行 | 备份可能被系统中断 |
| 剪贴板 | 识别分享链接并打开文件传输 | 仅在触发分享链接功能时读取 | 无法自动识别分享链接 |

## 4. Windows 和 macOS 客户端

| 平台 | 权限或系统能力 | 用于 | 关闭后的影响 |
| --- | --- | --- | --- |
| Windows | 桌面通知 | 显示任务进度、设备状态和异常 | 无法显示桌面提醒 |
| Windows | 本地文件系统 | 上传、下载和文件夹同步 | 无法完成本地文件操作 |
| macOS | 系统通知 | 提示备份进度和设备运行状态 | 无法收到系统通知 |
| macOS | 本地目录 | 文件管理、上传、下载和同步 | 无法完成对应文件任务 |

## 5. 其他说明

权限授权不等于持续收集个人信息。未经您的明确授权，我们不会主动读取、上传 NAS 中的私有文件，也不会申请后台定位权限或收集广告类设备标识符。您可以在设备系统设置中随时撤销权限；撤销后，相关功能会在下一次使用时提示原因和替代操作。

如某项功能由第三方应用或服务提供，请同时查看[《第三方个人信息共享清单》](./third-party-sdk-list)和该服务商自己的隐私政策。有关整体信息处理方式，请参阅[《隐私政策》](./privacy-policy)。
