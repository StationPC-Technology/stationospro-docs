title: "如何通過網頁端訪問設備?"
---

Web 客戶端（Beta）允許您直接通過瀏覽器訪問和管理設備，無需安裝桌面端或移動端應用。它支持兩種訪問方式：**局域網訪問**和**遠程訪問**，以滿足不同場景下的使用需求。

## 前提條件
1. 確保設備已開機並正常連接網絡。
2. 如需遠程訪問，請先在客戶端應用中[啟用遠程訪問功能](/portable/pocketcloud/remote-access)，並完成 Station ID 設置。

## 訪問方式
### 方式一：局域網訪問
適用於電腦與設備在同一局域網（同一 WiFi / 有線網絡）的場景，訪問速度更快、穩定性更高。

操作步驟：
1. 獲取設備的局域網 IP 地址：可通過設備自帶屏幕查看，或在客戶端應用的**設備信息**頁面中查看。
2. 打開瀏覽器，在地址欄輸入 `http://設備IP:9500` 格式的地址。
3. 在登錄頁面輸入用戶名和密碼，即可進入 Web 管理界面。

> 示例：如果設備 IP 為 `192.168.3.10`，則在地址欄輸入 `http://192.168.3.10:9500`。

### 方式二：遠程訪問
適用於出差、外出辦公等外網場景。您可以通過官方遠程訪問門戶訪問家中或辦公室的設備。

操作步驟：
1. 啟用遠程訪問功能。
2. 打開瀏覽器，輸入官方遠程訪問地址：`https://login.stationpc.com/`
3. 在登錄頁面輸入您的 Station ID、用戶名和密碼，驗證通過後即可訪問設備。

## 支持的瀏覽器
為確保功能完整和最佳使用體驗，建議使用以下瀏覽器（或更高版本）訪問 Web 客戶端：
1. Chrome 50 及以上版本
2. Microsoft Edge 78 及以上版本
3. QQ 瀏覽器極速版、360 瀏覽器極速版
4. Firefox 54 及以上版本
5. Safari 10 及以上版本（Mac）

## 注意事項
1. Web 客戶端目前處於 Beta 測試階段，部分功能可能暫不可用。建議配合客戶端應用使用以獲得完整功能。
2. 局域網訪問時，請確保電腦與設備連接在同一網絡，否則無法通過 IP 地址訪問。
3. 遠程訪問時，請確保設備已連接互聯網，否則無法通過遠程門戶連接。
4. 如果頁面加載異常，請嘗試切換至推薦瀏覽器，或清除瀏覽器緩存後重試。
