title: "如何透過網頁端存取裝置？"
---

Web 用戶端（Beta）允許你直接透過瀏覽器存取和管理裝置，無需安裝電腦端或行動端應用程式。它支援兩種存取方式：**區域網路存取**和**遠端存取**，以滿足不同情境下的使用需求。

## 前提條件
1. 確認裝置已開機並正常連線網路。
2. 如需遠端存取，請先在用戶端應用程式中[啟用遠端存取功能](/portable/guides/remote-access)，並完成 Station ID 設定。

## 存取方式
### 方式一：區域網路存取
適用於電腦與裝置位於同一區域網路（同一 WiFi／有線網路）的情境，存取速度更快、穩定性更高。

操作步驟：
1. 取得裝置的區域網路 IP 位址：可透過裝置內建螢幕查看，或在用戶端應用程式的**裝置資訊**頁面中查看。
2. 開啟瀏覽器，在網址列輸入 `http://设备IP:9500` 格式的位址。
3. 在登入頁面輸入使用者名稱和密碼，即可進入 Web 管理介面。

> 範例：如果裝置 IP 為 `192.168.3.10`，則在網址列輸入 `http://192.168.3.10:9500`。

### 方式二：遠端存取
適用於出差、外出辦公等外部網路情境。你可以透過官方遠端存取入口網站存取家中或辦公室的裝置。

操作步驟：
1. 啟用遠端存取功能。
2. 開啟瀏覽器，輸入官方遠端存取位址：`https://login.stationpc.com/`
3. 在登入頁面輸入你的 Station ID、使用者名稱和密碼，驗證通過後即可存取裝置。

## 支援的瀏覽器
為確保功能完整和最佳使用體驗，建議使用以下瀏覽器（或更新版本）存取 Web 用戶端：
1. Chrome 50 及以上版本
2. Microsoft Edge 78 及以上版本
3. QQ 瀏覽器極速版、360 瀏覽器極速版
4. Firefox 54 及以上版本
5. Safari 10 及以上版本（Mac）

## 注意事項
1. Web 用戶端目前處於 Beta 測試階段，部分功能可能暫未開放。建議搭配用戶端應用程式使用，以獲得完整功能。
2. 區域網路存取時，請確認電腦與裝置連線至同一網路，否則無法透過 IP 位址存取。
3. 遠端存取時，請確認裝置已連線至網際網路，否則無法透過遠端入口網站連線。
4. 如果頁面載入異常，請嘗試改用建議的瀏覽器，或清除瀏覽器快取後再試。
