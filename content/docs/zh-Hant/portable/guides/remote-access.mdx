title: "如何進行遠程訪問？"
---

PocketCloud 內置遠程訪問服務，可為你提供安全的遠程訪問功能。使用該服務前，需先綁定手機號 / 郵箱並創建唯一的 Station ID（用於標識你的設備），通過 Station ID 即可快速訪問你的 PocketCloud。

> 注意:
> * 使用遠程訪問服務需綁定手機號 / 郵箱；
> * 服務會為你的 PocketCloud 自動創建唯一 Station ID，通過該 ID 可安全訪問設備；
> * 基於當前網絡環境，系統會自動選擇最優訪問方式連接；
> * Station ID 支持自定義修改。

## 開啟遠程服務
方式1:
在設備首次初始化配置過程中，按照指引勾選 “開啟遠程訪問” 選項即可。

方式2:
1. 打開客戶端，進入**設備**頁面；
2. 找到**設備連接**，在其中可手動開啟或關閉遠程服務

## 解綁遠程服務

恢復出廠設置時,系統會自動解綁遠程服務
> 設備已綁定遠程服務時，恢復出廠設置需連接網絡；
