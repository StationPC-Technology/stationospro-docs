title: "如何進行遠端存取？"
---

PocketCloud 內建遠端存取服務，可為你提供安全的遠端存取功能。使用此服務前，需先綁定手機號碼／電子郵件並建立唯一的 Station ID（用於識別你的裝置），透過 Station ID 即可快速存取你的 PocketCloud。

> 注意：
> * 使用遠端存取服務需綁定手機號碼／電子郵件；
> * 服務會為你的 PocketCloud 自動建立唯一 Station ID，透過該 ID 可安全存取裝置；
> * 系統會依目前網路環境，自動選擇最佳的存取方式連線；
> * Station ID 支援自訂修改。

## 開啟遠端服務
方式 1：
在裝置首次初始化設定的過程中，依指引勾選「開啟遠端存取」選項即可。

方式 2：
1. 開啟用戶端，進入**裝置**頁面；
2. 找到**裝置連線**，即可手動開啟或關閉遠端服務

## 解除綁定遠端服務

恢復原廠設定時，系統會自動解除遠端服務綁定
> 裝置已綁定遠端服務時，恢復原廠設定需連線網路；
