PocketCloud 內置 SD 卡槽，支持 SD 卡數據備份功能，具體說明與操作步驟如下：

- SD 卡數據默認備份至路徑 **“My Backup/Backup From xxx”**（“xxx” 為 SD 卡識別名稱）。
- 備份操作支持兩種方式：通過設備小屏幕快速備份，或通過客戶端進行完整參數設置後備份。

> 注意：  
> 若已通過客戶端修改過 SD 卡備份的默認配置（如調整備份來源、備份目的地等），後續通過小屏幕執行備份或客戶端快速備份時，將自動沿用修改後的新配置，無需重複設置。

## 通過客戶端備份
客戶端提供“快速備份”與“高級備份”兩種模式，可根據需求選擇：

### 方式1：快速備份（一鍵啟動，無需配置）
1. 打開客戶端，進入 **首頁 > 我的設備** 頁面；
2. 在設備列表中找到已插入的 SD 卡，點擊對應“備份”按鈕，即可啟動快速備份。

### 方式2：高級備份（自定義參數，靈活配置）
1. 打開客戶端，進入 **首頁 > 我的設備** 頁面；
2. 點擊已識別的 SD 卡，進入“SD 卡備份設置”界面；
3. 根據需求調整以下備份參數，設置完成後啟動備份：
   - **備份來源**：支持“全盤備份”（默認）或“指定目錄備份”，可按需選擇需備份的文件路徑；
   - **備份目的地**：支持自定義備份文件的存儲目錄；
   - **備份方式**：提供“手動備份”（默認）、“定時備份”、“插入時自動備份”；
   - **文件過濾**：支持按文件大小篩選備份文件。

## 通過小屏幕備份（快速操作，適配無客戶端場景）
1. 插入 SD 卡到 Pocketcloud SD 卡槽。
2. 小屏幕會彈出檢測到 SD 卡插入界面。  
![](/images/common/portable/backup/sd-backup/sd-card-has-been-inserted.png)
3. 旋鈕選中**Backup**後，單擊旋鈕開始備份。
4. 備份完成之後，設備會“嗶”兩聲，小屏幕顯示備份成功。  
![](/images/common/portable/backup/sd-backup/sd-card-backup-finish.png)
