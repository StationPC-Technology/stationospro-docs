---

PocketCloud 底座可以安裝一顆 M.2 NVMe 2280 SSD。

## 操作方式

1. 將底座電源拔除。

2. 使用隨附螺絲起子逆時針旋轉螺絲，取下底板。

![](/images/zh-Hant/portable/hardware/ssd-install/dock/dock-ssd-install_1.png)

3. 將 SSD 插入 M.2 NVMe 插槽並旋緊螺絲固定。

![](/images/zh-Hant/portable/hardware/ssd-install/dock/dock-ssd-install_2.png)

4. 重新安裝底板。

![](/images/zh-Hant/portable/hardware/ssd-install/dock/dock-ssd-install_3.png)
