---

PocketCloud 主機可以安裝一顆 M.2 NVMe 2280 SSD。

## 操作方式

1. 關機直到指示燈熄滅。

![](/images/zh-Hant/portable/hardware/ssd-install/pkc/pkc-ssd-install_1.png)

2. 使用隨附螺絲起子逆時針旋轉螺絲，取下外罩。

![](/images/zh-Hant/portable/hardware/ssd-install/pkc/pkc-ssd-install_2.png)

3. 將 SSD 插入 M.2 NVMe 插槽並旋緊螺絲固定。

![](/images/zh-Hant/portable/hardware/ssd-install/pkc/pkc-ssd-install_3.png)

4. 重新安裝外罩。

![](/images/zh-Hant/portable/hardware/ssd-install/pkc/pkc-ssd-install_4.png)
