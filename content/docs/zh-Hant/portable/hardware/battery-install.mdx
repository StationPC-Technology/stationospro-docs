當電池老化時，可進行更換。操作步驟如下：

## 操作方式

1. 準備兩顆全新未使用的 18650（3.6/3.7V）電池，需為同一型號，且來自知名／常見品牌。建議容量在 3000mAh 以上。請勿使用損壞或膨脹的電池，禁止新舊電池混用。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_1.jpg)

2. 確認裝置已關機且指示燈熄滅。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_2.jpg)

3. 使用螺絲起子鬆開螺絲並取下外殼。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_3.jpg)

4. 依箭頭方向推開電池蓋。如下圖所示，雙手握住 PocketCloud，再用拇指向前推。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_4.jpg)

5. 依正確極性裝入新電池，闔上電池蓋。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_5.jpg)

6. 裝回外殼並鎖緊螺絲。

![](/images/zh-Hant/portable/hardware/battery-install/battery-install_6.jpg)
