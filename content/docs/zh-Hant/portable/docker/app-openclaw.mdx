## 應用簡介

OpenClaw 是一款執行於本機裝置的個人 AI 助理，支援多種常用通訊工具，實現智慧互動體驗。

## 前置準備

在開始之前，請確保你已準備：

- ✅ 可用的 API Key（例如 [OpenAI](https://platform.openai.com/api-keys) / [Z.AI](https://bigmodel.cn/apikey/platform) 等）

## 快速安裝流程

1. 在應用中心下載 OpenClaw

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-1.png" width="100%" />

2. 開啟 OpenClaw 容器的控制台

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-2.png" width="100%" />

3. 開啟終端機，輸入命令 **su node**，然後按下 Enter

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-3.png" width="100%" />

4. 輸入命令 **openclaw onboard**，然後按下 Enter

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-4.png" width="100%" />

5. 等待一段時間後，顯示 OpenClaw 設定安全須知，選擇**Yes**，按下 Enter 以確定選擇

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-5.png" width="100%" />

6. 選擇 **QuickStart**，可透過上下方向鍵調整選項

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-6.png" width="100%" />

7. 選擇 **Use existing values**

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-7.png" width="100%" />

8. 選擇模型，依準備的**API key** 廠商選擇

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-8.png" width="100%" />

9. 這裡以 Z.AI 為例

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-9.png" width="100%" />

10. 選擇 **Paste API key now**

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-10.png" width="100%" />

11. 輸入**API key**

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-11.png" width="100%" />

12. 選取預設的模型，一般選擇 ```Keep current```

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-12.png" width="100%" />

13. 選擇互動的軟體，這裡暫時選擇 **Skip for now**

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-13.png" width="100%" />

14. 到此就結束了，此時應用程式會重新啟動，前往**應用中心**，點選**開啟**

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-15.png" width="100%" />

15. 開啟後，即可與 **OpenClaw** 聊天了

<img src="/images/zh-Hant/portable/docker/app-openclaw/1-16.png" width="100%" />

## 常見問題

* Q：為什麼重新整理後提示無法連線？
* A：OpenClaw 前端與後端採用安全驗證機制，解決方法：
> 開啟左側邊欄：控制 → 總覽，輸入閘道權杖，點選「連接」，即可恢復正常使用

* Q：可以操作哪些檔案？
* A：預設掛載目錄為：/pocketcloud，你可以直接讓 OpenClaw 執行，例如：
> 幫我列出 /pocketcloud 下所有圖片檔案

* Q：不想每次輸入 /pocketcloud？
* A：可以設定「別名」，即可用更自然的表達方式，例如：
> 把 /pocketcloud 叫做 我的檔案
