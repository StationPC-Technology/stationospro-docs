為簡化使用者對 Docker 容器的部署與使用流程，使用者無須自行研究複雜的 Docker 映像篩選、設定與相容性測試，透過應用中心即可快速取得適配的容器應用，輕鬆完成部署與使用，大幅降低 Docker 應用的使用門檻。

> 注意：容器應用僅支援在區域網路環境中開啟，請確保您的 PocketCloud 與用戶端裝置位於同一區域網路

## 安裝容器應用
### 安裝前準備
首次安裝容器應用，需要初始化 Docker 的相關設定並分配儲存空間。
1. 開啟應用程式，進入**首頁 > 常用功能 > Docker**；
2. 依提示進行操作，分配儲存空間。

> 注意：
> * 可用儲存空間需大於 20GB，低於此容量將無法完成安裝；
> * 儲存空間分配後僅支援擴充、不支援縮減，建議依實際使用需求合理分配並預留備用空間；
> * 空間分配過程耗時較長，請耐心等候；若需臨時處理其他事務，可離開分配介面，分配作業會在背景繼續執行。

### 安裝應用
1. 進入**應用中心**；
2. 找到需要安裝的應用容器；
3. 點選「安裝」，等待系統自動完成安裝與部署。安裝完成後，容器應用會在 Docker 中建立對應的容器。

## 存取容器應用
### 開啟方式
* 透過用戶端存取：容器應用可透過**應用中心**存取；
* 透過 Web 端存取：在同一區域網路內，可透過裝置 IP 與應用程式連接埠號存取。

> 注意：
> * 應用程式連接埠可在應用程式詳情處檢視；
> * 圖示 IP 位址為範例，需替換為您的裝置 IP。

### 注意事項
#### 應用程式可存取目錄
* 實際目錄：位於主磁碟 @docker 目錄下。以 Jellyfin 為例，實際目錄為 @docker/jellyfin/data/；
* 對應目錄：
  * 應用程式目錄對應為 /data；
  * 主磁碟目錄對應為 /pocketcloud。注意應用程式掛載主磁碟目錄時請勿掛載主磁碟根目錄。
  > 注意：應用程式掛載主磁碟目錄時，請勿直接掛載主磁碟根目錄，避免影響裝置正常運作。
  
#### Jellyfin 注意事項
1. 新增媒體庫
   * 進入控制台 → 媒體庫 → 新增媒體庫；
   * 點選「新增資料夾」，選擇路徑：
     * 應用程式對應目錄：/ → 選擇 data；
     * 主磁碟對應目錄：/ → 選擇 pocketcloud → 選擇目標資料夾。

2. 解除安裝後再次安裝，提示選擇伺服器進行連線的問題
   解除安裝 Jellyfin 後，再次安裝可能會不顯示註冊介面，進入後提示選擇伺服器進行連線。
   解決方法：
   * 長按伺服器圖示，彈出操作選單；
   * 點選「刪除」，離開 Jellyfin；
   * 重新開啟 Jellyfin，即可看到註冊介面，進而建立新帳號。

3. 解除安裝後再次安裝，無法註冊使用者的問題
   解除安裝 Jellyfin 後，再次安裝可能會不顯示註冊介面，直接進入登入介面（但帳號密碼尚未設定）。
   解決方法：
   * 使用無痕瀏覽器存取裝置 IP＋連接埠號（如 192.168.10.140:35000）；
   * 此時應能看到註冊介面，建立新帳號即可。

#### Syncthing 注意事項
* 新增資料夾時，路徑僅能輸入 data，否則無法辨識；
* 在 @/docker/syncthing/data 下檢視同步的資料。

#### Transmission 注意事項
* 支援新增種子檔或種子連結；
* 下載的檔案儲存在 @docker/transmission 對應資料夾下。
