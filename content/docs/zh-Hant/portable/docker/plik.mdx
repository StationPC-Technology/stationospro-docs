## 簡介
Plik 是一款開源、輕量、安全的臨時文件分享服務，**支持純網頁使用**，打開瀏覽器就能完成文件上傳、分享、傳輸，配合 Docker 可快速自建私有臨時文件中轉站，無需複雜配置，簡潔易用且能保障隱私安全。

## 使用場景
- 跨設備臨時傳輸文件，手機、電腦直接互通，無需安裝客戶端
- 同事、朋友之間快速分享文件，即用即走，高效便捷
- 私密文件不想上傳公共雲盤，自建服務更安全可控
- 臨時分享日誌、安裝包、配置文件等工作資料

## 功能特點
- 純網頁訪問，全平臺通用，無需安裝任何 APP，操作門檻低
- 支持 CLI 客戶端操作，可通過命令行完成文件上傳、管理
- 支持文件加密，可設置分享密碼，保障文件安全
- 可自定義文件過期時間、下載次數，支持“閱後即焚”（OneShot）
- 一鍵生成分享鏈接，可隨時禁用分享，靈活可控
- 資源佔用低，Docker 一鍵部署，維護成本低

## 部署教程
### 創建Plik容器
1.  進入 Docker 界面，點擊「Images」（鏡像），在搜索框輸入「plik」，找到對應鏡像後點擊下載。
    <img src="/images/common/portable/docker/plik/1-2.png" width="100%" />

2.  鏡像下載完成後，進入「Containers」（容器）頁面，點擊「創建容器」，選擇「rootgg/plik」鏡像，點擊「下一步」。
    > 溫馨提示：若需要容器隨設備開機自動啟動，勾選頁面中的「開機啟動」選項即可。
    <img src="/images/common/portable/docker/plik/1-3.png" width="100%" />

3.  路徑映射設置，點擊添加路徑映射
    * 存放上傳文件:創建本地存儲路徑「My Files/upload」,將容器內路徑「/root/files」映射到本地路徑「My Files/upload」
    

4.  所有設置確認無誤後，點擊 「確認」，選擇 「創建後啟動」，即可完成Plik容器的創建與啟動。
    <img src="/images/common/portable/docker/plik/1-4.png" width="100%" />

## Plik 的基本使用
### 1.  訪問 Plik：

<img src="/images/common/portable/docker/plik/1-6.png" width="100%" />

訪問地址：http://IP:8080/，將IP替換為自己的服務器（或PocketCloud設備）IP地址；
> 注意：若為PocketCloud設備，直接使用設備自身IP即可；
> 若部署時修改了端口，需對應調整訪問地址的端口號。

### 2.  設置 Plik：
可根據需求進行相關配置。
<img src="/images/common/portable/docker/plik/1-7.png" width="100%" />

| 設置項 | 說明 |
| ---- | ---- |
| 下載後銷燬 | 文件被下載一次後將永久刪除 |
| 流式傳輸 | 文件直接流式傳輸給下載者，不存儲在服務器 |
| 可刪除 | 擁有鏈接者可刪除已上傳的文件 |
| 端到端加密 | 上傳前文件已加密，僅持有密碼者可解密 |
| 密碼保護 | 通過 HTTP 基礎認證設置訪問密碼，保障安全 |
| 備註說明 | 支持在上傳的內容中添加評論 |
| 過期時間 | 設置文件有效時長，到期自動失效 |

#### 3.  上傳文件
直接拖拽文件至網頁上傳區域，或點擊“選擇文件”上傳。
#### 4.  分享文件
上傳完成後，複製頁面生成的分享鏈接，點擊鏈接即可下載。
