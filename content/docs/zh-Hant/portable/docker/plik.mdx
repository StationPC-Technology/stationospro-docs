## 簡介
Plik 是一款開源、輕量、安全的臨時檔案分享服務，**支援純網頁使用**，開啟瀏覽器就能完成檔案上傳、分享、傳輸，搭配 Docker 可快速自建私有臨時檔案中繼站，無須複雜設定，簡潔易用且能保障隱私安全。

## 使用情境
- 跨裝置臨時傳輸檔案，手機、電腦直接互通，無須安裝用戶端
- 同事、朋友之間快速分享檔案，即用即走，高效便捷
- 私密檔案不想上傳公共雲端硬碟，自建服務更安全可控
- 臨時分享日誌、安裝檔、設定檔等工作資料

## 功能特點
- 純網頁存取，全平台通用，無須安裝任何 APP，操作門檻低
- 支援 CLI 用戶端操作，可透過命令列完成檔案上傳、管理
- 支援檔案加密，可設定分享密碼，保障檔案安全
- 可自訂檔案到期時間、下載次數，支援「讀後即焚」（OneShot）
- 一鍵產生分享連結，可隨時停用分享，靈活可控
- 資源占用低，Docker 一鍵部署，維護成本低

## 部署教學
### 建立 Plik 容器
1.  進入 Docker 介面，點選「Images」（映像），在搜尋框輸入「plik」，找到對應映像後點選下載。
    <img src="/images/zh-Hant/portable/docker/plik/1-2.png" width="100%" />

2.  映像下載完成後，進入「Containers」（容器）頁面，點選「建立容器」，選擇「rootgg/plik」映像，點選「下一步」。
    > 溫馨提醒：若需要容器隨裝置開機自動啟動，勾選頁面中的「開機啟動」選項即可。
    <img src="/images/zh-Hant/portable/docker/plik/1-3.png" width="100%" />

3.  路徑對應設定，點選新增路徑對應
    * 存放上傳檔案：建立本機儲存路徑「My Files/upload」，將容器內路徑「/root/files」對應到本機路徑「My Files/upload」
    

4.  所有設定確認無誤後，點選 「確認」，選擇 「建立後啟動」，即可完成 Plik 容器的建立與啟動。
    <img src="/images/zh-Hant/portable/docker/plik/1-4.png" width="100%" />

## Plik 的基本使用
### 1.  存取 Plik：

<img src="/images/zh-Hant/portable/docker/plik/1-6.png" width="100%" />

存取位址：http://IP:8080/，將 IP 替換為自己的伺服器（或 PocketCloud 裝置）IP 位址；
> 注意：若為 PocketCloud 裝置，直接使用裝置自身 IP 即可；
> 若部署時修改了連接埠，需對應調整存取位址的連接埠號。

### 2.  設定 Plik：
可依需求進行相關設定。
<img src="/images/zh-Hant/portable/docker/plik/1-7.png" width="100%" />

| 設定項目 | 說明 |
| ---- | ---- |
| 下載後銷毀 | 檔案被下載一次後將永久刪除 |
| 串流傳輸 | 檔案直接串流傳輸給下載者，不儲存在伺服器 |
| 可刪除 | 擁有連結者可刪除已上傳的檔案 |
| 端對端加密 | 上傳前檔案已加密，僅持有密碼者可解密 |
| 密碼保護 | 透過 HTTP 基本驗證設定存取密碼，保障安全 |
| 備註說明 | 支援在上傳的內容中新增留言 |
| 到期時間 | 設定檔案有效時長，到期自動失效 |

#### 3.  上傳檔案
直接將檔案拖曳至網頁上傳區域，或點選「選擇檔案」上傳。
#### 4.  分享檔案
上傳完成後，複製頁面產生的分享連結，點選連結即可下載。
