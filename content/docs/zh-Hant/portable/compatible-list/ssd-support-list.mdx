PocketCloud SSD 相容性說明：
* 規格：僅支援 M.2 NVMe 2280；
* 通訊協定與速度：相容 PCIe 3.0/4.0 通訊協定，實際執行速度為 PCIe 3.0 x2；
* 供電規格：3.3V，最大支援 3A 供電；
* 容量支援：最大容量為 8TB，理論上支援更大容量；實測部分品牌大於 8TB 的型號也可正常使用，詳見相容性清單；
* 安裝與散熱：附散熱片的 SSD 需先移除散熱片再安裝（主機／底座皆適用）；主機內建主動散熱風扇，底座自帶散熱片，無需額外加裝散熱配件，即可長期穩定運作。
