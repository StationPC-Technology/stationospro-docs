## 內建儲存支援的檔案系統格式

內建儲存主要支援 exFAT、NTFS 與 FAT32，官方建議使用 exFAT。

exFAT、NTFS 與 FAT32 檔案系統比較：

| 特性          | exFAT（建議）                          | NTFS                  | FAT32                   |
| :------------ | :------------------------------------- | :------------------------------------ | :------------------------------------ |
| **最大檔案**  | **支援超大檔案** | **支援超大檔案** | **單一檔案不能超過 4GB** |
| **最大分割區**  | **支援超大分割區** | **支援超大分割區**     | **最大僅支援 2TB**      |
| **系統相容性** | **Windows、Mac、Linux 皆支援**     | **Mac 僅能讀取** | **Windows、Mac、Linux 皆支援**                       |
| **安全性**    | **一般**               | **高**        | **低**                |
| **穩定性**    | **較好**             | **最好**              | **較差**               |
| **速度**      | **快**         | **快**            | **慢**         |
