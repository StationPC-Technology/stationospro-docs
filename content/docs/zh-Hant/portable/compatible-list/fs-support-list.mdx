## 內置存儲支持的文件系統格式

內置存儲主要支持 exFAT、NTFS 與 FAT32，官方推薦使用 exFAT。

exFAT、NTFS 與 FAT32 文件系統對比：

| 特點          | exFAT（推薦）                          | NTFS                  | FAT32                   |
| :------------ | :------------------------------------- | :------------------------------------ | :------------------------------------ |
| **最大文件**  | **支持超大文件** | **支持超大文件** | **單個文件不能超過4GB** |
| **最大分區**  | **支持超大分區** | **支持超大分區**     | **最大隻能2TB**      |
| **系統兼容性** | **Windows、Mac、Linux 均支持**     | **Mac 只能讀** | **Windows、Mac、Linux 均支持**                       |
| **安全性**    | **一般**               | **高**        | **低**                |
| **穩定性**    | **較好**             | **最好**              | **較差**               |
| **速度**      | **快**         | **快**            | **慢**         |
