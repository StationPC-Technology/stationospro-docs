## 影片格式

| 格式 | iOS 端  | Android 端 |
| ------ | ------ | --------- |
| MP4  | 支援 | 支援    |
| MOV  | 支援 | 支援    |
| WMV  | 支援 | 支援    |
| WTV  | 支援 | 支援    |
| WEBM | 支援 | 支援    |
| VOB  | 支援 | 支援    |
| TS   | 支援 | 支援    |
| SWF  | 支援 | 支援    |
| RM   | 支援 | 支援    |
| RMVB | 支援 | 支援    |
| OGV  | 支援 | 支援    |
| MXF  | 支援 | 支援    |
| MTS  | 支援 | 支援    |
| MPG  | 支援 | 支援    |
| MPEG | 支援 | 支援    |
| MKV  | 支援 | 支援    |
| M2V  | 支援 | 支援    |
| HEVC | 支援 | 支援    |
| F4V  | 支援 | 支援    |
| AVI  | 支援 | 支援    |
| 3GP  | 支援 | 支援    |

## 解析度

| 解析度 | iOS、Android 端 |
| -------- | ---------- |
| 4K     | 網路狀況較佳時（例如區域網路或直連裝置），可正常播放；使用行動網路連線時，容易出現卡頓 |
| 8K     | 不支援 |
