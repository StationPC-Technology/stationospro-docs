PocketCloud 提供遠程訪問服務，為用戶打造穩定、安全、便捷的遠程訪問體驗。無需用戶掌握公網IP、端口轉發或DDNS配置等專業技術知識，大幅降低使用門檻，讓非技術用戶也能輕鬆實現遠程操作。
> 用戶可以通過綁定手機號/郵箱的方式獲取Station ID，通過Station ID進行遠程訪問。

## 一、連接原理說明
遠程訪問採用 P2P（Peer-to-Peer，點對點）連接模式，核心原理為：
通過官方中轉服務器與用戶自身網絡的協同“打洞”，打破網絡邊界限制，最終在 PocketCloud 與客戶端（手機/PC）之間建立直接通信連接，無需經過第三方服務器轉發數據。

## 二、P2P 連接模式的優點
| 特點 | 說明 |
|------|------|
| 零配置 | 上手門檻極低，無需用戶手動進行網絡參數設置，打開功能即可嘗試連接 |
| 高效傳輸 | 當滿足直連條件時，數據直接在 PocketCloud 與客戶端間傳輸，帶寬不受中轉服務器限制，訪問速度更快 |
| 多端兼容 | 同時支持移動客戶端（手機/平板）與 PC 客戶端，適配不同使用場景（如外出辦公、居家遠程管理） |

## 三、注意事項
1. 當設備和客戶端處於同一局域網下，會自動切換為局域網連接。
2. 若 P2P 直連無法建立，將自動切換為 StationPC 中轉服務器轉發模式，保障遠程訪問功能可用；
3. 中轉模式下，訪問速度、帶寬會受限於中轉服務器。
