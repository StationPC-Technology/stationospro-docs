PocketCloud 提供遠端存取服務，為使用者打造穩定、安全、便利的遠端存取體驗。無需使用者具備公用 IP、連接埠轉送或 DDNS 設定等專業技術知識，大幅降低使用門檻，讓非技術使用者也能輕鬆實現遠端操作。
> 使用者可以透過綁定手機號碼/電子郵件的方式取得 Station ID，並透過 Station ID 進行遠端存取。

## 一、連線原理說明
遠端存取採用 P2P（Peer-to-Peer，點對點）連線模式，核心原理為：
透過官方中轉伺服器與使用者自身網路的協同「打洞」，打破網路邊界限制，最終在 PocketCloud 與用戶端（手機/PC）之間建立直接通訊連線，無需經過第三方伺服器轉送資料。

## 二、P2P 連線模式的優點
| 特點 | 說明 |
|------|------|
| 零設定 | 上手門檻極低，無需使用者手動進行網路參數設定，開啟功能即可嘗試連線 |
| 高效傳輸 | 當滿足直連條件時，資料直接在 PocketCloud 與用戶端間傳輸，頻寬不受中轉伺服器限制，存取速度更快 |
| 多端相容 | 同時支援行動用戶端（手機/平板）與 PC 用戶端，適配不同使用情境（如外出辦公、居家遠端管理） |

## 三、注意事項
1. 當裝置和用戶端處於同一區域網路下，會自動切換為區域網路連線。
2. 若 P2P 直連無法建立，將自動切換為 StationPC 中轉伺服器轉送模式，保障遠端存取功能可用；
3. 中轉模式下，存取速度、頻寬會受限於中轉伺服器。
