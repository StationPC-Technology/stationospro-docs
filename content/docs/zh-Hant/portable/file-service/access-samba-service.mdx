Samba 是一種基於 SMB/CIFS（Server Message Block / Common Internet File System）協定的檔案分享服務，廣泛用於 Linux、macOS 與 Windows 系統之間的檔案和印表機分享。
透過 Samba，使用者可以像存取本機檔案一樣存取遠端伺服器上的共用目錄，實現跨平台的檔案分享與協作。

**主要提供以下功能：**
1. 檔案分享：允許使用者在網路中存取、上傳、下載和管理共用檔案或資料夾。
2. 印表機分享：支援透過網路分享印表機，方便多台裝置共用同一印表資源。
3. 使用者權限控制：可設定不同使用者或使用者群的存取權限，確保資料安全。
4. 跨平台存取：相容於 Windows、Linux、macOS 等主流作業系統，支援多種用戶端接入。

## 啟用 Samba

Samba 預設為關閉狀態，需要手動啟用。請依照以下步驟操作：

1. 開啟 App 的 **檔案分享協定** 頁面。<br />
2. 點選 **Samba 服務**。<br />
3. 開啟 **開關按鈕**，即可啟用 **Samba 服務**。<br />

## 在 Windows 上存取

### 方式一

1. 按下 **Win + R** 組合鍵。  
2. 輸入 `\\NAS裝置IP`，然後點選 **確定**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/1-1.png" width="100%" height="100%" />
3. 輸入使用者名稱和密碼，點選 **確定**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/1-2.png" width="100%" height="100%" />
4. 現在，你可以在 **檔案總管** 中像存取本機資料夾一樣瀏覽和管理 NAS 上的檔案。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/1-3.png" width="100%" height="100%" />

### 方式二

1. 開啟檔案總管
2. 在 **網路** 上按右鍵，選擇 **對應網路磁碟機**
   <img src="/images/zh-Hant/portable/file-service/access-nfs-service/5-1.png" width="100%" height="100%" />
3. 輸入 `\\NAS裝置IP\管理員名稱`，然後點選 **完成**。
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/9-2.png" width="100%" height="100%" />
4. 輸入使用者名稱和密碼，點選 **確定**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/9-3.png" width="100%" height="100%" />
5. 現在，你可以在 **檔案總管** 中像存取本機資料夾一樣瀏覽和管理 NAS 上的檔案。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/9-4.png" width="100%" height="100%" />

## 在 iOS 上存取

1. 開啟 **檔案** App。  
2. 點選右上角的 **「...」** 圖示，選擇 **連接伺服器**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/2-1.png" width="240" height="500" />
3. 輸入 `smb://NAS裝置IP`，點選 **連接**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/2-2.png" width="240" height="500" />
4. 輸入使用者名稱和密碼，點選 **下一步**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/2-3.png" width="240" height="500" />
5. 現在，你可以在 **檔案** App 中像存取本機資料夾一樣瀏覽和管理 NAS 上的檔案。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/2-4.png" width="240" height="500" />

## 在 macOS 上存取

1. 在 **Finder** 上按右鍵，選擇選單列中的 **前往 → 連接伺服器**。  
   <img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. 在伺服器位址欄輸入 `smb://NAS裝置IP`，然後點選 **連接**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/3-2.png" width="100%" height="100%" />
3. 輸入使用者名稱和密碼，點選 **連接**。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/3-3.png" width="100%" height="100%" />
4. 現在，你可以在 Finder 中像存取本機資料夾一樣瀏覽和管理 NAS 上的檔案。  
   <img src="/images/zh-Hant/portable/file-service/access-samba-service/3-4.png" width="100%" height="100%" />

## 在 Linux 上存取

使用 **cifs-utils** 掛載 Samba 共用：

```bash
# 安裝 cifs-utils
sudo apt-get install cifs-utils

# 建立掛載點
# 範例：將 /mnt/samba_share 作為掛載目錄
sudo mkdir -p /mnt/samba_share

# 掛載 Samba 共用目錄
sudo mount -t cifs //NAS裝置IP/共用目錄 /mnt/samba_share -o username=使用者名稱,password=密碼

# 掛載成功後，你可以在 /mnt/samba_share 目錄中存取和管理 NAS 上的檔案
```

## 在 其他用戶端 上存取
- 連線資訊
    - IP：NAS 裝置 IP
    - 連接埠：預設為 445
    - 帳號：NAS 裝置登入使用者名稱
    - 密碼：NAS 裝置登入密碼
- 掛載目錄說明
    - 主磁碟 SSD：`/登入使用者名稱`
      - 範例1：所有目錄，目前使用者為 test，掛載目錄為 `/test`
      - 範例2：指定目錄，目前使用者為 test，掛載目錄為 `/test/Pictures`
      - 其他：支援多使用者，每位使用者對應一個掛載目錄
    - 外接儲存：`/外接儲存名稱`
      - 範例1：所有目錄，外接 SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26`
      - 範例2：指定目錄，SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分用戶端無法僅填寫根目錄 `/`，需指定上方對應的具體掛載目錄
      - 韌體&lt;= 3.1.0.16 升級到最新韌體後，掛載目錄有所調整，請以新版本的掛載方式為準
