WebDAV（Web-based Distributed Authoring and Versioning）是一種基於 HTTP 的擴充協定，用於在網路上進行檔案分享和協作。
它允許使用者透過網頁瀏覽器或用戶端應用程式存取、編輯和管理遠端伺服器上的檔案。

**主要提供以下功能：**
1. 檔案上傳與下載：支援將本機檔案上傳到伺服器，或從伺服器下載檔案到本機。
2. 檔案管理：可在遠端伺服器上建立、刪除、重新命名或移動檔案和資料夾。
3. 檔案同步：支援本機與遠端檔案的同步，確保資料保持一致。
4. 檔案分享與協作：可將伺服器上的檔案分享給其他使用者，實現團隊協作。

## 啟用 WebDAV
WebDAV 預設為關閉狀態，需要手動啟用。請依照以下步驟操作：
1. 開啟 App 的 **檔案分享協定** 頁面。<br />
2. 點選 **WebDAV 服務**。<br />
3. 開啟 **開關按鈕**，即可啟用 **WebDAV 服務**。<br />

## 在 Windows 上存取

> **注意**：建議在 Windows 上使用 **[RaiDrive](https://www.raidrive.com)** 存取 WebDAV 服務。

1. 按下 **Win + E** 開啟 **檔案總管**  
2. 在左側欄的 **網路** 上按右鍵，選擇 **對應網路磁碟機**  
   <img src="/images/zh-Hant/portable/file-service/access-nfs-service/5-1.png" width="100%" height="100%" />

3. 在彈出的視窗中輸入 WebDAV 位址：  
   ```http://NAS裝置IP:5005```
   然後點選 **完成**  
   <img src="/images/zh-Hant/portable/file-service/access-webdav-service/1-4.png" width="100%" height="100%" />

4. 在登入提示中輸入使用者名稱和密碼  
   <img src="/images/zh-Hant/portable/file-service/access-nfs-service/5-3.png" width="100%" height="100%" />

5. 完成後，你可以在 **本機** 中像本機磁碟一樣存取 NAS 上的檔案  
   <img src="/images/zh-Hant/portable/file-service/access-webdav-service/1-6.png" width="100%" height="100%" />

## 在 macOS 上存取

1. 在 **Finder** 上按右鍵，在選單列中選擇 **前往 → 連接伺服器...**  
   <img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />

2. 在伺服器位址欄輸入：  
   ```http://NAS裝置IP:5005```
   然後點選 **連接**  
   <img src="/images/zh-Hant/portable/file-service/access-webdav-service/3-2.png" width="100%" height="100%" />

3. 輸入使用者名稱和密碼，點選 **連接**  
   <img src="/images/zh-Hant/portable/file-service/access-webdav-service/3-3.png" width="100%" height="100%" />

4. 現在，你可以在 Finder 中像存取本機資料夾一樣瀏覽和管理 NAS 上的檔案  
   <img src="/images/zh-Hant/portable/file-service/access-webdav-service/3-4.png" width="100%" height="100%" />

## 在 Linux 上存取

使用 **davfs** 掛載 WebDAV 共用：

```bash
# 安裝 davfs2
sudo apt-get install davfs2

# 建立掛載點
# 範例：將 /mnt/webdav_share 作為掛載目錄
sudo mkdir /mnt/webdav_share

# 掛載 WebDAV 服務
sudo mount.davfs http://NAS裝置IP:5005 /mnt/webdav_share

# 掛載成功後，你可以在 /mnt/webdav_share 目錄中存取和管理 NAS 上的檔案
```

## 在 其他用戶端 上存取
- 連線資訊
    - IP：NAS 裝置 IP
    - 連接埠：http 預設為 5005，https 暫不支援
    - 帳號：NAS 裝置登入使用者名稱
    - 密碼：NAS 裝置登入密碼
- 掛載目錄說明
    - 主磁碟 SSD：`/登入使用者名稱`
      - 範例1：所有目錄，目前使用者為 test，掛載目錄為 `/test`
      - 範例2：指定目錄，目前使用者為 test，掛載目錄為 `/test/Pictures`
      - 其他：支援多使用者，每位使用者對應一個掛載目錄
    - 外接儲存：`/外接儲存名稱`
      - 範例1：所有目錄，外接 SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26`
      - 範例2：指定目錄，SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分用戶端無法僅填寫根目錄 `/`，需指定上方對應的具體掛載目錄
      - 韌體&lt;= 3.1.0.16 升級到最新韌體後，掛載目錄有所調整，請以新版本的掛載方式為準

## 其他問題

* 問：Windows 檔案總管無法掛載 WebDAV HTTP 服務怎麼辦？
* 答：請參考 [Windows 無法掛載 WebDAV 到本機電腦](/portable/file-service/windows-webdav-http-mount)

* 問：Windows 支援 WebDAV HTTPS 嗎？
* 答：Windows 檔案總管不支援 WebDAV over HTTPS。你可以使用 **[RaiDrive](https://www.raidrive.com)** 來掛載 WebDAV-HTTPS 服務。

* 問：WebDAV-HTTPS 服務使用哪個連接埠？
* 答：WebDAV-HTTPS 的預設連接埠是 5006。你可以使用以下位址存取服務：`https://NAS_IP_Address:5006`.

* 問：為什麼 Windows 無法透過 WebDAV 開啟大型檔案？
* 答：請參考 [Windows 透過 WebDAV 存取大於 50MB 檔案時出現錯誤提示](/portable/file-service/windows-webdav-filelimit)
