title: "如何通過 FTP 訪問 PocketCloud 中的文件？"
---

FTP（File Transfer Protocol）是一種常用的網絡文件傳輸協議，可用於在設備與服務器之間傳輸文件。
通過 FTP，用戶可以遠程連接 PocketCloud，進行文件瀏覽、上傳、下載和管理。

**主要具備以下功能：**
1. 文件上傳與下載：在本地設備與 PocketCloud 之間傳輸文件。
2. 遠程文件管理：可在 PocketCloud 上創建、重命名、移動和刪除文件或文件夾。
3. 用戶認證訪問：通過賬號和密碼進行訪問控制，提升安全性。
4. 跨平臺訪問：可通過支持 FTP 的 Windows 和 macOS 客戶端進行連接。

## 啟用 FTP

FTP 默認處於關閉狀態，需要手動啟用。請按照以下步驟操作：
1. 打開 App 的 **文件共享協議** 頁面。<br />
2. 點擊 **FTP 服務**。<br />
3. 打開 **開關按鈕**，即可啟用 **FTP 服務**。<br />

## 在 Windows 上訪問

1. 按下 **Win + E** 打開 **文件資源管理器**。
2. 在地址欄輸入 `ftp://NAS設備IP:21` 或者 `ftps://NAS_IP_Address:21`，然後按 **回車**。
<img src="/images/common/portable/file-service/access-ftp-service/3-1.png" width="100%" height="100%" />
3. 在登錄提示中輸入 **用戶名** 和 **密碼**，然後點擊 **登陸**
<img src="/images/common/portable/file-service/access-ftp-service/3-2.png" width="100%" height="100%" />
4. 現在，你可以在文件資源管理器中瀏覽和管理 PocketCloud 文件。
<img src="/images/common/portable/file-service/access-ftp-service/3-3.png" width="100%" height="100%" />

---

## 在 macOS 上訪問

1. 右鍵 **訪達（Finder）**，選擇 **連接服務器**。
<img src="/images/common/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. 輸入 `ftp://NAS設備IP:21` 或者 `ftps://NAS_IP_Address:21`，然後點擊 **連接**。
<img src="/images/common/portable/file-service/access-ftp-service/4-1.png" width="100%" height="100%" />
3. 輸入 **名稱** 和 **密碼**，然後點擊 **連接**。
<img src="/images/common/portable/file-service/access-ftp-service/4-2.png" width="100%" height="100%" />
4. 現在，你可以在訪達中訪問 PocketCloud 文件。  
<img src="/images/common/portable/file-service/access-ftp-service/4-3.png" width="100%" height="100%" />

## 在 其它客戶端 上訪問
- 連接信息
    - IP：NAS設備IP
    - 端口：默認為21
    - 賬號：NAS設備登錄用戶名
    - 密碼：NAS設備登錄密碼
- 掛載目錄說明
    - 主盤SSD：`/登錄用戶名`
      - 示例1：所有目錄，當前用戶為 test，掛載目錄為 `/test`
      - 示例2：指定目錄，當前用戶為 test，掛載目錄為 `/test/Pictures`
      - 其它：支持多用戶，每個用戶對應一個掛載目錄
    - 外接存儲：`/外接存儲名稱`
      - 示例1：所有目錄，外接SD卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26`
      - 示例2：指定目錄，外接SD卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分客戶端無法僅填寫根目錄 `/`，需指定上面對應的具體掛載目錄
      - 固件&lt;= 3.1.0.16升級到最新固件後，掛載目錄有所調整，以新版本的掛載方式為準
