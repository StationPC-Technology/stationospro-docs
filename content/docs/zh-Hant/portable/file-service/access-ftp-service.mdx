title: "如何透過 FTP 存取 PocketCloud 中的檔案？"
---

FTP（File Transfer Protocol）是一種常用的網路檔案傳輸協定，可用於在裝置與伺服器之間傳輸檔案。
透過 FTP，使用者可以遠端連線 PocketCloud，進行檔案瀏覽、上傳、下載和管理。

**主要提供以下功能：**
1. 檔案上傳與下載：在本機裝置與 PocketCloud 之間傳輸檔案。
2. 遠端檔案管理：可在 PocketCloud 上建立、重新命名、移動和刪除檔案或資料夾。
3. 使用者驗證存取：透過帳號和密碼進行存取控制，提升安全性。
4. 跨平台存取：可透過支援 FTP 的 Windows 和 macOS 用戶端進行連線。

## 啟用 FTP

FTP 預設為關閉狀態，需要手動啟用。請依照以下步驟操作：
1. 開啟 App 的 **檔案分享協定** 頁面。<br />
2. 點選 **FTP 服務**。<br />
3. 開啟 **開關按鈕**，即可啟用 **FTP 服務**。<br />

## 在 Windows 上存取

1. 按下 **Win + E** 開啟 **檔案總管**。
2. 在位址列輸入 `ftp://NAS裝置IP:21` 或者 `ftps://NAS_IP_Address:21`，然後按 **Enter**。
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/3-1.png" width="100%" height="100%" />
3. 在登入提示中輸入 **使用者名稱** 和 **密碼**，然後點選 **登入**
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/3-2.png" width="100%" height="100%" />
4. 現在，你可以在檔案總管中瀏覽和管理 PocketCloud 檔案。
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/3-3.png" width="100%" height="100%" />

---

## 在 macOS 上存取

1. 在 **Finder** 上按右鍵，選擇 **連接伺服器**。
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. 輸入 `ftp://NAS裝置IP:21` 或者 `ftps://NAS_IP_Address:21`，然後點選 **連接**。
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-1.png" width="100%" height="100%" />
3. 輸入 **名稱** 和 **密碼**，然後點選 **連接**。
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-2.png" width="100%" height="100%" />
4. 現在，你可以在 Finder 中存取 PocketCloud 檔案。  
<img src="/images/zh-Hant/portable/file-service/access-ftp-service/4-3.png" width="100%" height="100%" />

## 在 其他用戶端 上存取
- 連線資訊
    - IP：NAS 裝置 IP
    - 連接埠：預設為 21
    - 帳號：NAS 裝置登入使用者名稱
    - 密碼：NAS 裝置登入密碼
- 掛載目錄說明
    - 主磁碟 SSD：`/登入使用者名稱`
      - 範例1：所有目錄，目前使用者為 test，掛載目錄為 `/test`
      - 範例2：指定目錄，目前使用者為 test，掛載目錄為 `/test/Pictures`
      - 其他：支援多使用者，每位使用者對應一個掛載目錄
    - 外接儲存：`/外接儲存名稱`
      - 範例1：所有目錄，外接 SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26`
      - 範例2：指定目錄，SD 卡名稱為 SD 60GB BA26，掛載目錄為 `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 部分用戶端無法僅填寫根目錄 `/`，需指定上方對應的具體掛載目錄
      - 韌體&lt;= 3.1.0.16 升級到最新韌體後，掛載目錄有所調整，請以新版本的掛載方式為準
