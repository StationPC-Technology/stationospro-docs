title: "Windows 訪問 NFS 磁盤中文亂碼問題"
---

> 出現中文亂碼通常是由於編碼不匹配或系統區域設置問題導致的，針對 Windows 上 NFS 映射磁盤中文亂碼的問題，經過測試以下方法可以解決：

> 步驟：

1. 打開 **控制面板** → **時鐘和區域** → **區域**。
2. 切換到 **“管理”** 選項卡，點擊 **“更改系統區域設置”**。
3. 確保選擇的是 **“中文(簡體，中國)”**。 ```最下面有個Beta選項打鉤```
<img src="/images/common/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. 修改後重啟系統，再次掛載 NFS 磁盤，查看中文是否正常顯示。
