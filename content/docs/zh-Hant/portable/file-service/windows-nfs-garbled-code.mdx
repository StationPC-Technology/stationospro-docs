title: "Windows 存取 NFS 磁碟中文亂碼問題"
---

> 出現中文亂碼通常是因為編碼不符或系統地區設定問題所致。針對 Windows 上 NFS 對應磁碟的中文亂碼問題，經測試以下方法可以解決：

> 步驟：

1. 開啟 **控制台** → **時鐘和區域** → **區域**。
2. 切換到 **「系統管理」** 索引標籤，點選 **「變更系統地區設定」**。
3. 確認選擇的是 **「中文(簡體，中國)」**。 ```最下方有個 Beta 選項請勾選```
<img src="/images/zh-Hant/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. 修改後重新啟動系統，再次掛載 NFS 磁碟，查看中文是否正常顯示。
