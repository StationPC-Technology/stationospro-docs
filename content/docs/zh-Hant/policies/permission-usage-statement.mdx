StationHub 只會在您進入相應功能時申請所需權限。系統彈窗顯示的權限名稱可能因 iOS、Android、Windows 或 macOS 版本而不同；是否允許由您決定，拒絕權限不會影響與該權限無關的基本功能。

## 1. 權限處理原則

- 首次使用需要權限的功能時才提出申請，不會在啟動時一次申請全部權限。
- 權限用於目前功能的明確目的。關閉權限後，相關功能可能無法使用，但不會因此自動讀取其他資料。
- 第三方外掛或系統服務可能出現額外授權提示，是否授予仍由您控制。
- 位置權限只用於配網階段讀取 WiFi 名稱並推導國家碼；我們不進行背景定位，也不上傳或保存座標。

## 2. iPhone 與 iPad

| 系統權限 | 觸發功能 | 我們會做什麼 | 關閉後的影響 |
| --- | --- | --- | --- |
| 相機 | 掃碼綁定、快速登入、設定頭像 | 在裝置端讀取相機畫面以識別 QR Code 或拍攝頭像 | 無法掃碼或拍攝頭像 |
| 照片與影片 | 相簿備份、選取媒體上傳、設定頭像 | 讀取您選取的媒體；支援 iOS 受限照片範圍 | 無法備份或上傳對應媒體 |
| 本機網路 | 搜尋並連接同一區域網路的 NAS | 發現區域網路裝置並建立本機連線 | 無法發現或連接區域網路 NAS |
| 通知 | 裝置狀態、備份進度和帳號安全提醒 | 發送您允許的系統通知 | 無法收到相關提醒 |
| 藍牙 | 裝置綁定和配網 | 發現附近裝置並傳遞配網資訊 | 無法透過藍牙綁定或配網 |
| 使用期間的位置 | 配網時判定 WiFi 地區 | 暫時讀取 WiFi 名稱並推導國家碼 | 需要手動選擇 WiFi 與地區 |

## 3. Android 手機與平板

| 系統權限 | 觸發功能 | 使用範圍 | 關閉後的影響 |
| --- | --- | --- | --- |
| 相機 | 掃碼綁定和快速登入 | 在裝置端識別 QR Code | 無法掃碼綁定或登入 |
| 照片、影片或本機儲存空間 | 檔案上傳下載、相簿自動備份 | 存取您選取的檔案和媒體 | 無法完成相應檔案操作 |
| 附近裝置、區域網路和 WiFi | 發現裝置、建立本機連線和配網 | 讀取連線所需的網路狀態 | 無法發現裝置或建立本機連線 |
| 通知 | 任務進度、裝置異常和帳號安全提醒 | 發送推播或本機通知 | 無法收到相關提醒 |
| 藍牙 | 裝置配對和網路初始化 | 發現並連接配網裝置 | 無法透過藍牙完成配網 |
| 網路位置資訊 | 輔助配網識別 | 僅在配網時輔助判斷 WiFi 地區 | 需要手動選擇地區 |
| 背景自動啟動 | 使用者主動開啟的持續備份 | 維持備份任務執行 | 備份可能被系統中斷 |
| 剪貼簿 | 識別分享連結並開啟檔案傳輸 | 僅在觸發分享連結功能時讀取 | 無法自動識別分享連結 |

## 4. Windows 與 macOS 用戶端

| 平台 | 權限或系統能力 | 用於 | 關閉後的影響 |
| --- | --- | --- | --- |
| Windows | 桌面通知 | 顯示任務進度、裝置狀態和異常 | 無法顯示桌面提醒 |
| Windows | 本機檔案系統 | 上傳、下載和資料夾同步 | 無法完成本機檔案操作 |
| macOS | 系統通知 | 提示備份進度和裝置執行狀態 | 無法收到系統通知 |
| macOS | 本機目錄 | 檔案管理、上傳、下載和同步 | 無法完成對應檔案任務 |

## 5. 其他說明

權限授權不等於持續收集個人資料。未經您的明確授權，我們不會主動讀取、上傳 NAS 中的私有檔案，也不會申請背景定位權限或收集廣告類裝置識別碼。您可以在裝置系統設定中隨時撤銷權限；撤銷後，相關功能會在下次使用時提示原因和替代操作。

如某項功能由第三方應用程式或服務提供，請同時查看[《第三方個人資料分享清單》](./third-party-sdk-list)和該服務供應商自己的隱私權政策。關於整體資料處理方式，請參閱[《隱私權政策》](./privacy-policy)。
