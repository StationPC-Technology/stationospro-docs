## 前言

本說明向您說明 StationPC 配套 App、PC/Mac 用戶端申請、使用作業系統權限的情況。我們遵循**最小必要、按需申請**原則，僅在使用對應功能時動態申請權限。

您可隨時在系統設定中管理權限授權，關閉權限僅影響對應功能，不會影響產品基礎核心服務。

第三方外掛及服務可能申請額外權限，授權不代表持續蒐集個人資料。

## iOS 權限

| 情境 | 目的 | 拒絕或關閉權限的影響 |
| --- | --- | --- |
| 呼叫裝置相機 | 掃碼綁定 NAS 裝置、快速登入、拍照設定大頭貼 | 無法掃碼綁定裝置、拍照設定大頭貼 |
| 存取照片與影片相簿 | 備份手機相簿內容至 NAS、選取圖片影片上傳、設定帳號大頭貼；支援 iOS 受限照片存取（僅授權所選照片） | 無法備份相簿、上傳圖片影片 |
| 存取本機網路 | 區域網路發現並連接 StationPC 裝置 | 無法發現與連接區域網路內的 NAS 裝置 |
| 接收系統通知 | 接收裝置狀態、備份進度、帳號安全通知（含時效性通知） | 無法接收相關提醒通知 |
| 存取藍牙裝置 | 裝置綁定與配網：發現附近裝置、傳輸配網資訊 | 無法透過藍牙綁定與設定裝置 |
| 取得位置資訊（僅使用期間） | 配網時讀取目前 WiFi 名稱，並暫時取得一次位置推導國家碼用於裝置 WiFi 地區設定；不做背景定位，座標不上傳、不儲存 | 無法自動識別目前 WiFi 與地區，需手動選擇 |

## Android 權限

| 情境 | 目的 | 拒絕或關閉權限的影響 |
| --- | --- | --- |
| 呼叫裝置相機 | 掃碼綁定裝置、快速登入 | 無法掃碼綁定裝置、快速登入 |
| 存取本機儲存 | 實現檔案上傳、下載、相簿自動備份功能 | 無法上傳、下載檔案與自動備份相簿 |
| 存取區域網路與 WiFi | 區域網路裝置發現與本機連線 | 無法發現區域網路裝置、無法建立本機連線 |
| 接收推送通知 | 任務進度、裝置異常、帳號安全提醒 | 無法接收任務進度、裝置異常與安全提醒 |
| 存取藍牙裝置 | 裝置配對與網路初始化輔助 | 無法透過藍牙完成裝置配對與配網 |
| 取得網路位置資訊 | 輔助配網識別 | 無法自動識別目前 WiFi 與地區，需手動選擇 |
| 背景自動啟動 | 維持背景備份任務（使用者手動開啟） | 背景備份任務可能被中斷 |
| 讀取剪貼簿內容 | 識別分享連結，喚起檔案傳輸功能 | 無法識別分享連結並喚起檔案傳輸功能 |

## Windows 用戶端權限

| 情境 | 目的 | 拒絕或關閉權限的影響 |
| --- | --- | --- |
| 接收桌面通知 | 展示任務進度、裝置狀態與異常提醒 | 無法接收任務進度、裝置狀態與異常提醒 |
| 存取本機檔案系統 | 支援本機檔案上傳、下載、資料夾同步 | 無法上傳、下載本機檔案與同步資料夾 |

## Mac 用戶端權限

| 情境 | 目的 | 拒絕或關閉權限的影響 |
| --- | --- | --- |
| 接收系統通知 | 回饋備份進度與裝置運作狀態 | 無法接收備份進度與裝置狀態通知 |
| 存取本機目錄 | 完成檔案管理、上傳下載與同步任務 | 無法完成檔案管理、上傳下載與同步任務 |

## 補充說明

所有權限均為按需申請，不會在啟動時批次授權。

關閉權限僅停用部分功能，不影響登入、裝置連線、檔案瀏覽等基礎服務。

未經使用者明確授權，我們不會主動讀取、上傳 NAS 內任何私有使用者資料。

不申請背景定位權限、不蒐集廣告類裝置識別碼。位置資訊僅在裝置配網時暫時使用（讀取 WiFi 名稱、推導國家碼），座標不上傳、不儲存，符合全球隱私合規要求。
