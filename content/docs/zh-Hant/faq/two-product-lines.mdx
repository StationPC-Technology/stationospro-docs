StationPC 目前有兩條並列的 NAS 產品線：**桌上型 NAS** 和 **可攜式 NAS**。它們針對的使用情境不同，硬體形態、系統基礎和用戶端也分別設計，所以不是同一台機器的「標準版 / 可攜版」，而是兩套獨立的產品與系統。說明中心也因此依產品線分成兩套文件。

## 兩條產品線分別是什麼

| | 桌上型 NAS | 可攜式 NAS |
| --- | --- | --- |
| 型號 | DA400、DA400 Air | PA100、PA100 Pro |
| 系統 | StationOS Pro | StationOS |
| 系統基礎 | Debian | OpenWrt |
| 硬體形態 | 固定擺放，多硬碟槽，以固定供電和有線網路為主 | 內建電池，可隨身攜帶，支援無線 / AP 連線 |
| 典型用途 | 家庭或工作室的長期儲存、RAID、Station AI | 出差旅行、行動辦公 |
| 用戶端 | StationNAS（Windows / macOS）、StationHub（iOS / Android） | PocketNAS（Windows / macOS / Linux / iOS / Android） |

## 為什麼不能只用一套系統

1. **硬體邊界不同。** 桌上型要長期承載多顆硬碟、RAID 和更高的持續讀寫，可攜式要在電池、散熱和體積限制下運作。驅動、電源管理、硬碟管理和散熱策略很難共用一套。
2. **系統基礎不同。** StationOS Pro 基於 Debian，StationOS 基於 OpenWrt。兩者的軟體套件、服務管理、更新方式和底層工具鏈都不一樣，不能把同一個系統映像安裝到另一條產品線上。
3. **功能和用戶端不同。** 桌上型提供 Station AI、RAID 等能力；可攜式圍繞電池、AP 模式、SD / USB 備份和 PocketNAS 設計。兩邊都有 Docker 和檔案分享，但選單路徑、介面和限制並不相同。
4. **版本線獨立。** 兩套系統分別發布更新，更新記錄和版本號各自獨立。可攜式的更新包不能裝到桌上型，反之亦然。

## 對我的使用有什麼影響

- **先確認型號。** 看裝置標籤或購買紀錄：型號是 DA400 / DA400 Air，就是桌上型；是 PA100 / PA100 Pro，就是可攜式。
- **依產品線查文件。** 兩條產品線的選單、截圖和限制不同，請從對應的「桌上型 NAS」或「可攜式 NAS」入口進入，不要照著另一條產品線的步驟操作。
- **不要混用用戶端和更新包。** 桌上型用 StationNAS / StationHub，可攜式用 PocketNAS；更新包也不通用。
- **同名功能先看產品線。** 同樣的功能名稱（例如備份、遠端存取）在兩條產品線上的位置和做法可能不同。

## 為什麼說明中心也分成兩套文件

因為兩套系統的選單、截圖、限制和更新節奏都不同，如果把內容混在一起，同一個問題會出現兩個答案，搜尋也容易把使用者帶到另一條產品線的步驟上。所以本站採用「一個網站、兩個並列產品域」：通用內容（法務、聯絡我們、全站搜尋）共用，具體操作分別寫在桌上型和可攜式文件裡。

如果你還不確定自己的裝置屬於哪條產品線，可以先看裝置標籤上的型號，或[聯絡我們](../contact)。
