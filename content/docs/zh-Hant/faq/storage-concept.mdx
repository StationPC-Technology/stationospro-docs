在 StationOS Pro 中，**硬碟**與**儲存空間**是構建資料儲存的兩個核心概念。簡單來說，硬碟是資料的實體載體，儲存空間是你實際存放和管理檔案的邏輯區域。理解兩者之間的關係，是合理規劃容量、保障資料安全、發揮裝置效能的基礎。

## 硬碟：資料的實體載體

硬碟是實際儲存資料的實體裝置。StationPC 裝置同時支援機械硬碟（HDD）與固態硬碟（SSD）：

- **HDD（機械硬碟）**：容量大、單位容量價格低，適合照片、影片、下載資料等海量資料的長期儲存。
- **SSD（固態硬碟）**：讀寫速度快，適合承載 Docker 容器、虛擬機器等對效能要求較高的場景，也可作為 HDD 儲存空間的快取加速。

硬碟型號與容量的選擇請參考[硬碟相容性列表](../compatible/support-hdd)。

## 儲存空間：實際使用資料的邏輯區域

儲存空間是使用者實際存放和管理資料的邏輯區域，相當於一塊獨立的「虛擬硬碟」。系統透過 RAID 技術把一塊或多塊硬碟組織成儲存空間，但在介面上只需要一步操作：**直接建立儲存空間**，無需先單獨建立儲存池。

建立儲存空間時，精靈會引導你完成以下選擇：

1. **選擇硬碟**：從內建硬碟或外接儲存中挑選參與組建的硬碟。
2. **選擇儲存模式**：即 RAID 模式，決定容量的利用方式與資料保護等級。
3. **選擇檔案系統**：Btrfs 或 EXT4。
4. **設定使用權限**：選擇可使用該儲存空間的使用者，並可限制一般使用者的可用容量。
5. **確認並建立**：確認摘要與格式化警告後開始建立。

建立完成後，儲存空間卡片會顯示健康狀態、儲存模式、已用容量、檔案系統、成員硬碟與熱備援碟等資訊，便於隨時掌握儲存狀況。

## 儲存模式：容量與安全的平衡點

儲存模式（RAID）決定了多塊硬碟如何協同運作。不同模式在容量利用率與資料安全之間各有側重：

- **Basic**：單碟獨立使用，容量利用率最高，但沒有資料保護。
- **JBOD**（介面中顯示為 Linear）：將多塊硬碟容量線性拼接為一個空間，擴充簡單但無冗餘。
- **RAID 0**：資料分塊儲存在多塊硬碟上，讀寫速度快，但任意一塊硬碟損壞會導致全部資料遺失。
- **RAID 1**：資料在成員碟之間鏡像保存，允許部分硬碟故障而不遺失資料。
- **RAID 5 / RAID 6**：透過同位檢查提供容錯，兼顧容量利用率與安全，適合碟位較多的裝置。
- **RAID 10**：先鏡像後等量分割，兼顧高效能與高保護，空間利用率約為總容量的一半。

各模式的硬碟數量要求、容量計算方式與詳細對比，請參考[儲存空間設定](../app-guide/settings/storage)。

此外，還可以為 RAID 儲存空間指定**熱備援碟**：當成員碟故障時，熱備援碟會自動接手參與重建，縮短資料處於降級狀態的時間窗口。

## 硬碟與儲存空間的關係小結

一句話概括：**硬碟提供實體容量，儲存模式決定組織方式，儲存空間是最終呈現給你的可用區域。**

- **硬碟 → 儲存空間**：建立儲存空間時選定的硬碟，按儲存模式組合成一個整體。模式決定了實際可用容量與容錯能力。
- **儲存空間 → 使用者資料**：在儲存空間中建立共享資料夾、上傳檔案、設定存取權限後，即可透過[檔案管理](../app-guide/files)應用或 SMB、WebDAV 等協定在各類裝置上存取資料。

## 與其他 NAS 系統的差異：為什麼沒有「儲存池」？

不少 NAS 系統採用「硬碟 → 儲存池 → 儲存空間」的三層結構：先把硬碟組合成儲存池，再在池上劃分出多個儲存空間。

StationOS Pro 將這兩步合併為一步：建立儲存空間時選好硬碟與儲存模式，系統自動完成底層的池化。這樣的取捨是：

- **好處**：流程更簡單直觀，不需要先理解「儲存池」的概念，就能正確組建儲存。
- **限制**：一組硬碟只能對應一個儲存空間，無法在同一組硬碟上再劃分出多個空間。如果需要多個相互獨立的空間，請使用不同的硬碟分別建立。

## 儲存規劃建議

| 需求 | 建議 |
| --- | --- |
| 照片、文件等重要資料 | RAID 1 及以上冗餘模式，並保持定期備份 |
| Docker、虛擬機器等高效能場景 | 使用 SSD 組建儲存空間，或開啟 SSD 快取加速 |
| 影片、下載等大容量資料 | 大容量 HDD 搭配 JBOD 或 RAID 5 |
| 多人協作 | 分別建立儲存空間，或透過資料夾權限隔離不同成員的資料 |

<Callout title="提示" type="idea">
RAID 提供的是硬碟故障容錯，不能代替備份。重要資料仍建議遵循「3-2-1」備份原則：至少保留 3 份資料、存放在 2 種媒體上，其中 1 份存放於異地。
</Callout>
