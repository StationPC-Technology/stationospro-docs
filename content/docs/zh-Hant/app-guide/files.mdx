檔案管理是 StationOS Pro 的核心應用程式，用於集中管理裝置上的所有檔案。你可以在瀏覽器中完成檔案上傳下載、目錄管理、權限分享、回收站還原與重複檔案清理，還可以設定 SMB、WebDAV、FTP、NFS 等檔案服務，讓電腦、手機直連存取 NAS 中的檔案。

## 介面介紹

檔案管理頂部依功能劃分為以下標籤頁：

| 標籤頁 | 說明 |
| --- | --- |
| 我的檔案 | 目前使用者的個人檔案空間 |
| 團隊檔案 | 團隊共享空間，可多人協作存取 |
| 外接儲存 | 管理 USB 隨身碟、行動硬碟等外接裝置中的檔案 |
| 遠端掛載 | 掛載遠端 NAS 或伺服器上的共享目錄 |
| 應用檔案 | 檢視各應用程式產生的資料檔案 |
| 我的收藏 | 快速存取收藏的檔案與資料夾 |
| 外連分享 | 管理已建立的外部分享連結 |
| 回收站 | 還原或徹底刪除已刪除的檔案 |
| 重複檔案 | 掃描並清理重複檔案，釋放儲存空間 |
| 管理員檢視 | 管理員可依使用者維度檢視全部檔案（僅管理員可見） |

檔案列表支援列表/網格檢視切換，並顯示檔案名稱、大小、類型、修改時間、儲存位置、建立時間與擁有者等資訊，點擊欄位標題即可排序。

## 檔案基礎操作

工具列提供以下常用操作：

- **上傳**：上傳檔案或整個資料夾；
- **新增資料夾**：建立新的目錄；
- **排序**：依名稱、大小、時間等方式排序；
- **檢視切換**：在列表檢視與網格檢視之間切換。

### 新增資料夾

1. 進入目標目錄，點擊工具列的 **新增資料夾**。
2. 輸入資料夾名稱（最多 180 個字元）。
3. 選擇資料夾所在的儲存位置（如儲存空間 1）。
4. 點擊 **確認** 完成建立。

![New Folder](/images/zh-Hant/app-guide/files-img/new-folder.png)

### 右鍵選單

在檔案或資料夾上點擊右鍵，可執行以下操作：

| 選單項目 | 說明 |
| --- | --- |
| 在新視窗中開啟 | 在新視窗中開啟（資料夾） |
| 下載 | 下載到本機電腦 |
| 複製到 / 移動到 | 複製或移動到其他目錄 |
| 剪下 / 複製 | 剪下或複製 |
| 刪除 | 刪除（進入回收站） |
| 重新命名 | 重新命名 |
| 收藏 | 加入收藏 |
| 外連分享 | 建立外連分享 |
| 詳情 | 檢視檔案詳情 |

![Context Menu](/images/zh-Hant/app-guide/files-img/context-menu.png)

## 外連分享

透過外連分享，你可以將檔案或資料夾分享給沒有 NAS 帳號的外部使用者：

1. 右鍵點擊目標檔案或資料夾，選擇 **外連分享**。
2. 設定分享參數：
   - **分享名稱**：外連顯示名稱；
   - **有效期限**：永久有效或自訂截止時間；
   - **允許下載**：是否允許存取者下載檔案；
   - **密碼保護**：為連結設定存取密碼；
   - **存取次數限制**：限制連結的最大存取次數。
3. 點擊 **建立連結** 產生分享連結。

已建立的分享可在「外連分享」標籤頁中統一管理，包括檢視連結、修改規則或取消分享。

![Share Link](/images/zh-Hant/app-guide/files-img/share-link.png)

<Callout title="安全提示" type="warn">
  分享敏感檔案時建議開啟密碼保護並設定有效期限，分享完成後請及時關閉不再使用的連結，避免資料外洩。
</Callout>

## 檔案服務設定

點擊檔案管理右上角的 **設定**，可設定檔案服務。設定視窗包含以下標籤頁：

- **檔案共享協定**：分別設定 SMB、WebDAV、FTP、NFS 服務；
- **檔案規則**：設定檔案命名等規則；
- **遠端掛載**：設定遠端掛載相關參數；
- **外部分享**：設定外連分享的全域規則。

以 SMB 為例，設定頁面提供：

- **可見目錄範圍**：分別設定我的檔案、團隊檔案、應用檔案透過協定存取的可見性；
- **連線方式**：提供 Windows 與 macOS 連接 NAS 的圖文指引與存取位址；
- **其他連線資訊**：展示裝置 IP 位址與預設連接埠（SMB 為 445），可一鍵複製。

![File Settings](/images/zh-Hant/app-guide/files-img/settings.png)

### 在電腦上存取 NAS 檔案

- **macOS**：開啟 Finder → 前往 → 連接伺服器，輸入 `smb://裝置IP`，再輸入 NAS 本機帳號密碼即可存取。
- **Windows**：按 `Win + R`，輸入 `\\裝置IP`，再輸入 NAS 本機帳號密碼即可存取。

## 回收站

刪除的檔案會進入回收站，防止誤刪導致資料遺失：

- **還原**：將檔案還原到刪除前的原始位置；
- **徹底刪除**：永久刪除選取的檔案，無法還原；
- **清空回收站**：一鍵清空回收站中的全部檔案。

回收站依我的檔案與團隊檔案區分個人與團隊刪除內容，管理員可檢視所有使用者的回收站。
