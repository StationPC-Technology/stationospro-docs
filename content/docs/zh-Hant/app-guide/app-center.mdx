應用中心是 StationOS Pro 的應用程式商店，提供官方應用程式與第三方應用程式的一站式安裝、更新與管理。透過應用中心，你可以像使用手機應用程式商店一樣，為 NAS 擴充下載、影音、同步、生產力與開發維運等各類能力。

## 介面介紹

開啟應用中心後，頂部提供以下導覽：

- **全部應用**：瀏覽商店內所有可安裝應用程式；
- **已安裝**：檢視並管理目前裝置已安裝的應用程式；
- **分類篩選**：依同步、影視、影片錄製、下載、生產力、開發工具等分類快速篩選應用程式；
- **搜尋框**：依應用程式名稱快速尋找應用程式。

應用程式列表分為「官方應用」與第三方應用程式區域，每個應用程式卡片會顯示名稱、簡介/分類標籤及安裝按鈕。

![App Center](/images/zh-Hant/app-guide/app-center-img/all-apps.png)

## 安裝應用

1. 在應用中心透過分類或搜尋框找到目標應用程式。
2. 點擊應用程式卡片進入詳細資料頁。
3. 確認應用程式資訊後，點擊 **安裝**，系統將自動下載並安裝應用程式。
4. 安裝完成後，應用程式會出現在應用程式啟動器中；若開啟了自動建立桌面捷徑，還會在桌面產生捷徑。

## 應用詳細資料頁

應用詳細資料頁顯示以下資訊，幫助你瞭解並評估應用程式：

| 欄位 | 說明 |
| --- | --- |
| 開發者 | 應用程式的開發者或團隊 |
| 發佈者 | 應用程式的發佈方 |
| 下載量 | 該應用程式的累計下載次數 |
| 大小 | 應用程式安裝套件大小 |
| 目前版本 | 商店中提供的最新版本號 |
| 應用介紹 | 功能亮點與使用說明 |

![App Detail](/images/zh-Hant/app-guide/app-center-img/app-detail.png)

## 應用中心設定

點擊應用中心右上角的 **設定** 按鈕，可進行以下設定：

- **預設安裝位置**：
  - **每次詢問**：安裝時手動選擇儲存位置；
  - **固定儲存位置**：統一指定應用程式的安裝儲存空間。
- **自動建立桌面捷徑**：開啟後，新安裝的應用程式會自動在桌面建立捷徑。

![App Center Settings](/images/zh-Hant/app-guide/app-center-img/settings.png)

<Callout title="注意" type="warn">
  - 安裝應用程式前請確保所選儲存空間有足夠容量，否則安裝可能失敗。
  - 部分第三方應用程式由外部開發者提供，安裝前請確認應用程式來源與權限需求。
  - 應用程式安裝位置在部分情況下無法變更，如需遷移請先解除安裝後重新安裝。
</Callout>
