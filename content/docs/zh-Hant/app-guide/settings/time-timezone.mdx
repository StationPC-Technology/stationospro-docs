時間與時區頁用於確保裝置時間準確。正確時間對日誌排序、定時任務、憑證驗證、雙重驗證和 HTTPS 通訊都非常重要。

![Time](/images/zh-Hant/app-guide/settings-img/time.png)

## 時區

| 選項 | 說明 |
| --- | --- |
| Timezone | 選擇裝置所在時區，例如 `(UTC+08:00) Beijing, Chongqing, Hong Kong, Urumqi`。 |
| 搜尋/篩選 | 時區下拉方塊可搜尋城市或 UTC 偏移，快速定位目標時區。 |

如果裝置部署地區與使用者所在地不同，建議依裝置實際所在地設定時區，避免任務執行時間與本機預期偏差。

## 時間

### 自動同步

| 選項 | 說明 |
| --- | --- |
| Auto Sync | 由 NTP 伺服器定期校準系統時間。推薦日常使用。 |
| NTP 伺服器 | 可選擇 `pool.ntp.org`、`time.google.com`、`time.cloudflare.com`、`time.apple.com`、`time.windows.com`、`time.nist.gov`、`ntp.tencent.com`、`ntp.aliyun.com` 等，也可輸入自訂 NTP 位址。 |
| 目前時間 | 頁面即時顯示目前系統時間。 |

<Callout title="提示" type="info">
  若裝置無法存取所選 NTP 伺服器，請檢查 DNS、防火牆輸出規則和 UDP 123 連接埠。中國大陸網路環境下可優先嘗試 NTP 服務供應商提供的位址。
</Callout>

### 手動設定

| 選項 | 說明 |
| --- | --- |
| Manual Set | 手動指定日期和時間。 |
| Date | 選擇日期，格式如 `2026-10-14`。 |
| Time | 輸入時間，格式如 `17:46:26`。 |
| 警告提示 | 系統提醒確保時間準確；偏差過大可能導致網路請求失敗或服務異常。 |

手動設定適合隔離網路或無法存取 NTP 的環境。設定完成後點擊 **套用** 儲存。

<Callout title="注意" type="warn">
  不要把時間設定到憑證有效期限之外或與真實時間相差過大，否則 HTTPS、遠端存取、更新檢查和二次驗證可能出現失敗。
</Callout>

## NTP 與手動選擇

| 情境 | 推薦 |
| --- | --- |
| 可存取網際網路 | 自動同步。 |
| 隔離內網 | 手動設定，或接入內網 NTP 伺服器。 |
| 時間偏差導致憑證失敗 | 先切換可用 NTP，確認時間回到憑證有效範圍。 |
| 定時任務執行偏差 | 檢查時區和 NTP，不要只改時間。 |
| 跨時區團隊 | 依裝置實際所在時區設定，日誌時間保持一致。 |

## 時間異常影響

| 功能 | 可能影響 |
| --- | --- |
| HTTPS/憑證 | 憑證未生效或已過期驗證失敗。 |
| 雙重驗證/OTP | 動態碼時間視窗不符。 |
| 日誌稽核 | 事件順序和發生時間不可靠。 |
| 定時任務 | 開關機、備份任務提前或延後。 |
| 雲端同步/API | 請求簽章或權杖驗證失敗。 |
| 更新檢查 | 更新來源可能拒絕請求。 |

## 疑難排解建議

1. 先確認時區，再確認時間；兩個錯誤疊加會難以判斷。
2. NTP 不生效時測試 DNS 和 UDP 123 輸出。
3. 更換 NTP 服務供應商後等待一次同步週期。
4. 手動設定後立即套用，不要長時間停留在臨時時間。
5. 修改時間後重新登入用戶端，重新整理工作階段和快取。
