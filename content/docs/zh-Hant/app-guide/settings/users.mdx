使用者管理頁分為 **使用者** 與 **使用者群組** 兩個標籤。管理員可以在此建立本機帳號、控制帳號狀態、設定角色和可存取儲存空間，也可以透過使用者群組批次組織成員。

## 使用者標籤

### 頁面配置

- **左側使用者列表**：顯示所有使用者，支援依使用者名稱搜尋；列表會顯示大頭貼、使用者名稱、角色與狀態。
- **右側使用者詳情**：顯示所選使用者的基本資訊、可存取儲存空間與所屬使用者群組。
- **新增使用者**：在左側列表上方點擊新增按鈕，建立本機帳號。

![Users](/images/zh-Hant/app-guide/settings-img/users.png)

### 使用者角色與狀態

| 選項 | 值 | 權限/影響 |
| --- | --- | --- |
| 角色 | 管理員 | 可登入系統設定並管理系統設定、使用者、儲存、安全與應用程式。 |
| 角色 | 一般使用者 | 使用授權範圍內的檔案與應用程式功能，不能管理系統設定。 |
| 狀態 | 啟用 | 使用者可以正常登入。 |
| 狀態 | 停用 | 使用者無法登入裝置；既有共享、任務或檔案權限不會立即代表資料被刪除。 |

### 建立或編輯使用者

建立和編輯使用者時可能涉及以下資訊：

| 欄位/功能 | 說明 |
| --- | --- |
| 使用者名稱 | 支援指定長度內的英文字母、數字和 `-`；`-` 不能放在開頭或結尾，且部分保留名稱不可使用。 |
| 大頭貼 | 上傳或更換使用者大頭貼；圖片需符合格式與大小限制。 |
| 登入密碼/新密碼 | 支援 6~30 位字母、數字及 `@#*-_`，需同時包含字母和數字。 |
| 確認密碼 | 再次輸入密碼，兩次輸入必須一致。 |
| 編輯使用者資訊 | 修改大頭貼、使用者名稱、角色、狀態等基本資料。 |
| 修改密碼 | 為使用者設定新密碼；修改後需使用新密碼登入。 |
| 設為管理員 | 將一般使用者提升為管理員。提升前系統會要求確認。 |
| 停用/啟用 | 暫時禁止或恢復使用者登入，不等於刪除使用者。 |
| 刪除使用者 | 刪除帳號及其個人資料夾中的資料。系統會提示不可還原，請先確認沒有依賴該使用者的任務或共享。 |

### 可存取儲存空間

在使用者詳情的 **可存取儲存空間** 中點擊 **編輯**，可設定使用者可使用的儲存卷和容量：

| 欄位 | 說明 |
| --- | --- |
| 儲存空間 | 顯示卷名稱、已使用容量、總容量與該使用者的最大可用容量。 |
| 最大可用容量 | 可選擇 `Unlimited`，或輸入具體配額。配額不能超過儲存卷可用範圍。 |
| 儲存 | 儲存後立即更新使用者可寫入範圍。配額只限制該使用者的可寫入容量，不代表資料已佔用。 |

<Callout title="注意" type="warn">
  刪除使用者會同時刪除該使用者個人資料夾下的資料，且操作不可還原。刪除前請先遷移團隊檔案、備份個人資料，並確認備份任務、分享連結、同步任務和應用程式權限不再依賴該帳號。
</Callout>

## 使用者群組標籤

### 頁面配置

- **左側群組列表**：顯示所有使用者群組與成員數量，支援搜尋；內建群組如 Admin、Standard User 不可隨意刪除。
- **右側群組詳情**：顯示群組名稱、備註、成員列表與成員角色。
- **新增使用者群組**：建立自訂使用者群組。
- **新增成員**：從現有使用者中選擇一個或多個使用者加入群組。
- **編輯使用者群組**：修改群組名稱、備註或成員。
- **刪除使用者群組**：刪除自訂群組；刪除群組通常不刪除成員帳號，但會影響基於群組授權的資源存取。

### 常用欄位

| 欄位 | 說明 |
| --- | --- |
| 使用者群組名稱 | 用於識別群組，建議依部門、家庭角色或專案命名。 |
| 備註 | 選填，記錄群組用途或授權範圍。 |
| 成員 | 群組內使用者列表，可搜尋。 |
| 成員角色 | 顯示成員在系統中的角色，例如 Admin。 |

<Callout title="建議" type="info">
  當多個使用者需要相同檔案或應用程式權限時，優先使用使用者群組授權。後續只需要調整群組成員，不必逐一修改每個帳號。
</Callout>

## 新增使用者完整流程

| 步驟 | 操作 | 關鍵檢查 |
| --- | --- | --- |
| 1 | 點擊 **新增使用者** | 開啟新增使用者精靈。 |
| 2 | 填寫基礎資訊 | 使用者名稱符合格式；密碼同時包含字母和數字；兩次密碼一致。 |
| 3 | 設定大頭貼 | 僅選擇圖片檔案，大小不超過 2 MB。 |
| 4 | 選擇使用者類型/角色 | 日常使用優先一般使用者，避免所有人都擁有管理員權限。 |
| 5 | 設定可存取儲存空間 | 明確哪些卷可寫入，並決定是否限制容量。 |
| 6 | 設定所屬使用者群組 | 將使用者加入依部門、家庭角色或專案劃分的群組。 |
| 7 | 確認並建立 | 檢查配額、角色和個人資料刪除提示。 |

## 權限與資料影響

| 操作 | 立即影響 | 資料影響 | 可恢復性 |
| --- | --- | --- | --- |
| 修改密碼 | 該帳號所有裝置登出。 | 不刪除資料。 | 可再次修改。 |
| 停用使用者 | 使用者無法登入；相關工作階段不可繼續使用。 | 保留使用者資料。 | 可重新啟用。 |
| 設為管理員 | 可存取系統設定並管理系統。 | 不刪除資料，但權限顯著擴大。 | 可移除管理員身分。 |
| 移出使用者群組 | 群組授權的共享或應用程式權限隨之變化。 | 不刪除個人資料夾。 | 可重新加入群組。 |
| 刪除使用者 | 帳號不可登入。 | 個人資料夾下所有資料會被刪除。 | 不可還原。 |
| 刪除使用者群組 | 群組成員解散。 | 通常不刪除成員帳號，但群組授權失效。 | 需重建群組並重新授權。 |

## 儲存配額建議

- **家庭裝置**：可為每位成員設定配額，避免個人照片和影片佔滿共享卷。
- **團隊裝置**：依部門或專案群組統一容量策略，再對特殊情況單獨調整。
- **備份使用者**：依備份來源資料大小預留餘量，並定期檢查已使用容量。
- **應用程式專用帳號**：建議限制容量，防止應用程式日誌或快取無限成長。

配額只限制該使用者在此儲存卷上的可寫入容量；既有檔案、團隊檔案和系統資料可能分別統計，頁面顯示的已使用容量以實際儲存統計為準。

## 排查建議

| 問題 | 檢查方向 |
| --- | --- |
| 使用者無法登入 | 帳號是否停用、密碼是否修改、IP 是否被安全性中的防護規則封鎖。 |
| 使用者看不到共享目錄 | 可存取儲存空間、使用者群組成員關係、檔案共享協定可見目錄範圍。 |
| 寫入提示空間不足 | 使用者配額、儲存卷剩餘容量、硬碟是否唯讀或降級。 |
| 權限沒有隨群組變化生效 | 用戶端快取或工作階段未重新整理，可重新登入或重新連線檔案服務。 |
