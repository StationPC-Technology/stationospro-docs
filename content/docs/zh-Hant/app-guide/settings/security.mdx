安全性頁包含 **連接埠設定**、**帳號安全**、**防護**、**防火牆**、**憑證**、**裝置分析** 六個標籤，用於收緊系統入口、控制存取來源、加密傳輸並檢視隱私相關開關。

## 連接埠設定

![Port Settings](/images/zh-Hant/app-guide/settings-img/security-port-settings.png)

### 目前資訊

頁面顯示目前 Web 管理入口連接埠：

| 欄位 | 預設值 | 說明 |
| --- | --- | --- |
| HTTP 連接埠 | 9500 | 使用 HTTP 存取管理端。 |
| HTTPS 連接埠 | 9501 | 使用 HTTPS 存取管理端。 |

### 連接埠設定彈出視窗

| 選項 | 說明 |
| --- | --- |
| HTTP 連接埠號 | 必填，範圍為 1~65535，不能與 HTTPS 連接埠相同。 |
| HTTPS 連接埠號 | 必填，範圍為 1~65535。開啟強制 HTTPS 或預設連接埠重新導向時不能為 0。 |
| 強制 HTTPS 連線 | 將 HTTP 連線重新導向為 HTTPS 連線。 |
| 重新導向 80 與 443 連接埠 | 將 80 重新導向到 HTTP 連接埠、443 重新導向到 HTTPS 連接埠；啟用後存取裝置可不填連接埠號。 |

<Callout title="注意" type="warn">
  啟用預設連接埠重新導向時，HTTP/HTTPS 連接埠不能使用 80 或 443。修改連接埠後請使用新連接埠重新開啟管理端，並確認防火牆或路由器轉送規則已同步更新。
</Callout>

## 帳號安全

帳號安全頁控制系統級雙重驗證策略。

![Account Security](/images/zh-Hant/app-guide/settings-img/security-account-security.png)

| 選項 | 說明 |
| --- | --- |
| 強制使用雙重驗證 | 開啟後，受策略約束的使用者登入時必須完成第二步 OTP 驗證。 |
| 所有使用者 | 策略套用到全部使用者。 |
| 僅管理員 | 只強制管理員帳號使用雙重驗證。 |
| 指定使用者 | 只強制所選使用者或使用者群組使用雙重驗證。 |
| 編輯指定使用者 | 在使用者/使用者群組選擇器中新增或移除策略對象。 |

<Callout title="前提條件" type="info">
  雙重驗證相依郵件通知服務。開啟前請先在「系統設定 → 通知設定」中設定寄件信箱。若關閉郵件服務，雙重驗證驗證碼可能無法傳送。
</Callout>

## 防護

防護頁用於自動封鎖異常登入 IP，並維護允許清單與封鎖清單。

![Protection](/images/zh-Hant/app-guide/settings-img/security-protection.png)

### 封鎖異常 IP

| 選項 | 說明 |
| --- | --- |
| 服務開關 | 開啟後，系統依規則攔截異常 IP 登入。 |
| 編輯規則 | 設定自動封鎖閾值、統計時間與解除封鎖時間。 |

### 自動封鎖規則

| 欄位 | 預設值 | 範圍 | 說明 |
| --- | --- | --- | --- |
| 嘗試登入次數 | 10 次 | 1~100 | 觸發封鎖所需失敗次數。 |
| 設定時間內 | 5 分鐘 | 1~10080 分鐘 | 統計失敗次數的時間視窗。 |
| 自動解除封鎖規則 | 1 小時 | 30 分鐘/1 小時/1 天/7 天/30 天/永久 | 被封鎖 IP 的解除封鎖時間。 |

### 允許清單與封鎖清單

| 清單 | 優先級與作用 |
| --- | --- |
| 允許清單 | 清單內 IP/CIDR 始終允許連線和登入，不受封鎖規則影響，優先級高於封鎖清單。 |
| 封鎖清單 | 清單內 IP/CIDR 始終被限制連線和登入。 |

清單表格顯示用戶端 IP、最近存取時間、過期時間（封鎖清單）、永久標示與備註。支援：

| 操作 | 說明 |
| --- | --- |
| 新增 | 輸入一個或多個 IP/CIDR，多個位址用換行或逗號分隔；封鎖清單可選擇解除封鎖時間。 |
| 備註 | 最多 180 個字元，用於標記來源或用途。 |
| 刪除 | 選取一筆或多筆記錄後刪除，解除對應限制。 |

## 防火牆

防火牆頁依輸入和輸出規則控制網路流量。

![Firewall](/images/zh-Hant/app-guide/settings-img/security-firewall.png)

### 基礎設定

| 選項 | 說明 |
| --- | --- |
| 防火牆開關 | 開啟後，系統依輸入/輸出規則控制流量。 |
| 進階設定 | 設定工作模式與區域網路預設放行。 |

### 進階設定

| 選項 | 說明 |
| --- | --- |
| 工作模式 | Auto 優先選擇 XDP native 模式；Generic 使用傳統核心網路堆疊。出現相容性問題時可切換。 |
| 區域網路 | 「預設允許存取」開啟後，區域網路流量預設放行，可降低管理端被誤攔截的機率。 |

### 輸入規則與輸出規則

| 欄位 | 說明 |
| --- | --- |
| 網路連線 | 所有介面或指定網路介面。 |
| 連接埠 | 單一連接埠、逗號分隔連接埠或範圍，例如 `80`、`443`、`1-65535`。 |
| 協定 | 全部、TCP、UDP、ICMP。 |
| 來源 IP / 目標 IP | 自訂 IP 或 CIDR；輸入看來源 IP，輸出看目標 IP。 |
| 權限 | 允許或拒絕。 |
| 狀態 | 生效或停用。 |
| 備註 | 規則用途說明。 |
| 順序 | 規則可拖曳排序，越靠前優先級越高。 |
| 若下列規則均不符合時 | 設定預設允許存取或預設拒絕存取。 |

<Callout title="危險操作" type="error">
  錯誤的防火牆規則可能導致管理端、遠端存取或應用程式服務無法連線。設定前建議保留目前管理連線，並優先放行管理連接埠、SSH 連接埠和區域網路。
</Callout>

## 憑證

憑證頁用於管理系統 HTTPS、FTPS、WebDAV 與遠端存取使用的憑證。

![Certificate](/images/zh-Hant/app-guide/settings-img/security-certificate.png)

### 憑證列表

| 欄位 | 說明 |
| --- | --- |
| 憑證名稱 | 使用者可辨識的名稱。 |
| 憑證類型 | 系統自簽章憑證、Let's Encrypt 憑證或匯入憑證。 |
| 發證機構 | 憑證簽發者。 |
| 備用網域名稱 | 憑證涵蓋的其他網域名稱；無則顯示 `-`。 |
| 有效期限 | 到期時間。 |
| 自動續約 | 系統憑證或 Let's Encrypt 憑證可在到期前自動續約。 |
| 狀態 | 有效、即將過期、已過期。 |
| 操作 | 檢視/編輯詳情、更新、下載、刪除。刪除後不可還原。 |

### 新增憑證

| 方式 | 說明 |
| --- | --- |
| 匯入憑證 | 從本機上傳或 NAS 選擇憑證檔案、私密金鑰檔案與可選中繼憑證。適合已有 CA 簽發憑證的使用者。 |
| 取得憑證 | 從 Let's Encrypt 取得免費憑證，並自動續約。需填寫信箱，選擇 DDNS 網域名稱或自訂網域名稱與服務供應商。 |

### 取得 Let's Encrypt 憑證注意事項

- 免費憑證存在申請頻率與數量限制。
- HTTP 驗證需將 80 連接埠轉送到 NAS；DNS 驗證需服務供應商支援。
- 網域名稱必須正確指向目前公網 IP。
- 取得成功後系統會在憑證到期前自動續約。

### 服務設定

**Service Config** 用於為 FTPS、WebDAV 和遠端存取憑證選擇對應憑證。確認後相關服務將使用所選憑證建立加密連線。

## 裝置分析

裝置分析頁包含兩個隱私相關開關。

![Device Analytics](/images/zh-Hant/app-guide/settings-img/security-device-analytics.png)

| 選項 | 說明 |
| --- | --- |
| 加入裝置分析改進計畫 | 系統會收集部分匿名使用資料，用於分析產品使用、提升穩定性與改進功能。可隨時退出。 |
| 啟用 webfind 服務 | 開啟後可在區域網路內發現 Station OS 裝置。系統會收集 IP 位址和連接埠資訊以提供該服務。 |

兩項說明均連結隱私權政策。若不希望參與資料收集或對外提供區域網路發現能力，可關閉對應開關。

<Callout title="安全基準建議" type="info">
  建議啟用 HTTPS/強制 HTTPS、雙重驗證、異常 IP 防護和防火牆；僅開放必要連接埠；為憑證設定自動續約；外網存取優先使用 Station ID 或 VPN。
</Callout>

## 連接埠策略建議

| 情境 | 建議 |
| --- | --- |
| 家庭區域網路 | 可保留 HTTP/HTTPS，僅在可信裝置儲存登入狀態。 |
| 公網或共享網路 | 啟用 HTTPS/強制 HTTPS，避免明文提交密碼。 |
| 只想省略連接埠 | 啟用 80/443 重新導向，但確保路由器和防火牆規則同步。 |
| 更換預設連接埠 | 選擇 1024–65535 中未佔用連接埠，不要與 SMB/FTP/SSH 衝突。 |
| 遠端存取 | 優先使用 Station ID 或 VPN，不直接暴露管理連接埠。 |

## 雙重驗證策略對比

| 範圍 | 優點 | 適用 |
| --- | --- | --- |
| 所有使用者 | 安全基準最高。 | 存在敏感檔案或多人使用的裝置。 |
| 僅管理員 | 兼顧安全與一般使用者便利。 | 家庭裝置或一般帳號權限較低。 |
| 指定使用者 | 對高風險帳號精準管控。 | 僅備份、財務、維運等特殊帳號。 |

策略開啟後，指定範圍內的使用者必須在個人設定中完成驗證器或信箱驗證設定；管理員應先確認郵件服務可用。

## IP 防護設計建議

- **允許清單**：固定辦公網路、家庭出口、VPN 出口、堡壘機位址。
- **封鎖清單**：反覆嘗試登入的來源、失陷網段、明確掃描來源。
- **閾值**：家庭裝置可較嚴格；多人使用或代理出口環境應避免過小閾值。
- **解除封鎖時間**：關鍵裝置可設定較長；臨時網路可選擇短時間便於恢復。
- **VPN 提醒**：出口 IP 變化會影響偵測結果，必要時用固定出口或自訂偵測位址。

## 防火牆規則設計流程

1. 先放行管理連接埠、SSH 連接埠和區域網路網段。
2. 明確輸入服務及連接埠，例如 HTTPS、WebDAV、FTPS。
3. 依來源 IP、協定和連接埠建立最小範圍規則。
4. 使用拒絕規則阻擋明確不需要的來源。
5. 拖曳調整優先級，越靠前越先比對。
6. 設定預設策略；不熟悉防火牆時先保持允許存取，驗證規則後再收緊。
7. 保留一個已連線管理工作階段，直到確認新規則可靠。

## 憑證疑難排解

| 問題 | 檢查 |
| --- | --- |
| 瀏覽器提示憑證網域名稱不符 | 存取網域名稱與憑證備用網域名稱是否一致。 |
| Let's Encrypt 申請失敗 | 網域名稱解析、80 連接埠轉送、API 權限、頻率限制。 |
| HTTPS 無法存取 | HTTPS 連接埠、防火牆、服務設定是否選擇憑證。 |
| 憑證未自動續約 | 系統時間、DNS 解析、80/443 可達性。 |
| 匯入後用戶端不信任 | 缺少中繼憑證或使用自簽章憑證。 |
