SSH 頁用於開啟或關閉遠端命令列服務。管理員可透過 SSH 執行診斷命令、排查系統問題；SFTP 開啟後還可透過 SSH 通道傳輸檔案。

![SSH](/images/zh-Hant/app-guide/settings-img/ssh.png)

## 基礎設定

| 選項 | 說明 |
| --- | --- |
| 啟用 | 開啟 SSH 服務。關閉後無法透過 SSH/SFTP 連線裝置。 |
| 連接埠 | SSH 監聽連接埠，預設 22。可改為其他未被佔用的連接埠以減少掃描暴露。 |
| 有效期限 | 服務保持開啟的時間，可選 10 分鐘、30 分鐘、1 小時、3 小時、6 小時或永久。短期開啟適合臨時疑難排解，到期後自動關閉。 |
| 進階設定 | 設定加密演算法強度、存取範圍與 SFTP。 |
| 套用 | 儲存連接埠、有效期限和進階設定修改。 |

## 進階設定

| 選項 | 說明 |
| --- | --- |
| 加密演算法 | 可選高、中、低。建議使用「高」；僅在舊用戶端無法協商連線時才降低強度。 |
| 存取限制 | **僅區域網路**開啟後，SSH 只接受區域網路連線，禁止來自網際網路的遠端 SSH 存取。 |
| SFTP | 開啟後可透過 SFTP 用戶端使用 SSH 帳號傳輸檔案。關閉後僅保留命令列 SSH。 |

## 連線範例

1. 在電腦開啟終端機或 SSH 用戶端。
2. 輸入 `ssh 使用者名稱@裝置IP -p 連接埠`。
3. 使用裝置本機帳號密碼登入。
4. 如使用 SFTP，用戶端協定選擇 SFTP，位址填寫裝置 IP，連接埠填寫目前 SSH 連接埠。

<Callout title="安全建議" type="warn">
  - 不要長期對公網開放 SSH；確需遠端維護時使用短期有效期限，並開啟僅區域網路或透過 VPN 存取。
  - 避免使用 22 等預設連接埠、弱密碼或將管理員密碼分享給不可信人員。
  - SSH 命令可直接修改系統狀態，執行來源不明的命令可能導致服務異常或資料遺失。
</Callout>

## 使用模式建議

| 情境 | 推薦設定 |
| --- | --- |
| 臨時技術支援 | 10/30 分鐘，僅區域網路。 |
| 日常內網維護 | 永久 + 僅區域網路，保持高加密強度。 |
| 遠端疑難排解 | 透過 VPN 或 Station ID 遠端存取進入內網，再開啟短期 SSH。 |
| 需要傳檔案 | 開啟 SFTP，使用受控帳號和明確目錄。 |
| 舊用戶端無法連線 | 先確認帳號密碼和連接埠；確實不支援新演算法時再臨時降低加密等級。 |

## 操作流程

1. 確認必須使用命令列維護，優先考慮網頁管理介面。
2. 設定非預設連接埠和短期有效期限。
3. 開啟進階設定，保持高加密演算法。
4. 開啟僅區域網路，依需求開啟 SFTP。
5. 點擊套用並用用戶端測試。
6. 完成維護後關閉 SSH。

## 疑難排解

| 現象 | 檢查 |
| --- | --- |
| Connection refused | SSH 未開啟、連接埠錯誤、服務未監聽。 |
| Timeout | 防火牆、路由、僅區域網路限制、IP 不通。 |
| Auth failed | 使用者名稱/密碼錯誤、使用者停用、權限不足。 |
| 演算法協商失敗 | 用戶端過舊，或加密演算法不相容。 |
| SFTP 可連但無法寫入 | 目錄權限、儲存卷唯讀、使用者配額已滿。 |
