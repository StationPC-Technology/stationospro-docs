AI 模型頁分為 **基礎能力**、**模型管理**、**儲存位置** 三個標籤。這裡控制全域搜尋與 Station AI 使用的本機辨識能力、大型語言模型檔案，以及模型和索引資料的儲存位置。

## 基礎能力

基礎能力頁管理全域搜尋與內容辨識所需的 AI 能力模組。

![AI Basic Capabilities](/images/zh-Hant/app-guide/settings-img/ai-models.png)

### 能力模組

| 能力 | 功能 | 關閉影響 |
| --- | --- | --- |
| 臉部辨識 | 辨識人物並分組，支援臉部搜尋和智慧相簿。 | 臉部搜尋、人物分組等能力不可用。 |
| 文字辨識 | 辨識圖片中的文字，可透過關鍵字定位圖片內容。 | 圖片 OCR 與圖片文字搜尋能力受限。 |
| 檔案辨識 | 索引檔案名稱、路徑、文件內容與語意，提升全域搜尋效果。 | 文件內容與語意搜尋能力受限。 |
| 視覺內容辨識 | 辨識圖片/影片中的場景與物體，並用於內容比對搜尋。 | 以圖搜圖、場景/物體搜尋能力受限。 |

### 狀態與索引資訊

文字辨識、檔案辨識、視覺內容辨識等模組會顯示：

| 欄位 | 說明 |
| --- | --- |
| 已辨識檔案 | 已完成索引的檔案數量。 |
| 索引失敗 | 無法建立索引的檔案數量。可能是檔案損壞、格式不支援、權限異常或儲存暫時無法使用。 |
| 最近索引時間 | 最近一次完成索引的時間。 |
| 能力狀態 | 正常、已停用、安裝中、更新中、重建中、遷移中、異常、低空間暫停等。 |
| 維護操作 | 可依能力安裝、更新、啟用/停用、修復或重建索引。 |

<Callout title="提示" type="info">
  首次開啟能力後需要建立索引，耗時取決於檔案數量、文件類型和儲存效能。索引期間可繼續使用裝置，但搜尋結果可能不完整。
</Callout>

## 模型管理

模型管理頁用於下載、啟用、更新和解除安裝本機大型模型，也可管理 OpenAI 相容 API 存取。

![AI Model Management](/images/zh-Hant/app-guide/settings-img/ai-model-management.png)

### 模型卡片

每個模型顯示：

| 欄位 | 說明 |
| --- | --- |
| 模型名稱 | 例如 Qwen3.5-0.8B、Qwen3-8B、Gemma4-E4B 等。 |
| 類型 | Text Generation、Any-to-Any 等模型能力類型。 |
| 大小 | 模型檔案預計佔用空間。 |
| 狀態 | 未下載、下載中、已下載、目前使用中等。 |
| 啟用/停用 | 控制該模型是否出現在可用模型列表。 |
| 解除安裝/刪除 | 刪除本機模型檔案；刪除後需要時可重新下載。 |
| 設定模型 | 檢視或修改模型相關設定。 |

### API 存取

點擊 **API Access** 可以管理 OpenAI 相容介面存取：

| 功能 | 說明 |
| --- | --- |
| API 位址 | 展示本機模型或服務的存取位址。 |
| API Key | 建立、檢視、更新或刪除存取金鑰。 |
| 呼叫說明 | 可用於相容 OpenAI API 的第三方應用程式或開發指令碼。 |

<Callout title="注意" type="warn">
  刪除本機模型會永久清除該模型全部本機檔案。若目前正在使用該模型，系統可能切換到其他可用模型或 OpenAI 相容 API。
</Callout>

## 儲存位置

儲存位置頁管理本機模型和索引資料的儲存位置，並提供低空間保護。

![AI Storage](/images/zh-Hant/app-guide/settings-img/ai-model-storage.png)

### 本機模型儲存

| 欄位/操作 | 說明 |
| --- | --- |
| 目前儲存卷 | 顯示卷名稱、RAID 類型和可用容量。 |
| 更換儲存 | 將本機大型模型檔案遷移到其他儲存卷。遷移過程中本機模型暫時不可用。 |
| 狀態 | 正常、空間偏低、唯讀、不可用、遷移中等。 |

### 索引資料儲存

| 欄位 | 說明 |
| --- | --- |
| 狀態 | 索引池整體健康狀態。 |
| 檔案索引 | 檔案名稱、路徑等基礎索引佔用。 |
| 文字內容 | OCR 與文件文字/向量資料佔用。 |
| 圖片內容 | 圖片視覺向量資料佔用。 |
| 可用空間 | 目前索引儲存剩餘空間。 |
| 低空間閾值 | 觸發保護的空間閾值，目前範例為低於 10 GB 時暫停任務。 |
| 更換儲存 | 遷移索引資料到其他儲存位置。 |

### 低空間保護

開啟後，當可用空間低於設定閾值時，系統會自動暫停模型下載和索引重建任務，避免儲存被寫滿導致服務異常。空間恢復後可手動繼續任務。

<Callout title="建議" type="info">
  大型模型和索引資料會隨檔案數量成長而增加。建議將模型和索引放在容量充足、狀態健康的 SSD 儲存卷上，並保持低空間保護開啟。
</Callout>

## 能力狀態與處理

| 狀態 | 含義 | 建議 |
| --- | --- | --- |
| 正常 | 能力可用。 | 保持模型更新，定期重建索引。 |
| 已停用 | 管理員或使用者關閉該能力。 | 需要時重新開啟。 |
| 安裝/更新中 | 正在下載或更新相依元件與模型。 | 保持網路和儲存可用。 |
| 重建中 | 正在重建索引資料。 | 等待完成，避免大量移動檔案。 |
| 遷移中 | 模型或索引正在遷往新卷。 | 本機模型可能暫不可用。 |
| 低空間暫停 | 剩餘空間低於閾值。 | 清理空間或遷移到更大卷。 |
| 唯讀 | 儲存位置唯讀。 | 檢查卷狀態並更換儲存位置。 |
| 異常/失敗 | 相依元件、儲存或服務異常。 | 檢視日誌中心，嘗試修復或重建。 |

## 索引維護建議

| 操作 | 適用情況 |
| --- | --- |
| 安裝/更新全部 | 首次啟用能力，或能力有新版本。 |
| 修復 | 索引狀態異常、部分檔案無法搜尋。 |
| 重建索引 | 大量檔案移動、索引儲存遷移後結果不完整。 |
| 停用能力 | 不需要臉部、OCR、文件語意或視覺搜尋。 |
| 遷移儲存 | 目前卷空間不足或更換更快的 SSD。 |

<Callout title="索引範圍" type="info">
  索引只作用於系統可讀取且有權限存取的檔案。加密檔案、暫不支援的格式、損壞檔案或權限不足的目錄可能出現在索引失敗統計中。
</Callout>

## 模型選擇與維護

| 項目 | 建議 |
| --- | --- |
| 小參數模型 | 佔用更小、回應更快，適合輕量問答和低規格裝置。 |
| 大參數模型 | 理解和產生能力更強，但佔用記憶體/儲存更多，回應可能更慢。 |
| Any-to-Any 模型 | 適合需要多種輸入輸出形態的情境，下載體積通常更大。 |
| 本機模型 | 資料不出裝置，適合隱私情境；受硬體算力限制。 |
| OpenAI 相容 API | 可接入外部服務，需設定 Base URL、模型名稱和 API Key。 |
| 刪除模型 | 釋放空間；後續可重新下載，但會消耗流量和時間。 |

## API Access 使用注意

- API Key 只儲存必要憑證，不要提交到程式碼倉庫或公開分享。
- 呼叫位址應只暴露給可信內網或經過反向代理/防火牆限制的用戶端。
- 若 Key 外洩，立即刪除或更新 Key。
- 外部呼叫仍受裝置負載、模型狀態和儲存空間影響。

## 儲存遷移注意事項

1. 遷移前確認目標卷容量大於模型與索引資料合計大小，並預留成長空間。
2. 遷移期間不要修改模型設定或重新啟動裝置。
3. 本機模型遷移完成前，聊天功能可能暫時不可用。
4. 索引遷移後建議執行一次搜尋驗證，必要時重建索引。
