系統設定是 StationOS Pro 的控制中心，集中管理裝置資訊、使用者、儲存、網路、遠端存取、安全策略、硬體電源與系統更新等核心設定。該應用程式通常需要管理員權限存取；不同型號、韌體版本與已安裝硬體不同，可見選項可能存在差異，請以裝置實際介面為準。

## 進入系統設定

1. 登入 StationOS Pro 桌面。
2. 在 Dock 列或應用程式啟動器中開啟 **系統設定**。
3. 在左側標籤列選擇需要設定的功能模組。

![Settings window](/images/zh-Hant/app-guide/settings-img/device-info.png)

左側標籤列依功能分為以下 14 個模組：

| 模組 | 主要用途 | 適用情境 |
| --- | --- | --- |
| 裝置資訊 | 檢視裝置名稱、Station ID、版本、硬體、序號與網路資訊 | 確認裝置身分、排查連線、聯絡售後 |
| 使用者管理 | 管理本機使用者、角色、狀態、使用者群組與儲存配額 | 為家人或團隊成員分配帳號與空間 |
| 儲存空間 | 建立和管理儲存卷、RAID、熱備碟與 SSD 快取 | 初始化硬碟、擴充容量、提升讀寫效能 |
| 硬碟 | 檢視硬碟詳情與健康狀態，格式化或安全移除硬碟 | 硬碟巡檢、更換、故障排查 |
| 檔案共享協定 | 設定 SMB、WebDAV、FTP、NFS 與 Time Machine | 讓電腦、手機、電視盒等裝置存取 NAS 檔案 |
| AI 模型 | 管理基礎 AI 能力、本機模型與索引資料儲存位置 | 開啟臉部/文字/檔案/視覺辨識，控制模型空間 |
| 網路設定 | 設定閘道、DNS、網路卡、橋接與鏈路聚合 | 修改 IP、多網路埠負載、網路備援 |
| 遠端存取 | 設定 Station ID 遠端存取與 DDNS | 從網際網路或自有網域名稱存取裝置 |
| SSH | 開啟或關閉 SSH/SFTP 遠端終端機服務 | 遠端維護、命令列管理、安全管控 |
| 安全性 | 設定存取連接埠、雙重驗證、IP 防護、防火牆、憑證與資料分析 | 收緊系統入口、阻擋可疑存取、啟用 HTTPS |
| 通知設定 | 設定郵件通知服務與通知語言 | 接收驗證碼、重設密碼與系統通知郵件 |
| 硬體與電源 | 管理蜂鳴器、風扇、記憶體壓縮、電源計畫與硬碟休眠 | 控制噪音、散熱、自動開關機與能耗 |
| 時間與時區 | 設定時區、NTP 自動同步或手動時間 | 確保日誌、憑證、任務排程時間正確 |
| 更新與還原 | 檢查/安裝系統更新、檢視更新日誌、恢復原廠或重設網路 | 升級系統、修復網路設定、恢復預設設定 |

<Callout title="操作建議" type="info">
  涉及儲存卷、RAID、格式化、防火牆、連接埠、恢復原廠和重設網路的操作可能影響資料或連線。修改前請確認業務影響，並為重要資料保留備份。
</Callout>

## 功能分組與操作風險

| 分類 | 模組 | 主要風險 |
| --- | --- | --- |
| 唯讀資訊 | 裝置資訊 | 基本無風險；修改裝置名稱會影響識別方式。 |
| 帳號與授權 | 使用者管理 | 刪除使用者會刪除個人資料；提升管理員會擴大系統控制權。 |
| 資料結構 | 儲存空間、硬碟 | 建立、修改、格式化、更換硬碟可能刪除資料或降低備援。 |
| 服務入口 | 檔案共享協定、SSH、安全性 | 開啟協定或連接埠會增加暴露面；錯誤的防火牆/連接埠設定可能中斷管理連線。 |
| 網路與遠端存取 | 網路設定、遠端存取 | 修改 IP、橋接、聚合、DDNS 可能導致目前連線中斷。 |
| 系統維護 | 硬體與電源、時間與時區、更新與還原 | 重新啟動、重設、錯誤時間或中斷更新可能影響服務可用性。 |

## 管理員操作清單

執行高風險操作前建議確認：

1. 重要資料已有獨立備份，且備份可還原。
2. 目前有區域網路或主控台恢復路徑，不只依賴正在修改的遠端連線。
3. 儲存卷健康狀態正常，硬碟沒有降級、損壞或唯讀告警。
4. 已通知相關使用者停止寫入檔案、備份、下載、容器和索引任務。
5. 裝置供電穩定；機械硬碟、SSD 快取和系統更新期間不要強制斷電。
6. 記錄修改前的 IP、連接埠、DNS、防火牆規則、Station ID 和版本號。
