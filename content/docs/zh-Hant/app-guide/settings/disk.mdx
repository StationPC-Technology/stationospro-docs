硬碟頁用於檢視裝置識別到的內建硬碟與外接硬碟。你可以在這裡確認硬碟容量、介面、溫度和通電時間，也可以進入健康詳情執行 S.M.A.R.T 檢測，或對未使用硬碟執行格式化、安全移除等維護操作。

## 硬碟列表

頁面頂部提供三個篩選標籤：

| 標籤 | 說明 |
| --- | --- |
| 全部 | 同時顯示內建硬碟與外接硬碟；「全部」檢視中會依內建硬碟、外接硬碟分組。 |
| 內建 | 只顯示裝置內部安裝的硬碟。 |
| 外接 | 只顯示 USB 等外接儲存裝置。 |

![Disk](/images/zh-Hant/app-guide/settings-img/disk.png)

## 硬碟卡片資訊

每顆硬碟卡片顯示：

| 欄位 | 說明 |
| --- | --- |
| 硬碟名稱 | 系統分配的識別名稱，例如 DiskA、Disknvme0n1。 |
| 用途/所屬儲存空間 | 顯示閒置、未掛載、所屬儲存卷、快取池等用途。 |
| 總容量 | 硬碟可用總容量。 |
| 硬碟類型 | HDD、SSD 等。 |
| 健康狀態 | 正常、異常、警告或未知。 |
| 型號 | 硬碟廠商型號。 |
| 介面 | SATA、NVMe、USB 等。 |
| 序號 | 硬碟唯一序號，可點擊複製。 |
| 供應商 | 硬碟品牌或廠商。 |
| 溫度 | 目前硬碟溫度。溫度持續過高會增加故障風險。 |
| 通電時間 | 硬碟累計通電時長，可用於評估使用年限。 |
| 分割區 | 外接或未完全佔用硬碟可能顯示分割區資訊。 |

## 硬碟操作

在硬碟卡片右側點擊更多按鈕，可用操作取決於硬碟目前用途：

| 操作 | 適用對象 | 說明 |
| --- | --- | --- |
| 格式化硬碟 | 閒置硬碟、外接硬碟或未使用分割區 | 清除硬碟資料並重新建立檔案系統。可選擇格式化整顆硬碟或指定分割區。 |
| 安全移除 | 外接硬碟 | 停止相關服務後安全移除硬碟，降低資料毀損風險。 |
| 健康詳情 | 支援健康檢測的硬碟 | 開啟 S.M.A.R.T 檢測與健康屬性頁。 |
| 停用硬碟 | 支援停用的內建成員碟 | 將硬碟從關聯儲存空間移除。停用可能影響儲存備援，需謹慎執行。 |
| 唯讀標示 | 唯讀硬碟 | 硬碟處於唯讀狀態時，格式化等寫入操作會被停用。 |

### 格式化設定

| 選項 | 可選值 | 說明 |
| --- | --- | --- |
| 格式化對象 | 整顆硬碟 / 分割區 | 選擇清除整顆硬碟或僅清除某個分割區。 |
| 格式化後的檔案系統 | exFAT / EXT4 | exFAT 適合 Windows 與 macOS 跨平台使用；EXT4 是 Linux 常用檔案系統，適合長期連接 NAS 使用。 |

<Callout title="危險操作" type="error">
  格式化會刪除目標硬碟或分割區中的所有資料，操作開始後無法終止。請勿在格式化過程中斷電、重新啟動或拔插硬碟。
</Callout>

## 硬碟健康詳情

點擊 **健康詳情** 後，可以檢視硬碟健康狀態資訊並執行檢測。

![Disk Health](/images/zh-Hant/app-guide/settings-img/disk-health.png)

### 檢測方式

| 檢測方式 | 預計時間 | 說明 |
| --- | --- | --- |
| 快速檢測 | 約 2 分鐘 | 基本診斷測試，檢測機械與電氣誤差，適合日常巡檢。 |
| 完整檢測 | 約 2 小時 30 分鐘 | 全面掃描硬碟，結果更準確，耗時更長。兩種檢測均不影響硬碟正常使用。 |

### 檢測狀態與結果

- **開始檢測**：提交檢測任務。
- **檢測中**：可檢視目前進度，並可在需要時停止檢測。
- **檢查結果**：顯示目前檢測結論。
- **S.M.A.R.T 屬性表**：展示編號、指標、結果、目前值、最差值、參考值與原始資料。臨界值由硬碟廠商定義，異常項目不一定立即代表硬碟損壞，但需要持續關注。

<Callout title="維護建議" type="warn">
  健康狀態異常、溫度持續偏高或多項 S.M.A.R.T 指標接近臨界值時，請立即備份該硬碟及關聯儲存卷中的重要資料，並儘快更換硬碟。
</Callout>

## 健康與用途標示解讀

| 標示 | 含義 | 建議 |
| --- | --- | --- |
| Normal | 硬碟健康檢測正常。 | 保持定期檢測和備份。 |
| Warning | 出現可疑屬性或溫度偏高。 | 立即備份資料並持續觀察。 |
| Abnormal/Serious | 檢測結果異常。 | 停止非必要寫入，儘快更換硬碟。 |
| Unknown | 未取得有效健康資料，或硬碟/橋接裝置不支援完整 S.M.A.R.T。 | 更換連線方式或檢視硬碟詳情。 |
| Storage volume N | 硬碟屬於該儲存卷。 | 操作前確認卷狀態和備援能力。 |
| Cache pool | 硬碟用於 SSD 快取。 | 先在儲存空間刪除快取，再移除硬碟。 |
| Unused | 硬碟未被儲存結構佔用。 | 可用於建立卷、快取或其他設定。 |
| Not mounted | 外接硬碟未掛載。 | 檢查檔案系統、連線狀態和硬碟健康。 |
| Read-only | 硬碟或檔案系統被保護性禁寫。 | 先備份資料，不要強行格式化。 |
| Formatting | 硬碟正在格式化。 | 等待完成，不要斷電或拔出。 |

## 格式化決策

| 目標 | 建議 |
| --- | --- |
| Windows 和 macOS 都要直接讀寫 | exFAT。 |
| 僅 NAS 長期使用、穩定優先 | EXT4。 |
| 硬碟曾出現異常 | 先執行健康檢測並備份資料，再決定是否格式化。 |
| 只想清理分割區 | 選擇分割區格式化，避免誤刪整顆硬碟。 |
| 硬碟包含系統或儲存成員資料 | 不要格式化，先確認所屬卷和用途。 |

## S.M.A.R.T 關注點

- **Reallocated Sectors Count**：重新分配磁區持續增加說明媒體不穩定。
- **Current Pending Sector**：等待重新對應磁區增加可能預示壞軌。
- **Offline Uncorrectable**：無法修正錯誤，應儘快備份資料。
- **Temperature**：長期高溫會加速老化。
- **Power-On Time**：結合使用年限評估保固和更換計畫。
- **Raw Data**：不同廠商編碼方式不同，不能只比較數值大小。

<Callout title="檢測建議" type="info">
  快速檢測適合日常巡檢；更換硬碟、卷降級、頻繁離線或出現 I/O 錯誤時建議執行完整檢測。檢測不影響一般使用，但高負載期間結果可能受干擾。
</Callout>
