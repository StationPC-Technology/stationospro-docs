遠端存取頁分為 **遠端存取** 與 **DDNS**。Station ID 適合使用官方中轉服務快速存取；DDNS 適合已有網域名稱並希望透過自有網域名稱解析公網 IP 的使用者。

## Station ID 遠端存取

![Remote Access](/images/zh-Hant/app-guide/settings-img/remote-access.png)

### 基礎設定

| 功能/欄位 | 說明 |
| --- | --- |
| Station ID 遠端存取開關 | 開啟後裝置可透過網際網路遠端存取。開啟或關閉前需要身分驗證，並需同意使用者協議與隱私權政策。 |
| Station ID | 遠端存取識別碼。規則為 4~30 個字元，只能使用數字、小寫字母和連字號，且連字號不能在開頭或結尾。 |
| 綁定信箱 | 顯示目前綁定的遠端存取帳號信箱。必須先綁定信箱才能開啟遠端存取。 |
| 修改/編輯 | 點擊 Station ID 或編輯入口可更換 ID；ID 已被使用時需要更換。 |

### 遠端存取方式

| 方式 | 使用方法 |
| --- | --- |
| 網頁端 | 在瀏覽器存取 `https://scnas.cloud/<Station ID>/web`。 |
| 用戶端 | 在 StationCloud 用戶端中輸入 Station ID 新增並存取裝置。 |

### 帳號解除綁定

為保障帳號安全，解除綁定需登入已綁定的 StationCloud/思特雲帳號：

1. 瀏覽器開啟 `login.stationpc.com`。
2. 登入裝置綁定的帳號。
3. 進入「我的裝置」或 App 中的裝置管理。
4. 選擇目前裝置並解除綁定。

<Callout title="注意" type="warn">
  關閉遠端存取會斷開目前遠端連線。解除綁定帳號後遠端存取不可用，再次使用需要重新綁定並完成驗證。
</Callout>

## DDNS

DDNS 會定期偵測公網 IP，並把變化同步到網域名稱解析服務供應商。沒有設定時，頁面顯示空白狀態，可點擊 **新增設定**。

![DDNS](/images/zh-Hant/app-guide/settings-img/ddns.png)

### 設定列表

| 欄位 | 說明 |
| --- | --- |
| 服務供應商 | DNS 服務提供方，例如 Cloudflare、DNSPod.cn、No-IP.com、Duck DNS、FreeDNS、ChangeIP.com、DynDNS 等；實際列表由伺服器傳回。 |
| 網域名稱 | 目前 DDNS 記錄綁定的網域名稱。 |
| 狀態 | 已更新、已停用、未連線、連線中、異常。 |
| 上次更新時間 | 最近一次偵測或同步 IP 的時間。 |
| 操作 | 編輯設定、立即重新整理/更新、啟用/停用、刪除。刪除後不可還原。 |

### 新增/編輯設定

#### 基礎設定

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| 服務供應商 | 是 | 選擇網域名稱解析服務供應商。新增後服務供應商不可直接變更。 |
| 網域名稱 | 是 | 輸入完整網域名稱；網域名稱需符合格式，且不能與既有 DDNS 設定重複。 |
| AccessKey/API Token/帳號 | 視服務供應商 | 服務供應商要求的帳號或 AccessKey。欄位名稱隨服務供應商變化。 |
| SecretKey/API Secret/密碼 | 視服務供應商 | 服務供應商金鑰。編輯時留空表示繼續使用已儲存金鑰。 |
| IPv4 | 是或 IPv6 至少一項 | 預設「自動」，會顯示偵測到的公網 IPv4。也可選擇介面位址或自訂偵測位址。 |
| IPv6 | 是或 IPv4 至少一項 | 預設關閉。可選擇自動公網 IPv6、介面 IPv6 或自訂偵測位址。 |

<Callout title="VPN 提示" type="info">
  頁面提示：若開啟 VPN，外部 IP 位址檢查可能不準確。可暫時關閉 VPN 後重新設定，或手動輸入正確的外部 IP 位址。
</Callout>

#### 更多設定

| 欄位 | 說明 |
| --- | --- |
| 更新時間 | 每 1、5、10、15、30 或 60 分鐘定期檢查 IP 更新。 |
| 測試連線 | 立即驗證設定。結果顯示未連線、連線中、已更新或異常。 |

#### 底部選項

| 選項 | 說明 |
| --- | --- |
| 開啟設定 | 控制該 DDNS 設定是否啟用。 |

<Callout title="使用前提" type="warn">
  DDNS 只負責網域名稱解析，不會自動穿透路由器 NAT。若需從網際網路存取 NAS，還需在路由器上完成連接埠轉送，或使用 Station ID 遠端存取。公開服務請務必啟用 HTTPS、強密碼和雙重驗證。
</Callout>

## Station ID 使用規則

| 項目 | 說明 |
| --- | --- |
| 字元規則 | 4–30 位，小寫字母、數字、連字號；連字號不能在首尾。 |
| 唯一性 | 已被其他裝置使用的 ID 不能重複使用。 |
| 產生條件 | 需開啟遠端存取服務並完成綁定。 |
| 修改影響 | 舊 Web/用戶端位址立即失效，需要使用新 ID。 |
| 安全關係 | Station ID 不是密碼；仍需裝置本機帳號登入。 |
| 解除綁定影響 | 遠端存取不可用，再次使用需重新綁定。 |

## 開啟遠端存取的典型流程

1. 在通知設定中設定可用信箱。
2. 在遠端存取頁綁定信箱並完成驗證。
3. 設定符合規則的 Station ID。
4. 同意使用者協議和隱私權政策。
5. 開啟遠端存取服務。
6. 在外網瀏覽器或用戶端測試存取。
7. 建議開啟 HTTPS/強密碼/雙重驗證。

## DDNS 欄位詳解

| 欄位 | 說明 |
| --- | --- |
| 服務供應商 | 決定 DNS API 位址和驗證欄位。新增後不建議隨意重建，編輯時服務供應商不可直接變更。 |
| 網域名稱 | 必須是已代管在該服務供應商下的完整網域名稱。 |
| AccessKey/API Token | 服務供應商授予 DNS 操作權限的憑證，建議只給最小 DNS 權限。 |
| SecretKey/API Secret | 與 AccessKey 配對；編輯時留空可沿用已儲存金鑰。 |
| IPv4 自動偵測 | 使用公共偵測服務取得公網 IPv4。 |
| IPv4 介面位址 | 使用裝置指定介面位址，適合有固定公網 IP 的環境。 |
| IPv4 自訂 URL | 使用自訂服務傳回 IP，適合 NAT/代理環境。 |
| IPv6 | 預設關閉；可自動偵測或使用介面位址。 |
| 更新時間 | 越短生效越快，但請求更頻繁。 |

## DDNS 疑難排解

| 現象 | 檢查 |
| --- | --- |
| 測試連線異常 | AccessKey/Secret、網域名稱代管商、API 權限、伺服器網路。 |
| 網域名稱解析 IP 不變 | 本機 DNS 快取、TTL、偵測服務是否取得正確公網 IP。 |
| 網域名稱解析正確但無法存取 | 路由器連接埠轉送、防火牆、服務連接埠、是否被 ISP 封鎖。 |
| VPN 環境偵測錯誤 | 暫時關閉 VPN 或使用自訂 IP 偵測位址。 |
| IPv6 不可用 | 路由器/電信業者 IPv6 前綴、介面位址、防火牆放行。 |
