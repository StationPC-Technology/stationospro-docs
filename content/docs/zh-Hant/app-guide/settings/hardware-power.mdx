硬體與電源頁分為 **一般** 與 **電源**。一般頁控制聲音、散熱與記憶體壓縮；電源頁控制供電恢復、網路喚醒、定時開關機與硬碟休眠。

## 一般

![Hardware General](/images/zh-Hant/app-guide/settings-img/hardware-general.png)

### 蜂鳴器

點擊蜂鳴器設定按鈕後，可選擇哪些事件觸發蜂鳴提示：

| 分類 | 事件 | 說明 |
| --- | --- | --- |
| 一般 | 裝置開機 | 開機過程發出提示音。 |
| 一般 | 裝置關機 | 關機過程發出提示音。 |
| 一般 | 一鍵備份成功 | 一鍵備份任務完成時提示。 |
| 裝置錯誤 | 溫度過高 | 裝置溫度超過安全範圍時警報。 |
| 裝置錯誤 | 儲存空間錯誤 | 儲存卷或硬碟狀態異常時警報。 |
| 裝置錯誤 | 風扇錯誤 | 風扇停止運轉或異常時警報。 |

儲存後，僅勾選的事件會觸發蜂鳴器。若裝置放在臥室或安靜環境，可只保留高風險錯誤提示。

### 散熱風扇

| 模式 | 說明 |
| --- | --- |
| 一般 | 依裝置溫度自動調節轉速，平衡散熱與噪音，適合大多數情境。 |
| 靜音 | 低噪低轉速運作，但裝置溫度可能升高。適合噪音敏感且負載較低的環境。 |
| 全速 | 強制最大轉速，確保極致散熱，但噪音較大。適合高負載、高溫環境或散熱異常時暫時使用。 |

頁面卡片會顯示目前模式，例如「目前模式：一般」。

### 記憶體壓縮

| 選項 | 說明 |
| --- | --- |
| 記憶體壓縮開關 | 開啟後可釋放記憶體空間、加速資料讀取，讓系統運作更有效率。 |

記憶體壓縮會消耗少量 CPU 換取更大的可用記憶體空間。一般使用者建議保持預設；執行高 CPU 負載任務且記憶體壓力較低時，可依實際效能測試結果調整。

## 電源

![Power](/images/zh-Hant/app-guide/settings-img/power.png)

### 通電自動開機

| 選項 | 說明 |
| --- | --- |
| Power On When Power Returns | 外部供電恢復後裝置自動啟動。適合搭配穩定 UPS 或需要無人值守重新啟動的情境。 |

### 網路喚醒

| 選項 | 說明 |
| --- | --- |
| Wake On LAN (WOL) | 裝置關機或休眠時，可由區域網路魔術封包喚醒。需網路卡、主機板和路由環境支援。 |

### 定時開關機

| 選項 | 說明 |
| --- | --- |
| Scheduled Power On / Off 開關 | 開啟後依排程自動開機或關機。首次開啟時會引導新增第一條排程。 |
| Add Schedule | 新增排程。 |
| Day | 可選擇每天、週一至週日。 |
| Time | 排程執行時間。 |
| Action | 開機或關機。 |
| Actions | 編輯或刪除現有排程。 |

多條排程依週重複執行；重複或無效排程會被系統驗證。使用自動開機時，請確保裝置供電和 BIOS/韌體策略支援定時啟動。

### 硬碟休眠

硬碟休眠僅適用於支援休眠的機械硬碟，內建硬碟與外接硬碟可分別設定。系統碟可能不支援休眠。

| 選項 | 說明 |
| --- | --- |
| Enable Internal Disk Sleep | 開啟內建硬碟休眠。 |
| Enable External Disk Sleep | 開啟外接硬碟休眠。 |
| Wake Internal Disks When a User Logs In | 使用者登入時自動喚醒內建硬碟。 |
| Wake External Disks When a User Logs In | 使用者登入時自動喚醒外接硬碟。 |
| Idle Time | 閒置多久後休眠，可選 10 分鐘、20 分鐘、30 分鐘、1 小時、2 小時、3 小時。 |

<Callout title="注意" type="info">
  頻繁存取會使硬碟難以進入休眠。若有備份、索引、下載、監控錄影或容器應用程式持續讀寫硬碟，請適當延長閒置時間，或只為非關鍵硬碟開啟休眠。
</Callout>

## 蜂鳴器策略

| 情境 | 建議 |
| --- | --- |
| 機房或辦公室 | 保留溫度過高、風扇錯誤、儲存錯誤。 |
| 臥室或安靜客廳 | 僅保留嚴重錯誤，關閉開關機提示。 |
| 無人值守遠端部署 | 開啟全部錯誤提示，便於第一時間發現高溫/儲存異常。 |
| 一鍵備份重要 | 保留備份成功提示。 |

## 風扇模式選擇

| 條件 | 建議 |
| --- | --- |
| 一般家用 | 一般。 |
| 夜間低負載 | 靜音，但隔日可切回一般。 |
| 高溫環境、滿載下載、容器/AI 任務 | 全速。 |
| 風扇錯誤告警 | 先關機檢查風扇，不要長期依賴全速掩蓋故障。 |

## 電源策略組合

| 目標 | 建議組合 |
| --- | --- |
| 家庭定時節省功耗 | 定時關機 + 手動/網路喚醒。 |
| 斷電恢復後自動可用 | 通電自動開機。 |
| 遠端維護 | WOL + 可靠區域網路/VPN + 固定 IP 或 DHCP 保留。 |
| 重要業務持續運作 | 定時排程謹慎使用，設定 UPS 和備援儲存。 |

## 定時開關機注意事項

- 自動開機還依賴裝置硬體/韌體支援。
- 關機前應確認備份、同步、下載、索引、錄影和容器任務可中斷。
- 不要設定同一時間既開機又關機。
- 多條排程重複時系統會驗證，但仍應人工複核。
- 使用 NTP 保持時間準確，否則排程執行時間可能偏移。

## 硬碟休眠疑難排解

| 現象 | 檢查 |
| --- | --- |
| 硬碟從不休眠 | 日誌中心、備份、索引、容器、監控、下載任務是否持續存取。 |
| 頻繁喚醒/休眠 | 閒置時間是否過短，用戶端是否輪詢 SMB/WebDAV。 |
| 休眠後存取慢 | 屬於喚醒等待，可縮短閒置時間或關閉休眠。 |
| 外接硬碟無法休眠 | 外接碟/USB 橋接是否支援休眠。 |
| 系統碟不休眠 | 系統碟通常需持續服務，可能不支援休眠。 |
