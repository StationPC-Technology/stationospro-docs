儲存空間頁分為 **儲存空間** 與 **SSD 快取加速**。儲存空間標籤用於建立和管理由一顆或多顆硬碟組成的卷；SSD 快取標籤用於將高速 SSD 作為 HDD 卷的快取，提高熱點資料存取效能。

## 儲存空間標籤

![Storage](/images/zh-Hant/app-guide/settings-img/storage.png)

### 儲存卷列表

每個儲存卷卡片顯示：

| 欄位 | 說明 |
| --- | --- |
| 名稱 | 儲存卷名稱，例如 Storage volume1。 |
| 健康狀態 | Normal、Degraded 等狀態；異常時需要儘快檢查硬碟。 |
| 儲存模式/RAID | Basic、JBOD、RAID0、RAID1、RAID5、RAID6、RAID10 等。 |
| 容量 | 已使用容量 / 總容量。 |
| 硬碟類型 | HDD、SSD 等。 |
| 介面 | SATA、NVMe 等。 |
| 檔案系統 | 目前卷使用的檔案系統，例如 Btrfs。 |
| 使用的硬碟 | 顯示組成該卷的硬碟及容量；點擊硬碟可檢視對應硬碟資訊。 |

### 儲存卷操作

儲存卷卡片或更多選單中可能提供以下操作：

| 操作 | 說明 |
| --- | --- |
| 建立儲存空間 | 將閒置硬碟初始化為新儲存卷。建立過程會格式化所選硬碟。 |
| 修改儲存模式 | 在相容條件下變更 RAID 類型，可能需要新增或移除硬碟。 |
| 新增硬碟 | 為支援的 RAID 卷擴充容量；新硬碟會被格式化。 |
| 新增/移除熱備碟 | 為 RAID 卷指定備用硬碟。當成員碟故障時，熱備碟可自動參與恢復。 |
| 更換硬碟 | 在故障或容量升級情境中替換成員碟。 |
| 修復/檢測 | 用於異常狀態排查和恢復。 |

### RAID 與儲存模式

| 模式 | 硬碟要求 | 優點 | 風險/限制 |
| --- | --- | --- | --- |
| Basic | 1 顆 | 充分利用單碟容量 | 無資料保護，硬碟損壞則該碟資料遺失 |
| JBOD | 至少 1 顆 | 將多顆硬碟串聯為一個可用空間，擴充簡單 | 無備援，任一成員碟故障可能導致整個空間資料遺失 |
| RAID 0 | 至少 2 顆 | 讀寫速度最快，容量利用率高 | 無資料保護，任一硬碟損壞會導致全部資料遺失 |
| RAID 1 | 至少 2 顆 | 鏡像保護，支援 n-1 顆碟故障不遺失資料 | 容量利用率低 |
| RAID 5 | 至少 3 顆 | 兼顧效能與保護，支援單碟故障後透過校驗恢復 | 寫入相對較慢，恢復耗時較長 |
| RAID 6 | 至少 4 顆 | 雙校驗，支援同時 2 顆碟故障 | 寫入速度與空間利用率進一步降低 |
| RAID 10 | 至少 4 顆且為偶數 | 先鏡像後條帶，兼顧高效能與高保護 | 空間利用率約一半 |

### 檔案系統選擇

建立精靈中可選擇檔案系統：

| 檔案系統 | 適用性 |
| --- | --- |
| Btrfs | 支援快照、子卷與高效率複製，適合需要彈性備份和版本管理的家庭使用者或輕度開發者。 |
| EXT4 | 成熟穩定，適合傳統檔案服務、資源有限的裝置或追求穩定性的辦公情境。 |

### 建立儲存空間流程

1. 點擊 **建立儲存空間**。
2. 選擇閒置硬碟。系統會即時計算可用 RAID 模式和預計容量。
3. 選擇儲存模式/RAID，並確認可用容量、資料保護容量等資訊。
4. 選擇檔案系統格式。
5. 選擇可使用該儲存空間的使用者，並可設定一般使用者容量限制。
6. 確認摘要與格式化警告。
7. 開始建立並等待格式化完成。

<Callout title="危險操作" type="error">
  建立、修改、擴充或更換儲存卷都可能格式化所選硬碟，並刪除硬碟中的所有資料。操作開始後請勿斷電、重新啟動或拔插硬碟。務必先備份重要資料。
</Callout>

## SSD 快取加速標籤

SSD 快取將熱點資料儲存在高速 SSD 上，減少 HDD 讀取等待時間。使用該功能前，裝置中必須至少安裝一顆未被佔用的 SSD。

![SSD Cache](/images/zh-Hant/app-guide/settings-img/storage-ssd-cache.png)

### 建立 SSD 快取

| 設定項目 | 說明 |
| --- | --- |
| 加速對象 | 選擇要加速的 HDD 儲存卷。 |
| 快取 SSD | 選擇閒置 SSD；沒有可用 SSD 時需先安裝或釋放硬碟。 |
| 快取名稱 | 預設可自動產生，也可依用途命名。 |
| 快取模式 | 唯讀快取或讀寫快取。 |
| 快取 RAID | 多顆 SSD 時可選擇快取 RAID 模式。 |
| 快取容量 | 可選擇容量最大化或自訂容量；剩餘容量可繼續分配給其他卷。 |
| 風險確認 | 需要確認瞭解快取建立、格式化 SSD 與讀寫快取斷電風險。 |

### 快取模式對比

| 模式 | 說明 |
| --- | --- |
| 唯讀快取 | 只快取熱點讀取資料，SSD 故障或斷電對來源資料風險較低。 |
| 讀寫快取 | 讀取與寫入均加速，效能更好；SSD 故障或異常斷電可能影響尚未寫回的資料。 |

### 快取管理

| 操作 | 說明 |
| --- | --- |
| 檢視狀態 | 檢視快取名稱、模式、容量、命中率和關聯卷。 |
| 刪除快取 | 解除快取與卷的綁定。刪除讀寫快取前系統會確保資料寫回，期間請勿關機或移除 SSD。 |
| 修復快取 | 快取降級或損壞時，可依提示重新接入全部快取碟並嘗試修復。 |
| 分配既有快取 | 使用既有快取池的剩餘容量為其他卷加速。 |

<Callout title="資料安全" type="warn">
  建立 SSD 快取會清除所選 SSD 資料。讀寫快取需設定可靠供電；異常斷電或 SSD 故障可能造成資料風險。移除 SSD 前，務必先在系統中刪除對應快取。
</Callout>

## 儲存狀態解讀

| 狀態/標示 | 含義 | 建議處理 |
| --- | --- | --- |
| Normal | 儲存卷可正常讀寫。 | 保持例行備份和硬碟健康檢查。 |
| Degraded | RAID 備援降低，但通常仍可存取資料。 | 立即備份資料，檢查成員碟，儘快修復或更換硬碟。 |
| Damaged/異常 | 儲存結構或成員碟嚴重異常。 | 避免繼續寫入，先備份可讀資料並聯絡支援。 |
| Syncing/恢復中 | RAID 正在同步或重建。 | 保持供電穩定，不要重新啟動、斷電或拔插硬碟。 |
| Formatting | 正在格式化。 | 等待完成，不要中斷操作。 |
| Read-only | 系統偵測到連線、硬碟或檔案系統風險後保護性禁寫。 | 檢查硬碟與連線，備份資料後依提示修復。 |
| 熱備 | 硬碟待命，成員碟故障時可自動參與恢復。 | 保持熱備碟健康，不要隨意挪用。 |

## 建立或修改前的檢查清單

1. 確認所選硬碟確實沒有需要保留的資料。
2. 檢視硬碟健康狀態、溫度、通電時間和 S.M.A.R.T 結果。
3. 確認硬碟數量、介面和容量滿足目標 RAID 要求。
4. 理解預計可用容量、資料保護容量和未利用容量。
5. 停止備份、下載、同步、容器、索引和資料庫寫入任務。
6. 準備不間斷供電或避免電力不穩定時段。
7. 記錄目前儲存卷名稱、成員碟編號和掛載路徑。

## RAID 選擇建議

| 需求 | 推薦模式 |
| --- | --- |
| 單碟最大容量，不關注備援 | Basic |
| 順序拼接多碟、後續繼續加碟 | JBOD |
| 臨時快取、可重建資料、追求速度 | RAID 0 |
| 兩碟保護重要照片和文件 | RAID 1 |
| 家用或小型團隊均衡容量、效能與保護 | RAID 5 |
| 更高故障容忍度，可用硬碟數充足 | RAID 6 |
| 高效能且需要鏡像保護 | RAID 10 |

<Callout title="容量提醒" type="info">
  RAID 可用容量會受校驗、鏡像和硬碟容量差異影響。不同容量硬碟組成 RAID 時，通常依較小容量或模式規則計算。建立精靈中的預計容量是最終判斷依據。
</Callout>

## 熱備碟策略

- **全域熱備/池內熱備**：當關聯儲存空間成員碟故障時自動接管，縮短恢復視窗。
- **適用情境**：不方便立即更換硬碟的遠端部署、重要業務卷、硬碟數量較多的 RAID 6/10。
- **注意事項**：熱備碟不是備份；同步期間效能可能下降，且原卷在恢復完成前仍處於降級狀態。

## SSD 快取選擇建議

| 情境 | 建議 |
| --- | --- |
| 主要提升重複讀取熱點資料 | 唯讀快取，風險較低。 |
| 需要提升寫入回應，且有 UPS | 可評估讀寫快取。 |
| 無 UPS 或資料極其重要 | 避免讀寫快取，優先提升 HDD/RAID 效能。 |
| 多使用者並行存取同一目錄 | 唯讀快取收益較明顯。 |
| 隨機寫入大量小檔案 | 需結合應用程式寫入模式和 SSD 壽命評估。 |

建立或刪除讀寫快取時，系統可能需要將 SSD 中未寫回的資料同步到 HDD。期間不要關機、重新啟動或移除 SSD。
