裝置資訊頁用於確認裝置身分和執行狀態。你可以在該頁檢視系統版本、硬體規格、序號與每個網路埠的位址，也可以修改裝置名稱或複製 Station ID 與 IP 位址。

## 裝置基礎資訊

| 欄位/操作 | 說明 |
| --- | --- |
| 裝置名稱 | 顯示目前裝置名稱。點擊名稱右側的編輯圖示可修改；名稱支援 1~15 位英文字母、數字和 `-`，且 `-` 不能在開頭或結尾。 |
| Station ID | 裝置的遠端存取識別碼。開啟遠端存取服務後產生，可點擊複製；如需修改，點擊 ID 進入修改流程。 |
| 系統版本 | 目前 StationOS Pro 版本號，例如 `v1.1.0.17`。若偵測到新版本，可能顯示新版本提示。 |
| 系統執行時間 | 自最近一次啟動以來持續執行的時長。 |
| 上次開機時間 | 最近一次啟動的系統時間。 |

![Device Info](/images/zh-Hant/app-guide/settings-img/device-info.png)

## 硬體資訊

硬體資訊分為三個區塊：

| 區塊 | 欄位 | 用途 |
| --- | --- | --- |
| CPU | CPU 型號、主頻、核心數、執行緒數 | 判斷處理器效能與平行任務能力。 |
| 記憶體 | 記憶體容量 | 判斷應用程式、容器、索引和 AI 任務可用的執行空間。 |
| AI 模組擴充 | AI 模組型號與算力，例如 RK1828、20 TOPS INT8 | 確認裝置是否具備 AI 加速硬體及算力等級。 |

## 裝置詳情

| 欄位 | 說明 |
| --- | --- |
| 裝置型號 | 裝置的產品型號，例如 DA400。 |
| 序號 | 裝置唯一識別碼之一。點擊複製按鈕可快速複製，常用於註冊、保固和技術支援。 |

## 網路資訊

網路資訊依網路埠展示，例如「有線連線 1」「有線連線 2」。選擇網路埠後可檢視：

| 欄位 | 說明 |
| --- | --- |
| 網路埠名稱 | 系統識別的介面名稱，例如 `enP2p33s0`。 |
| 網路設定 | 雙工模式與 MTU，例如 Full-duplex、MTU1500。 |
| IPv4 位址 | 目前 IPv4 位址；點擊複製按鈕可複製。 |
| IPv4 連線狀態 | 顯示 IPv4 是否已連線。 |
| IPv6 位址 | 目前 IPv6 位址；無位址時顯示 `-`。 |
| IPv6 連線狀態 | 顯示 IPv6 是否已連線。 |

<Callout title="提示" type="info">
  如果裝置資訊中的 IP 與你目前存取的位址不一致，可能是多網路埠裝置同時連接多條鏈路。請以用戶端實際連線的網段為準，或在網路設定中進一步檢視每個介面的閘道與 DNS。
</Callout>

## 欄位使用建議

| 情境 | 建議檢視欄位 |
| --- | --- |
| 瀏覽器無法存取裝置 | 網路資訊中的 IPv4/IPv6 位址、連線狀態、網路埠名稱。 |
| 遠端用戶端無法新增裝置 | Station ID、系統版本、遠端存取開關狀態。 |
| 判斷是否能執行 AI 或容器 | CPU 核心執行緒、記憶體容量、AI 模組算力。 |
| 聯絡技術支援或保固 | 裝置型號、序號、系統版本、執行時間。 |
| 排查反覆重新啟動 | 上次開機時間、系統執行時間，並可結合日誌中心系統日誌。 |
| 多網路埠鏈路確認 | 每個網路埠標籤下的位址、雙工模式、MTU 和連線狀態。 |

## 狀態解讀

| 狀態/表現 | 含義 | 建議處理 |
| --- | --- | --- |
| IPv4 連線正常但 IPv6 顯示 `-` | 目前鏈路未取得 IPv6，不一定影響 IPv4 存取。 | 僅在需要 IPv6 時檢查路由器 SLAAC/DHCPv6。 |
| 某網路埠顯示未連線 | 網路線未插入、交換器連接埠異常或鏈路協商失敗。 | 更換網路線/連接埠，再到網路設定檢視介面狀態。 |
| 執行時間很短 | 裝置剛開機或發生過異常重新啟動。 | 到日誌中心篩選 System 使用者檢視關機、重新啟動和更新記錄。 |
| 有新版本提示 | 更新伺服器傳回新韌體。 | 到更新與還原檢視版本說明，先備份再升級。 |

## 常見問題

### 修改裝置名稱會影響檔案存取嗎？

裝置名稱主要用於識別裝置和部分通知情境，一般不會改變儲存路徑或帳號。若用戶端使用主機名稱存取服務，修改後需要依新主機名稱重新連線；使用 IP 存取則通常不受影響。

### 為什麼多個網路埠都有 IP？

多網路埠裝置可同時連接多條鏈路。每個網路埠的資訊獨立顯示，用戶端應使用與其同網段的位址。若需要頻寬疊加或鏈路備援，可在網路設定中評估橋接或鏈路聚合。

### Station ID 可以當作帳號嗎？

不可以。Station ID 是裝置遠端存取識別碼，不是登入帳號。遠端存取仍需輸入裝置本機使用者和密碼；綁定信箱用於關聯遠端存取帳號與身分驗證。
