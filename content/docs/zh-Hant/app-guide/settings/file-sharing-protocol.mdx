檔案共享協定頁提供 **SMB**、**WebDAV**、**FTP**、**NFS** 四個標籤。開啟對應服務後，電腦、手機、NAS、電視盒等用戶端可透過協定存取裝置中的檔案。每個協定頁面都提供連線方式指引，方便複製位址並依步驟掛載。

![File Sharing](/images/zh-Hant/app-guide/settings-img/file-sharing.png)

## 可見資料夾範圍

SMB、WebDAV、FTP 的服務卡片均提供 **設定可見目錄範圍**。該設定決定各檔案區域透過對應協定是否可見：

| 區域 | 說明 |
| --- | --- |
| 我的檔案、他人共享 | 目前使用者個人目錄與收到的共享檔案。 |
| 團隊檔案 | 團隊共享目錄。 |
| 外接儲存 | USB 等外接儲存中的檔案。 |
| 遠端掛載 | 從遠端 NAS、伺服器或雲端硬碟掛載的目錄。 |
| 應用檔案 | 應用程式產生的資料目錄。 |

每個區域可選擇：

| 模式 | 效果 |
| --- | --- |
| 全部可見 | 目前及未來新增的資料夾都可透過該協定存取。 |
| 自訂資料夾 | 僅指定第一層資料夾可見，卡片顯示自訂數量。 |
| 全部禁止/無 | 該區域下任何資料夾都無法透過該協定檢視。 |

<Callout title="命名限制" type="info">
  第一層資料夾名稱包含空格或 `! " # % & ' ( ) * + , / : ; < = > ? @ [ ] ^ { } | ~` 等特殊字元時，無法透過檔案共享協定存取。建議第一層目錄使用字母、數字、中文、底線或連字號命名。
</Callout>

## SMB

SMB 是 Windows、macOS 和大多數用戶端最常用的檔案共享協定，適合日常區域網路檔案存取。

| 功能 | 說明 |
| --- | --- |
| SMB 服務開關 | 開啟後，裝置可在區域網路內透過 SMB 共享和存取檔案。 |
| 進階設定 | 設定 SMB3 多通道、SMB1、NTLMv1 與 macOS 檔案名稱相容。 |
| 設定可見目錄範圍 | 跳轉到檔案管理設定，設定各目錄透過檔案服務可見的範圍。 |
| Time Machine 服務 | 開啟後，Mac 可透過 Time Machine 備份到此 NAS。 |
| Time Machine 資料夾 | 顯示或設定 Time Machine 備份目錄。 |
| 檢視資料夾 | 開啟目前 Time Machine 備份目錄。 |
| 連線方式 | 提供 macOS Finder、Windows 執行視窗的連線步驟和 `smb://IP`、`\\IP` 位址。 |
| 其他連線資訊 | 顯示裝置 IP、預設連接埠 445 與主機名稱。 |

### SMB 進階設定

| 選項 | 說明 | 建議 |
| --- | --- | --- |
| 支援 SMB3 多通道 | 允許多個網路連線平行傳輸，提高速度和可靠性。 | 多網路埠或高並行傳輸情境建議開啟。 |
| 支援 SMB1 | 相容舊裝置，但協定安全性較弱。 | 僅在舊裝置無法連線時暫時開啟。 |
| 支援 NTLMv1 | 相容部分電視盒、播放機等僅支援 NTLMv1 的終端，但驗證協定不安全。 | 僅對必要裝置開啟，並限制存取範圍。 |
| 為 macOS 轉換檔案名稱中的特殊字元 | 增強與 macOS 的檔案名稱相容性。 | Mac 存取異常時可開啟。 |

### Time Machine 設定

| 選項 | 說明 |
| --- | --- |
| Time Machine 服務開關 | 必須先開啟 SMB 服務。 |
| 儲存位置 | 選擇用於儲存 Mac 備份的儲存卷。 |
| 備份容量限制 | 選擇「限制大小」並輸入容量，或選擇「不限制大小」。 |
| 容量單位 | 支援 GB 與 TB；限制不能超過所選儲存空間總容量。 |

![SMB](/images/zh-Hant/app-guide/settings-img/file-sharing.png)

## WebDAV

WebDAV 基於 HTTP/HTTPS 提供檔案存取，常見於第三方用戶端、行動應用程式和部分掛載工具。

![WebDAV](/images/zh-Hant/app-guide/settings-img/file-sharing-webdav.png)

| 功能 | 說明 |
| --- | --- |
| WebDAV 服務開關 | 開啟後可在區域網路透過 WebDAV 存取檔案。 |
| 進階設定 | 設定 HTTP/HTTPS 協定與監聽連接埠。 |
| 設定可見目錄範圍 | 設定 WebDAV 可見的檔案目錄。 |
| 連線方式 | 提供 macOS 與 Windows 的對應/連線步驟，位址格式為 `http://IP:連接埠`。 |

### WebDAV 進階設定

| 選項 | 說明 |
| --- | --- |
| 啟用 HTTP | 使用明文 HTTP 協定，預設常見連接埠為 5005。 |
| HTTP 連接埠 | HTTP 服務監聽連接埠，範圍為 1~65535。 |
| 啟用 HTTPS | 使用加密傳輸，建議在不可信網路或需要保護帳號資料時開啟。 |
| HTTPS 連接埠 | HTTPS 服務監聽連接埠，不能與 HTTP 連接埠相同。 |
| 偵錯模式 | 輸出詳細日誌，可能影響效能，僅疑難排解時暫時開啟。 |

## FTP

FTP 適合跨系統批次傳輸檔案。系統同時支援無加密 FTP 與 FTPS。

![FTP](/images/zh-Hant/app-guide/settings-img/file-sharing-ftp.png)

| 功能 | 說明 |
| --- | --- |
| FTP 服務開關 | 開啟後允許 FTP/FTPS 用戶端連線。 |
| 進階設定 | 設定協定、連接埠、被動連接埠範圍與閒置逾時。 |
| 設定可見目錄範圍 | 設定 FTP 可見的檔案目錄。 |
| 連線方式 | 提供 macOS Finder、Windows 檔案總管連線步驟，位址格式為 `ftp://IP:21`。 |

### FTP 進階設定

| 選項 | 說明 |
| --- | --- |
| 啟用 FTP 服務（無加密） | 啟用標準 FTP。傳輸內容未加密，不建議在不可信網路使用。 |
| 啟用 FTPS 服務（安全加密） | 啟用 FTP over SSL/TLS，提供加密傳輸。 |
| FTP 連接埠 | 服務監聽連接埠，預設 21，有效範圍 1~65535。 |
| 被動式 FTP 連接埠範圍 | 可選預設或自訂。自訂範圍必須在 55536~65535 內，且上限不能小於下限。 |
| 閒置逾時時間 | 用戶端無操作後自動斷開連線，支援 1~120 分鐘。 |

## NFS

NFS 常用於 Linux、Unix、虛擬機或部分播放裝置直接掛載共享目錄。目前頁面說明中提示：開啟後區域網路裝置可本機掛載共享資料夾並直接存取檔案，無需帳號驗證。

![NFS](/images/zh-Hant/app-guide/settings-img/file-sharing-nfs.png)

| 功能 | 說明 |
| --- | --- |
| NFS 服務開關 | 開啟後才可使用 NFS 位址掛載。 |
| 設定可見目錄範圍 | 服務未開啟時不可用；開啟後可設定 NFS 可見目錄。 |
| 連線方式 | 提供 macOS `nfs://IP/路徑` 與 Windows `\\IP\路徑` 範例。 |

<Callout title="安全提示" type="warn">
  - NFS 可能不進行帳號密碼驗證，請只在可信區域網路內開啟，並透過可見目錄範圍和用戶端權限限制存取。
  - SMB1、NTLMv1、明文 FTP/HTTP 均存在安全風險。裝置相容時優先使用 SMB3、HTTPS、FTPS 或 SFTP。
  - 修改服務連接埠後，請同步調整防火牆輸出/輸入規則和用戶端位址。
</Callout>

## 服務開關影響

| 操作 | 用戶端影響 | 資料影響 |
| --- | --- | --- |
| 開啟協定 | 對應用戶端可嘗試連線。 | 不改變檔案權限。 |
| 關閉協定 | 既有協定連線會失敗或斷開。 | 不刪除檔案。 |
| 修改連接埠 | 舊位址立即失效。 | 不刪除檔案。 |
| 修改可見範圍 | 部分目錄從協定用戶端消失。 | 只影響顯示與存取入口，不刪除目錄。 |
| 格式化協定所在儲存卷 | 協定本身仍可開啟，但來源資料被清除。 | 卷內檔案全部刪除。 |

## 帳號與權限關係

檔案協定使用裝置本機帳號驗證，最終可見和可寫內容還受以下設定影響：

1. 使用者是否啟用；
2. 使用者可存取儲存空間和配額；
3. 使用者群組授權；
4. 檔案/目錄自身權限；
5. 協定可見目錄範圍；
6. 防火牆和 IP 清單；
7. 儲存卷是否唯讀。

## 預設位址與連接埠

| 協定 | 預設連接埠 | 常見位址 |
| --- | --- | --- |
| SMB | 445 | `smb://IP`、`\\IP` |
| WebDAV | 5005，可在進階設定修改 | `http://IP:連接埠` |
| FTP/FTPS | 21，可在進階設定修改 | `ftp://IP:連接埠` |
| NFS | 由系統匯出路徑決定 | `nfs://IP/共享路徑` |

## 連線疑難排解

| 現象 | 檢查順序 |
| --- | --- |
| 用戶端無法連線 | 服務開關、IP/連接埠、防火牆、交換器路由、用戶端所在網段。 |
| 能連線但看不到目錄 | 可見目錄範圍、帳號權限、資料夾名稱特殊字元。 |
| 提示帳號密碼錯誤 | 使用者是否啟用、密碼是否修改、協定是否要求本機帳號。 |
| 傳輸速度慢 | 鏈路速率/雙工、SMB 多通道、聚合模式、硬碟負載、CPU/記憶體佔用。 |
| 修改連接埠後無法存取 | 用戶端位址連接埠、防火牆規則、路由器連接埠轉送。 |
| Mac 特殊檔案名稱異常 | 開啟為 macOS 轉換檔案名稱特殊字元，並檢查目錄命名。 |

<Callout title="最小暴露原則" type="warn">
  只開啟實際需要的協定；僅在可信網路使用 NFS；公網存取優先使用遠端存取或 VPN，不要直接暴露 SMB、FTP 或管理連接埠。
</Callout>
