更新與還原頁分為 **系統更新** 與 **還原與重設**。系統更新頁用於線上偵測、下載安裝韌體或手動安裝本機韌體；還原與重設頁用於恢復系統預設設定或重設網路。

## 系統更新

![System Update](/images/zh-Hant/app-guide/settings-img/update.png)

### 目前版本資訊

| 欄位 | 說明 |
| --- | --- |
| 目前版本 | 目前系統版本號，例如 `v1.1.0.17`。 |
| 偵測更新 | 手動向更新伺服器查詢新版本。檢查結果會顯示是否已有最新版本。 |
| 上次檢查時間 | 部分版本會顯示最近一次檢查更新的時間。 |

### 自動更新

| 選項 | 說明 |
| --- | --- |
| 自動安裝更新 | 開啟後，系統可自動下載並安裝更新，並在需要時自動重新啟動。關閉後仍會收到新版本提示，但必須手動點擊「重新啟動升級」後才會升級。 |

<Callout title="操作建議" type="warn">
  更新會影響系統服務和所有應用程式服務。建議先停止備份、同步、下載、索引和容器寫入任務，並確保電量或供電穩定。更新過程中請勿斷電、重新整理頁面或強制關機。
</Callout>

### 手動安裝

| 選項 | 說明 |
| --- | --- |
| Click to select | 選擇已下載到本機的韌體檔案。目前介面說明要求選擇比目前版本更高的韌體套件。 |
| 檔案格式 | 依系統提示上傳支援的韌體格式；上傳後系統會計算校驗值並驗證版本。 |
| 版本驗證 | 若安裝套件版本低於或等於目前版本，系統會阻擋或提示無法安裝。 |
| 安裝流程 | 上傳韌體 → 驗證 → 確認更新提示 → 等待系統安裝並重新啟動。 |

### 更新日誌

| 功能 | 說明 |
| --- | --- |
| View details | 開啟版本更新記錄。可檢視版本號、版本類型、發佈時間和功能/Bug 修復內容。 |

## 還原與重設

![Restore and Reset](/images/zh-Hant/app-guide/settings-img/restore.png)

### 恢復原廠設定

| 項目 | 說明 |
| --- | --- |
| 影響範圍 | 系統設定恢復為原廠預設值，硬碟資料會保留。 |
| 驗證 | 需要驗證管理員身分。 |
| 重新啟動 | 裝置自動重新啟動，恢復過程中請勿斷電。 |
| 網路/IP | 重設後若無法用原 IP 存取，請在實體機螢幕檢視新 IP 並重新註冊。 |
| 解除綁定帳號 | 如需解除帳號綁定，依提示前往 StationCloud 帳號中心操作。 |

### 重設網路

| 項目 | 說明 |
| --- | --- |
| 影響範圍 | 恢復所有網路連線設定與防火牆設定為初始狀態。 |
| 前提 | 確認至少有一條有線網路可用。 |
| 連線影響 | 重設過程和完成後，目前連線可能斷開；可能需要重新取得 IP。 |
| 驗證 | 需要驗證管理員身分。 |

<Callout title="危險操作" type="error">
  恢復原廠設定和重設網路都會中斷系統服務並需要重新啟動。執行前請記錄網路參數、備份設定，並確認有本機存取途徑可恢復連線。
</Callout>

## 線上更新流程

1. 點擊 **偵測更新**。
2. 若發現新版本，檢視版本號、套件大小和更新說明。
3. 閱讀更新提示，確認停止高風險寫入任務。
4. 點擊立即更新或繼續更新。
5. 系統檢查更新條件，如存在阻擋任務需先處理。
6. 等待下載、安裝和自動重新啟動。
7. 更新完成後重新登入並檢查版本、儲存、應用程式和網路狀態。

## 更新條件與阻擋任務

系統可能在更新前檢查正在執行的任務。某些任務會直接阻擋更新，另一些任務建議先停止：

- 備份、同步和下載任務；
- 容器寫入或資料庫服務；
- 檔案索引或 AI 模型任務；
- 儲存卷同步、修復或格式化；
- 其他可能持續寫入硬碟的服務。

處理完阻擋項目後再繼續更新，可降低升級中斷導致的資料風險。

## Beta 版本更新

若頁面顯示 **Beta 版本更新**，開啟後可參與測試版本內測，提前體驗未完成功能。測試版本可能存在穩定性、相容性和功能不完整問題：

- 重要資料裝置不建議開啟；
- 生產環境或無人值守裝置不建議開啟；
- 更新前應完整備份；
- 遇到問題可透過日誌中心和意見回饋管道提交。

## 手動安裝詳細規則

- 僅支援選擇 `.zip` 韌體套件。
- 安裝套件版本必須高於目前版本；低於或等於目前版本會被拒絕。
- 上傳過程中可暫停、繼續或取消。
- 上傳完成後系統計算校驗值並解析韌體資訊。
- 確認後進入更新條件檢查和升級確認。
- 更新過程中不要關閉瀏覽器電源、重新整理系統或斷開供電。

## 恢復與重設對比

| 操作 | 恢復原廠設定 | 重設網路 |
| --- | --- | --- |
| 系統設定 | 恢復預設 | 網路與防火牆設定恢復預設 |
| 硬碟資料 | 保留 | 保留 |
| 管理員驗證 | 需要 | 需要 |
| 網路 | 可能改變 IP | 必然可能改變 IP/連線 |
| 應用程式設定 | 恢復預設或需重新設定 | 通常只影響網路相關設定 |
| 適用情境 | 清空設定移交/重新初始化 | 網路設定混亂且無法恢復時 |
