日誌中心集中記錄系統執行、登入連線、檔案傳輸與硬碟儲存等事件。你可以依關鍵字、等級、模組、使用者與時間範圍檢索日誌，用於安全稽核、操作追溯與疑難排解。

## 頁面配置

日誌中心分為頂部工具列、日誌表格與底部分頁區：

| 區域 | 功能 |
| --- | --- |
| 關鍵字搜尋框 | 依日誌內容關鍵字檢索。輸入後按 Enter 或讓輸入框失焦生效。 |
| 篩選 | 依等級、模組、使用者、時間範圍組合篩選。 |
| 清空 | 依時間範圍清除日誌。 |
| 匯出日誌 | 將所選時間範圍的日誌匯出為 CSV 檔案。 |
| 日誌歸檔 | 設定自動歸檔條件與歸檔儲存位置。 |
| 日誌表格 | 顯示等級、模組、時間、使用者與事件。 |
| 分頁區 | 顯示日誌總數，支援重新整理、切換頁碼、調整每頁筆數與跳轉頁碼。 |

## 檢視系統使用者日誌

如需只檢視系統產生的日誌，可將 **使用者** 篩選為 `system`：

1. 點擊頂部 **篩選**。
2. 在 **使用者** 下拉方塊中選擇 `system`。
3. 點擊 **確認**。

篩選結果中的使用者欄位均為 `system`，適合重點檢視系統開關機、系統更新、網路介面狀態、硬碟辨識、硬碟 S.M.A.R.T 狀態與儲存卷異常等系統事件。

![按 system 使用者篩選後的日誌列表](/images/zh-Hant/app-guide/log-center-img/logs.png)

## 日誌欄位

| 欄位 | 說明 |
| --- | --- |
| 等級 | 日誌嚴重程度：一般、警告、嚴重。一般為常規執行資訊；警告表示需要關注；嚴重表示功能或硬體存在較高風險。 |
| 模組 | 事件來源：系統、登入連線、檔案傳輸、硬碟儲存。 |
| 時間 | 事件發生時間。 |
| 使用者 | 觸發事件的使用者。`system` 表示系統自動產生的事件；一般使用者名稱表示使用者操作或使用者工作階段相關事件。 |
| 事件 | 事件詳情，例如系統關機、硬碟移除、儲存卷降級、系統版本更新等。 |

## 搜尋與篩選

### 關鍵字搜尋

在搜尋框輸入事件內容關鍵字，例如硬碟型號、儲存卷名稱、系統版本或錯誤描述，然後按 Enter。搜尋會與條件篩選疊加生效。

### 條件篩選

點擊 **篩選** 後可組合以下條件：

| 條件 | 可選值/說明 |
| --- | --- |
| 等級 | 一般、警告、嚴重，支援多選與全選。 |
| 模組 | 系統、登入連線、檔案傳輸、硬碟儲存，支援多選與全選。 |
| 使用者 | 選項來自目前日誌中出現的使用者，支援多選與全選。本文範例選擇 `system`。 |
| 時間 | 選擇起訖日期，只檢視指定時間範圍內的日誌。 |

篩選條件先儲存在彈出視窗中，點擊 **確認** 後才套用到列表；點擊 **重設** 可清空篩選條件並恢復預設檢視。

![篩選使用者選擇 system](/images/zh-Hant/app-guide/log-center-img/filter.png)

## 分頁與重新整理

- **總數**：分頁區顯示目前篩選條件下的日誌總數。
- **重新整理**：點擊總數左側重新整理圖示可重新載入目前列表。
- **每頁筆數**：可選 50、100、500。
- **跳頁**：輸入頁碼後按 Enter，或使用上一頁/下一頁切換。

## 匯出日誌

點擊頂部下載圖示可匯出日誌：

1. 選擇時間範圍：全部、最近一週、最近一個月、最近三個月、最近半年、最近一年。
2. 點擊 **確認**。
3. 等待日誌檔案產生，匯出的 CSV 會儲存到本機瀏覽器下載目錄。

匯出適合長期留存稽核記錄，或在無法直接存取裝置時交由技術人員分析。

## 清除日誌

點擊 **清空** 後：

1. 選擇要清除的時間範圍：全部、一年前、半年前、三個月前、一個月前、一週前。
2. 確認清理範圍。
3. 等待清理進度完成。

<Callout title="注意" type="warn">
  清除日誌不可還原。清理前建議先匯出需要留存的歷史日誌；出現安全事件或硬體異常時，不要急於清除相關時間段日誌。
</Callout>

## 日誌歸檔

點擊頂部設定圖示開啟 **日誌歸檔**。系統預設保留近 300 萬筆傳輸日誌且不自動歸檔；開啟自動歸檔後，可依以下任一條件觸發：

| 條件 | 可選值 |
| --- | --- |
| 日誌資料量大於 | 500 MB、1 GB、3 GB |
| 日誌時間早於 | 一週前、一個月前、三個月前、半年前、一年前 |

還需選擇團隊檔案中的歸檔儲存位置。至少啟用一個歸檔條件後才能儲存。

<Callout title="建議" type="info">
  - 排查登入異常時，優先篩選「登入連線」並關注警告與嚴重等級。
  - 排查硬碟或儲存卷故障時，可篩選使用者為 `system`、模組為「系統」或「硬碟儲存」。
  - 定期匯出或歸檔重要日誌，避免清除後無法追溯。
</Callout>
