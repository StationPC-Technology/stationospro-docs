StationOS Pro 是 StationNAS 裝置搭載的作業系統，圍繞資料儲存、檔案共享、備份容災、容器應用與 AI 服務，提供完整的應用中心化管理體驗。本章節將逐一介紹系統內建應用程式的功能與使用方法，幫助你快速上手並充分發揮裝置能力。

## 桌面介紹

登入系統後即可進入桌面。桌面由頂部狀態列、桌面圖示區域與底部 Dock 列組成：

- **頂部狀態列**：左側提供「回到桌面」與「應用程式啟動器」按鈕；中間懸浮顯示 CPU、RAM、網路速率等即時資源資訊；右側提供通知中心與個人設定入口。
- **Dock 列**：集中放置常用應用程式，點擊圖示即可開啟對應應用程式視窗。
- **視窗管理**：應用程式視窗右上角提供最小化、最大化/還原、關閉按鈕，可像傳統桌面系統一樣自由切換與排列視窗。

![Desktop](/images/zh-Hant/app-guide/overview-img/desktop.png)

## 應用程式啟動器

點擊頂部狀態列左側的啟動器按鈕，即可開啟應用程式啟動器。啟動器支援：

- 透過頂部搜尋框依名稱快速尋找應用程式；
- 檢視系統全部內建應用程式，點擊圖示即可啟動。

![App Launcher](/images/zh-Hant/app-guide/overview-img/app-launcher.png)

## 內建應用程式一覽

| 應用 | 說明 |
| --- | --- |
| 檔案管理 | 管理個人與團隊檔案，支援上傳下載、外連分享、回收站、重複檔案清理，以及 SMB/WebDAV/FTP/NFS 等檔案服務設定 |
| 備份 | 提供本機備份、遠端備份與一鍵備份能力，支援 NAS、外接儲存、雲端硬碟與檔案協定等多種備份來源 |
| Docker | 容器化管理主控台，支援容器、專案（Compose）、映像、網路的完整生命週期管理 |
| 日誌中心 | 集中檢視系統執行日誌，支援關鍵字搜尋與多條件篩選 |
| 資源管理 | 即時監控 CPU、記憶體、網路、NPU 與硬碟狀態，並管理系統服務與程序 |
| 系統設定 | 管理裝置資訊、使用者、儲存、網路、遠端存取、硬體電源、安全與系統更新等核心設定 |
| 應用中心 | 一站式應用程式商店，提供官方應用程式與第三方應用程式的安裝、更新與管理 |
| Station AI | 內建 AI 智慧助理，支援對話問答、知識庫檢索、文件翻譯與總結 |
| 說明中心 | 快速開啟本說明文件站點，查詢安裝、應用教學與常見問題 |

<Callout title="提示" type="info">
  部分功能與應用程式可能因裝置型號、韌體版本或安裝的應用程式不同而有所差異，請以裝置實際介面為準。
</Callout>
