title: "¿Es obligatorio vincular un número de teléfono o un correo electrónico para usarlo? ¿Se pueden vincular varios dispositivos al mismo número de teléfono o correo electrónico?"
---

* La vinculación de un número de teléfono o de un correo electrónico sirve para el acceso remoto; si solo se utiliza en la red de área local, no es necesario vincularlos
* Sí, el mismo número de teléfono o correo electrónico se puede vincular a varios dispositivos
