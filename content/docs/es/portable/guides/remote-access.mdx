title: ¿Cómo realizar un acceso remoto?
---

PocketCloud incluye un servicio de acceso remoto integrado que le proporciona una función de acceso remoto segura. Antes de utilizar este servicio, debe vincular un número de teléfono o una dirección de correo electrónico y crear un Station ID único (que identifica su dispositivo); mediante el Station ID podrá acceder rápidamente a su PocketCloud.

> Nota:
> * Para usar el servicio de acceso remoto es necesario vincular un número de teléfono o una dirección de correo electrónico;
> * El servicio crea automáticamente un Station ID único para su PocketCloud, a través del cual puede acceder al dispositivo de forma segura;
> * Según el entorno de red actual, el sistema selecciona automáticamente el mejor método de acceso para la conexión;
> * El Station ID se puede personalizar.

## Activar el servicio de acceso remoto
Método 1:
Durante la configuración inicial del dispositivo, siga las indicaciones y marque la opción «Activar el acceso remoto».

<img src="/images/es/portable/guides/remote-access/setupwized-remote_access-2.jpg" width="30%" />

Método 2:
1. Abra el cliente y vaya a la página **Dispositivo**;
2. Busque **Conexión del dispositivo**, donde puede activar o desactivar manualmente el servicio de acceso remoto.

## Desvincular el servicio de acceso remoto

Al restaurar la configuración de fábrica, el sistema desvincula automáticamente el servicio de acceso remoto.
> Si el dispositivo tiene vinculado el servicio de acceso remoto, es necesario estar conectado a la red para restaurar la configuración de fábrica;
