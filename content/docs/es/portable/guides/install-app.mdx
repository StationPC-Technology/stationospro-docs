title: ¿Cómo descargar e instalar el cliente?
---

Este artículo explica cómo instalar el cliente de PocketNAS en cada plataforma.

## Móvil
<Tabs items={["iOS","Android"]}>

<Tab>

1. Abra la App Store y busque «PocketNAS»;
2. Descargue la aplicación PocketNAS y siga las indicaciones para completar la instalación.

\* Este cliente solo es compatible con iOS 12 o versiones posteriores

</Tab>

<Tab>

* Método 1:
1. Abra la tienda Google Play y busque «PocketNAS»;
2. Descargue la aplicación PocketNAS y siga las indicaciones para completar la instalación.

* Método 2:
1. Visite el sitio web oficial de StationPC y descargue el [instalador del cliente Android](https://www.stationpc.com/pages/download);
2. Una vez descargado, ejecute el instalador y siga las indicaciones para completar la instalación del cliente Android.

\* Este cliente solo es compatible con Android 10 o versiones posteriores

</Tab>

</Tabs>

## Escritorio
<Tabs items={["MacOS","Windows"]}>

<Tab>

1. Visite el sitio web oficial de StationPC y, según el tipo de chip del dispositivo (X86 o chip M), seleccione la plataforma correspondiente y descargue el [instalador del cliente para macOS](https://www.stationpc.com/pages/download);
2. Una vez descargado, ejecute el instalador y siga las indicaciones para completar la instalación del cliente para macOS.

\* Este cliente solo es compatible con macOS 14.0 o versiones posteriores

</Tab>

<Tab>

1. Visite el sitio web oficial de StationPC y descargue el [instalador del cliente para Windows](https://www.stationpc.com/pages/download);
2. Una vez descargado, ejecute el instalador y siga las indicaciones para completar la instalación del cliente para Windows.

\* Este cliente solo es compatible con Windows 10 o versiones posteriores

</Tab>

</Tabs>

## Televisión
<Tabs items={["AndroidTV","AppleTV"]}>

<Tab>

* Método 1:
1. Abra la tienda Google Play y busque «StationCloudTV»;
2. Descargue la aplicación StationCloudTV y siga las indicaciones para completar la instalación.

* Método 2:
1. Visite el sitio web oficial de StationPC y descargue el [instalador del cliente para TV](https://www.stationpc.com/pages/download);
2. Copie el archivo del instalador a una unidad flash USB;
3. Conecte la unidad flash USB con el archivo del instalador al dispositivo de TV e instale el cliente de TV en el dispositivo.

\* Este cliente solo es compatible con Android TV 6.0 o versiones posteriores

</Tab>
