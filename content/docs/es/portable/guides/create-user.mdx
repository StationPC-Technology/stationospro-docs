title: ¿Cómo crear un subusuario?
---

En PocketCloud, puede crear varias cuentas de subusuario para facilitar el uso compartido entre varias personas.

> Nota:
> * Cada subusuario dispone de un espacio independiente y no puede acceder directamente a los demás.
> * Los distintos subusuarios pueden acceder a los datos mediante el uso compartido local.
> * La cuenta de administrador no puede ver los datos de los subusuarios.
> * Los subusuarios admiten la función Cine.

1. Inicie sesión en el cliente con la cuenta de administrador, vaya a la página **Dispositivo**, abra **Gestión de usuarios > Usuarios** y haga clic en «+» para añadir un usuario.

<img src="/images/es/portable/guides/create-user/create-user-2.jpg" width="30%" />

2. Cree la cuenta de subusuario y configure los permisos de usuario según sea necesario.

<img src="/images/es/portable/guides/create-user/create-user-3.jpg" width="30%" />
<img src="/images/es/portable/guides/create-user/create-user-4.jpg" width="30%" />

3. Una vez creado el subusuario, puede hacer clic en la zona del recuadro rojo para editarlo o eliminarlo.
