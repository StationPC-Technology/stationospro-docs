title: ¿Cómo conectarse a PocketCloud?
---

Puede conectarse a PocketCloud mediante los siguientes métodos de acceso; elija el que mejor se adapte a sus necesidades.

## Con conexión a Internet
Con el dispositivo conectado a Internet, puede conectarse a PocketCloud de las siguientes formas.
### Método 1: Introducir la dirección IP
Una vez que PocketCloud se haya conectado correctamente a Internet, puede consultar la dirección IP de las siguientes formas:
* Puede encontrar la dirección IP de PocketCloud en la gestión del router.
* Puede consultar la dirección IP de PocketCloud en la pantalla pequeña.

<img src="/images/es/portable/guides/device-connection/1-1.jpg" width="30%" />
<img src="/images/es/portable/guides/device-connection/1-2.jpg" width="30%" />

### Método 2: Introducir el Station ID
Si ha activado el servicio de acceso remoto, puede introducir el Station ID para conectarse a PocketCloud.

### Método 3: Descubrir dispositivos en la red local
Después de entrar en la aplicación, haga clic en Descubrir dispositivos en la red local (señalado con el recuadro rojo) para abrir la lista de búsqueda; se detectarán y mostrarán automáticamente todos los dispositivos PocketCloud de la misma red local. Seleccione el dispositivo PocketCloud al que desee conectarse.

<img src="/images/es/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/es/portable/guides/device-connection/1-5.jpg" width="30%" />

### Método 4: Inicio de sesión anterior
Después de entrar en la aplicación, haga clic en Descubrir dispositivos en la red local (señalado con el recuadro rojo) para abrir la lista de búsqueda. Si el dispositivo tiene registros de inicio de sesión anteriores, puede usar Inicio de sesión anterior para rellenar rápidamente la información de acceso y de la cuenta.

<img src="/images/es/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/es/portable/guides/device-connection/1-7.jpg" width="30%" />

Una vez detectado el dispositivo, introduzca el usuario y la contraseña para iniciar sesión.

## Sin conexión a Internet
Si no dispone de conexión a Internet, puede conectarse a PocketCloud de las siguientes formas.

### Método 1: Conexión directa por WiFi
> Después de conectar el teléfono directamente a PocketCloud por WiFi, no es necesario desconectar esa conexión: puede activar al mismo tiempo los datos móviles del teléfono para acceder a redes externas (por ejemplo, navegar por la web o recibir mensajes), cubriendo así tanto el acceso a los datos del dispositivo como las necesidades de red externa.
Después de entrar en la aplicación, haga clic en Conexión directa al dispositivo para abrir la lista de búsqueda; mediante Bluetooth se detectarán y mostrarán automáticamente todos los dispositivos PocketCloud cercanos. Seleccione el dispositivo PocketCloud al que desee conectarse.

### Método 2: Acceso mediante el punto de acceso del teléfono
> Nota: con este método, cuando se accede a datos externos (como el acceso a la nube o las descargas sin conexión), PocketCloud utiliza datos móviles a través del punto de acceso del teléfono. Controle el consumo de datos para evitar cargos adicionales por exceder el límite.
Si necesita utilizar los datos móviles del teléfono, puede crear una red temporal mediante el punto de acceso del teléfono. Los pasos son los siguientes:  
1. Active la función de punto de acceso del teléfono y establezca el nombre (SSID) y la contraseña;  
2. Abra la aplicación, haga clic en «Configuración de red», siga las indicaciones para entrar en la página de configuración de red e introduzca manualmente el nombre y la contraseña del punto de acceso del teléfono para conectar PocketCloud con el punto de acceso;

3. Una vez establecida la conexión, entre en la aplicación y haga clic en Descubrir dispositivos en la red local; se detectarán automáticamente los dispositivos PocketCloud de la misma red del punto de acceso. Seleccione el dispositivo correspondiente e introduzca el usuario y la contraseña para iniciar sesión.
