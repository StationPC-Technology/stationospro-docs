title: Instalación de un SSD M.2 en la base
---

La base de PocketCloud permite instalar un SSD M.2 NVMe 2280.

## Procedimiento

1. Desconecte la base de la alimentación.

2. Con el destornillador incluido, gire el tornillo en sentido antihorario y retire la placa inferior.

![](/images/es/portable/hardware/ssd-install/dock/dock-ssd-install_1.png)

3. Inserte el SSD en la ranura M.2 NVMe y fíjelo girando el tornillo.

![](/images/es/portable/hardware/ssd-install/dock/dock-ssd-install_2.png)

4. Vuelva a colocar la placa inferior.

![](/images/es/portable/hardware/ssd-install/dock/dock-ssd-install_3.png)
