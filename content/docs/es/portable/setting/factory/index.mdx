title: "Restablecimiento de fábrica"
---

El restablecimiento de fábrica permite devolver el dispositivo a su estado inicial; la operación debe realizarse desde la APP.  

> Nota: si el dispositivo ya tiene vinculado un servicio remoto, el restablecimiento de fábrica desvinculará automáticamente dicho servicio y será necesario conectarse a Internet para completar la operación;

## Cómo restablecer los valores de fábrica
1. Abra el cliente, acceda a la página **Dispositivo** y busque la opción **Hardware y sistema > Restablecimiento de fábrica**;  
2. Haga clic en **Restablecimiento de fábrica** e introduzca la contraseña para iniciar el proceso de restablecimiento.  
> * Formatear el disco: si se elige «No formatear», el sistema creará automáticamente el directorio «olduserdata»; una vez finalizado el restablecimiento, los archivos de datos originales se guardarán en dicho directorio.
