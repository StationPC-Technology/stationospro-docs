## Formatos de vídeo

| Formato | iOS  | Android |
| ------ | ------ | --------- |
| MP4  | Compatible | Compatible    |
| MOV  | Compatible | Compatible    |
| WMV  | Compatible | Compatible    |
| WTV  | Compatible | Compatible    |
| WEBM | Compatible | Compatible    |
| VOB  | Compatible | Compatible    |
| TS   | Compatible | Compatible    |
| SWF  | Compatible | Compatible    |
| RM   | Compatible | Compatible    |
| RMVB | Compatible | Compatible    |
| OGV  | Compatible | Compatible    |
| MXF  | Compatible | Compatible    |
| MTS  | Compatible | Compatible    |
| MPG  | Compatible | Compatible    |
| MPEG | Compatible | Compatible    |
| MKV  | Compatible | Compatible    |
| M2V  | Compatible | Compatible    |
| HEVC | Compatible | Compatible    |
| F4V  | Compatible | Compatible    |
| AVI  | Compatible | Compatible    |
| 3GP  | Compatible | Compatible    |

## Resolución

| Resolución | iOS y Android |
| -------- | ---------- |
| 4K     | Con una red en buen estado (por ejemplo, red de área local o conexión directa al dispositivo) se reproduce con normalidad; con una conexión de datos móviles suelen producirse cortes |
| 8K     | No compatible |
