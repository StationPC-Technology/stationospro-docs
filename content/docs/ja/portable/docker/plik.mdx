## イントロダクション
Plik はオープンソースで軽量、安全な一時ファイル共有サービスで、**純粋にウェブでの使用をサポート**しており、ブラウザを開くだけでファイルのアップロード、共有、転送を行えます。Docker と組み合わせることで、複雑な設定なしに素早くプライベートな一時ファイル中継ステーションを構築でき、シンプルで使いやすく、プライバシーと安全性を確保できます。

## 使用シーン
- デバイス間での一時的なファイル転送、スマホとパソコンが直接やり取りでき、クライアントソフトのインストールは不要
- 同僚や友人との間でファイルをすばやく共有、すぐに使えて効率的で便利
- 機密ファイルを公共クラウドにアップロードしたくない場合、自前でサービスを構築する方がより安全で管理しやすい
- 一時的に作業用資料として、ログ、インストールパッケージ、設定ファイルなどを共有する

## 機能特徴
- 純粋なウェブアクセス、全プラットフォーム対応、何のAPPもインストール不要、操作ハードルが低い
- CLI クライアント操作をサポートし、コマンドラインでファイルのアップロードや管理を行うことができます
- ファイルの暗号化をサポートし、共有パスワードを設定してファイルの安全を確保できます
- ファイルの有効期限やダウンロード回数をカスタマイズ可能で、「閲覧後すぐに消える」機能をサポート（OneShot）
- ワンクリックで共有リンクを生成でき、共有をいつでも無効にでき、柔軟にコントロール可能
- リソース占有が低く、Docker ワンクリックでデプロイ、メンテナンスコストが低い

## デプロイメントチュートリアル
### Plikコンテナを作成
1。Dockerの画面に入り、「Images」（イメージ）をクリックし、検索ボックスに「plik」と入力して、対応するイメージを見つけたらダウンロードをクリックします。
    <img src="/images/common/portable/docker/plik/1-2.png" width="100%" />

2. ミラーのダウンロードが完了したら、「Containers」（コンテナ）ページに入り、「コンテナの作成」をクリックし、「rootgg/plik」イメージを選択して、「次へ」をクリックします。
＞ 温かいヒント：コンテナをデバイスの起動時に自動で開始させたい場合は、ページの「起動時に開始」オプションにチェックを入れてください。
    <img src="/images/common/portable/docker/plik/1-3.png" width="100%" />

3. パスマッピングの設定で、パスマッピングを追加をクリック
* アップロードファイルの保存: ローカルストレージパス「My Files/upload」を作成し、コンテナ内パス「/root/files」をローカルパス「My Files/upload」にマッピングします
    

4.  すべての設定を確認して間違いがなければ、「確認」をクリックし、「作成後に起動」を選択すると、Plikコンテナの作成と起動が完了します。
    <img src="/images/common/portable/docker/plik/1-4.png" width="100%" />

## Plik の基本的な使い方
### 1. Plikにアクセス：

<img src="/images/common/portable/docker/plik/1-6.png" width="100%" />

アクセスアドレス：http://IP:8080/、IPを自分のサーバー（またはPocketCloudデバイス）のIPアドレスに置き換える；
> 注意：PocketCloudデバイスの場合は、直接デバイス自身のIPを使用してください；
> デプロイ時にポートを変更した場合、アクセスアドレスのポート番号も対応して調整する必要があります。

### 2. 設定 Plik：
ニーズに応じて関連の設定を行うことができます。
<img src="/images/common/portable/docker/plik/1-7.png" width="100%" />

| 設定項目 | 説明 |
| ---- | ---- |
| ダウンロード後に破棄 | ファイルは一度ダウンロードされると永久に削除されます |
| ストリーミング | ファイルを直接ダウンロード者にストリーミングし、サーバーに保存しない |
| 削除可能 | リンクを持っている人はアップロードしたファイルを削除できます |
| エンドツーエンド暗号化 | アップロード前にファイルは暗号化され、パスワードを持つ者のみが復号可能 |
| パスワード保護 | HTTP 基本認証でアクセスパスワードを設定し、安全を確保 |
| 備考説明 | アップロードされた内容にコメントを追加することをサポート |
| 有効期限 | ファイルの有効期間を設定し、期限が切れると自動的に無効になります |

#### 3. ファイルをアップロード
ファイルを直接ウェブページのアップロードエリアにドラッグするか、または「ファイルを選択」をクリックしてアップロードしてください。
#### 4.  ファイルを共有する
アップロードが完了したら、ページで生成された共有リンクをコピーし、リンクをクリックするとダウンロードできます。
