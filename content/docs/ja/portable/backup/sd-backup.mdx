PocketCloud 内蔵 SD スロット、SD カードデータバックアップ機能をサポートし、具体的な説明と操作手順は以下の通りです：

- SD カードデータはデフォルトでパス **「My Backup/Backup From xxx」** にバックアップされます（「xxx」 は SD カード識別名です）。
- バックアップ操作は2つの方法をサポートしています：デバイスの小さい画面での迅速なバックアップ、またはクライアントを通じて完全なパラメータ設定後のバックアップ。

> 注意：
> 既にクライアントで SD カードのバックアップのデフォルト設定（バックアップ元やバックアップ先の調整など）を変更している場合、その後小画面でバックアップを実行したり、クライアントでクイックバックアップを行ったりすると、変更後の新しい設定が自動的に使用され、再設定は不要です。

## クライアントを通じてバックアップ
クライアントは「クイックバックアップ」と「高度バックアップ」の2つのモードを提供しており、ニーズに応じて選択できます：

### 方法1：高速バックアップ（ワンクリックで起動、設定不要）
1. クライアントを開き、**ホーム > マイデバイス** ページに入る；
2. デバイスリストで挿入済みの SD カードを見つけて、対応する「バックアップ」ボタンをクリックすると、クイックバックアップを開始できます。

### 方法2：高度なバックアップ（カスタムパラメータ、柔軟な設定）
1. クライアントを開き、**ホーム > マイデバイス** ページに入る；
2. 認識された SD カードをクリックして、「SD カードバックアップ設定」画面に入ります；
3. 必要に応じて以下のバックアップパラメータを調整し、設定完了後にバックアップを開始します：
- **バックアップ元**：『全体バックアップ』（デフォルト）または『指定フォルダのバックアップ』をサポートしており、バックアップするファイルのパスを必要に応じて選択できます；
- **バックアップ先**：バックアップファイルの格納ディレクトリをカスタマイズ可能；
- **バックアップ方法**：'手動バックアップ'（デフォルト）、'定期バックアップ'、'挿入時自動バックアップ'を提供；
- **ファイルフィルタリング**：ファイルサイズでバックアップファイルをフィルタリングすることをサポートします。

## 小さな画面でバックアップ（高速操作、クライアント不要のシナリオに対応）
1. SDカードをPocketcloud SDスロットに挿入します。
2. 小さい画面にSDカードが挿入された検出画面が表示されます。
![](/images/common/portable/backup/sd-backup/sd-card-has-been-inserted.png)
3. ノブで**Backup**を選択した後、ノブをクリックしてバックアップを開始します。
4. バックアップが完了すると、機器は「ビー」と二回鳴り、小さい画面にバックアップ成功と表示されます。
![](/images/common/portable/backup/sd-backup/sd-card-backup-finish.png)
