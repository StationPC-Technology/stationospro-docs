title: "Windows で NFS ディスクにアクセスすると中国語が文字化けする"
---

> 中国語の文字化けは通常、エンコードの不一致やシステムの地域設定の問題によって発生します。Windows 上の NFS マップドディスクの中国語文字化けに関して、テストの結果、以下の方法で解決できます：

> 手順：

1. **コントロールパネル** を開く → **時計と地域** → **地域**。
2. **「管理」** タブに切り替え、**「システムロケールの変更」** をクリックします。
3. 選択されているのが **「中国語（簡体字、中国）」** であることを確認してください。 リストの一番下にある **Beta オプション** にチェックを入れてください。
<img src="/images/common/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. 修正後にシステムを再起動し、再度 NFS ディスクをマウントして、中国語が正常に表示されるか確認してください。
