title: "Windows で WebDAV リンク失効後にファイルマネージャーが固まる"
---

1. 「windowsロゴキー」と「R」を押して、[ファイル名を指定して実行] ウィンドウを開き、cmd を入力して[OK] をクリックすると、レジストリエディターウィンドウが開きます。

2. ```net use z: /delete```を入力して、Enterキーを押して、WebDAVのマウントを削除します。

- その中で「z:」はWebDAVにマウントされたドライブ文字です。もしマウントされたドライブ文字がzでない場合、zを実際のドライブ文字に置き換えてください。
