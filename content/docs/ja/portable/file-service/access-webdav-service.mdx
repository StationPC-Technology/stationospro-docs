WebDAV（Web-based Distributed Authoring and Versioning）は、HTTPに基づく拡張プロトコルであり、ネットワーク上でのファイル共有と協力のために使用されます。
それはユーザーが Web ブラウザ または クライアントアプリケーション を通じてリモートサーバー上のファイルにアクセス、編集、管理することを可能にします。

**主に以下の機能を備えています：**
1. ファイルのアップロードとダウンロード：ローカルファイルをサーバーにアップロードしたり、サーバーからローカルにファイルをダウンロードすることをサポートします。
2. ファイル管理：リモートサーバー上でファイルやフォルダを作成、削除、名前変更、または移動することができます。
3. ファイル同期：ローカルとリモートのファイルの同期をサポートし、データの一貫性を維持します。
4. ファイル共有とコラボレーション：サーバー上のファイルを他のユーザーと共有し、チームでの協力を実現できます。

## WebDAVを有効にする
WebDAV デフォルトではオフになっており、手動で有効にする必要があります。以下の手順に従って操作してください：
1. Appの**ファイル共有プロトコル**のページを開きます。<br />
2. **WebDAV サービス**をクリックします。<br />
3. **スイッチボタン**をオンにすると、**WebDAV サービス**を有効にできます。<br />

## ブラウザでアクセスする

## 在 Windows 上访问

> **注意**：建议在 Windows 上使用 **[RaiDrive](https://www.raidrive.com)** 访问 WebDAV 服务。

1. 按下 **Win + E** 打开 **文件资源管理器**  
2. 在左侧栏右键点击 **网络**，选择 **映射网络驱动器**  
   <img src="/images/common/portable/file-service/access-samba-service/9-1.png" width="100%" height="100%" />

3. 在弹出的窗口中输入 WebDAV 地址：  
   ```http://NAS设备IP:5005```
そして **完了** をクリックします
   <img src="/images/common/portable/file-service/access-webdav-service/1-4.png" width="100%" height="100%" />

4. ログインのプロンプトでユーザー名とパスワードを入力する
   <img src="/images/common/portable/file-service/access-webdav-service/1-5.png" width="100%" height="100%" />

5. 完了したら、**このPC**でローカルディスクのようにNAS上のファイルにアクセスできます
   <img src="/images/common/portable/file-service/access-webdav-service/1-6.png" width="100%" height="100%" />

## macOS 上でアクセス

1. 右クリックで **Finder（Finder）** を開き、メニューバーから **移動 → サーバへ接続…** を選択します
   <img src="/images/common/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />

2. サーバーのアドレスバーに入力してください：
   ```http://NAS设备IP:5005```
   然后点击 **连接**  
   <img src="/images/common/portable/file-service/access-webdav-service/3-2.png" width="100%" height="100%" />

3. 输入用户名和密码，点击 **连接**  
   <img src="/images/common/portable/file-service/access-webdav-service/3-3.png" width="100%" height="100%" />

4. 现在，你可以在访达中像访问本地文件夹一样浏览和管理 NAS 上的文件  
   <img src="/images/common/portable/file-service/access-webdav-service/3-4.png" width="100%" height="100%" />

## 在 Linux 上访问

使用 **davfs** 挂载 WebDAV 共享：

```bash
# インストール davfs2
sudo apt-get install davfs2

# マウントポイントを作成
# 例：/mnt/webdav_share をマウントディレクトリとして使用する
sudo mkdir /mnt/webdav_share

# WebDAV サービスをマウント
sudo mount.davfs http://NAS装置IP:5005 /mnt/webdav_share

# マウントに成功した後、/mnt/webdav_share ディレクトリで NAS 上のファイルにアクセスして管理できます
```

## その他のクライアントでアクセス
- 接続情報
    - IP：NASデバイスIP
    - ポート：http のデフォルトは5005、https は現在サポートされていません
    - アカウント：NASデバイスのログインユーザー名
    - パスワード：NASデバイスのログインパスワード
- マウントディレクトリの説明
    - メインSSD：`/ログインユーザー名`
      - 例1：すべてのディレクトリ。現在のユーザーが test の場合、マウントディレクトリは `/test`
      - 例2：指定ディレクトリ。現在のユーザーが test の場合、マウントディレクトリは `/test/Pictures`
      - その他：複数ユーザーに対応し、各ユーザーに1つのマウントディレクトリが対応します
    - 外部ストレージ：`/外部ストレージ名`
      - 例1：すべてのディレクトリ。外部SDカード名が SD 60GB BA26 の場合、マウントディレクトリは `/SD_60GB_BA26`
      - 例2：指定ディレクトリ。外部SDカード名が SD 60GB BA26 の場合、マウントディレクトリは `/SD_60GB_BA26/Pictures`
    - ⚠️ 注意：
      - 一部のクライアントではルートディレクトリ `/` だけを指定できないため、上記の対応する具体的なマウントディレクトリを指定してください
      - ファームウェア &lt;= 3.1.0.16 から最新ファームウェアへアップグレードした後は、マウントディレクトリが調整されます。新バージョンのマウント方式に従ってください

## 其他问题

* 问：Windows 文件资源管理器无法挂载 WebDAV HTTP 服务怎么办？
* 答：请参考 [Windows 无法挂载 WebDAV 到本地计算机](/zh-CN/pocketcloud/file-service/windows-webdav-http-mount)

* 问：Windows 支持 WebDAV HTTPS 吗？
* 答：Windows 文件资源管理器不支持 WebDAV over HTTPS。你可以使用 **[RaiDrive](https://www.raidrive.com)** 来挂载 WebDAV-HTTPS 服务。

* 问：WebDAV-HTTPS 服务使用哪个端口？
* 答：WebDAV-HTTPS 的默认端口是 5006。你可以使用以下地址访问服务：`https://NAS_IP_Address:5006`.

* 问：为什么 Windows 无法通过 WebDAV 打开大文件？
* 答：请参考 [Windows 通过 WebDAV 访问大于 50MB 文件时出现错误提示](/zh-CN/pocketcloud/file-service/windows-webdav-filelimit)
