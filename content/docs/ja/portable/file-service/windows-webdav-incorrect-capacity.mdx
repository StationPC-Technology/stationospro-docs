title: "Windows で WebDAV をマウントした後に容量表示が異常になる"
---

この問題は Windows に標準搭載されている WebClient コンポーネントが WebDAV サーバーの実際のストレージ容量を取得できないことに起因しています。WebDAV ネットワークドライブをマウントする際に、システムがリモートストレージのクォータデータを取得できないため、デフォルトでローカルシステムディスク（C ドライブ）の容量情報を読み取り、割り当てられたドライブ文字に表示してしまい、最終的にディスク容量の表示異常が発生します。

もし容量表示の問題を解決する必要がある場合は、サードパーティのツール：RaiDrive、CloudMounterなどの使用をお勧めします。
