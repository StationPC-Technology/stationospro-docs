PocketCloud に接続しようとして失敗した場合は、「まずデバイスの状態を確認し、その後ネットワーク環境を調査する」という手順で原因を特定し、効率的に問題を解決できます。

> 問題のトラブルシューティングには、モバイルアプリの使用を優先することを推奨します

## 一、機器ハードウェアの状態確認
- **PocketCloud 電源とバッテリー**
デバイスが正常に起動していることを確認してください（画面が点灯しており、黒画面や点滅などの異常がないこと）。バッテリー残量が20％以上のときに接続を試みることを推奨します。残量が少ない場合は、先に電源に接続してから操作してください。バッテリー不足によりデバイスがスリープモードに入るのを避けるためです。

- **PocketCloud ネットワーク状態の確認**
- 接続 WIFI：デバイスの小さい画面を通してネットワーク接続状態（「接続済み」「信号強度」など）および対応する IP アドレスを確認し、WIFI が切断されていないことを確認する。
- 有線ネットワークに接続する場合：デバイスの状態ランプで判断できます（緑ランプが点灯＝ネットワーク正常、赤ランプが点滅＝LANケーブルがしっかり接続されていないか、ネットワークに異常がある）、再度LANケーブルを抜き差しして確認してください。

## 二、ネットワーク環境の基本チェック

### 1. 問題の状況：PocketCloudがスキャンできない
- WIFI 直接接続モード
- デバイスの「WIFI 直接接続機能」が有効になっていることを確認します：デバイスの画面で【設定】－【接続方法】を操作し、「WIFI 直接接続スキャンを許可」にチェックを入れます（機種によっては初期設定で無効になっています）。
- 接続距離の制御：携帯電話と PocketCloud は 1 メートル以内で接続する必要があります。距離が遠すぎると信号が減衰します。また、携帯電話の「Bluetooth」と「テザリング」をオフにして、信号干渉を避けてください。
- クライアントを再起動する：PocketCloud APPを閉じ、携帯電話のバックグラウンドでプロセスを完全に終了させ、再度開いた後【Direct Device】をクリックしてスキャンし、APPのキャッシュ問題を排除する。

- ローカルエリアネットワークモード
- IP のアドレスの有効性を確認する：
① デバイスの小さな画面を通じて公式 IP を取得する（経路：【デバイス情報】-【ネットワーク設定】-【LAN IP】、例：192.168.1.40）；
② もしルーターのバックエンドやサードパーティのツールを通じて IP を取得する場合、公式の IP と比較し、「デバイスの現在の IP ではないもの」の使用を避ける必要があります（ルーターの再起動により IP が変わる可能性があります）。
- VPN/代理を無効にする：携帯電話やコンピューターのVPN/代理はネットワークのルーティングを変更し、LAN内の機器にアクセスできなくなることがあります。完全に無効にしてから再試行してください。
- ローカルネットワークを確認：スマートフォン/パソコンが PocketCloud と同じローカルネットワークに接続されていることを確認してください（異なる周波数帯での接続を避ける、例えばスマートフォンが 5G や WIFI に、デバイスが 2.4G や WIFI に接続される場合）。

### 2. 問題の状況：デバイスは見つかるが、接続がタイムアウト/失敗する
- アカウントパスワード確認の問題
- アカウントとパスワードの確認：入力したアカウントとパスワードが PocketCloud に紐づけられたアカウントと一致していることを確認してください。パスワードを忘れた場合は、APP のログインページで「パスワードを忘れた」をクリックし、紐づけられたメール/電話番号で確認コードを受け取り再設定してください。再設定後は、5 分以内に再試行することをお勧めします。
- アカウント権限の区分：初回接続を開始できるのは「デバイス管理者アカウント」のみです。「ゲストアカウント」は、まず管理者がデバイスの【権限設定】で許可した後に、正常に接続できるようになります。

- ポートとアドレスの衝突
- IP の住所入力を確認してください：
① IP（例えば 192.168.1.40）を手動で入力する際、入力ミス（例えば 192.168.0.40と誤入力するなど）がないこと、余分な文字が追加されていないことを確認する；
② もしアドレスにポート番号が付いている場合（例：192.168.1.40:8080）、ポート番号がデバイスのデフォルトポートであることを確認する必要があります（【ネットワーク設定】-【ポート設定】で確認可能です）。デフォルトでないポートは APP 接続ページで手動入力する必要があります。
- ポートの使用状況を確認する：もしLAN内で他の機器が「32400」「8096」「8080」などの一般的なポートを使用している場合は、機器の【ネットワーク設定】－【ポート設定】に入り、デフォルトポートを使用されていないポート（例：8080を8081に変更）に変更してください。変更後、機器を再起動して接続を試みてください。
