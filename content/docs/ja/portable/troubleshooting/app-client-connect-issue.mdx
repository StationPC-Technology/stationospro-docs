## 1. 小型画面でネットワーク状態を確認
小型画面：デバイス設定 -> デバイス情報 -> デバイスのネットワーク状態を確認

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/1-2.jpg" width="80%" />

## 2. 直接接続
### 2.1 小型画面で確認
2.1.1 AP モードに回転・スワイプ
2.1.2 IP、名前、パスワードを確認

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/2-1.jpg" width="80%" />

### 2.2 App での操作
#### 2.2.1 スマートフォンのシステム Wi-Fi で直接接続
AP モードの名前（Wi-Fi 名）とパスワードに従って、システムの Wi-Fi リストから接続します

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/2-2-1.jpg" width="80%" />

#### 2.2.2 直接接続 IP を入力してログイン
ログイン時には、AP モードの IP と対応するアカウント・パスワードを使用してログインします

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/2-2-2.jpg" width="80%" />

## 3. 未接続
### 3.1 小型画面で確認
デバイス設定 -> デバイス情報
スワイプして名前を確認

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/3-1.jpg" width="80%" />

### 3.2 App での操作
#### 3.2.1 デバイスのネットワーク設定で接続
デバイス情報の名前に基づいて、デバイスリストから該当する名前を探し、クリックして接続します

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/3-2-1-1.jpg" width="40%" />
<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/3-2-1-2.jpg" width="40%" />

#### 3.2.2 設定済みネットワーク IP を入力してログイン
設定完了後、ログイン画面に戻ります
自動入力された IP、または小型画面のデバイス情報の IP と、対応するアカウント・パスワードを使用してログインします

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/3-2-2-1.jpg" width="80%" />
<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/3-2-2-2.jpg" width="80%" />

## 4. ネットワーク接続済み
### 4.1 IP ログイン
スマートフォンとデバイスが同じネットワークにあることを確認します
小型画面のデバイス情報の IP を使用し、対応するアカウントとパスワードを入力してログインします
3.2.2 の手順と同じです

### 4.2 StationID ログイン
有効化時の StationID 情報（通常は電話番号またはメールアドレス）を使用します
ログイン画面で StationID とパスワードを入力してログインします

<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/4-2-1.jpg" width="40%" />
<img src="/images/ja/portable/troubleshooting/app-client-connect-issue/4-2-2.jpg" width="40%" />

#### 4.2.1 注意
StationID の前後にスペースがないこと、およびリモートログイン有効化時と一致していることを確認してください

## 5. それでも接続できない場合
デバイス接続失敗画面で、フィードバックに進み、ログをアップロードします
