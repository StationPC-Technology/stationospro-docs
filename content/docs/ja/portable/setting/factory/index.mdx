工場出荷状態にリセットすると、デバイスを初期状態に戻すことができます。操作はAPP端から行う必要があります。

＞ 注意：デバイスがリモートサービスに既に紐付けられている場合、工場出荷時設定にリセットするとそのサービスの紐付けが自動的に解除され、操作を完了するにはインターネットに接続する必要があります；

## 工場出荷時設定に戻す方法
クライアントを開き、**デバイス**ページに移動し、**ハードウェアとシステム > 工場出荷時設定に戻す**オプションを見つけます；
2. **工場出荷時設定に戻す**をクリックし、パスワードを入力すると復元プロセスが開始されます。
> * ハードディスクのフォーマット：『フォーマットしない』を選択した場合、システムは自動的に「olduserdata」ディレクトリを作成し、復元完了後、元のデータファイルはそのディレクトリに保存されます。
