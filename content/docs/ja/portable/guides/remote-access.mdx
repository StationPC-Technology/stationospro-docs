title: "リモートアクセスを行うには？"
---

PocketCloud 内蔵リモートアクセスサービスは、安全なリモートアクセス機能を提供します。このサービスを使用する前に、電話番号／メールアドレスを紐付け、ユニークな Station ID（あなたのデバイスを識別するため）を作成する必要があります。Station ID を通じて、あなたの PocketCloud に迅速にアクセスできます。

> 注意：
> * リモートアクセスサービスを使用するには、携帯番号またはメールアドレスを登録する必要があります；
> * サービスはあなたの PocketCloud のために自動で一意の Station ID を作成し、その ID を通じてデバイスに安全にアクセスできます；
> * 現在のネットワーク環境に基づき、システムは最適な接続方法を自動で選択します；
> * Station ID カスタム変更をサポートします。

## リモートサービスを開始
方法1:
デバイスの初回初期設定の際、ガイドに従って「リモートアクセスを有効にする」オプションにチェックを入れるだけです。

<img src="/images/common/portable/guides/remote-access/setupwized-remote_access-2.jpg" width="30%" />

方法2:
1. クライアントを開き、**デバイス**ページに入る；
2. **デバイス接続**を見つけ、その中でリモートサービスを手動でオンまたはオフにできます

## リモートサービスの解除

工場出荷時の設定に戻すと、システムは自動的にリモートサービスの紐付けを解除します
> デバイスがリモートサービスにバインドされている場合、工場出荷時の設定に戻すにはネットワークに接続する必要があります；
