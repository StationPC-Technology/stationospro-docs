title: "Web からデバイスにアクセスするには？"
---

Web クライアント（Beta）は、デスクトップまたはモバイルアプリをインストールすることなく、ブラウザを通じて直接デバイスにアクセスして管理することを可能にします。二つのアクセス方式をサポートしています：**ローカルネットワークアクセス**と**リモートアクセス**で、さまざまなシナリオでの使用ニーズに応えます。

## 前提条件
1. デバイスが起動しており、正常にネットワークに接続されていることを確認してください。
2. リモートアクセスが必要な場合は、まずクライアントアプリで[リモートアクセス機能を有効化](/portable/guides/remote-access)を行い、Station IDの設定を完了してください。

## アクセス方法
### 方法一：ローカルエリアネットワークアクセス
コンピュータとデバイスが同じローカルエリアネットワーク（同じ WiFi / 有線ネットワーク）にある場合に適しており、アクセス速度が速く、安定性が高いです。

操作手順：
1. デバイスのLANIPアドレスを取得：デバイス付属の画面で確認するか、クライアントアプリの**デバイス情報**ページで確認できます。
2. ブラウザを開き、アドレスバーに `http://デバイスIP:9500` の形式のアドレスを入力します。
3。ログインページでユーザー名とパスワードを入力すると、Web管理画面に入ることができます。

> 例：もしデバイス IP が `192.168.3.10` の場合、アドレスバーに `http://192.168.3.10:9500` を入力します。

### 方法二：リモートアクセス
出張や外出先でのオフィス作業など、外部ネットワークの環境に適しています。公式のリモートアクセスポータルを通じて、自宅やオフィスの機器にアクセスできます。

操作手順：
1. リモートアクセス機能を有効にする。
2. ブラウザを開き、公式リモートアクセスのアドレスを入力してください：`https://login.stationpc.com/`
3. ログインページであなたの Station ID、ユーザー名、パスワードを入力し、認証が通ればデバイスにアクセスできます。

## 対応ブラウザ
機能の完全性と最適な使用体験を確保するために、以下のブラウザ（またはそれ以上のバージョン）で Web クライアントにアクセスすることを推奨します：
1. Chrome 50 以上のバージョン
2. Microsoft Edge 78 以上のバージョン
3. QQ ブラウザ高速版、360 ブラウザ高速版
4. Firefox 54 以上のバージョン
5. Safari 10 およびそれ以上のバージョン（Mac）

## 注意事項
1. Web クライアントは現在 Beta テスト段階にあり、部分的な機能は一時的に使用できない場合があります。完全な機能を得るために、クライアントアプリと併用することを推奨します。
2. LANアクセス時は、パソコンとデバイスが同じネットワークに接続されていることを確認してください。そうでないと、IP アドレスでアクセスできません。
3. リモートアクセス時は、デバイスがインターネットに接続されていることを確認してください。さもなければ、リモートポータルに接続できません。
4. ページの読み込みが正常でない場合は、推奨ブラウザに切り替えるか、ブラウザのキャッシュをクリアしてから再試行してください。
