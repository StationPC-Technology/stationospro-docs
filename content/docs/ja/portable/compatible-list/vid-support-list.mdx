## ビデオ形式

| フォーマット | iOS 端 | Android 端 |
| ------ | ------ | --------- |
| MP4  | 支持 | 支持    |
| MOV  | 支持 | 支持    |
| WMV  | 支持 | 支持    |
| WTV  | 支持 | 支持    |
| WEBM | サポート | サポート    |
| VOB  | 支持 | 支持    |
| TS   | 支持 | 支持    |
| SWF  | 支持 | 支持    |
| RM   | 支持 | 支持    |
| RMVB | サポート | サポート    |
| OGV  | 支持 | 支持    |
| MXF  | 支持 | 支持    |
| MTS  | 支持 | 支持    |
| MPG  | 支持 | 支持    |
| MPEG | サポート | サポート    |
| MKV  | 支持 | 支持    |
| M2V  | 支持 | 支持    |
| HEVC | サポート | サポート    |
| F4V  | 支持 | 支持    |
| AVI  | 支持 | 支持    |
| 3GP  | 支持 | 支持    |

## 解像度

| 解像度 | iOS、Android 端 |
| -------- | ---------- |
| 4K     | ネットワーク状況が良い場合（例えばローカルエリアネットワークや直接接続デバイス）、正常に再生できる。セルラーネットワーク接続時は、途切れやすい |
| 8K     | サポートされていません |
