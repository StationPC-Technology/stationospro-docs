## ビデオ形式

| フォーマット | iOS | Android |
| ------ | ------ | --------- |
| MP4  | 対応 | 対応 |
| MOV  | 対応 | 対応 |
| WMV  | 対応 | 対応 |
| WTV  | 対応 | 対応 |
| WEBM | サポート | サポート    |
| VOB  | 対応 | 対応 |
| TS   | 対応 | 対応 |
| SWF  | 対応 | 対応 |
| RM   | 対応 | 対応 |
| RMVB | サポート | サポート    |
| OGV  | 対応 | 対応 |
| MXF  | 対応 | 対応 |
| MTS  | 対応 | 対応 |
| MPG  | 対応 | 対応 |
| MPEG | サポート | サポート    |
| MKV  | 対応 | 対応 |
| M2V  | 対応 | 対応 |
| HEVC | サポート | サポート    |
| F4V  | 対応 | 対応 |
| AVI  | 対応 | 対応 |
| 3GP  | 対応 | 対応 |

## 解像度

| 解像度 | iOS、Android |
| -------- | ---------- |
| 4K     | ネットワーク状況が良い場合（例えばローカルエリアネットワークや直接接続デバイス）、正常に再生できる。セルラーネットワーク接続時は、途切れやすい |
| 8K     | サポートされていません |
