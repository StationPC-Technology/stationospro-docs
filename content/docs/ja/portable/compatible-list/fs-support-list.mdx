## 内蔵ストレージがサポートするファイルシステム形式

内蔵ストレージは主に exFAT、NTFS、および FAT32 をサポートしており、公式には exFAT の使用が推奨されています。

exFAT、NTFS と FAT32 のファイルシステム比較：

| 特徴          | exFAT（推奨）                        | NTFS                  | FAT32                   |
| :------------ | :------------------------------------- | :------------------------------------ | :------------------------------------ |
| **最大ファイル**  | **超大容量ファイルをサポート** | **超大容量ファイルをサポート** | **単一ファイルは4KBを超えてはいけません** |
| **最大パーティション**  | **超大パーティションをサポート** | **超大パーティションをサポート**     | **最大で2TBのみ**      |
| **システム互換性** | **Windows、Mac、Linux はすべて対応** | **Mac は読み取りのみ** | **Windows、Mac、Linux はすべて対応** |
| **安全性**    | **一般**               | **高い**        | **低い**                |
| **安定性**    | **比較的良い**       | **最良**              | **やや悪い**           |
| **速度**      | **速い**       | **速い**          | **遅い**       |
