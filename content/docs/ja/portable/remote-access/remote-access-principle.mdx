PocketCloud リモートアクセスサービスを提供し、ユーザーに安定で安全、便利なリモートアクセス体験を提供します。ユーザーがパブリックネットワークIP、ポート転送やDDNS設定などの専門的な技術知識を習得する必要はなく、使用のハードルを大幅に下げ、非技術ユーザーでも簡単にリモート操作を実現できるようにします。
> ユーザーは携帯電話番号/メールアドレスを紐付けることでStation IDを取得でき、Station IDを通じてリモートアクセスを行うことができます。

## 一、接続原理の説明
リモートアクセスは P2P（Peer-to-Peer、ポイントツーポイント）接続モードを採用しており、核心原理は次の通りです：
公式の中継サーバーとユーザー自身のネットワークの協調による「パンチホール」により、ネットワークの境界制限を打破し、最終的に PocketCloud とクライアント（携帯 /PC）間で直接通信接続を確立し、第三者サーバーを経由してデータを転送する必要はありません。

## 二、P2P接続モードの利点
| 特徴 | 説明 |
|------|------|
| ゼロコンフィギュレーション | 操作のハードルが非常に低く、ユーザーが手動でネットワークパラメータを設定する必要はなく、機能を開くだけで接続を試すことができます |
| 高効率伝送 | 直結条件を満たす場合、データは PocketCloud とクライアント間で直接伝送され、帯域幅は中継サーバーの制限を受けず、アクセス速度がより速くなります |
| 多端対応 | 同時にモバイルクライアント（スマートフォン／タブレット）と PC クライアントをサポートし、異なる使用シーン（外出先での業務、在宅リモート管理など）に適応 |

## 三、注意事項
1. 当デバイスとクライアントが同じローカルエリアネットワークにある場合、自動的にローカルネットワーク接続に切り替わります。
2. もし P2P の直接接続が確立できない場合、自動的に StationPC 経由の中継サーバ転送モードに切り替わり、リモートアクセス機能の利用を保障します；
3. 中継モードでは、アクセス速度や帯域幅は中継サーバーに制限されます。
