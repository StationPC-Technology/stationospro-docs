StationHubは、該当する機能を利用するときに必要な権限だけを申請します。システムのポップアップに表示される権限名は、iOS、Android、WindowsまたはmacOSのバージョンによって異なる場合があります。許可するかどうかはお客様が決定でき、権限を拒否しても、その権限に関係しない基本機能には影響しません。

## 1. 権限の取り扱い原則

- 権限が必要な機能を初めて利用するときにのみ申請し、起動時にすべての権限を一括で申請することはありません。
- 権限は現在の機能の明確な目的に使用します。権限をオフにすると関連機能が利用できなくなる場合がありますが、それによって他のデータを自動的に読み取ることはありません。
- 第三者プラグインまたはシステムサービスから追加の許可を求められる場合がありますが、許可するかどうかは引き続きお客様が管理します。
- 位置情報の権限は、ネットワーク設定の段階でWiFi名を読み取り、国コードを推定するためだけに使用します。バックグラウンド測位は行わず、座標を送信または保存しません。

## 2. iPhoneおよびiPad

| システム権限 | 起動する機能 | 当社が行うこと | オフにした場合の影響 |
| --- | --- | --- | --- |
| カメラ | QRコードによる紐付け、クイックログイン、アバター設定 | デバイス上でカメラ映像を読み取り、QRコードを認識するかアバターを撮影します | QRコードの読み取りやアバターの撮影ができません |
| 写真と動画 | アルバムのバックアップ、メディアの選択とアップロード、アバター設定 | お客様が選択したメディアを読み取ります。iOSの限定された写真範囲に対応しています | 該当するメディアをバックアップまたはアップロードできません |
| ローカルネットワーク | 同じLANにあるNASの検索と接続 | LAN内のデバイスを検出し、ローカル接続を確立します | LAN内のNASを検出または接続できません |
| 通知 | デバイス状態、バックアップの進行状況、アカウントセキュリティの通知 | お客様が許可したシステム通知を送信します | 該当する通知を受け取れません |
| Bluetooth | デバイスの紐付けとネットワーク設定 | 近くのデバイスを検出し、ネットワーク設定情報を渡します | Bluetoothで紐付けやネットワーク設定ができません |
| 使用中の位置情報 | ネットワーク設定時のWiFi地域の判定 | WiFi名を一時的に読み取り、国コードを推定します | WiFiと地域を手動で選択する必要があります |

## 3. Androidスマートフォンおよびタブレット

| システム権限 | 起動する機能 | 利用範囲 | オフにした場合の影響 |
| --- | --- | --- | --- |
| カメラ | QRコードによる紐付けとクイックログイン | デバイス上でQRコードを認識します | QRコードによる紐付けやログインができません |
| 写真、動画またはローカルストレージ | ファイルのアップロードとダウンロード、アルバムの自動バックアップ | お客様が選択したファイルとメディアにアクセスします | 該当するファイル操作を完了できません |
| 付近のデバイス、LANおよびWiFi | デバイスの検出、ローカル接続、ネットワーク設定 | 接続に必要なネットワーク状態を読み取ります | デバイスの検出やローカル接続の確立ができません |
| 通知 | タスクの進行状況、デバイス異常、アカウントセキュリティの通知 | プッシュ通知またはローカル通知を送信します | 該当する通知を受け取れません |
| Bluetooth | デバイスのペアリングとネットワーク初期化 | ネットワーク設定対象のデバイスを検出して接続します | Bluetoothでネットワーク設定を完了できません |
| ネットワーク位置情報 | ネットワーク設定の識別補助 | ネットワーク設定時にWiFi地域の判定を補助します | 地域を手動で選択する必要があります |
| バックグラウンド自動起動 | お客様が有効にした継続的なバックアップ | バックアップタスクを継続して実行します | バックアップがシステムにより中断される場合があります |
| クリップボード | 共有リンクを認識してファイル転送を開始 | 共有リンク機能を起動したときだけ読み取ります | 共有リンクを自動認識できません |

## 4. WindowsおよびmacOSクライアント

| プラットフォーム | 権限またはシステム機能 | 用途 | オフにした場合の影響 |
| --- | --- | --- | --- |
| Windows | デスクトップ通知 | タスクの進行状況、デバイス状態、異常を表示します | デスクトップ通知を表示できません |
| Windows | ローカルファイルシステム | アップロード、ダウンロード、フォルダー同期を行います | ローカルファイル操作を完了できません |
| macOS | システム通知 | バックアップの進行状況とデバイスの稼働状態を通知します | システム通知を受け取れません |
| macOS | ローカルディレクトリ | ファイル管理、アップロード、ダウンロード、同期を行います | 該当するファイルタスクを完了できません |

## 5. その他の説明

権限の許可は、個人情報の継続的な収集を意味しません。お客様の明確な許可なく、当社がNAS内の私有ファイルを主体的に読み取ったりアップロードしたりすることはありません。また、バックグラウンド測位の権限を申請したり、広告用のデバイス識別子を収集したりしません。デバイスのシステム設定からいつでも権限を取り消せます。取り消した後、関連機能を次回使用する際に理由と代替操作が表示されます。

機能が第三者アプリまたはサービスにより提供される場合は、[「第三者個人情報共有一覧」](./third-party-sdk-list)および当該サービス提供者のプライバシーポリシーも確認してください。情報の全体的な処理方法については、[「プライバシーポリシー」](./privacy-policy)をご覧ください。
