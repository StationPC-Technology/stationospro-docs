## はじめに

本説明では、StationPC 対応アプリおよび PC/Mac クライアントがオペレーティングシステムの権限を申請し、使用する状況についてご説明します。当社は**最小限の必要性、必要に応じた申請**という原則に従い、対応する機能を使用する際にのみ動的に権限を申請します。

権限の許可はいつでもシステム設定で管理できます。権限をオフにしても影響するのは対応する機能のみであり、製品の基本的なコアサービスには影響しません。

第三者のプラグインやサービスが追加の権限を申請する場合がありますが、許可したからといって個人情報を継続的に収集するわけではありません。

## iOS の権限

| シーン | 目的 | 権限を拒否またはオフにした場合の影響 |
| --- | --- | --- |
| デバイスのカメラを呼び出す | コードをスキャンして NAS デバイスを紐付け、クイックログイン、撮影によるアバター設定 | コードをスキャンしてデバイスを紐付けたり、撮影してアバターを設定したりできなくなります |
| 写真と動画のアルバムにアクセス | スマートフォンのアルバムの内容を NAS にバックアップ、画像や動画を選択してアップロード、アカウントのアバターを設定。iOS の限定的な写真アクセス（選択した写真のみを許可）に対応 | アルバムのバックアップや画像・動画のアップロードができなくなります |
| ローカルネットワークにアクセス | LAN 内で StationPC デバイスを検出して接続 | LAN 内の NAS デバイスを検出して接続できなくなります |
| システム通知を受信 | デバイス状態、バックアップ進捗、アカウントセキュリティ通知（時効性のある通知を含む）を受信 | 関連する通知を受け取れなくなります |
| Bluetooth デバイスにアクセス | デバイスの紐付けとネットワーク設定：付近のデバイスを検出し、ネットワーク設定情報を転送 | Bluetooth 経由でデバイスを紐付け、設定できなくなります |
| 位置情報を取得（使用中のみ） | ネットワーク設定時に現在の WiFi 名を読み取り、一時的に 1 回位置情報を取得して国コードを導出し、デバイスの WiFi 地域設定に使用。バックグラウンド測位は行わず、座標はアップロードも保存もされません | 現在の WiFi と地域を自動的に識別できず、手動で選択する必要があります |

## Android の権限

| シーン | 目的 | 権限を拒否またはオフにした場合の影響 |
| --- | --- | --- |
| デバイスのカメラを呼び出す | コードをスキャンしてデバイスを紐付け、クイックログイン | コードをスキャンしてデバイスを紐付けたり、クイックログインしたりできなくなります |
| ローカルストレージにアクセス | ファイルのアップロード、ダウンロード、アルバムの自動バックアップ機能を実現 | ファイルのアップロード、ダウンロード、アルバムの自動バックアップができなくなります |
| LAN と WiFi にアクセス | LAN 内のデバイス検出とローカル接続 | LAN 内のデバイスを検出できず、ローカル接続を確立できなくなります |
| プッシュ通知を受信 | タスク進捗、デバイス異常、アカウントセキュリティのリマインダー | タスク進捗、デバイス異常、セキュリティのリマインダーを受け取れなくなります |
| Bluetooth デバイスにアクセス | デバイスのペアリングとネットワーク初期化の補助 | Bluetooth 経由でデバイスのペアリングとネットワーク設定を完了できなくなります |
| ネットワーク位置情報を取得 | ネットワーク設定の識別を補助 | 現在の WiFi と地域を自動的に識別できず、手動で選択する必要があります |
| バックグラウンド自動起動 | バックグラウンドのバックアップタスクを維持（ユーザーが手動で有効化） | バックグラウンドのバックアップタスクが中断される可能性があります |
| クリップボードの内容を読み取る | 共有リンクを識別し、ファイル転送機能を起動 | 共有リンクを識別してファイル転送機能を起動できなくなります |

## Windows クライアントの権限

| シーン | 目的 | 権限を拒否またはオフにした場合の影響 |
| --- | --- | --- |
| デスクトップ通知を受信 | タスク進捗、デバイス状態、異常のリマインダーを表示 | タスク進捗、デバイス状態、異常のリマインダーを受け取れなくなります |
| ローカルファイルシステムにアクセス | ローカルファイルのアップロード、ダウンロード、フォルダー同期に対応 | ローカルファイルのアップロード、ダウンロード、フォルダー同期ができなくなります |

## Mac クライアントの権限

| シーン | 目的 | 権限を拒否またはオフにした場合の影響 |
| --- | --- | --- |
| システム通知を受信 | バックアップ進捗とデバイスの稼働状態を通知 | バックアップ進捗とデバイス状態の通知を受け取れなくなります |
| ローカルディレクトリにアクセス | ファイル管理、アップロード・ダウンロード、同期タスクを実行 | ファイル管理、アップロード・ダウンロード、同期タスクを実行できなくなります |

## 補足説明

すべての権限は必要に応じて申請され、起動時に一括で許可を求めることはありません。

権限をオフにすると一部の機能のみが無効になり、ログイン、デバイス接続、ファイル閲覧などの基本サービスには影響しません。

ユーザーの明確な許可なく、当社が NAS 内の私有ユーザーデータを主体的に読み取ったり、アップロードしたりすることはありません。

バックグラウンド測位の権限は申請せず、広告用のデバイス識別子も収集しません。位置情報はデバイスのネットワーク設定時に一時的にのみ使用され（WiFi 名の読み取り、国コードの導出）、座標はアップロードも保存もされず、世界的なプライバシーコンプライアンス要件に適合しています。
