ファイルマネージャーは StationOS Pro の中核アプリであり、デバイス上のすべてのファイルを一元管理するために使用します。ブラウザー上でファイルのアップロード／ダウンロード、ディレクトリ管理、権限共有、ゴミ箱からの復元、重複ファイルの整理を行えるほか、SMB、WebDAV、FTP、NFS などのファイルサービスを設定して、パソコンやスマートフォンから NAS 内のファイルに直接アクセスできます。

## インターフェースの紹介

ファイルマネージャーの上部は機能ごとに次のタブに分かれています。

| タブ | 説明 |
| --- | --- |
| マイファイル | 現在のユーザーの個人ファイル領域 |
| チームファイル | 複数人で協力してアクセスできるチーム共有領域 |
| 外部ストレージ | USB メモリやポータブルハードディスクなどの外部デバイス内のファイルを管理 |
| リモートマウント | リモート NAS やサーバー上の共有ディレクトリをマウント |
| アプリファイル | 各アプリが生成したデータファイルを表示 |
| お気に入り | お気に入りのファイルとフォルダーにすばやくアクセス |
| 外部リンク共有 | 作成済みの外部共有リンクを管理 |
| ゴミ箱 | 削除済みファイルの復元または完全削除 |
| 重複ファイル | 重複ファイルをスキャンして整理し、ストレージ領域を解放 |
| 管理者ビュー | 管理者がユーザー単位ですべてのファイルを表示（管理者のみ表示可能） |

ファイル一覧はリスト／グリッド表示の切り替えに対応し、ファイル名、サイズ、種類、更新日時、保存場所、作成日時、所有者などの情報を表示します。列ヘッダーをクリックすると並べ替えができます。

![My Files](/images/ja/app-guide/files-img/my-files.png)

## ファイルの基本操作

ツールバーには次の一般的な操作があります。

- **アップロード**：ファイルまたはフォルダー全体をアップロードします。
- **新規フォルダー**：新しいディレクトリを作成します。
- **並べ替え**：名前、サイズ、時間などで並べ替えます。
- **表示切り替え**：リスト表示とグリッド表示を切り替えます。

### 新規フォルダー

1. 対象のディレクトリに移動し、ツールバーの **新規フォルダー** をクリックします。
2. フォルダー名を入力します（最大 180 文字）。
3. フォルダーを保存するストレージ領域（例：ストレージ領域 1）を選択します。
4. **確認** をクリックして作成を完了します。

![New Folder](/images/ja/app-guide/files-img/new-folder.png)

### 右クリックメニュー

ファイルまたはフォルダーを右クリックすると、次の操作を実行できます。

| メニュー項目 | 説明 |
| --- | --- |
| 新しいウィンドウで開く | 新しいウィンドウで開く（フォルダー） |
| ダウンロード | ローカルのパソコンにダウンロード |
| コピー先／移動先 | 他のディレクトリにコピーまたは移動 |
| 切り取り／コピー | 切り取りまたはコピー |
| 削除 | 削除（ゴミ箱に移動） |
| 名前の変更 | 名前を変更 |
| お気に入り | お気に入りに追加 |
| 外部リンク共有 | 外部リンク共有を作成 |
| 詳細 | ファイルの詳細を表示 |

![Context Menu](/images/ja/app-guide/files-img/context-menu.png)

## 外部リンク共有

外部リンク共有では、NAS アカウントを持っていない外部ユーザーにファイルやフォルダーを共有できます。

1. 対象のファイルまたはフォルダーを右クリックし、**外部リンク共有** を選択します。
2. 共有パラメーターを設定します。
   - **共有名**：外部リンクに表示する名前。
   - **有効期限**：無期限、またはカスタムの終了日時。
   - **ダウンロードを許可**：アクセス者にファイルのダウンロードを許可するかどうか。
   - **パスワード保護**：リンクにアクセスパスワードを設定します。
   - **アクセス回数制限**：リンクの最大アクセス回数を制限します。
3. **リンクを作成** をクリックして共有リンクを生成します。

作成済みの共有は「外部リンク共有」タブで一括管理でき、リンクの確認、ルールの変更、共有の解除を行えます。

![Share Link](/images/ja/app-guide/files-img/share-link.png)

<Callout title="セキュリティのヒント" type="warn">
  機密ファイルを共有する場合は、パスワード保護を有効にし、有効期限を設定することをおすすめします。共有が完了したら、不要になったリンクを速やかに無効にしてデータの漏えいを防いでください。
</Callout>

## ファイルサービスの設定

ファイルマネージャー右上の **設定** をクリックすると、ファイルサービスを設定できます。設定ウィンドウには次のタブがあります。

- **ファイル共有プロトコル**：SMB、WebDAV、FTP、NFS サービスをそれぞれ設定します。
- **ファイルルール**：ファイルの命名などのルールを設定します。
- **リモートマウント**：リモートマウントに関するパラメーターを設定します。
- **外部共有**：外部リンク共有のグローバルルールを設定します。

SMB を例にすると、設定ページには次の項目があります。

- **表示するディレクトリ範囲**：マイファイル、チームファイル、アプリファイルのプロトコル経由での表示可否をそれぞれ設定します。
- **接続方法**：Windows と macOS から NAS に接続するための図解付きガイドとアクセスアドレスを提供します。
- **その他の接続情報**：デバイスの IP アドレスとデフォルトポート（SMB は 445）を表示し、ワンクリックでコピーできます。

![File Settings](/images/ja/app-guide/files-img/settings.png)

### パソコンから NAS のファイルにアクセスする

- **macOS**：Finder を開き、移動 → サーバへ接続 を選択し、`smb://デバイスIP` を入力してから、NAS のローカルアカウントのパスワードを入力するとアクセスできます。
- **Windows**：`Win + R` を押し、`\\デバイスIP` を入力してから、NAS のローカルアカウントのパスワードを入力するとアクセスできます。

## ゴミ箱

削除したファイルはゴミ箱に移動し、誤削除によるデータ損失を防ぎます。

- **復元**：ファイルを削除前の元の場所に復元します。
- **完全削除**：選択したファイルを完全に削除します。復元はできません。
- **ゴミ箱を空にする**：ゴミ箱内のすべてのファイルをワンクリックで空にします。

ゴミ箱はマイファイルとチームファイルに分かれており、個人とチームの削除内容を区別します。管理者はすべてのユーザーのゴミ箱を確認できます。
