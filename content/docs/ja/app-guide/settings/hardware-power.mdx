ハードウェアと電源ページは **一般** と **電源** に分かれています。一般ページでは音、冷却、メモリ圧縮を制御し、電源ページでは電源復帰、Wake on LAN、スケジュール電源オン／オフ、ハードディスクのスリープを制御します。

## 一般

![Hardware General](/images/ja/app-guide/settings-img/hardware-general.png)

### ブザー

ブザー設定ボタンをクリックすると、ブザーを鳴らすイベントを選択できます。

| 分類 | イベント | 説明 |
| --- | --- | --- |
| 一般 | デバイスの起動 | 起動時に通知音を鳴らします。 |
| 一般 | デバイスのシャットダウン | シャットダウン時に通知音を鳴らします。 |
| 一般 | ワンクリックバックアップの成功 | ワンクリックバックアップタスクの完了時に通知します。 |
| デバイスエラー | 温度が高すぎる | デバイス温度が安全範囲を超えたときに警告します。 |
| デバイスエラー | ストレージ領域のエラー | ストレージボリュームまたはハードディスクの状態が異常なときに警告します。 |
| デバイスエラー | ファンエラー | ファンが停止または異常なときに警告します。 |

保存後は、チェックしたイベントのみがブザーを鳴らします。寝室や静かな環境にデバイスを設置する場合は、リスクの高いエラー通知のみを残すことができます。

### 冷却ファン

| モード | 説明 |
| --- | --- |
| 標準 | デバイス温度に応じて回転数を自動調整し、冷却と騒音のバランスを取ります。ほとんどのシーンに適しています。 |
| 静音 | 低騒音・低回転で動作しますが、デバイス温度が上昇する場合があります。騒音に敏感で負荷が低い環境に適しています。 |
| 全速 | 最大回転数を強制し、最大限の冷却を確保しますが、騒音が大きくなります。高負荷・高温環境、または冷却異常時の一時的な使用に適しています。 |

ページのカードには現在のモードが表示されます（例：「現在のモード：標準」）。

### メモリ圧縮

| オプション | 説明 |
| --- | --- |
| メモリ圧縮のスイッチ | 有効にするとメモリ領域を解放し、データの読み取りを高速化して、システムをより効率的に動作させます。 |

メモリ圧縮は少量の CPU を消費して、より大きな使用可能メモリ領域を得ます。一般のユーザーはデフォルトのままにすることをおすすめします。CPU 負荷の高いタスクを実行し、メモリのプレッシャーが低い場合は、実際の性能テストの結果に応じて調整できます。

## 電源

![Power](/images/ja/app-guide/settings-img/power.png)

### 通電時の自動起動

| オプション | 説明 |
| --- | --- |
| Power On When Power Returns | 外部電源が回復するとデバイスが自動的に起動します。安定した UPS と組み合わせる場合や、無人での再起動が必要なシーンに適しています。 |

### Wake on LAN

| オプション | 説明 |
| --- | --- |
| Wake On LAN (WOL) | デバイスのシャットダウン中またはスリープ中に、LAN 内のマジックパケットで起動できます。ネットワークカード、マザーボード、ルーター環境の対応が必要です。 |

### スケジュール電源オン／オフ

| オプション | 説明 |
| --- | --- |
| Scheduled Power On / Off のスイッチ | 有効にすると、スケジュールに従って自動的に電源オン／オフします。初回の有効化時には、最初のスケジュールの追加を案内します。 |
| Add Schedule | スケジュールを追加します。 |
| Day | 毎日、または月曜日から日曜日までを選択できます。 |
| Time | スケジュールの実行時刻。 |
| Action | 電源オンまたは電源オフ。 |
| Actions | 既存のスケジュールを編集または削除します。 |

複数のスケジュールは週単位で繰り返し実行されます。重複したスケジュールや無効なスケジュールはシステムによって検証されます。自動起動を使用する場合は、デバイスの電源と BIOS／ファームウェアのポリシーがスケジュール起動に対応していることを確認してください。

### ハードディスクのスリープ

ハードディスクのスリープは、スリープに対応した機械式ハードディスクにのみ適用され、内蔵ハードディスクと外部ハードディスクを個別に設定できます。システムディスクはスリープに対応していない場合があります。

| オプション | 説明 |
| --- | --- |
| Enable Internal Disk Sleep | 内蔵ハードディスクのスリープを有効にします。 |
| Enable External Disk Sleep | 外部ハードディスクのスリープを有効にします。 |
| Wake Internal Disks When a User Logs In | ユーザーのログイン時に内蔵ハードディスクを自動的に復帰させます。 |
| Wake External Disks When a User Logs In | ユーザーのログイン時に外部ハードディスクを自動的に復帰させます。 |
| Idle Time | アイドル状態がどれだけ続いたらスリープするか。10 分、20 分、30 分、1 時間、2 時間、3 時間から選択できます。 |

<Callout title="注意" type="info">
  頻繁なアクセスがあると、ハードディスクはスリープしにくくなります。バックアップ、インデックス、ダウンロード、監視録画、コンテナアプリが継続的にハードディスクを読み書きする場合は、アイドル時間を適切に延ばすか、重要でないハードディスクのみスリープを有効にしてください。
</Callout>

## ブザーのポリシー

| シーン | 推奨 |
| --- | --- |
| サーバールームやオフィス | 温度過熱、ファンエラー、ストレージエラーを残します。 |
| 寝室や静かなリビング | 重大なエラーのみを残し、起動／シャットダウンの通知をオフにします。 |
| 無人でのリモート運用 | すべてのエラー通知を有効にし、高温／ストレージ異常をいち早く発見できるようにします。 |
| ワンクリックバックアップを重視する | バックアップ成功の通知を残します。 |

## ファンモードの選択

| 条件 | 推奨 |
| --- | --- |
| 一般的な家庭での使用 | 標準。 |
| 夜間の低負荷 | 静音。ただし翌日は標準に戻すことを検討してください。 |
| 高温環境、ダウンロードが満載、コンテナ／AI タスク | 全速。 |
| ファンエラーの警告 | まずシャットダウンしてファンを確認し、全速で長期間にわたって故障を覆い隠さないでください。 |

## 電源ポリシーの組み合わせ

| 目標 | 推奨する組み合わせ |
| --- | --- |
| 家庭でスケジュールにより消費電力を節約する | スケジュール電源オフ + 手動／Wake on LAN。 |
| 停電復旧後に自動で利用可能にする | 通電時の自動起動。 |
| リモートでのメンテナンス | WOL + 信頼性の高い LAN／VPN + 固定 IP または DHCP 予約。 |
| 重要な業務を継続して稼働させる | スケジュールの使用は慎重にし、UPS と冗長ストレージを構成します。 |

## スケジュール電源オン／オフの注意

- 自動起動はデバイスのハードウェア／ファームウェアの対応にも依存します。
- シャットダウン前に、バックアップ、同期、ダウンロード、インデックス、録画、コンテナのタスクを中断できることを確認してください。
- 同じ時刻に電源オンと電源オフの両方を設定しないでください。
- 複数のスケジュールが重複する場合はシステムが検証しますが、それでも手動で再確認してください。
- NTP を使用して時刻を正確に保ってください。そうしないと、スケジュールの実行時刻がずれる可能性があります。

## ハードディスクスリープのトラブルシューティング

| 現象 | 確認事項 |
| --- | --- |
| ハードディスクがまったくスリープしない | ログセンター、バックアップ、インデックス、コンテナ、監視、ダウンロードのタスクが継続的にアクセスしていないか。 |
| 頻繁に復帰／スリープする | アイドル時間が短すぎないか、クライアントが SMB/WebDAV をポーリングしていないか。 |
| スリープ後のアクセスが遅い | 復帰待ちによるものです。アイドル時間を短くするか、スリープをオフにできます。 |
| 外部ハードディスクがスリープしない | 外部ディスク／USB ブリッジがスリープに対応しているか。 |
| システムディスクがスリープしない | システムディスクは通常継続的なサービスが必要で、スリープに対応していない場合があります。 |
