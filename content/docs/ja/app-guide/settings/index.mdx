システム設定は StationOS Pro のコントロールセンターであり、デバイス情報、ユーザー、ストレージ、ネットワーク、リモートアクセス、セキュリティポリシー、ハードウェアと電源、システム更新などの主要な設定を一元管理します。このアプリは通常、管理者権限でのアクセスが必要です。モデル、ファームウェアのバージョン、搭載ハードウェアによって表示されるオプションが異なる場合があります。実際のデバイスの画面を基準にしてください。

## システム設定を開く

1. StationOS Pro のデスクトップにログインします。
2. Dock バーまたはアプリランチャーで **システム設定** を開きます。
3. 左側のタブバーで、設定する機能モジュールを選択します。

![Settings window](/images/ja/app-guide/settings-img/device-info.png)

左側のタブバーは機能ごとに次の 14 のモジュールに分かれています。

| モジュール | 主な用途 | 適用シーン |
| --- | --- | --- |
| デバイス情報 | デバイス名、Station ID、バージョン、ハードウェア、シリアル番号、ネットワーク情報を表示 | デバイスの識別、接続のトラブルシューティング、アフターサポートへの連絡 |
| ユーザー管理 | ローカルユーザー、ロール、状態、ユーザーグループ、ストレージクォータを管理 | 家族やチームメンバーへのアカウントと領域の割り当て |
| ストレージ領域 | ストレージボリューム、RAID、ホットスペア、SSD キャッシュの作成と管理 | ハードディスクの初期化、容量拡張、読み書き性能の向上 |
| ハードディスク | ハードディスクの詳細と健康状態を確認し、フォーマットや安全な取り外しを実行 | ハードディスクの点検、交換、故障のトラブルシューティング |
| ファイル共有プロトコル | SMB、WebDAV、FTP、NFS、Time Machine を設定 | パソコン、スマートフォン、テレビボックスなどから NAS のファイルにアクセス |
| AI モデル | 基本的な AI 機能、ローカルモデル、インデックスデータの保存場所を管理 | 顔／文字／ファイル／視覚認識の有効化、モデル容量の制御 |
| ネットワーク設定 | ゲートウェイ、DNS、ネットワークカード、ブリッジ、リンクアグリゲーションを設定 | IP の変更、複数ネットワークポートの負荷分散、ネットワークの冗長化 |
| リモートアクセス | Station ID リモートアクセスと DDNS を設定 | インターネットまたは独自ドメインからデバイスにアクセス |
| SSH | SSH/SFTP リモートターミナルサービスを有効化または無効化 | リモートメンテナンス、コマンドライン管理、セキュリティ管理 |
| セキュリティ | アクセスポート、二要素認証、IP 保護、ファイアウォール、証明書、デバイス分析を設定 | システム入口の厳格化、疑わしいアクセスの遮断、HTTPS の有効化 |
| 通知設定 | メール通知サービスと通知言語を設定 | 確認コード、パスワードリセット、システム通知メールの受信 |
| ハードウェアと電源 | ブザー、ファン、メモリ圧縮、電源プラン、ハードディスクのスリープを管理 | 騒音、冷却、自動電源オン／オフ、消費電力の制御 |
| 時間とタイムゾーン | タイムゾーン、NTP 自動同期、手動時刻を設定 | ログ、証明書、タスクスケジュールの時刻を正確に保つ |
| アップデートと復元 | システム更新の確認／インストール、更新履歴の表示、工場出荷状態への復元、ネットワークのリセット | システムのアップグレード、ネットワーク設定の修復、デフォルト設定への復元 |

<Callout title="操作の推奨" type="info">
  ストレージボリューム、RAID、フォーマット、ファイアウォール、ポート、工場出荷状態への復元、ネットワークのリセットに関わる操作は、データや接続に影響する可能性があります。変更前に業務への影響を確認し、重要なデータのバックアップを保持してください。
</Callout>

## 機能グループと操作リスク

| 分類 | モジュール | 主なリスク |
| --- | --- | --- |
| 読み取り専用情報 | デバイス情報 | 基本的にリスクはありません。デバイス名の変更は識別方法に影響します。 |
| アカウントと認可 | ユーザー管理 | ユーザーを削除すると個人データが削除されます。管理者に昇格するとシステムの制御権が拡大します。 |
| データ構造 | ストレージ領域、ハードディスク | 作成、変更、フォーマット、ハードディスクの交換により、データが削除されたり冗長性が低下したりする可能性があります。 |
| サービス入口 | ファイル共有プロトコル、SSH、セキュリティ | プロトコルやポートを有効にすると公開範囲が広がります。誤ったファイアウォール／ポート設定は管理接続を切断する可能性があります。 |
| ネットワークとリモートアクセス | ネットワーク設定、リモートアクセス | IP、ブリッジ、アグリゲーション、DDNS の変更により、現在の接続が中断する可能性があります。 |
| システムメンテナンス | ハードウェアと電源、時間とタイムゾーン、アップデートと復元 | 再起動、リセット、誤った時刻、更新の中断により、サービスの可用性が影響を受ける可能性があります。 |

## 管理者向け操作チェックリスト

リスクの高い操作を実行する前に、次の点を確認することをおすすめします。

1. 重要なデータに独立したバックアップがあり、そのバックアップから復元できること。
2. LAN またはコンソールからの復旧経路があり、変更中のリモート接続だけに依存していないこと。
3. ストレージボリュームの健康状態が正常で、ハードディスクに降格、破損、読み取り専用の警告がないこと。
4. 関連するユーザーに、ファイルの書き込み、バックアップ、ダウンロード、コンテナ、インデックスのタスクを停止するよう通知済みであること。
5. デバイスの電源が安定していること。機械式ハードディスク、SSD キャッシュ、システム更新の期間中は強制的に電源を切らないこと。
6. 変更前の IP、ポート、DNS、ファイアウォールルール、Station ID、バージョン番号を記録しておくこと。
