デバイス情報ページは、デバイスの識別情報と稼働状態を確認するために使用します。このページでは、システムバージョン、ハードウェア仕様、シリアル番号、各ネットワークポートのアドレスを確認できるほか、デバイス名の変更、Station ID と IP アドレスのコピーも行えます。

## デバイスの基本情報

| 項目／操作 | 説明 |
| --- | --- |
| デバイス名 | 現在のデバイス名を表示します。名前の右側にある編集アイコンをクリックすると変更できます。名前には 1～15 文字の英字、数字、`-` を使用でき、`-` を先頭または末尾に置くことはできません。 |
| Station ID | デバイスのリモートアクセス識別子。リモートアクセスサービスを有効にすると生成され、クリックしてコピーできます。変更が必要な場合は、ID をクリックして変更手続きに進みます。 |
| システムバージョン | 現在の StationOS Pro のバージョン番号（例：`v1.1.0.17`）。新しいバージョンが検出されると、新しいバージョンの案内が表示される場合があります。 |
| システム稼働時間 | 前回の起動以降の連続稼働時間。 |
| 前回の起動時刻 | 前回起動したシステム時刻。 |

![Device Info](/images/ja/app-guide/settings-img/device-info.png)

## ハードウェア情報

ハードウェア情報は 3 つのブロックに分かれています。

| ブロック | 項目 | 用途 |
| --- | --- | --- |
| CPU | CPU の型番、クロック周波数、コア数、スレッド数 | プロセッサーの性能と並列タスクの処理能力を判断します。 |
| メモリ | メモリ容量 | アプリ、コンテナ、インデックス、AI タスクが使用できる実行領域を判断します。 |
| AI モジュール拡張 | AI モジュールの型番と演算能力（例：RK1828、20 TOPS INT8） | デバイスが AI アクセラレーションハードウェアを備えているか、およびその演算能力の等級を確認します。 |

## デバイスの詳細

| 項目 | 説明 |
| --- | --- |
| デバイスモデル | デバイスの製品モデル（例：DA400）。 |
| シリアル番号 | デバイスの一意の識別子の 1 つ。コピーボタンをクリックするとすばやくコピーでき、登録、保証、テクニカルサポートでよく使用されます。 |

## ネットワーク情報

ネットワーク情報はネットワークポートごとに表示され、たとえば「有線接続 1」「有線接続 2」のようになります。ネットワークポートを選択すると、次の情報を確認できます。

| 項目 | 説明 |
| --- | --- |
| ネットワークポート名 | システムが認識したインターフェース名（例：`enP2p33s0`）。 |
| ネットワーク設定 | デュプレックスモードと MTU（例：Full-duplex、MTU1500）。 |
| IPv4 アドレス | 現在の IPv4 アドレス。コピーボタンをクリックするとコピーできます。 |
| IPv4 接続状態 | IPv4 が接続されているかどうかを表示します。 |
| IPv6 アドレス | 現在の IPv6 アドレス。アドレスがない場合は `-` と表示されます。 |
| IPv6 接続状態 | IPv6 が接続されているかどうかを表示します。 |

<Callout title="ヒント" type="info">
  デバイス情報の IP が現在アクセスしているアドレスと一致しない場合は、複数のネットワークポートを備えたデバイスが複数のリンクに同時に接続している可能性があります。クライアントが実際に接続しているネットワークセグメントを基準にするか、ネットワーク設定で各インターフェースのゲートウェイと DNS を確認してください。
</Callout>

## 項目の確認の推奨

| シーン | 確認を推奨する項目 |
| --- | --- |
| ブラウザーからデバイスにアクセスできない | ネットワーク情報の IPv4/IPv6 アドレス、接続状態、ネットワークポート名。 |
| リモートクライアントからデバイスを追加できない | Station ID、システムバージョン、リモートアクセスのスイッチ状態。 |
| AI やコンテナを実行できるか判断する | CPU のコア数・スレッド数、メモリ容量、AI モジュールの演算能力。 |
| テクニカルサポートや保証に連絡する | デバイスモデル、シリアル番号、システムバージョン、稼働時間。 |
| 繰り返し再起動する問題を調査する | 前回の起動時刻、システム稼働時間。ログセンターのシステムログと併用できます。 |
| 複数ネットワークポートのリンクを確認する | 各ネットワークポートのタブにあるアドレス、デュプレックスモード、MTU、接続状態。 |

## ステータスの読み方

| 状態／現象 | 意味 | 推奨する対処 |
| --- | --- | --- |
| IPv4 接続は正常だが IPv6 が `-` と表示される | 現在のリンクで IPv6 を取得していません。IPv4 でのアクセスには影響しない場合があります。 | IPv6 が必要な場合のみ、ルーターの SLAAC/DHCPv6 を確認してください。 |
| 特定のネットワークポートが未接続と表示される | ネットワークケーブルが挿入されていない、スイッチのポートに異常がある、またはリンクのネゴシエーションに失敗しています。 | ケーブル／ポートを交換し、ネットワーク設定でインターフェースの状態を確認してください。 |
| 稼働時間が非常に短い | デバイスを起動したばかり、または異常な再起動が発生しています。 | ログセンターでユーザーを System に絞り込み、シャットダウン、再起動、更新の記録を確認してください。 |
| 新しいバージョンの案内が表示される | 更新サーバーが新しいファームウェアを返しています。 | アップデートと復元でバージョンの説明を確認し、先にバックアップしてからアップグレードしてください。 |

## よくある質問

### デバイス名を変更するとファイルアクセスに影響しますか？

デバイス名は主にデバイスの識別や一部の通知シーンで使用され、通常はストレージのパスやアカウントを変更しません。クライアントがホスト名でサービスにアクセスしている場合は、変更後に新しいホスト名で再接続する必要があります。IP アドレスでアクセスしている場合は通常影響を受けません。

### 複数のネットワークポートに IP があるのはなぜですか？

複数のネットワークポートを備えたデバイスは、複数のリンクに同時に接続できます。各ネットワークポートの情報は個別に表示され、クライアントは同じネットワークセグメントのアドレスを使用する必要があります。帯域幅の合計やリンクの冗長化が必要な場合は、ネットワーク設定でブリッジまたはリンクアグリゲーションを検討してください。

### Station ID はアカウントとして使用できますか？

いいえ。Station ID はデバイスのリモートアクセス識別子であり、ログインアカウントではありません。リモートアクセスには引き続きデバイスのローカルユーザーとパスワードの入力が必要です。メールアドレスの紐付けは、リモートアクセスアカウントと本人認証を関連付けるために使用します。
