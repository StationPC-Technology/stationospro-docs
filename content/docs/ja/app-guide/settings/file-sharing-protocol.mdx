ファイル共有プロトコルページは **SMB**、**WebDAV**、**FTP**、**NFS** の 4 つのタブを提供します。対応するサービスを有効にすると、パソコン、スマートフォン、NAS、テレビボックスなどのクライアントから、プロトコルを通じてデバイス内のファイルにアクセスできます。各プロトコルのページには接続方法のガイドが用意されており、アドレスをコピーして手順通りにマウントできます。

![File Sharing](/images/ja/app-guide/settings-img/file-sharing.png)

## 表示するフォルダーの範囲

SMB、WebDAV、FTP のサービスカードにはいずれも **表示するディレクトリ範囲の設定** があります。この設定は、各ファイル領域が対応するプロトコルで表示されるかどうかを決定します。

| 領域 | 説明 |
| --- | --- |
| マイファイル、他のユーザーとの共有 | 現在のユーザーの個人ディレクトリと、受け取った共有ファイル。 |
| チームファイル | チーム共有ディレクトリ。 |
| 外部ストレージ | USB などの外部ストレージ内のファイル。 |
| リモートマウント | リモート NAS、サーバー、クラウドストレージからマウントしたディレクトリ。 |
| アプリファイル | アプリが生成したデータディレクトリ。 |

各領域では次のいずれかを選択できます。

| モード | 効果 |
| --- | --- |
| すべて表示 | 現在および今後追加されるフォルダーを、そのプロトコルでアクセスできます。 |
| カスタムフォルダー | 指定した第 1 階層のフォルダーのみを表示します。カードにはカスタムの数が表示されます。 |
| すべて禁止／なし | その領域内のどのフォルダーも、そのプロトコルでは表示できません。 |

<Callout title="命名制限" type="info">
  第 1 階層のフォルダー名にスペースや `! " # % & ' ( ) * + , / : ; < = > ? @ [ ] ^ { } | ~` などの特殊文字が含まれている場合、ファイル共有プロトコルではアクセスできません。第 1 階層のディレクトリには、英字、数字、中国語、アンダースコア、ハイフンを使用した命名をおすすめします。
</Callout>

## SMB

SMB は Windows、macOS、およびほとんどのクライアントで最もよく使用されるファイル共有プロトコルであり、日常の LAN 内ファイルアクセスに適しています。

| 機能 | 説明 |
| --- | --- |
| SMB サービスのスイッチ | 有効にすると、デバイスは LAN 内で SMB を通じてファイルを共有・アクセスできます。 |
| 詳細設定 | SMB3 マルチチャネル、SMB1、NTLMv1、macOS のファイル名互換を設定します。 |
| 表示するディレクトリ範囲の設定 | ファイルマネージャーの設定に移動し、各ディレクトリをファイルサービスで表示する範囲を設定します。 |
| Time Machine サービス | 有効にすると、Mac から Time Machine でこの NAS にバックアップできます。 |
| Time Machine フォルダー | Time Machine のバックアップディレクトリを表示または設定します。 |
| フォルダーを表示 | 現在の Time Machine バックアップディレクトリを開きます。 |
| 接続方法 | macOS Finder と Windows のファイル名を指定して実行の接続手順、および `smb://IP`、`\\IP` アドレスを提供します。 |
| その他の接続情報 | デバイスの IP、デフォルトポート 445、ホスト名を表示します。 |

### SMB 詳細設定

| オプション | 説明 | 推奨 |
| --- | --- | --- |
| SMB3 マルチチャネルをサポート | 複数のネットワーク接続を並行して転送し、速度と信頼性を向上させます。 | 複数ネットワークポートや高並行転送のシーンで有効化をおすすめします。 |
| SMB1 をサポート | 古いデバイスとの互換性がありますが、プロトコルの安全性は低くなります。 | 古いデバイスが接続できない場合にのみ一時的に有効にしてください。 |
| NTLMv1 をサポート | NTLMv1 のみに対応する一部のテレビボックスやプレーヤーなどの端末との互換性がありますが、認証プロトコルは安全ではありません。 | 必要なデバイスのみ有効にし、アクセス範囲を制限してください。 |
| macOS 向けにファイル名の特殊文字を変換 | macOS とのファイル名の互換性を高めます。 | Mac からのアクセスに異常がある場合に有効にできます。 |

### Time Machine の設定

| オプション | 説明 |
| --- | --- |
| Time Machine サービスのスイッチ | 先に SMB サービスを有効にする必要があります。 |
| 保存場所 | Mac のバックアップを保存するストレージボリュームを選択します。 |
| バックアップ容量の制限 | 「サイズを制限」を選択して容量を入力するか、「サイズを制限しない」を選択します。 |
| 容量の単位 | GB と TB に対応しています。制限は選択したストレージ領域の総容量を超えることはできません。 |

![SMB](/images/ja/app-guide/settings-img/file-sharing.png)

## WebDAV

WebDAV は HTTP/HTTPS に基づいてファイルアクセスを提供し、サードパーティのクライアント、モバイルアプリ、一部のマウントツールでよく使用されます。

![WebDAV](/images/ja/app-guide/settings-img/file-sharing-webdav.png)

| 機能 | 説明 |
| --- | --- |
| WebDAV サービスのスイッチ | 有効にすると、LAN 内で WebDAV を通じてファイルにアクセスできます。 |
| 詳細設定 | HTTP/HTTPS プロトコルと待ち受けポートを設定します。 |
| 表示するディレクトリ範囲の設定 | WebDAV で表示するファイルディレクトリを設定します。 |
| 接続方法 | macOS と Windows のマウント／接続手順を提供します。アドレス形式は `http://IP:ポート` です。 |

### WebDAV 詳細設定

| オプション | 説明 |
| --- | --- |
| HTTP を有効化 | 平文の HTTP プロトコルを使用します。一般的なデフォルトポートは 5005 です。 |
| HTTP ポート | HTTP サービスの待ち受けポート。範囲は 1～65535 です。 |
| HTTPS を有効化 | 暗号化通信を使用します。信頼できないネットワークやアカウントデータの保護が必要な場合に有効化をおすすめします。 |
| HTTPS ポート | HTTPS サービスの待ち受けポート。HTTP ポートと同じにすることはできません。 |
| デバッグモード | 詳細ログを出力します。性能に影響する可能性があるため、トラブルシューティング時のみ一時的に有効にしてください。 |

## FTP

FTP は異なるシステム間での一括ファイル転送に適しています。システムは暗号化されていない FTP と FTPS の両方をサポートします。

![FTP](/images/ja/app-guide/settings-img/file-sharing-ftp.png)

| 機能 | 説明 |
| --- | --- |
| FTP サービスのスイッチ | 有効にすると、FTP/FTPS クライアントの接続を許可します。 |
| 詳細設定 | プロトコル、ポート、パッシブポートの範囲、アイドルタイムアウトを設定します。 |
| 表示するディレクトリ範囲の設定 | FTP で表示するファイルディレクトリを設定します。 |
| 接続方法 | macOS Finder と Windows エクスプローラーの接続手順を提供します。アドレス形式は `ftp://IP:21` です。 |

### FTP 詳細設定

| オプション | 説明 |
| --- | --- |
| FTP サービスを有効化（暗号化なし） | 標準 FTP を有効にします。転送内容は暗号化されないため、信頼できないネットワークでの使用はおすすめしません。 |
| FTPS サービスを有効化（安全な暗号化） | FTP over SSL/TLS を有効にし、暗号化通信を提供します。 |
| FTP ポート | サービスの待ち受けポート。デフォルトは 21、有効範囲は 1～65535 です。 |
| パッシブ FTP ポート範囲 | デフォルトまたはカスタムを選択できます。カスタム範囲は 55536～65535 内である必要があり、上限は下限より小さくできません。 |
| アイドルタイムアウト時間 | クライアントが無操作のときに自動的に接続を切断します。1～120 分に対応しています。 |

## NFS

NFS は Linux、Unix、仮想マシン、一部の再生デバイスが共有ディレクトリを直接マウントするためによく使用されます。現在のページの説明には、有効にすると LAN 内のデバイスが共有フォルダーをローカルにマウントしてファイルに直接アクセスでき、アカウント認証が不要であると記載されています。

![NFS](/images/ja/app-guide/settings-img/file-sharing-nfs.png)

| 機能 | 説明 |
| --- | --- |
| NFS サービスのスイッチ | 有効にした後でのみ、NFS アドレスでマウントできます。 |
| 表示するディレクトリ範囲の設定 | サービスが無効のときは使用できません。有効にすると NFS で表示するディレクトリを設定できます。 |
| 接続方法 | macOS の `nfs://IP/パス` と Windows の `\\IP\パス` の例を提供します。 |

<Callout title="セキュリティのヒント" type="warn">
  - NFS はアカウントとパスワードによる認証を行わない場合があります。信頼できる LAN 内でのみ有効にし、表示するディレクトリ範囲とクライアントの権限でアクセスを制限してください。
  - SMB1、NTLMv1、平文の FTP/HTTP にはいずれもセキュリティリスクがあります。デバイスが対応している場合は、SMB3、HTTPS、FTPS、SFTP を優先して使用してください。
  - サービスポートを変更した後は、ファイアウォールのアウトバウンド／インバウンドルールとクライアントのアドレスも合わせて調整してください。
</Callout>

## サービスのスイッチによる影響

| 操作 | クライアントへの影響 | データへの影響 |
| --- | --- | --- |
| プロトコルを有効化 | 対応するクライアントが接続を試みられます。 | ファイルの権限は変更されません。 |
| プロトコルを無効化 | 既存のプロトコル接続は失敗または切断されます。 | ファイルは削除されません。 |
| ポートを変更 | 古いアドレスは直ちに無効になります。 | ファイルは削除されません。 |
| 表示範囲を変更 | 一部のディレクトリがプロトコルのクライアントから見えなくなります。 | 表示とアクセスの入口にのみ影響し、ディレクトリは削除されません。 |
| プロトコルが使用するストレージボリュームをフォーマット | プロトコル自体は引き続き有効にできますが、元のデータは消去されます。 | ボリューム内のファイルがすべて削除されます。 |

## アカウントと権限の関係

ファイルプロトコルはデバイスのローカルアカウントで認証を行います。最終的に表示・書き込みできる内容は、次の設定の影響も受けます。

1. ユーザーが有効かどうか。
2. ユーザーがアクセスできるストレージ領域とクォータ。
3. ユーザーグループの認可。
4. ファイル／ディレクトリ自体の権限。
5. プロトコルで表示するディレクトリ範囲。
6. ファイアウォールと IP リスト。
7. ストレージボリュームが読み取り専用かどうか。

## デフォルトのアドレスとポート

| プロトコル | デフォルトポート | 一般的なアドレス |
| --- | --- | --- |
| SMB | 445 | `smb://IP`、`\\IP` |
| WebDAV | 5005。詳細設定で変更可能 | `http://IP:ポート` |
| FTP/FTPS | 21。詳細設定で変更可能 | `ftp://IP:ポート` |
| NFS | システムがエクスポートするパスによって決まる | `nfs://IP/共有パス` |

## 接続のトラブルシューティング

| 現象 | 確認する順序 |
| --- | --- |
| クライアントが接続できない | サービスのスイッチ、IP／ポート、ファイアウォール、スイッチのルーティング、クライアントのネットワークセグメント。 |
| 接続できるがディレクトリが見えない | 表示するディレクトリ範囲、アカウントの権限、フォルダー名の特殊文字。 |
| アカウントまたはパスワードが違うと表示される | ユーザーが有効か、パスワードが変更されていないか、プロトコルがローカルアカウントを要求しているか。 |
| 転送速度が遅い | リンク速度／デュプレックス、SMB マルチチャネル、アグリゲーションモード、ハードディスクの負荷、CPU／メモリ使用率。 |
| ポート変更後にアクセスできない | クライアントのアドレスとポート、ファイアウォールルール、ルーターのポート転送。 |
| Mac で特殊なファイル名が異常になる | macOS 向けのファイル名特殊文字変換を有効にし、ディレクトリの命名を確認してください。 |

<Callout title="最小公開の原則" type="warn">
  実際に必要なプロトコルのみを有効にしてください。NFS は信頼できるネットワークでのみ使用してください。インターネットからのアクセスにはリモートアクセスや VPN を優先し、SMB、FTP、管理ポートを直接公開しないでください。
</Callout>
