ハードディスクページは、デバイスが認識した内蔵ハードディスクと外部ハードディスクを確認するために使用します。ここでは、ハードディスクの容量、インターフェース、温度、通電時間を確認でき、健康詳細から S.M.A.R.T 検査を実行したり、未使用のハードディスクに対してフォーマットや安全な取り外しなどのメンテナンス操作を行ったりできます。

## ハードディスク一覧

ページ上部には 3 つのフィルタータブがあります。

| タブ | 説明 |
| --- | --- |
| すべて | 内蔵ハードディスクと外部ハードディスクを同時に表示します。「すべて」ビューでは内蔵ハードディスクと外部ハードディスクにグループ分けされます。 |
| 内蔵 | デバイス内部に搭載されたハードディスクのみを表示します。 |
| 外部 | USB などの外部ストレージデバイスのみを表示します。 |

![Disk](/images/ja/app-guide/settings-img/disk.png)

## ハードディスクカードの情報

各ハードディスクカードには次の情報が表示されます。

| 項目 | 説明 |
| --- | --- |
| ハードディスク名 | システムが割り当てた識別名（例：DiskA、Disknvme0n1）。 |
| 用途／所属するストレージ領域 | 空き、未マウント、所属するストレージボリューム、キャッシュプールなどの用途を表示します。 |
| 総容量 | ハードディスクの使用可能な総容量。 |
| ハードディスクの種類 | HDD、SSD など。 |
| 健康状態 | 正常、異常、警告、不明。 |
| 型番 | ハードディスクメーカーの型番。 |
| インターフェース | SATA、NVMe、USB など。 |
| シリアル番号 | ハードディスクの一意のシリアル番号。クリックしてコピーできます。 |
| ベンダー | ハードディスクのブランドまたはメーカー。 |
| 温度 | 現在のハードディスク温度。温度が高い状態が続くと故障リスクが高まります。 |
| 通電時間 | ハードディスクの累計通電時間。使用年数の評価に使用できます。 |
| パーティション | 外部または完全に使用されていないハードディスクでは、パーティション情報が表示される場合があります。 |

## ハードディスクの操作

ハードディスクカードの右側にあるその他のボタンをクリックすると、ハードディスクの現在の用途に応じた操作を利用できます。

| 操作 | 対象 | 説明 |
| --- | --- | --- |
| ハードディスクのフォーマット | 空きハードディスク、外部ハードディスク、未使用のパーティション | ハードディスクのデータを消去し、ファイルシステムを再作成します。ハードディスク全体または指定したパーティションをフォーマットできます。 |
| 安全な取り外し | 外部ハードディスク | 関連サービスを停止してからハードディスクを安全に取り外し、データ破損のリスクを低減します。 |
| 健康詳細 | 健康検査に対応したハードディスク | S.M.A.R.T 検査と健康属性のページを開きます。 |
| ハードディスクの無効化 | 無効化に対応した内蔵メンバーディスク | ハードディスクを関連するストレージ領域から取り外します。無効化はストレージの冗長性に影響する可能性があるため、慎重に実行してください。 |
| 読み取り専用の表示 | 読み取り専用のハードディスク | ハードディスクが読み取り専用の状態にある場合、フォーマットなどの書き込み操作は無効になります。 |

### フォーマットの設定

| オプション | 選択可能な値 | 説明 |
| --- | --- | --- |
| フォーマット対象 | ハードディスク全体／パーティション | ディスク全体を消去するか、特定のパーティションのみを消去するかを選択します。 |
| フォーマット後のファイルシステム | exFAT／EXT4 | exFAT は Windows と macOS のクロスプラットフォームでの使用に適しています。EXT4 は Linux で一般的なファイルシステムで、NAS への長期的な接続に適しています。 |

<Callout title="危険な操作" type="error">
  フォーマットすると、対象のハードディスクまたはパーティション内のすべてのデータが削除され、操作開始後は中止できません。フォーマット中は電源を切ったり、再起動したり、ハードディスクを抜き差ししたりしないでください。
</Callout>

## ハードディスクの健康詳細

**健康詳細** をクリックすると、ハードディスクの健康状態情報を確認し、検査を実行できます。

![Disk Health](/images/ja/app-guide/settings-img/disk-health.png)

### 検査方式

| 検査方式 | 所要時間の目安 | 説明 |
| --- | --- | --- |
| クイック検査 | 約 2 分 | 機械的・電気的な誤差を検出する基本的な診断テストで、日常の点検に適しています。 |
| 完全検査 | 約 2 時間 30 分 | ハードディスクを全面的にスキャンするため、結果の精度が高く、時間がかかります。どちらの検査もハードディスクの通常使用には影響しません。 |

### 検査の状態と結果

- **検査を開始**：検査タスクを送信します。
- **検査中**：現在の進捗を確認でき、必要に応じて検査を停止できます。
- **検査結果**：現在の検査の結論を表示します。
- **S.M.A.R.T 属性テーブル**：番号、指標、結果、現在値、最悪値、基準値、生データを表示します。しきい値はハードディスクメーカーが定義しており、異常項目が直ちにハードディスクの故障を意味するわけではありませんが、継続的な注意が必要です。

<Callout title="メンテナンスの推奨" type="warn">
  健康状態が異常、温度が高い状態が続く、複数の S.M.A.R.T 指標がしきい値に近い場合は、直ちにそのハードディスクと関連するストレージボリュームの重要なデータをバックアップし、できるだけ早くハードディスクを交換してください。
</Callout>

## 健康状態と用途の表示の読み方

| 表示 | 意味 | 推奨 |
| --- | --- | --- |
| Normal | ハードディスクの健康検査は正常です。 | 定期的な検査とバックアップを続けてください。 |
| Warning | 疑わしい属性がある、または温度が高めです。 | 直ちにデータをバックアップし、継続的に観察してください。 |
| Abnormal/Serious | 検査結果が異常です。 | 不要な書き込みを停止し、できるだけ早くハードディスクを交換してください。 |
| Unknown | 有効な健康データを取得できない、またはハードディスク／ブリッジデバイスが完全な S.M.A.R.T に対応していません。 | 接続方式を変更するか、ハードディスクの詳細を確認してください。 |
| Storage volume N | ハードディスクがそのストレージボリュームに属しています。 | 操作前にボリュームの状態と冗長性を確認してください。 |
| Cache pool | ハードディスクが SSD キャッシュに使用されています。 | 先にストレージ領域でキャッシュを削除してから、ハードディスクを取り外してください。 |
| Unused | ハードディスクがストレージ構成で使用されていません。 | ボリュームの作成、キャッシュ、その他の設定に使用できます。 |
| Not mounted | 外部ハードディスクがマウントされていません。 | ファイルシステム、接続状態、ハードディスクの健康状態を確認してください。 |
| Read-only | ハードディスクまたはファイルシステムが保護のために書き込み禁止になっています。 | 先にデータをバックアップし、強制的にフォーマットしないでください。 |
| Formatting | ハードディスクをフォーマット中です。 | 完了を待ち、電源を切ったり取り外したりしないでください。 |

## フォーマットの判断

| 目的 | 推奨 |
| --- | --- |
| Windows と macOS の両方で直接読み書きする | exFAT。 |
| NAS での長期的な使用のみ、安定性を優先する | EXT4。 |
| ハードディスクに異常が発生したことがある | 先に健康検査を実行してデータをバックアップし、その後フォーマットするか判断してください。 |
| パーティションのみを整理したい | パーティションのフォーマットを選択し、ディスク全体を誤って消去しないようにしてください。 |
| ハードディスクにシステムまたはストレージメンバーのデータが含まれている | フォーマットしないでください。先に所属するボリュームと用途を確認してください。 |

## S.M.A.R.T の注目点

- **Reallocated Sectors Count**：再割り当てセクター数が増え続ける場合は、媒体が不安定であることを示します。
- **Current Pending Sector**：再マッピング待ちのセクターが増加すると、不良セクターの可能性があります。
- **Offline Uncorrectable**：修正できないエラーです。できるだけ早くデータをバックアップしてください。
- **Temperature**：長期間の高温は劣化を加速させます。
- **Power-On Time**：使用年数と組み合わせて、保証や交換計画を評価してください。
- **Raw Data**：メーカーによってエンコード方式が異なるため、数値の大小だけを比較することはできません。

<Callout title="検査の推奨" type="info">
  クイック検査は日常の点検に適しています。ハードディスクの交換、ボリュームの降格、頻繁な切断、I/O エラーの発生時には、完全検査の実行をおすすめします。検査は通常の使用に影響しませんが、高負荷時には結果が影響を受ける場合があります。
</Callout>
