ユーザー管理ページは **ユーザー** と **ユーザーグループ** の 2 つのタブに分かれています。管理者はここでローカルアカウントの作成、アカウント状態の制御、ロールとアクセス可能なストレージ領域の設定を行えるほか、ユーザーグループでメンバーを一括整理できます。

## ユーザータブ

### ページレイアウト

- **左側のユーザー一覧**：すべてのユーザーを表示し、ユーザー名で検索できます。一覧にはアバター、ユーザー名、ロール、ステータスが表示されます。
- **右側のユーザー詳細**：選択したユーザーの基本情報、アクセス可能なストレージ領域、所属するユーザーグループを表示します。
- **ユーザーの追加**：左側の一覧の上部にある追加ボタンをクリックし、ローカルアカウントを作成します。

![Users](/images/ja/app-guide/settings-img/users.png)

### ユーザーのロールとステータス

| オプション | 値 | 権限／影響 |
| --- | --- | --- |
| ロール | 管理者 | システム設定にログインし、システム設定、ユーザー、ストレージ、セキュリティ、アプリを管理できます。 |
| ロール | 一般ユーザー | 認可された範囲内のファイルとアプリ機能を使用できます。システム設定は管理できません。 |
| ステータス | 有効 | ユーザーは正常にログインできます。 |
| ステータス | 無効 | ユーザーはデバイスにログインできません。既存の共有、タスク、ファイル権限は、直ちにデータが削除されたことを意味するものではありません。 |

### ユーザーの作成または編集

ユーザーの作成と編集では、次の情報が関係する場合があります。

| 項目／機能 | 説明 |
| --- | --- |
| ユーザー名 | 指定された長さ内の英字、数字、`-` を使用できます。`-` を先頭または末尾に置くことはできず、一部の予約名は使用できません。 |
| アバター | ユーザーのアバターをアップロードまたは変更します。画像は形式とサイズの制限を満たす必要があります。 |
| ログインパスワード／新しいパスワード | 6～30 文字の英字、数字、`@#*-_` に対応し、英字と数字の両方を含む必要があります。 |
| パスワードの確認 | パスワードを再入力します。2 回の入力が一致している必要があります。 |
| ユーザー情報の編集 | アバター、ユーザー名、ロール、ステータスなどの基本情報を変更します。 |
| パスワードの変更 | ユーザーに新しいパスワードを設定します。変更後は新しいパスワードでログインする必要があります。 |
| 管理者に設定 | 一般ユーザーを管理者に昇格します。昇格前にシステムが確認を求めます。 |
| 無効化／有効化 | ユーザーのログインを一時的に禁止または復旧します。ユーザーの削除とは異なります。 |
| ユーザーの削除 | アカウントとその個人フォルダー内のデータを削除します。システムは復元できない旨を通知します。そのユーザーに依存するタスクや共有がないことを事前に確認してください。 |

### アクセス可能なストレージ領域

ユーザー詳細の **アクセス可能なストレージ領域** で **編集** をクリックすると、ユーザーが使用できるストレージボリュームと容量を設定できます。

| 項目 | 説明 |
| --- | --- |
| ストレージ領域 | ボリューム名、使用済み容量、総容量、そのユーザーの最大使用可能容量を表示します。 |
| 最大使用可能容量 | `Unlimited` を選択するか、具体的なクォータを入力できます。クォータはストレージボリュームの使用可能範囲を超えることはできません。 |
| 保存 | 保存すると、ユーザーが書き込みできる範囲が直ちに更新されます。クォータはそのユーザーの書き込み可能容量を制限するものであり、データが既に占有されていることを意味するものではありません。 |

<Callout title="注意" type="warn">
  ユーザーを削除すると、そのユーザーの個人フォルダー下のデータも同時に削除され、操作は復元できません。削除前に、チームファイルを移行し、個人データをバックアップし、バックアップタスク、共有リンク、同期タスク、アプリの権限がそのアカウントに依存していないことを確認してください。
</Callout>

## ユーザーグループタブ

### ページレイアウト

- **左側のグループ一覧**：すべてのユーザーグループとメンバー数を表示し、検索できます。Admin、Standard User などの組み込みグループは自由に削除できません。
- **右側のグループ詳細**：グループ名、備考、メンバー一覧、メンバーのロールを表示します。
- **ユーザーグループの追加**：カスタムユーザーグループを作成します。
- **メンバーの追加**：既存のユーザーから 1 人または複数人を選択してグループに追加します。
- **ユーザーグループの編集**：グループ名、備考、メンバーを変更します。
- **ユーザーグループの削除**：カスタムグループを削除します。グループを削除しても通常はメンバーのアカウントは削除されませんが、グループベースの認可によるリソースアクセスに影響します。

### よく使用する項目

| 項目 | 説明 |
| --- | --- |
| ユーザーグループ名 | グループを識別するための名前。部門、家庭での役割、プロジェクトに応じた命名をおすすめします。 |
| 備考 | 任意。グループの用途や認可範囲を記録します。 |
| メンバー | グループ内のユーザー一覧。検索できます。 |
| メンバーのロール | メンバーのシステム上のロール（例：Admin）を表示します。 |

<Callout title="推奨" type="info">
  複数のユーザーに同じファイルやアプリの権限が必要な場合は、ユーザーグループによる認可を優先してください。後からはグループのメンバーを調整するだけで済み、各アカウントを個別に変更する必要がありません。
</Callout>

## ユーザー追加の完全な流れ

| ステップ | 操作 | 重要な確認 |
| --- | --- | --- |
| 1 | **ユーザーの追加** をクリック | ユーザー追加ウィザードを開きます。 |
| 2 | 基本情報を入力 | ユーザー名が形式に適合していること、パスワードに英字と数字の両方が含まれていること、2 回のパスワードが一致していることを確認します。 |
| 3 | アバターを設定 | 画像ファイルのみを選択し、サイズは 2 MB 以下にします。 |
| 4 | ユーザーの種類／ロールを選択 | 日常的な使用では一般ユーザーを優先し、全員が管理者権限を持つことを避けます。 |
| 5 | アクセス可能なストレージ領域を設定 | どのボリュームに書き込めるかを明確にし、容量を制限するかどうかを決定します。 |
| 6 | 所属するユーザーグループを設定 | ユーザーを部門、家庭での役割、プロジェクトで分けたグループに追加します。 |
| 7 | 確認して作成 | クォータ、ロール、個人データ削除の注意事項を確認します。 |

## 権限とデータへの影響

| 操作 | 直ちに生じる影響 | データへの影響 | 復元可能性 |
| --- | --- | --- | --- |
| パスワードの変更 | そのアカウントのすべてのデバイスがログアウトされます。 | データは削除されません。 | 再度変更できます。 |
| ユーザーの無効化 | ユーザーはログインできず、関連するセッションも継続使用できません。 | ユーザーデータは保持されます。 | 再度有効化できます。 |
| 管理者に設定 | システム設定にアクセスし、システムを管理できます。 | データは削除されませんが、権限が大幅に拡大します。 | 管理者の立場を解除できます。 |
| ユーザーグループから削除 | グループで認可された共有やアプリの権限がそれに応じて変化します。 | 個人フォルダーは削除されません。 | 再度グループに追加できます。 |
| ユーザーの削除 | アカウントはログインできなくなります。 | 個人フォルダー下のすべてのデータが削除されます。 | 復元できません。 |
| ユーザーグループの削除 | グループのメンバーが解散します。 | 通常はメンバーのアカウントは削除されませんが、グループの認可が失効します。 | グループを再作成して再認可する必要があります。 |

## ストレージクォータの推奨

- **家庭用デバイス**：各メンバーにクォータを設定し、個人の写真や動画で共有ボリュームが満杯になるのを防ぎます。
- **チーム用デバイス**：部門またはプロジェクトグループ単位で容量ポリシーを統一し、特殊なケースのみ個別に調整します。
- **バックアップユーザー**：バックアップ元データのサイズに応じて余裕を確保し、使用済み容量を定期的に確認します。
- **アプリ専用アカウント**：容量を制限し、アプリのログやキャッシュが無制限に増加するのを防ぐことをおすすめします。

クォータはそのユーザーのこのストレージボリューム上での書き込み可能容量を制限するものです。既存のファイル、チームファイル、システムデータはそれぞれ別に集計される場合があり、ページに表示される使用済み容量は実際のストレージ統計に基づきます。

## トラブルシューティングの推奨

| 問題 | 確認する方向性 |
| --- | --- |
| ユーザーがログインできない | アカウントが無効になっていないか、パスワードが変更されていないか、IP がセキュリティの保護ルールでブロックされていないか。 |
| ユーザーに共有ディレクトリが表示されない | アクセス可能なストレージ領域、ユーザーグループのメンバー関係、ファイル共有プロトコルで表示するディレクトリ範囲。 |
| 書き込み時に容量不足と表示される | ユーザーのクォータ、ストレージボリュームの残り容量、ハードディスクが読み取り専用または降格していないか。 |
| グループの変更が権限に反映されない | クライアントのキャッシュまたはセッションが更新されていません。再ログインするか、ファイルサービスに再接続してください。 |
