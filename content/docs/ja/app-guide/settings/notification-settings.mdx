通知設定ページは **メール** と **通知言語** に分かれています。メール通知サービスは、二要素認証の緊急確認コードやパスワードリセットメールなど、アカウントセキュリティに関するメールの送信に使用します。通知言語は、メールや SMS などのプッシュ通知の内容に使用する言語を決定します。

## メール

![Email Notification](/images/ja/app-guide/settings-img/notifications.png)

### メール通知サービス

| 機能／項目 | 説明 |
| --- | --- |
| サービスのスイッチ | 有効にすると、システムは指定した SMTP サービスを通じてセキュリティメールを送信できます。 |
| 送信元メールアドレス | 現在の送信元メールアドレスを表示します。未設定の場合は「未設定」と表示されます。 |
| 編集 | メール設定ダイアログを開き、サービスプロバイダー、送信元メールアドレス、認証情報を設定します。 |
| メール件名のプレフィックス | システムメールの件名プレフィックスを設定し、メールボックス内で送信元デバイスを識別しやすくします。 |
| テストメールの送信 | 指定した宛先にテストメールを 1 通送信し、SMTP 設定が利用可能かどうかを検証します。 |

<Callout title="二要素認証の依存関係" type="warn">
  二要素認証にはメール通知サービスのサポートが必要です。システムで二要素認証が必須になっている場合、メールサービスを直接オフにするとログイン確認コードを送信できなくなる可能性があります。ページには、先にアカウントセキュリティ設定で二要素認証をオフにするよう案内が表示されます。
</Callout>

### メール設定

#### プリセットメール

Gmail、QQ メール、126 メール、163 メールを選択する場合は、次の項目を設定する必要があります。

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| メールサービスプロバイダー | はい | システムのプリセットプロバイダーを選択します。 |
| 送信元メールアドレス | はい | システムメールの送信に使用するメールアドレス。 |
| 認証コード | はい | メールサービスプロバイダーで生成した SMTP 認証コード。通常はメールのログインパスワードではありません。 |

プリセットメールは通常、SSL 465 ポートを使用します。ページには、ファイアウォールのアウトバウンドルールが該当ポートをブロックしていないことを確認するよう案内が表示されます。

#### カスタムメール

カスタムメールを選択した場合は、次の項目を設定する必要があります。

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| SMTP サーバー | はい | メールサービスプロバイダーの SMTP アドレス（例：`smtp.example.com`）。 |
| ポート | はい | SMTP サービスに応じて入力します。一般的なデフォルトポート：暗号化なし 25、SSL 465、TLS 587。 |
| セキュリティの種類 | はい | なし、SSL、TLS から選択できます。SSL または TLS の使用をおすすめします。 |
| ユーザー名 | はい | SMTP 認証のユーザー名。通常はメールアカウントです。 |
| パスワード | はい | SMTP パスワードまたは認証コード。 |
| 送信者名 | いいえ | メールの送信者名に表示されます。 |
| 送信元メールアドレス | はい | 実際に対外送信するメールアドレス。 |

### メール件名のプレフィックス

| オプション | 説明 |
| --- | --- |
| デバイス名を使用 | 現在のデバイス名をメール件名のプレフィックスとして自動的に使用します。 |
| カスタム | プレフィックスを手動で入力します。この方式を選択した場合、プレフィックスは必須です。 |

メール件名のプレフィックスは、複数のデバイスが 1 つのメールアドレスで通知を受け取る場合に、送信元デバイスをすばやく区別するのに適しています。

### テストメールの送信

1. メールサービスが設定済みで有効になっていることを確認します。
2. **テストメールの送信** をクリックします。
3. 宛先メールアドレスを入力します。
4. **送信** をクリックします。
5. 受信トレイでテストメールを確認します。届かない場合は、認証コード、SMTP ポート、セキュリティの種類、ファイアウォールのアウトバウンドルールを確認してください。

## 通知言語

![Notification Language](/images/ja/app-guide/settings-img/notification-language.png)

| オプション | 説明 |
| --- | --- |
| 通知言語 | メールや SMS などのプッシュ通知の内容の言語を制御します。 |
| 選択可能な言語 | 簡体字中国語、繁体字中国語、English、日本語、한국어、Deutsch、Français、Español。 |
| 適用 | 言語の変更を保存します。 |

<Callout title="ヒント" type="info">
  通知言語はシステムが送信するプッシュ通知の内容にのみ影響し、Web デスクトップのインターフェース言語を直接切り替えることはありません。デスクトップの言語は個人設定で調整できます。
</Callout>

## メール設定のトラブルシューティング

| 現象 | 確認事項 |
| --- | --- |
| 認証コードが間違っている | サービスプロバイダーで SMTP が有効か、認証コードが完全にコピーされているか、ログインパスワードを認証コードの代わりに使用していないか。 |
| SMTP 接続がタイムアウトする | SMTP アドレス、ポート、セキュリティの種類、ファイアウォールのアウトバウンドルール。 |
| SSL ポートを使用しているのに TLS を選択している | サービスプロバイダーのドキュメントを確認してください。一般的には 465/SSL、587/TLS です。 |
| メールが迷惑メールフォルダーに入る | 送信者名、SPF/DKIM/DMARC、カスタムドメインの DNS。 |
| テストメールは成功するが確認コードが届かない | 受信トレイの迷惑メール、通知言語、アカウントセキュリティポリシー、メールの遅延。 |
| メールサービスのオフがブロックされる | システムが二要素認証のメール依存を検出しています。先に関連ポリシーをオフにする必要があります。 |

## カスタム SMTP のチェックリスト

1. SMTP サーバーアドレスがサービスプロバイダーの推奨アドレスか。
2. ポートとセキュリティの種類が一致しているか。
3. ユーザー名が完全なメールアドレス、またはサービスプロバイダーが要求するアカウントか。
4. パスワード／認証コードにスペースや改行が含まれていないか。
5. 送信元メールアドレスが SMTP アカウントと一致しているか、またはサービスプロバイダーがエイリアスを明確に許可しているか。
6. ファイアウォールが対応するアウトバウンドポートをブロックしていないか。
7. テストメールを送信し、迷惑メールフォルダーを確認したか。

## 言語と複数デバイスの通知

- 通知言語はシステムが送信するメールまたは SMS の内容に適用されます。
- 送信済みの過去のメールは、後から変更しても再翻訳されません。
- 複数のデバイスが同じ送信元メールアドレスを使用する場合は、デバイス名、設置場所、用途など、異なる件名プレフィックスを設定することをおすすめします。
