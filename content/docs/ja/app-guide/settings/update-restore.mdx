アップデートと復元ページは **システム更新** と **復元とリセット** に分かれています。システム更新ページは、オンラインでのファームウェアの検出・ダウンロード・インストール、またはローカルファームウェアの手動インストールに使用します。復元とリセットページは、システムのデフォルト設定への復元やネットワークのリセットに使用します。

## システム更新

![System Update](/images/ja/app-guide/settings-img/update.png)

### 現在のバージョン情報

| 項目 | 説明 |
| --- | --- |
| 現在のバージョン | 現在のシステムバージョン番号（例：`v1.1.0.17`）。 |
| 更新の確認 | 更新サーバーに新しいバージョンを手動で問い合わせます。確認結果には、最新バージョンがあるかどうかが表示されます。 |
| 前回の確認時刻 | 一部のバージョンでは、最後に更新を確認した時刻が表示されます。 |

### 自動更新

| オプション | 説明 |
| --- | --- |
| 更新を自動インストール | 有効にすると、システムが更新を自動的にダウンロード・インストールし、必要に応じて自動的に再起動します。無効にしても新しいバージョンの案内は届きますが、手動で「再起動してアップグレード」をクリックしない限りアップグレードされません。 |

<Callout title="操作の推奨" type="warn">
  更新はシステムサービスとすべてのアプリサービスに影響します。先にバックアップ、同期、ダウンロード、インデックス、コンテナの書き込みタスクを停止し、バッテリーまたは電源が安定していることを確認することをおすすめします。更新中は電源を切ったり、ページを更新したり、強制シャットダウンしたりしないでください。
</Callout>

### 手動インストール

| オプション | 説明 |
| --- | --- |
| Click to select | ローカルにダウンロード済みのファームウェアファイルを選択します。現在の画面の説明では、現在のバージョンより高いファームウェアパッケージを選択するよう求められます。 |
| ファイル形式 | システムの案内に従って対応するファームウェア形式をアップロードします。アップロード後、システムがチェックサムを計算し、バージョンを検証します。 |
| バージョンの検証 | インストールパッケージのバージョンが現在のバージョン以下の場合、システムはインストールを阻止するか、インストールできない旨を表示します。 |
| インストールの流れ | ファームウェアのアップロード → 検証 → 更新案内の確認 → システムのインストールと再起動を待つ。 |

### 更新履歴

| 機能 | 説明 |
| --- | --- |
| View details | バージョンの更新記録を開きます。バージョン番号、バージョンの種類、公開日時、機能／バグ修正の内容を確認できます。 |

## 復元とリセット

![Restore and Reset](/images/ja/app-guide/settings-img/restore.png)

### 工場出荷状態への復元

| 項目 | 説明 |
| --- | --- |
| 影響範囲 | システム設定が工場出荷時のデフォルト値に戻ります。ハードディスクのデータは保持されます。 |
| 認証 | 管理者の本人認証が必要です。 |
| 再起動 | デバイスが自動的に再起動します。復元中は電源を切らないでください。 |
| ネットワーク／IP | リセット後に元の IP でアクセスできない場合は、実機の画面で新しい IP を確認し、再登録してください。 |
| アカウントの紐付け解除 | アカウントの紐付けを解除する必要がある場合は、案内に従って StationCloud アカウントセンターに移動して操作してください。 |

### ネットワークのリセット

| 項目 | 説明 |
| --- | --- |
| 影響範囲 | すべてのネットワーク接続設定とファイアウォール設定が初期状態に戻ります。 |
| 前提 | 少なくとも 1 つの有線ネットワークが利用可能であることを確認してください。 |
| 接続への影響 | リセットの途中と完了後に、現在の接続が切断される可能性があります。IP の再取得が必要になる場合があります。 |
| 認証 | 管理者の本人認証が必要です。 |

<Callout title="危険な操作" type="error">
  工場出荷状態への復元とネットワークのリセットは、どちらもシステムサービスを中断し、再起動が必要になります。実行前にネットワークパラメーターを記録し、設定をバックアップし、ローカルから接続を復旧できる経路があることを確認してください。
</Callout>

## オンライン更新の流れ

1. **更新の確認** をクリックします。
2. 新しいバージョンが見つかったら、バージョン番号、パッケージサイズ、更新の説明を確認します。
3. 更新の案内を読み、リスクの高い書き込みタスクを停止することを確認します。
4. 今すぐ更新、または更新を続行をクリックします。
5. システムが更新条件を確認します。ブロックするタスクがある場合は先に処理する必要があります。
6. ダウンロード、インストール、自動再起動を待ちます。
7. 更新完了後に再ログインし、バージョン、ストレージ、アプリ、ネットワークの状態を確認します。

## 更新条件とブロックするタスク

システムは更新前に実行中のタスクを確認する場合があります。一部のタスクは更新を直接ブロックし、別のタスクは先に停止することを推奨します。

- バックアップ、同期、ダウンロードのタスク。
- コンテナの書き込みまたはデータベースサービス。
- ファイルインデックスまたは AI モデルのタスク。
- ストレージボリュームの同期、修復、フォーマット。
- その他、継続的にハードディスクへ書き込む可能性のあるサービス。

ブロック項目を処理してから更新を続行すると、アップグレードの中断によるデータリスクを低減できます。

## Beta バージョンの更新

ページに **Beta バージョンの更新** が表示される場合、有効にするとテストバージョンの先行テストに参加し、未完成の機能をいち早く試せます。テストバージョンには、安定性、互換性、機能の不完全さの問題がある可能性があります。

- 重要なデータがあるデバイスでは有効にしないことをおすすめします。
- 本番環境や無人運用のデバイスでは有効にしないことをおすすめします。
- 更新前に完全なバックアップを取ってください。
- 問題が発生した場合は、ログセンターとフィードバック経路から報告できます。

## 手動インストールの詳細ルール

- `.zip` ファームウェアパッケージのみを選択できます。
- インストールパッケージのバージョンは現在のバージョンより高い必要があります。現在のバージョン以下は拒否されます。
- アップロード中は一時停止、再開、キャンセルができます。
- アップロード完了後、システムがチェックサムを計算し、ファームウェア情報を解析します。
- 確認後、更新条件の確認とアップグレードの確認に進みます。
- 更新中はブラウザーの電源を切ったり、システムを更新したり、電源供給を切断したりしないでください。

## 復元とリセットの比較

| 操作 | 工場出荷状態への復元 | ネットワークのリセット |
| --- | --- | --- |
| システム設定 | デフォルトに戻る | ネットワークとファイアウォール設定がデフォルトに戻る |
| ハードディスクのデータ | 保持 | 保持 |
| 管理者認証 | 必要 | 必要 |
| ネットワーク | IP が変わる可能性がある | 必ず IP／接続が変わる可能性がある |
| アプリの設定 | デフォルトに戻る、または再設定が必要 | 通常はネットワーク関連の設定にのみ影響 |
| 適用シーン | 設定を消去して引き渡す／再初期化する | ネットワーク設定が混乱し復旧できない場合 |
