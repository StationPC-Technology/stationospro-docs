AI モデルページは **基本機能**、**モデル管理**、**保存場所** の 3 つのタブに分かれています。ここでは、グローバル検索と Station AI が使用するローカル認識機能、大規模言語モデルのファイル、モデルとインデックスデータの保存先を制御します。

## 基本機能

基本機能ページでは、グローバル検索とコンテンツ認識に必要な AI 機能モジュールを管理します。

![AI Basic Capabilities](/images/ja/app-guide/settings-img/ai-models.png)

### 機能モジュール

| 機能 | 機能内容 | 無効化時の影響 |
| --- | --- | --- |
| 顔認識 | 人物を認識してグループ化し、顔検索とスマートアルバムをサポートします。 | 顔検索、人物のグループ化などが使用できなくなります。 |
| 文字認識 | 画像内の文字を認識し、キーワードで画像内容を特定できます。 | 画像 OCR と画像内文字検索の機能が制限されます。 |
| ファイル認識 | ファイル名、パス、文書内容、意味をインデックス化し、グローバル検索の効果を高めます。 | 文書内容と意味検索の機能が制限されます。 |
| 視覚コンテンツ認識 | 画像／動画内のシーンと物体を認識し、コンテンツマッチング検索に使用します。 | 画像による画像検索、シーン／物体検索の機能が制限されます。 |

### ステータスとインデックス情報

文字認識、ファイル認識、視覚コンテンツ認識などのモジュールには次の情報が表示されます。

| 項目 | 説明 |
| --- | --- |
| 認識済みファイル | インデックス化が完了したファイル数。 |
| インデックス失敗 | インデックスを構築できなかったファイル数。ファイルの破損、未対応の形式、権限の異常、ストレージの一時的な利用不可などが原因として考えられます。 |
| 最終インデックス時刻 | 最後にインデックス化が完了した時刻。 |
| 機能ステータス | 正常、無効、インストール中、更新中、再構築中、移行中、異常、容量不足による一時停止など。 |
| メンテナンス操作 | 機能ごとにインストール、更新、有効化／無効化、修復、インデックスの再構築を行えます。 |

<Callout title="ヒント" type="info">
  機能を初めて有効にすると、インデックスの構築が必要になります。所要時間はファイル数、文書の種類、ストレージの性能によって異なります。インデックス作成中もデバイスは引き続き使用できますが、検索結果が不完全になる場合があります。
</Callout>

## モデル管理

モデル管理ページは、ローカル大規模モデルのダウンロード、有効化、更新、アンインストールに使用します。また、OpenAI 互換 API のアクセスを管理できます。

![AI Model Management](/images/ja/app-guide/settings-img/ai-model-management.png)

### モデルカード

各モデルには次の情報が表示されます。

| 項目 | 説明 |
| --- | --- |
| モデル名 | 例：Qwen3.5-0.8B、Qwen3-8B、Gemma4-E4B など。 |
| 種類 | Text Generation、Any-to-Any などのモデル能力の種類。 |
| サイズ | モデルファイルが使用すると予想される容量。 |
| ステータス | 未ダウンロード、ダウンロード中、ダウンロード済み、現在使用中など。 |
| 有効化／無効化 | このモデルを利用可能なモデル一覧に表示するかどうかを制御します。 |
| アンインストール／削除 | ローカルモデルファイルを削除します。削除後も必要に応じて再ダウンロードできます。 |
| モデルの設定 | モデルに関連する設定を表示または変更します。 |

### API アクセス

**API Access** をクリックすると、OpenAI 互換インターフェースへのアクセスを管理できます。

| 機能 | 説明 |
| --- | --- |
| API アドレス | ローカルモデルまたはサービスのアクセスアドレスを表示します。 |
| API Key | アクセスキーの作成、表示、更新、削除を行います。 |
| 呼び出し説明 | OpenAI API 互換のサードパーティアプリや開発スクリプトで使用できます。 |

<Callout title="注意" type="warn">
  ローカルモデルを削除すると、そのモデルのローカルファイルがすべて完全に消去されます。現在そのモデルを使用している場合、システムが他の利用可能なモデルまたは OpenAI 互換 API に切り替えることがあります。
</Callout>

## 保存場所

保存場所ページでは、ローカルモデルとインデックスデータの保存先を管理し、容量不足からの保護を提供します。

![AI Storage](/images/ja/app-guide/settings-img/ai-model-storage.png)

### ローカルモデルの保存

| 項目／操作 | 説明 |
| --- | --- |
| 現在のストレージボリューム | ボリューム名、RAID タイプ、空き容量を表示します。 |
| 保存先の変更 | ローカル大規模モデルのファイルを他のストレージボリュームに移行します。移行中はローカルモデルを一時的に使用できません。 |
| ステータス | 正常、容量不足気味、読み取り専用、使用不可、移行中など。 |

### インデックスデータの保存

| 項目 | 説明 |
| --- | --- |
| ステータス | インデックスプール全体の健全性。 |
| ファイルインデックス | ファイル名、パスなどの基本インデックスが使用する容量。 |
| テキスト内容 | OCR と文書テキスト／ベクトルデータが使用する容量。 |
| 画像内容 | 画像の視覚ベクトルデータが使用する容量。 |
| 空き容量 | 現在のインデックス保存領域の残り容量。 |
| 容量不足のしきい値 | 保護を発動する容量のしきい値。現在の例では 10 GB 未満でタスクを一時停止します。 |
| 保存先の変更 | インデックスデータを他の保存場所に移行します。 |

### 容量不足からの保護

有効にすると、空き容量が設定したしきい値を下回ったときに、システムがモデルのダウンロードとインデックスの再構築タスクを自動的に一時停止し、ストレージが満杯になってサービスが異常になるのを防ぎます。容量が回復した後、手動でタスクを再開できます。

<Callout title="推奨" type="info">
  大規模モデルとインデックスデータは、ファイル数の増加に伴って増大します。モデルとインデックスは容量に余裕があり、状態の健全な SSD ストレージボリュームに配置し、容量不足からの保護を有効にしておくことをおすすめします。
</Callout>

## 機能ステータスと対処

| ステータス | 意味 | 推奨 |
| --- | --- | --- |
| 正常 | 機能を利用できます。 | モデルを最新に保ち、定期的にインデックスを再構築してください。 |
| 無効 | 管理者またはユーザーがこの機能を無効にしています。 | 必要に応じて再度有効にしてください。 |
| インストール／更新中 | 依存関係とモデルをダウンロードまたは更新しています。 | ネットワークとストレージを利用可能に保ってください。 |
| 再構築中 | インデックスデータを再構築しています。 | 完了を待ち、大量のファイル移動を避けてください。 |
| 移行中 | モデルまたはインデックスを新しいボリュームに移行しています。 | ローカルモデルが一時的に使用できない場合があります。 |
| 容量不足による一時停止 | 残り容量がしきい値を下回っています。 | 容量を確保するか、より大きなボリュームに移行してください。 |
| 読み取り専用 | 保存場所が読み取り専用です。 | ボリュームの状態を確認し、保存場所を変更してください。 |
| 異常／失敗 | 依存関係、ストレージ、サービスに異常があります。 | ログセンターを確認し、修復または再構築を試してください。 |

## インデックスのメンテナンスの推奨

| 操作 | 適用される状況 |
| --- | --- |
| すべてインストール／更新 | 機能を初めて有効にする場合、または機能の新しいバージョンがある場合。 |
| 修復 | インデックスの状態が異常で、一部のファイルを検索できない場合。 |
| インデックスの再構築 | 大量のファイル移動後、インデックス保存場所の移行後に結果が不完全な場合。 |
| 機能の無効化 | 顔、OCR、文書の意味検索、視覚検索が不要な場合。 |
| 保存先の移行 | 現在のボリュームの容量が不足している場合、またはより高速な SSD に交換する場合。 |

<Callout title="インデックスの範囲" type="info">
  インデックスは、システムが読み取れ、権限を持ってアクセスできるファイルにのみ適用されます。暗号化されたファイル、未対応の形式、破損したファイル、権限が不足しているディレクトリは、インデックス失敗の統計に表示される場合があります。
</Callout>

## モデルの選択とメンテナンス

| 項目 | 推奨 |
| --- | --- |
| 小規模パラメーターモデル | 占有容量が小さく応答も速いため、軽量な質問応答や低スペックのデバイスに適しています。 |
| 大規模パラメーターモデル | 理解と生成の能力が高い一方、メモリ／ストレージの使用量が多く、応答が遅くなる場合があります。 |
| Any-to-Any モデル | 多様な入力・出力形式が必要なシーンに適していますが、ダウンロードサイズは通常大きくなります。 |
| ローカルモデル | データがデバイスの外に出ないため、プライバシーが重要なシーンに適しています。ハードウェアの演算能力の制約を受けます。 |
| OpenAI 互換 API | 外部サービスに接続できます。Base URL、モデル名、API Key の設定が必要です。 |
| モデルの削除 | 容量を解放します。後で再ダウンロードできますが、通信量と時間を消費します。 |

## API Access 使用時の注意

- API Key は必要な認証情報のみを保存し、コードリポジトリにコミットしたり、公開したりしないでください。
- 呼び出しアドレスは、信頼できる内部ネットワーク、またはリバースプロキシ／ファイアウォールで制限されたクライアントにのみ公開してください。
- Key が漏えいした場合は、直ちに Key を削除または更新してください。
- 外部からの呼び出しは、デバイスの負荷、モデルの状態、ストレージ容量の影響を依然として受けます。

## 保存先移行時の注意

1. 移行前に、移行先ボリュームの容量がモデルとインデックスデータの合計サイズより大きく、増加分の余裕があることを確認します。
2. 移行中はモデル設定を変更したり、デバイスを再起動したりしないでください。
3. ローカルモデルの移行が完了するまで、チャット機能が一時的に使用できない場合があります。
4. インデックス移行後は、一度検索で検証し、必要に応じてインデックスを再構築することをおすすめします。
