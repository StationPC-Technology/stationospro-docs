SSH ページは、リモートのコマンドラインサービスを有効化または無効化するために使用します。管理者は SSH を通じて診断コマンドを実行し、システムの問題を調査できます。SFTP を有効にすると、SSH チャネルを通じてファイルを転送することもできます。

![SSH](/images/ja/app-guide/settings-img/ssh.png)

## 基本設定

| オプション | 説明 |
| --- | --- |
| 有効化 | SSH サービスを有効にします。無効にすると、SSH/SFTP でデバイスに接続できなくなります。 |
| ポート | SSH の待ち受けポート。デフォルトは 22 です。他の未使用ポートに変更すると、スキャンによる公開を減らせます。 |
| 有効期限 | サービスを有効に保つ時間。10 分、30 分、1 時間、3 時間、6 時間、無期限から選択できます。短期間の有効化は一時的なトラブルシューティングに適しており、期限が切れると自動的に無効になります。 |
| 詳細設定 | 暗号アルゴリズムの強度、アクセス範囲、SFTP を設定します。 |
| 適用 | ポート、有効期限、詳細設定の変更を保存します。 |

## 詳細設定

| オプション | 説明 |
| --- | --- |
| 暗号アルゴリズム | 高、中、低から選択できます。「高」の使用をおすすめします。古いクライアントが接続をネゴシエートできない場合にのみ、強度を下げてください。 |
| アクセス制限 | **LAN のみ** を有効にすると、SSH は LAN からの接続のみを受け付け、インターネットからのリモート SSH アクセスを禁止します。 |
| SFTP | 有効にすると、SFTP クライアントから SSH アカウントでファイルを転送できます。無効にすると、コマンドラインの SSH のみが残ります。 |

## 接続例

1. パソコンでターミナルまたは SSH クライアントを開きます。
2. `ssh ユーザー名@デバイスIP -p ポート` を入力します。
3. デバイスのローカルアカウントのパスワードでログインします。
4. SFTP を使用する場合は、クライアントのプロトコルで SFTP を選択し、アドレスにデバイスの IP、ポートに現在の SSH ポートを入力します。

<Callout title="セキュリティの推奨" type="warn">
  - SSH を長期間インターネットに公開しないでください。どうしてもリモートメンテナンスが必要な場合は、短い有効期限を使用し、LAN のみまたは VPN 経由のアクセスを有効にしてください。
  - 22 などのデフォルトポートの使用、弱いパスワード、管理者パスワードを信頼できない相手と共有することを避けてください。
  - SSH コマンドはシステムの状態を直接変更できます。出所不明のコマンドを実行すると、サービス異常やデータ損失を引き起こす可能性があります。
</Callout>

## 使用モードの推奨

| シーン | 推奨設定 |
| --- | --- |
| 一時的なテクニカルサポート | 10／30 分、LAN のみ。 |
| 日常の内部ネットワークメンテナンス | 無期限 + LAN のみ、高い暗号強度を維持。 |
| リモートでのトラブルシューティング | VPN または Station ID リモートアクセスで内部ネットワークに入り、短期間の SSH を有効にする。 |
| ファイル転送が必要 | SFTP を有効にし、管理されたアカウントと明確なディレクトリを使用する。 |
| 古いクライアントが接続できない | まずアカウント、パスワード、ポートを確認し、本当に新しいアルゴリズムに対応していない場合にのみ暗号強度を一時的に下げる。 |

## 操作の流れ

1. コマンドラインでのメンテナンスが本当に必要か確認し、まず Web 管理画面を検討します。
2. デフォルト以外のポートと短い有効期限を設定します。
3. 詳細設定を開き、高い暗号アルゴリズムを維持します。
4. LAN のみを有効にし、必要に応じて SFTP を有効にします。
5. 適用をクリックし、クライアントでテストします。
6. メンテナンス完了後に SSH を無効にします。

## トラブルシューティング

| 現象 | 確認事項 |
| --- | --- |
| Connection refused | SSH が無効、ポートが誤っている、サービスが待ち受けていない。 |
| Timeout | ファイアウォール、ルーティング、LAN のみの制限、IP が到達不能。 |
| Auth failed | ユーザー名／パスワードが誤っている、ユーザーが無効、権限不足。 |
| アルゴリズムのネゴシエーションに失敗 | クライアントが古すぎる、または暗号アルゴリズムに互換性がない。 |
| SFTP は接続できるが書き込めない | ディレクトリの権限、ストレージボリュームが読み取り専用、ユーザーのクォータが満杯。 |
