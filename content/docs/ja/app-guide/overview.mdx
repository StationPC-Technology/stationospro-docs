StationOS Pro は StationNAS デバイスに搭載されたオペレーティングシステムであり、データストレージ、ファイル共有、バックアップと災害対策、コンテナアプリ、AI サービスを中心に、アプリの一元管理体験を提供します。この章では、システムに内蔵された各アプリの機能と使い方を順に紹介し、すぐに使い始めてデバイスの能力を最大限に活用できるようにします。

## デスクトップの紹介

システムにログインするとデスクトップが表示されます。デスクトップは上部のステータスバー、デスクトップアイコン領域、下部の Dock バーで構成されています。

- **上部ステータスバー**：左側に「デスクトップへ戻る」と「アプリランチャー」のボタンがあります。中央には CPU、RAM、ネットワーク速度などのリアルタイムリソース情報が浮動表示されます。右側には通知センターと個人設定の入口があります。
- **Dock バー**：よく使うアプリがまとめて配置されており、アイコンをクリックすると対応するアプリのウィンドウが開きます。
- **ウィンドウ管理**：アプリウィンドウの右上には最小化、最大化／元に戻す、閉じるボタンがあり、従来のデスクトップシステムと同じようにウィンドウを自由に切り替えて配置できます。

![Desktop](/images/ja/app-guide/overview-img/desktop.png)

## アプリランチャー

上部ステータスバー左側のランチャーボタンをクリックすると、アプリランチャーが開きます。ランチャーは次の機能をサポートします。

- 上部の検索ボックスから名前でアプリをすばやく検索する。
- システムに内蔵されたすべてのアプリを表示し、アイコンをクリックすると起動する。

![App Launcher](/images/ja/app-guide/overview-img/app-launcher.png)

## 内蔵アプリ一覧

| アプリ | 説明 |
| --- | --- |
| ファイルマネージャー | 個人ファイルとチームファイルを管理し、アップロード／ダウンロード、外部リンク共有、ゴミ箱、重複ファイルの整理、SMB/WebDAV/FTP/NFS などのファイルサービス設定をサポート |
| バックアップ | ローカルバックアップ、リモートバックアップ、ワンクリックバックアップを提供し、NAS、外部ストレージ、クラウドストレージ、ファイルプロトコルなど多様なバックアップ元をサポート |
| Docker | コンテナ管理コンソール。コンテナ、プロジェクト（Compose）、イメージ、ネットワークのライフサイクル全体を管理 |
| ログセンター | システム稼働ログを集中的に表示し、キーワード検索と複数条件のフィルターをサポート |
| リソース管理 | CPU、メモリ、ネットワーク、NPU、ハードディスクの状態をリアルタイムで監視し、システムサービスとプロセスを管理 |
| システム設定 | デバイス情報、ユーザー、ストレージ、ネットワーク、リモートアクセス、ハードウェアと電源、セキュリティ、システム更新などの主要な設定を管理 |
| アプリセンター | ワンストップのアプリストア。公式アプリとサードパーティアプリのインストール、更新、管理を提供 |
| Station AI | 内蔵 AI スマートアシスタント。会話による質問応答、ナレッジベース検索、文書翻訳と要約をサポート |
| ヘルプセンター | このヘルプドキュメントサイトをすばやく開き、インストール、アプリチュートリアル、よくある質問を確認 |

<Callout title="ヒント" type="info">
  一部の機能とアプリは、デバイスのモデル、ファームウェアのバージョン、インストールされているアプリによって異なる場合があります。実際のデバイスの画面を基準にしてください。
</Callout>
