アプリセンターは StationOS Pro のアプリストアであり、公式アプリとサードパーティアプリのインストール、アップデート、管理をワンストップで提供します。アプリセンターを利用すると、スマートフォンのアプリストアと同じように、ダウンロード、メディア、同期、生産性、開発・運用など、さまざまな機能を NAS に追加できます。

## インターフェースの紹介

アプリセンターを開くと、上部に次のナビゲーションが表示されます。

- **すべてのアプリ**：ストア内のインストール可能なすべてのアプリを閲覧します。
- **インストール済み**：現在のデバイスにインストールされているアプリを表示・管理します。
- **カテゴリフィルター**：同期、映像、動画録画、ダウンロード、生産性、開発ツールなどのカテゴリでアプリをすばやく絞り込めます。
- **検索ボックス**：アプリ名でアプリをすばやく検索できます。

アプリ一覧は「公式アプリ」とサードパーティアプリのエリアに分かれており、各アプリカードには名前、概要／カテゴリタグ、インストールボタンが表示されます。

![App Center](/images/ja/app-guide/app-center-img/all-apps.png)

## アプリのインストール

1. アプリセンターでカテゴリまたは検索ボックスから目的のアプリを探します。
2. アプリカードをクリックして詳細ページを開きます。
3. アプリ情報を確認したら **インストール** をクリックします。システムが自動的にアプリをダウンロードしてインストールします。
4. インストールが完了すると、アプリがアプリランチャーに表示されます。デスクトップショートカットの自動作成が有効な場合は、デスクトップにもショートカットが作成されます。

## アプリ詳細ページ

アプリ詳細ページには次の情報が表示され、アプリを理解して評価するのに役立ちます。

| 項目 | 説明 |
| --- | --- |
| 開発者 | アプリの開発者またはチーム |
| 配信元 | アプリの提供元 |
| ダウンロード数 | このアプリの累計ダウンロード数 |
| サイズ | アプリのインストールパッケージのサイズ |
| 現在のバージョン | ストアで提供されている最新のバージョン番号 |
| アプリ紹介 | 機能のハイライトと使用説明 |

![App Detail](/images/ja/app-guide/app-center-img/app-detail.png)

## アプリセンターの設定

アプリセンター右上の **設定** ボタンをクリックすると、次の設定を行えます。

- **デフォルトのインストール場所**：
  - **毎回確認**：インストール時に保存場所を手動で選択します。
  - **固定の保存場所**：アプリをインストールするストレージ領域を統一して指定します。
- **デスクトップショートカットの自動作成**：有効にすると、新しくインストールしたアプリのショートカットが自動的にデスクトップに作成されます。

![App Center Settings](/images/ja/app-guide/app-center-img/settings.png)

<Callout title="注意" type="warn">
  - アプリをインストールする前に、選択したストレージ領域に十分な容量があることを確認してください。容量が不足しているとインストールに失敗する場合があります。
  - 一部のサードパーティアプリは外部の開発者が提供しています。インストール前にアプリの提供元と必要な権限を確認してください。
  - アプリのインストール場所は状況によって変更できない場合があります。移行が必要な場合は、いったんアンインストールしてから再インストールしてください。
</Callout>
