ログセンターは、システムの稼働、ログイン接続、ファイル転送、ハードディスクのストレージなどのイベントを集中的に記録します。キーワード、レベル、モジュール、ユーザー、期間でログを検索でき、セキュリティ監査、操作の追跡、トラブルシューティングに利用できます。

## ページレイアウト

ログセンターは上部ツールバー、ログテーブル、下部のページング領域に分かれています。

| 領域 | 機能 |
| --- | --- |
| キーワード検索ボックス | ログ内容のキーワードで検索します。入力後に Enter を押すか、入力ボックスからフォーカスを外すと反映されます。 |
| フィルター | レベル、モジュール、ユーザー、期間を組み合わせて絞り込みます。 |
| クリア | 期間を指定してログを削除します。 |
| ログのエクスポート | 選択した期間のログを CSV ファイルとしてエクスポートします。 |
| ログのアーカイブ | 自動アーカイブの条件とアーカイブの保存場所を設定します。 |
| ログテーブル | レベル、モジュール、時間、ユーザー、イベントを表示します。 |
| ページング領域 | ログの総数を表示し、更新、ページ番号の切り替え、1 ページあたりの件数の変更、ページ番号の移動をサポートします。 |

## システムユーザーのログを表示する

システムが生成したログのみを表示する場合は、**ユーザー** フィルターを `system` に設定します。

1. 上部の **フィルター** をクリックします。
2. **ユーザー** ドロップダウンで `system` を選択します。
3. **確認** をクリックします。

絞り込み結果のユーザー列はすべて `system` になり、システムの電源オン／オフ、システム更新、ネットワークインターフェースの状態、ハードディスクの認識、ハードディスクの S.M.A.R.T 状態、ストレージボリュームの異常などのシステムイベントを重点的に確認するのに適しています。

![system ユーザーで絞り込んだログ一覧](/images/ja/app-guide/log-center-img/logs.png)

## ログの項目

| 項目 | 説明 |
| --- | --- |
| レベル | ログの重大度：通常、警告、重大。通常は通常の稼働情報です。警告は注意が必要であることを示します。重大は機能またはハードウェアに高いリスクがあることを示します。 |
| モジュール | イベントの発生元：システム、ログイン接続、ファイル転送、ハードディスクのストレージ。 |
| 時間 | イベントの発生日時。 |
| ユーザー | イベントを発生させたユーザー。`system` はシステムが自動的に生成したイベントを示します。通常のユーザー名は、ユーザー操作またはユーザーセッションに関連するイベントを示します。 |
| イベント | イベントの詳細。たとえば、システムのシャットダウン、ハードディスクの取り外し、ストレージボリュームの降格、システムバージョンの更新などです。 |

## 検索とフィルター

### キーワード検索

検索ボックスにイベント内容のキーワード（ハードディスクの型番、ストレージボリューム名、システムバージョン、エラーの説明など）を入力し、Enter を押します。検索は条件フィルターと組み合わせて適用されます。

### 条件フィルター

**フィルター** をクリックすると、次の条件を組み合わせられます。

| 条件 | 選択可能な値／説明 |
| --- | --- |
| レベル | 通常、警告、重大。複数選択とすべて選択に対応します。 |
| モジュール | システム、ログイン接続、ファイル転送、ハードディスクのストレージ。複数選択とすべて選択に対応します。 |
| ユーザー | 選択肢は現在のログに登場するユーザーです。複数選択とすべて選択に対応します。本文の例では `system` を選択しています。 |
| 時間 | 開始日と終了日を選択し、指定した期間のログのみを表示します。 |

フィルター条件はまずダイアログ内に保持され、**確認** をクリックして初めて一覧に適用されます。**リセット** をクリックすると、フィルター条件をクリアしてデフォルトの表示に戻ります。

![ユーザーで system を選択したフィルター](/images/ja/app-guide/log-center-img/filter.png)

## ページングと更新

- **総数**：ページング領域に現在のフィルター条件でのログ総数が表示されます。
- **更新**：総数の左側にある更新アイコンをクリックすると、現在の一覧を再読み込みします。
- **1 ページあたりの件数**：50、100、500 から選択できます。
- **ページ移動**：ページ番号を入力して Enter を押すか、前のページ／次のページで切り替えます。

## ログのエクスポート

上部のダウンロードアイコンをクリックするとログをエクスポートできます。

1. 期間を選択します：すべて、過去 1 週間、過去 1 か月、過去 3 か月、過去半年、過去 1 年。
2. **確認** をクリックします。
3. ログファイルの生成を待ちます。エクスポートされた CSV はローカルブラウザーのダウンロードディレクトリに保存されます。

エクスポートは、監査記録を長期的に保存したい場合や、デバイスに直接アクセスできないときに技術者へ分析を依頼する場合に適しています。

## ログのクリア

**クリア** をクリックした後は、次の手順で操作します。

1. クリアする期間を選択します：すべて、1 年前、半年前、3 か月前、1 か月前、1 週間前。
2. クリア範囲を確認します。
3. クリア処理の完了を待ちます。

<Callout title="注意" type="warn">
  ログのクリアは復元できません。クリアする前に、保存が必要な過去のログをエクスポートすることをおすすめします。セキュリティインシデントやハードウェア異常が発生した場合は、該当期間のログを急いで削除しないでください。
</Callout>

## ログのアーカイブ

上部の設定アイコンをクリックして **ログのアーカイブ** を開きます。システムはデフォルトで直近 300 万件の転送ログを保持し、自動アーカイブは行いません。自動アーカイブを有効にすると、次のいずれかの条件で実行できます。

| 条件 | 選択可能な値 |
| --- | --- |
| ログデータ量が次を超える | 500 MB、1 GB、3 GB |
| ログの時間が次より前 | 1 週間前、1 か月前、3 か月前、半年前、1 年前 |

また、チームファイル内のアーカイブ保存場所を選択する必要があります。少なくとも 1 つのアーカイブ条件を有効にしないと保存できません。

<Callout title="推奨" type="info">
  - ログイン異常を調査するときは、まず「ログイン接続」で絞り込み、警告と重大レベルに注目してください。
  - ハードディスクやストレージボリュームの故障を調査するときは、ユーザーを `system`、モジュールを「システム」または「ハードディスクのストレージ」で絞り込めます。
  - 重要なログを定期的にエクスポートまたはアーカイブし、クリア後に追跡できなくなることを防いでください。
</Callout>
