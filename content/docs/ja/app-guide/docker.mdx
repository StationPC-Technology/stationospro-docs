Docker アプリは StationOS Pro のコンテナ管理プラットフォームであり、コンテナ、プロジェクト（Compose）、イメージ、ネットワークをグラフィカルに管理できます。コマンドラインを使わずに、一般的なコンテナアプリのデプロイと運用を行えます。

## Docker サービスの有効化

Docker アプリを初めて開くときは、初期設定を完了する必要があります。

1. **保存場所** で Docker データを保存するストレージ領域を選択します。
2. 必要に応じて **起動時の自動開始** を選択します。
   - **自動起動**：デバイスの起動後に Docker サービスを自動的に開始します。
   - **起動しない**：必要時に手動で開始します。
3. **Docker を起動** をクリックすると、システムが保存領域を準備してサービスを開始します。

![Docker Setup](/images/ja/app-guide/docker-img/setup.png)

<Callout title="注意" type="warn">
  Docker サービスを起動すると、選択したストレージ領域に Docker データディレクトリが作成されます。処理中は電源を切ったり、強制シャットダウンしたりしないでください。
</Callout>

## 概要

サービスが起動すると概要ページに移動し、Docker の実行状態をすばやく把握できます。

- **サービス状態**：サービスが正常かどうかを表示します。
- **プロジェクト**：実行中／すべてのプロジェクト数。
- **コンテナ**：実行中／すべてのコンテナ数。
- **ローカルイメージ**：使用中／すべてのイメージ数。
- **データサイズ**：Docker データが使用している容量。

![Docker Overview](/images/ja/app-guide/docker-img/overview.png)

## コンテナ管理

**コンテナ** ページに移動すると、すべてのコンテナの名前、イメージ、状態、CPU／メモリ使用率などを確認でき、次の操作をサポートします。

- コンテナの検索。
- **コンテナを作成** をクリックし、ウィザードでイメージ、ポート、マウントディレクトリ、環境変数などのパラメーターを設定してコンテナを作成する。
- コンテナの起動、停止、再起動、削除。
- コンテナログとリソース使用状況の詳細を表示する。

![Containers](/images/ja/app-guide/docker-img/containers.png)

## プロジェクト管理

**プロジェクト** ページは Docker Compose 方式でのアプリデプロイをサポートします。

1. プロジェクト作成をクリックし、プロジェクト名を入力します。
2. `docker-compose.yml` を編集するか、ファイルからオーケストレーション内容をインポートします。
3. 保存すると、システムが自動的にイメージを取得し、プロジェクト内で定義されたすべてのサービスを起動します。

プロジェクト一覧では、プロジェクトの実行状態と含まれるサービスを確認でき、プロジェクトの起動、停止、再構築などの操作を行えます。

![Docker Project](/images/ja/app-guide/docker-img/project.png)

## イメージ管理

**イメージ** ページは 2 つのビューに分かれています。

- **イメージリポジトリ**：必要なイメージをオンラインで検索して取得でき、Tag の選択をサポートします。
- **ローカルイメージ**：ローカルに取得済みのイメージを管理し、表示、削除、イメージからのコンテナ作成などの操作をサポートします。

![Docker Images](/images/ja/app-guide/docker-img/images.png)

<Callout title="ヒント" type="info">
  イメージをオンラインで取得するには、デバイスがイメージリポジトリのネットワークにアクセスできる必要があります。取得に失敗した場合は、ネットワーク接続を確認するか、Docker 設定で利用可能なイメージアクセラレーターアドレスを設定してください。
</Callout>

## ネットワーク管理

**ネットワーク** ページには Docker のネットワーク一覧が表示され（デフォルトで `bridge`、`host` などのネットワークを提供）、次の操作をサポートします。

- **更新**：ネットワーク一覧を更新します。
- **ネットワークを追加**：コンテナ間通信に使用するカスタムネットワークを作成します。

![Docker Networks](/images/ja/app-guide/docker-img/networks.png)

## Docker 設定

**設定** ページでは、Docker の保存場所や起動時の自動開始などのグローバル設定を変更できます。一部の設定は、変更後に Docker サービスを再起動しないと反映されません。
