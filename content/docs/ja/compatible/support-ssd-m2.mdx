## ハードウェア互換性に関する注意事項
下の表に記載したモデルは、いずれも StationPC ラボでの動作検証を経ており、安心してご利用いただけます。DA400 シリーズ自体は、市場で入手できるほとんどのハードディスクモデルに対応しており、リストに記載されていないからといって非対応を意味するものではありません。互換リストは不定期に更新され、今後もテストを継続しながら、より多くのハードディスクモデルを追加していく予定です。

1. M.2 スロットには、NVMe プロトコル対応の 2280 サイズ SSD を取り付けることができます。
2. PCIe 4.0 の互換性と消費電力の影響を受けるため、消費電力の大きい PCIe 4.0 SSD の取り付けはおすすめしません。
3. M.2 スロットは PCIe 3.0 SSD と下位互換性があり（PCIe 3.0 の速度で動作します）、消費電力と発熱も通常はより低く抑えられます。
4. 高速ストレージを設定する場合、SSD の容量は 32GB 未満にできず、最大で 8TB まで対応しています。
5. 大手ブランドの SSD を選ぶことをおすすめします。
6. ヒートシンク付きの SSD には対応していません。SSD の裏面に厚みのあるラベルが貼られている場合は、剥がしてから取り付けることをおすすめします。

注意：SSD の寿命は書き込み回数の制約を受けます。潜在的なリスクを軽減するため、できるだけ耐久性の高いモデルを選択してください。
