StationPC には現在、**デスクトップNAS** と **ポータブルNAS** という 2 つの並列する NAS 製品ラインがあります。想定する利用シーンが異なり、ハードウェアの形態、システムの基盤、クライアントもそれぞれ別に設計されています。同じ機器の「標準版」と「ポータブル版」ではなく、独立した 2 つの製品とシステムです。そのため、ヘルプセンターも製品ラインごとに 2 つのドキュメントに分かれています。

## 2 つの製品ラインとは

| | デスクトップNAS | ポータブルNAS |
| --- | --- | --- |
| 型番 | DA400、DA400 Air | PA100、PA100 Pro |
| システム | StationOS Pro | StationOS |
| システムの基盤 | Debian | OpenWrt |
| ハードウェアの形態 | 固定設置、複数のドライブベイ、主に固定電源と有線ネットワーク | 内蔵バッテリー、持ち運び可能、無線 / AP 接続に対応 |
| 主な用途 | 家庭やスタジオでの長期保存、RAID、Station AI | 出張、モバイルワーク |
| クライアント | StationNAS（Windows / macOS）、StationHub（iOS / Android） | PocketNAS（Windows / macOS / Linux / iOS / Android） |

## なぜ 1 つのシステムではだめなのですか？

1. **ハードウェアの制約が異なります。** デスクトップNAS は複数のドライブ、RAID、より高い持続スループットを長時間支える必要があり、ポータブルNAS はバッテリー、放熱、筐体サイズの制約の中で動作する必要があります。ドライバー、電源管理、ドライブ管理、放熱制御を共通化するのは困難です。
2. **システムの基盤が異なります。** StationOS Pro は Debian、StationOS は OpenWrt を基盤としています。パッケージ管理、サービス管理、更新方法、基盤ツールチェーンが異なるため、同じシステムイメージを別の製品ラインにインストールすることはできません。
3. **機能とクライアントが異なります。** デスクトップNAS は Station AI、RAID などを提供し、ポータブルNAS はバッテリー、AP モード、SD / USB バックアップ、PocketNAS を中心に設計されています。どちらも Docker とファイル共有に対応しますが、メニューの場所、画面、制限は同じではありません。
4. **リリース系統が独立しています。** 2 つのシステムは別々に更新され、更新履歴とバージョン番号もそれぞれ独立しています。ポータブルNAS の更新パッケージをデスクトップNAS にインストールすることはできず、その逆もできません。

## 利用者には何が影響しますか？

- **まず型番を確認してください。** 本体のラベルや購入記録で確認できます。DA400 / DA400 Air ならデスクトップNAS、PA100 / PA100 Pro ならポータブルNAS です。
- **製品ラインに合ったドキュメントを参照してください。** メニュー、画面写真、制限が異なるため、該当する「デスクトップNAS」または「ポータブルNAS」の入口から進み、もう一方の製品ラインの手順をまねしないでください。
- **クライアントと更新パッケージを混在させないでください。** デスクトップNAS は StationNAS / StationHub、ポータブルNAS は PocketNAS を使用します。更新パッケージも共通ではありません。
- **同じ機能名でも製品ラインを確認してください。** 同じ機能名（バックアップやリモートアクセスなど）でも、製品ラインによって場所と操作方法が異なる場合があります。

## ヘルプセンターも 2 つのドキュメントに分かれているのはなぜですか？

2 つのシステムはメニュー、画面写真、制限、更新のペースが異なるため、内容を混ぜると同じ質問に 2 つの答えが生まれ、検索でも利用者を誤った製品ラインの手順に導くおそれがあります。そこで当サイトは「1 つのサイト、2 つの並列する製品ドメイン」という構成を採っています。共通の内容（法務、お問い合わせ、サイト全体の検索）は共有し、具体的な操作はデスクトップとポータブルのドキュメントに分けて掲載しています。

お使いの機器がどちらの製品ラインに属するかわからない場合は、本体ラベルの型番を確認するか、[お問い合わせ](../contact) ください。
