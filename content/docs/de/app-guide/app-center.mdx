Das App Center ist der App-Store von StationOS Pro und bietet eine zentrale Anlaufstelle für Installation, Updates und Verwaltung offizieller und Drittanbieter-Anwendungen. Über das App Center können Sie Ihrem NAS – ähnlich wie mit einem App-Store auf dem Smartphone – Funktionen für Download, Multimedia, Synchronisierung, Produktivität sowie Entwicklung und Betrieb hinzufügen.

## Oberfläche

Nach dem Öffnen des App Centers stehen oben folgende Navigationsbereiche zur Verfügung:

- **Alle Apps**: Durchsuchen aller im Store installierbaren Anwendungen;
- **Installiert**: Anzeigen und Verwalten der auf dem aktuellen Gerät installierten Anwendungen;
- **Kategoriefilter**: Schnelles Filtern von Anwendungen nach Kategorien wie Synchronisierung, Film und Fernsehen, Videoaufnahme, Download, Produktivität und Entwicklerwerkzeuge;
- **Suchfeld**: Schnelles Finden von Anwendungen über den Anwendungsnamen.

Die Anwendungsliste ist in die Bereiche „Offizielle Apps“ und Drittanbieter-Apps unterteilt. Jede App-Karte zeigt den Namen, eine Kurzbeschreibung bzw. Kategorie-Tags sowie die Installationsschaltfläche.

![App Center](/images/de/app-guide/app-center-img/all-apps.png)

## Anwendungen installieren

1. Suchen Sie im App Center über die Kategorie oder das Suchfeld die gewünschte Anwendung.
2. Klicken Sie auf die App-Karte, um die Detailseite zu öffnen.
3. Prüfen Sie die Anwendungsinformationen und klicken Sie auf **Installieren**; das System lädt die Anwendung automatisch herunter und installiert sie.
4. Nach Abschluss der Installation erscheint die Anwendung im App-Starter; ist die automatische Erstellung von Desktop-Verknüpfungen aktiviert, wird zusätzlich eine Verknüpfung auf dem Desktop angelegt.

## Anwendungsdetailseite

Die Anwendungsdetailseite zeigt folgende Informationen, damit Sie die Anwendung besser einschätzen können:

| Feld | Beschreibung |
| --- | --- |
| Entwickler | Der Entwickler oder das Team der Anwendung |
| Herausgeber | Die herausgebende Stelle der Anwendung |
| Downloads | Die kumulierte Anzahl der Downloads dieser Anwendung |
| Größe | Die Größe des Installationspakets der Anwendung |
| Aktuelle Version | Die im Store angebotene neueste Versionsnummer |
| App-Beschreibung | Funktionshighlights und Anwendungshinweise |

![App Detail](/images/de/app-guide/app-center-img/app-detail.png)

## Einstellungen des App Centers

Klicken Sie oben rechts im App Center auf die Schaltfläche **Einstellungen**, um folgende Konfigurationen vorzunehmen:

- **Standard-Installationspfad**:
  - **Jedes Mal fragen**: Bei der Installation den Speicherort manuell auswählen;
  - **Fester Speicherort**: Einheitlich den Speicherbereich für die Installation von Anwendungen festlegen.
- **Automatische Desktop-Verknüpfung erstellen**: Ist diese Option aktiviert, erstellt das System für neu installierte Anwendungen automatisch eine Verknüpfung auf dem Desktop.

![App Center Settings](/images/de/app-guide/app-center-img/settings.png)

<Callout title="Hinweis" type="warn">
  - Stellen Sie vor der Installation einer Anwendung sicher, dass der ausgewählte Speicherbereich über ausreichend Kapazität verfügt; andernfalls kann die Installation fehlschlagen.
  - Einige Drittanbieter-Anwendungen werden von externen Entwicklern bereitgestellt. Prüfen Sie vor der Installation die Quelle der Anwendung und die benötigten Berechtigungen.
  - Der Installationsort einer Anwendung kann in manchen Fällen nicht geändert werden. Wenn Sie die Anwendung verschieben möchten, deinstallieren Sie sie zuerst und installieren Sie sie anschließend neu.
</Callout>
