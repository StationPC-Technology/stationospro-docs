## Auflösung

| Auflösung | iOS, Android Anschluss |
| -------- | ---------- |
| 4K     | Unter guten Netzwerkbedingungen (z. B. LAN oder direkte Verbindung zu Geräten) kann normal abgespielt werden; bei Verwendung einer Mobilfunkverbindung tritt leicht Ruckeln auf |
| 8K     | Nicht unterstützt |
