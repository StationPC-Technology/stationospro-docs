title: "Host M.2 SSD Installation"
---

Auf dem Pocketcloud-Host kann eine M.2 NVMe 2280 SSD installiert werden.

## Bedienungsanleitung

1. Schalten Sie das Gerät aus, bis die Anzeigeleuchte erlischt.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_1.png)

2. Drehen Sie die Schraube mit dem passenden Schraubendreher gegen den Uhrzeigersinn, um die Abdeckung zu entfernen.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_2.png)

3. Setzen Sie SSD in den M.2 NVMe-Steckplatz ein und drehen Sie die Schraube zur Befestigung.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_3.png)

4. Die Abdeckung wieder anbringen.

![](/images/common/portable/hardware/ssd-install/pkc/pkc-ssd-install_4.png)
