Wenn die Batterie altert, kann sie ausgetauscht werden. Die Vorgehensweise ist wie folgt:

## Bedienungsanleitung

1. Bereiten Sie zwei brandneue, unbenutzte 18650-Batterien (3,6/3,7 V) vor, die dasselbe Modell haben und von bekannten/üblichen Marken stammen. Es wird eine Kapazität von über 3000 mAh empfohlen. Verwenden Sie keine beschädigten oder angeschwollenen Batterien und mischen Sie keine neuen und alten Batterien.

![](/images/common/portable/hardware/battery-install/battery-install_1.jpg)

2. Stellen Sie sicher, dass das Gerät ausgeschaltet ist und die Anzeigeleuchte erloschen ist.

![](/images/common/portable/hardware/battery-install/battery-install_2.jpg)

3. Verwenden Sie einen Schraubendreher, um die Schrauben zu lockern und das Gehäuse abzunehmen.

![](/images/common/portable/hardware/battery-install/battery-install_3.jpg)

4. Schieben Sie die Batteriefachabdeckung in Pfeilrichtung auf. Wie in der Abbildung unten gezeigt, halten Sie das PocketCloud mit beiden Händen und schieben Sie es dann mit dem Daumen nach vorne.

![](/images/common/portable/hardware/battery-install/battery-install_4.jpg)

5. Setzen Sie die neuen Batterien mit der richtigen Polarität ein und schließen Sie die Batteriefachabdeckung.

![](/images/common/portable/hardware/battery-install/battery-install_5.jpg)

6. Setzen Sie das Gehäuse wieder auf und ziehen Sie die Schrauben fest.

![](/images/common/portable/hardware/battery-install/battery-install_6.jpg)
