title: "Wie greift man über FTP auf die Dateien in PocketCloud zu?"
---

FTP (File Transfer Protocol) ist ein häufig verwendetes Netzwerkdateiübertragungsprotokoll, das zum Übertragen von Dateien zwischen Geräten und Servern verwendet werden kann.
Durch FTP können Benutzer eine Remote-Verbindung zu PocketCloud herstellen, um Dateien zu durchsuchen, hochzuladen, herunterzuladen und zu verwalten.

**Hauptsächlich folgende Funktionen:**
1. Datei-Upload und -Download: Dateien zwischen dem lokalen Gerät und PocketCloud übertragen.
2. Fernverwaltung von Dateien: Dateien oder Ordner können auf PocketCloud erstellt, umbenannt, verschoben und gelöscht werden.
3. Benutzer-Authentifizierung: Zugriffskontrolle durch Konto und Passwort, um die Sicherheit zu erhöhen.
4. Plattformübergreifender Zugriff: Es kann über die Windows- und macOS-Clients, die FTP unterstützen, eine Verbindung hergestellt werden.

## FTP aktivieren

FTP ist standardmäßig deaktiviert und muss manuell aktiviert werden. Bitte folgen Sie den folgenden Schritten:
1. Öffnen Sie die **Dateifreigabeprotokoll**-Seite von App. <br />
2. Klicken Sie auf **FTP Service**. <br />
3. Schalten Sie den **Schalter** ein, um den **FTP-Dienst** zu aktivieren. <br />

## Zugriff auf Windows

1. Drücken Sie **Win   E**, um den **Datei-Explorer** zu öffnen.
2. Geben Sie in die Adressleiste `ftp://NAS设备IP:21` oder `ftps://NAS_IP_Address:21` ein und drücken Sie dann die **Eingabetaste**.
<img src="/images/common/portable/file-service/access-ftp-service/3-1.png" width="100%" height="100%" />
3. Geben Sie im Anmeldehinweis **Benutzername** und **Passwort** ein und klicken Sie dann auf **Anmelden**
<img src="/images/common/portable/file-service/access-ftp-service/3-2.png" width="100%" height="100%" />
4. Jetzt können Sie die Datei PocketCloud im Datei-Explorer durchsuchen und verwalten.
<img src="/images/common/portable/file-service/access-ftp-service/3-3.png" width="100%" height="100%" />

---

## Zugriff auf macOS

1. Rechtsklick auf **Finder**, dann **Mit Server verbinden** auswählen.
<img src="/images/common/portable/file-service/access-ftp-service/4-0.png" width="100%" height="100%" />
2. Geben Sie `ftp://NAS设备IP:21` oder `ftps://NAS_IP_Address:21` ein und klicken Sie dann auf **Verbinden**.
<img src="/images/common/portable/file-service/access-ftp-service/4-1.png" width="100%" height="100%" />
3. Geben Sie **Name** und **Passwort** ein und klicken Sie dann auf **Verbinden**.
<img src="/images/common/portable/file-service/access-ftp-service/4-2.png" width="100%" height="100%" />
4. Jetzt können Sie auf die Datei PocketCloud im Finder zugreifen.
<img src="/images/common/portable/file-service/access-ftp-service/4-3.png" width="100%" height="100%" />

## Zugriff über andere Clients
- Verbindungsinformationen
    - IP: NAS-Geräte-IP
    - Port: standardmäßig 21
    - Konto: Anmeldebenutzername des NAS-Geräts
    - Passwort: Anmeldepasswort des NAS-Geräts
- Beschreibung des Mount-Verzeichnisses
    - Haupt-SSD: `/Anmeldebenutzername`
      - Beispiel 1: Alle Verzeichnisse. Wenn der aktuelle Benutzer test ist, lautet das Mount-Verzeichnis `/test`
      - Beispiel 2: Angegebenes Verzeichnis. Wenn der aktuelle Benutzer test ist, lautet das Mount-Verzeichnis `/test/Pictures`
      - Weitere: Mehrere Benutzer werden unterstützt, jeder Benutzer entspricht einem Mount-Verzeichnis
    - Externer Speicher: `/Name_des_externen_Speichers`
      - Beispiel 1: Alle Verzeichnisse. Wenn die externe SD-Karte SD 60GB BA26 heißt, lautet das Mount-Verzeichnis `/SD_60GB_BA26`
      - Beispiel 2: Angegebenes Verzeichnis. Wenn die externe SD-Karte SD 60GB BA26 heißt, lautet das Mount-Verzeichnis `/SD_60GB_BA26/Pictures`
    - ⚠️ Hinweis:
      - Einige Clients können nicht nur das Root-Verzeichnis `/` verwenden. Geben Sie das entsprechende konkrete Mount-Verzeichnis oben an
      - Nach dem Upgrade von Firmware &lt;= 3.1.0.16 auf die neueste Firmware wird das Mount-Verzeichnis angepasst. Verwenden Sie die Mount-Methode der neuen Version
