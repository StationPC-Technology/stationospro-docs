title: "Windows Zugriff auf NFS Festplatten-Chinesisch-Zeichenproblem"
---

> Das Auftreten von chinesischen Zeichenfehlern wird normalerweise durch eine nicht übereinstimmende Codierung oder ein Problem mit den Systemeinstellungen verursacht. Für das Problem der chinesischen Zeichenfehler auf der auf Windows gemappten Festplatte auf NFS können die folgenden Methoden nach Tests gelöst werden:

> Schritt:

1. Öffnen Sie die **Systemsteuerung** → **Uhr und Region** → **Region**.
2. Wechseln Sie zur Registerkarte **„Verwalten“** und klicken Sie auf **„Systemsregion ändern“**.
3. Stellen Sie sicher, dass **„Chinesisch (vereinfacht, China)“** ausgewählt ist. ```最下面有个Beta选项打钩```
<img src="/images/common/portable/file-service/windows-nfs-garbled-code/1-1.png" width="100%" height="100%" />
4. Nach der Änderung das System neu starten, die NFS-Festplatte erneut einhängen und prüfen, ob die chinesischen Zeichen korrekt angezeigt werden.
