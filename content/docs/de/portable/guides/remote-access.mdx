title: "Wie führt man einen Fernzugriff durch?"
---

PocketCloud verfügt über einen integrierten Fernzugriffsdienst, der dir sicheren Fernzugriff bietet. Bevor du diesen Dienst nutzt, musst du zuerst deine Handynummer / E-Mail-Adresse verknüpfen und ein einzigartiges Station ID erstellen (zur Identifizierung deines Geräts). Über Station ID kannst du schnell auf dein PocketCloud zugreifen.

> Hinweis:
> * Für die Nutzung des Fernzugriffs muss eine Handynummer/E-Mail-Adresse verknüpft werden;
> * Der Dienst erstellt automatisch eine eindeutige Station ID für dein PocketCloud, über diese ID kann sicher auf das Gerät zugegriffen werden;
> * Basierend auf der aktuellen Netzwerkumgebung wählt das System automatisch die optimale Zugriffsmethode für die Verbindung.
> * Station ID unterstützt benutzerdefinierte Änderungen.

## Fernwartungsdienste aktivieren
Methode 1:
Während des ersten Initialisierungsvorgangs des Geräts können Sie einfach die Option „Fernzugriff aktivieren“ gemäß der Anleitung anklicken.

## Remote-Dienste trennen

Beim Zurücksetzen auf die Werkseinstellungen wird der Fernservice automatisch deaktiviert.
> Wenn das Gerät bereits mit dem Remote-Dienst verbunden ist, muss zum Zurücksetzen auf die Werkseinstellungen eine Netzwerkverbindung bestehen;
