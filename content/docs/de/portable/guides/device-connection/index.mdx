---

Es kann auf verschiedene Arten auf PocketCloud zugegriffen werden, je nach Bedarf kann ausgewählt werden.

## Mit Internetverbindung
Im vernetzten Zustand kann PocketCloud auf folgende Weise verbunden werden.
### Methode 1: Geben Sie die IP-Adresse ein
Nach dem erfolgreichen Verbinden des PocketCloud-Netzwerks kann die IP-Adresse auf folgende Weise angezeigt werden
* Die IP-Adresse von PocketCloud kann über die Router-Verwaltung gefunden werden.
* Die IP-Adresse von PocketCloud kann über den kleinen Bildschirm angezeigt werden.

<img src="/images/common/portable/guides/device-connection/1-1.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-2.jpg" width="30%" />

### Methode 2: Eingabe von Station ID
Wenn Sie den Fernzugriffsdienst aktiviert haben, können Sie Station ID eingeben, um eine Verbindung zu PocketCloud herzustellen.

### Methode 3: Geräte im lokalen Netzwerk finden
Nachdem Sie App betreten haben, klicken Sie auf 'Geräte im lokalen Netzwerk entdecken' (wie im roten Rahmen gezeigt), um auf die Suchliste zuzugreifen. Alle PocketCloud-Geräte im gleichen lokalen Netzwerk werden automatisch erkannt und angezeigt. Wählen Sie das PocketCloud-Gerät aus, mit dem Sie eine Verbindung herstellen möchten.

<img src="/images/common/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-5.jpg" width="30%" />

### Methode 4: Historische Anmeldung
Nachdem Sie App betreten haben, klicken Sie auf Geräte im lokalen Netzwerk entdecken (im roten Rahmen dargestellt), um die Suchliste zu öffnen. Wenn dieses Gerät frühere Anmeldeaufzeichnungen hat, können Sie über Frühere Anmeldungen schnell Zugriffsinformationen und Kontoinformationen ausfüllen.

<img src="/images/common/portable/guides/device-connection/1-4.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/1-7.jpg" width="30%" />

Nachdem das Gerät gefunden wurde, geben Sie den Benutzernamen und das Passwort ein, um sich anzumelden.

## Ohne Netzwerkumgebung
Wenn Sie sich in einer netzwerklosen Umgebung befinden, können Sie über die folgende Methode eine Verbindung zu PocketCloud herstellen.

### Methode 1: WiFi Direktverbindung
> Nachdem das Handy über WIFI direkt mit PocketCloud verbunden ist, kann es gleichzeitig mobile Daten verwenden, um auf das externe Netzwerk zuzugreifen (z. B. Webseiten zu durchsuchen oder Nachrichten zu empfangen), ohne die Verbindung trennen zu müssen, und sowohl auf Gerätedaten als auch auf externe Netzwerkressourcen zuzugreifen.
Nach dem Eintritt in App klicken Sie auf Geräteschnellverbindung, um die Suchliste zu öffnen. Alle in der Nähe befindlichen PocketCloud-Geräte werden automatisch über Bluetooth erkannt und angezeigt. Wählen Sie das PocketCloud-Gerät aus, das Sie verbinden möchten.

<img src="/images/common/portable/guides/device-connection/2-1-2.jpg" width="30%" />

### Methode 2: Zugriff über den mobilen Hotspot
> Hinweis: Bei dieser Methode, wenn auf externe Daten zugegriffen wird (z. B. Zugriff auf Netzwerkfestplatten, Offline-Downloads usw.), verwendet PocketCloud die mobile Datenverbindung über den Handy-Hotspot. Bitte achten Sie darauf, das Datenvolumen zu kontrollieren, um zusätzliche Kosten zu vermeiden.
Wenn Sie auf mobile Daten zugreifen müssen, können Sie über den mobilen Hotspot eine temporäre Netzwerkumgebung einrichten. Die Vorgehensweise ist wie folgt:
1. Aktivieren Sie die mobile Hotspot-Funktion und legen Sie den Hotspot-Namen (SSID) sowie das Passwort fest;
2. Öffnen Sie App, klicken Sie auf "Netzwerk einrichten", folgen Sie den Anweisungen, um zur Netzwerkeinrichtungsseite zu gelangen, geben Sie manuell den Namen und das Passwort des Handy-Hotspots ein und schließen Sie die Verbindung von PocketCloud zum Hotspot ab;

<img src="/images/common/portable/guides/device-connection/2-2-1.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/2-2-2.jpg" width="30%" />
<img src="/images/common/portable/guides/device-connection/2-2-3.jpg" width="30%" />

3. Nach erfolgreicher Verbindung gehen Sie zu App und klicken auf ‚Geräte im Netzwerk entdecken‘. Das System erkennt automatisch PocketCloud-Geräte im selben Hotspot-Netzwerk. Wählen Sie das entsprechende Gerät aus und geben Sie Benutzername und Passwort ein, um sich anzumelden.
