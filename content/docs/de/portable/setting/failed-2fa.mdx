title: "Doppelte Konto-Verifizierung kann nicht abgeschlossen werden (2FA)"
---

Wenn Sie aufgrund eines Handywechsels oder -verlustes den dynamischen Bestätigungscode nicht erhalten können, können Sie die Zwei-Faktor-Authentifizierung auf folgende Weise deaktivieren und den Kontozugriff wiederherstellen.

## Methode 1: Abrufen des Notfall-Codes über die Sicherheits-E-Mail
Wenn eine Sicherheits-E-Mail-Adresse verknüpft ist, klicken Sie auf der Anmeldeseite auf **Nicht erreichbar**, das System sendet einen einmaligen Notfallcode an Ihre Sicherheits-E-Mail-Adresse. Nach Eingabe können Sie die Anmeldung abschließen.
<img src="/images/common/portable/setting/failed-2fa/1-1-1.png" width="30%" />

## Methode 2: Über bereits vertrauenswürdige Geräte操作
Wenn Sie bereits Vertrauensgeräte eingerichtet haben, können Sie sich auf einem vertrauenswürdigen Gerät normal anmelden und dann die Zwei-Faktor-Authentifizierungsfunktion manuell deaktivieren.

## Methode 3: Kontaktieren Sie den Systemadministrator
Wenn Sie ein Konto ohne Administratorrechte verwenden, kontaktieren Sie bitte den Administrator, um die Zwei-Faktor-Authentifizierung für Sie zu deaktivieren.
