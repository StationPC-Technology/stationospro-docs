Das Zurücksetzen auf die Werkseinstellungen kann das Gerät auf den Anfangszustand zurücksetzen, der Vorgang muss über das APP-Terminal durchgeführt werden.

> Hinweis: Wenn das Gerät bereits mit einem Fernservice verbunden ist, wird durch das Zurücksetzen auf die Werkseinstellungen dieser Service automatisch getrennt, und eine Internetverbindung ist erforderlich, um den Vorgang abzuschließen;

## Wie man die Werkseinstellungen wiederherstellt
1. Öffnen Sie den Client, gehen Sie zur **Geräte**-Seite und suchen Sie die Option **Hardware und System > Auf Werkseinstellungen zurücksetzen**;
2. Klicken Sie auf **Auf Werkseinstellungen zurücksetzen** und geben Sie das Passwort ein, um den Wiederherstellungsprozess zu starten.
> * Festplatte formatieren: Wenn „Nicht formatieren“ ausgewählt wird, erstellt das System automatisch das Verzeichnis „olduserdata“. Nach Abschluss der Wiederherstellung werden die ursprünglichen Daten in diesem Verzeichnis gespeichert.
